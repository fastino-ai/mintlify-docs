Fastino can persist supported inference calls and return an `inference_id`. Keep that identifier when you need audit history or human feedback.

## Workflow

1. Run inference through the appropriate endpoint and retain the returned `inference_id`.
2. [List inference history](/api-reference/inference/history/list) or [retrieve one record](/api-reference/inference/history/get).
3. [Submit feedback](/api-reference/inference/history/submit-feedback) using the exact OpenAPI request contract.
4. [Read stored feedback](/api-reference/inference/history/get-feedback) when you need to confirm the annotation.

<Note>OpenAPI owns all filters, validation constraints, request fields, and response schemas. This guide owns only the workflow.</Note>
