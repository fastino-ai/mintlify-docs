# Changelog

<Update label="2026-08-10">
  # Legacy model sunset: two global dates, one replacement per model

  We're retiring several models from our catalog to ensure you always have access to the latest generation of highest quality and performant models. These models will stop accepting requests starting August 14, 2026.

  * **Deprecated (retroactive):** `2026-08-06` — deprecated models continue to serve requests, but responses carry a `Deprecation` header and a `Link` header pointing to their replacement.
  * **Sunset:** `2026-08-14` — after this date, deprecated models stop serving inference requests entirely.

  ## Migration Guide

  - Grok 4.5, Qwen3.6 Max Preview, Qwen3.7 Max, Sakana Fugu Ultra — migrate to **[Claude Opus 5](/concepts/models)**
  - Poolside Laguna S 2.1, Meta Muse Spark 1.1 — migrate to **[Claude Opus 5](/concepts/models)**

  - GPT-4.1, GPT-4.1 mini, GPT-4.1 nano, GPT-4o, GPT-4o mini — migrate to **[GPT-5.5](/concepts/models)**

  This is purely additive — no model is removed on this date, and no routing behavior changes until the sunset date above. See the [models page](/concepts/models) for the current catalogue and each model's lifecycle status.

<Update label="2026-08-03">
  # Zero Data Retention (ZDR) visibility on the Models page

  The Models page now shows a **ZDR** badge on every model that has at least one Zero Data Retention–compliant provider route, so you can filter for ZDR support without checking each model's routing individually.

  This is informational — it does not change routing or enforcement. See [Trust & Safety](/trust-safety) for what ZDR means on Pioneer and how it's implemented per provider.
</Update>
