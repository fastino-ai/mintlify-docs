`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

Enregistre les poids LoRA de la tâche sous `sampler_weights/<name>`. Vous pouvez [échantillonner](/fr/api-reference/interactive-jobs/sample) depuis celui-ci, y compris après l’arrêt de la tâche, ou le [télécharger](/fr/api-reference/training-jobs/download-checkpoint) en fichiers PEFT LoRA. Il ne contient pas l’état de l’optimiseur : une tâche ne peut donc ni le charger ni démarrer depuis celui-ci ; utilisez pour cela [`POST /v1/training/jobs/{job_id}/save-weights`](/fr/api-reference/interactive-jobs/save-weights).

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID de la tâche interactive.
</ParamField>

<ParamField body="name" type="string" required>
  1 à 128 caractères parmi `A-Z`, `a-z`, `0-9`, `.`, `_` et `-`.
</ParamField>

<ParamField body="ttl_seconds" type="integer | null">
  Supprime automatiquement le checkpoint après ce nombre de secondes, de `3600` (1 heure) à
  `315360000` (10 ans). Omettez-le pour le conserver jusqu’à sa suppression.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/save-weights-for-sampler" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "step-000100", "ttl_seconds": 86400}'
```

</RequestExample>

La réponse contient le `future_id` du future `save`, `checkpoint_id` et `path`.

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "save",
  "checkpoint_id": "sampler_weights/step-000100",
  "path": "tinker://SESSION_ID:train:0/sampler_weights/step-000100"
}
```

</ResponseExample>
