`GET /v1/training/jobs/{job_id}/futures/{future_id}`

Lisez le future jusqu’à ce que son `status` vaille `completed`, `failed` ou `cancelled`. Les
résultats sont conservés une heure. Avec `wait=true`, la requête attend jusqu’à 25 secondes.

- `type` : `create`, `load`, `forward`, `forward_backward`, `optim_step`, `save` ou `sample`.
- `result` (si `completed`) : `loss_fn_outputs` et `metrics` pour forward ; `sequences` (chacune
  avec `tokens`, `logprobs` et `stop_reason`) pour `sample` ; le chemin du checkpoint pour `save`.
- `error` (si `failed` ou `cancelled`) : `message` et `category` (`user` ou `server`).

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/futures/$FUTURE_ID?wait=true" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
