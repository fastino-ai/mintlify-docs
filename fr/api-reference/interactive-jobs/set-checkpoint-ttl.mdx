`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

Conserve un checkpoint `ttl_seconds` à partir de maintenant puis le supprime, de `3600` (1 heure) à `315360000` (10 ans). Envoyez `null` pour le conserver jusqu’à sa suppression. `kind` vaut `weights` ou `sampler_weights`. Renvoie `204 No Content`.

<RequestExample>

```bash cURL
curl -X PUT "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100/ttl" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"ttl_seconds": 604800}'
```

</RequestExample>
