`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

Supprime un checkpoint. Il cesse aussitôt de compter dans le stockage ; ses fichiers sont purgés plus tard. `kind` vaut `weights` ou `sampler_weights`. Renvoie `204 No Content`.

<RequestExample>

```bash cURL
curl -X DELETE "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
