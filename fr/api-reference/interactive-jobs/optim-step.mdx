`POST /v1/training/jobs/{job_id}/optim-step`

Applique avec AdamW les gradients accumulés par les passes forward-backward depuis la dernière
étape. La tâche exécute les opérations dans l’ordre de réception : vous pouvez donc la mettre en
file juste après une passe forward-backward, sans attendre.

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID de la tâche interactive.
</ParamField>

<ParamField body="adam_params" type="object">
  Paramètres AdamW facultatifs : `learning_rate` (par défaut `0.0001`), `beta1` (`0.9`), `beta2`
  (`0.95`), `eps` (`1e-12`), `weight_decay` (`0`) et `grad_clip_norm` (`0` désactive l’écrêtage).
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/optim-step" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"adam_params": {"learning_rate": 0.0001}}'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "optim_step"
}
```

</ResponseExample>
