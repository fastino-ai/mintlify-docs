`GET /v1/training-runs`

Renvoie les exécutions d’entraînement visibles par l’appelant authentifié, de la plus récente à la plus ancienne. Les exécutions d’entraînement sont des exécutions pas à pas que vous créez et pilotez avec le SDK compatible Tinker. Définissez le `base_url` du SDK sur `https://api.fastino.ai/v1/training-runs/sdk` et authentifiez-vous avec votre clé d’API Fastino. Vous voyez vos propres exécutions et celles de votre équipe dans les projets auxquels vous avez accès.

## Requête

<ParamField header="X-API-Key" type="string" required>
  Votre clé d’API Fastino.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Taille de page. Les valeurs sont ramenées entre `1` et `1000`.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Nombre d’exécutions à ignorer.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training-runs?limit=20&offset=0" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Réponse

<ResponseField name="success" type="boolean">
  Indique si la requête a réussi.
</ResponseField>

<ResponseField name="training_runs" type="object[]">
  Exécutions d’entraînement de cette page. Chaque exécution contient les champs décrits dans [Obtenir une exécution d’entraînement](/fr/api-reference/training-runs/get).
</ResponseField>

<ResponseField name="count" type="integer">
  Nombre d’exécutions dans cette page.
</ResponseField>

<ResponseField name="total" type="integer">
  Nombre total d’exécutions visibles avant pagination.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  Indique si une autre page suit celle-ci.
</ResponseField>
