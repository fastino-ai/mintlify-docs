Met à jour le nom du modèle sur un job d'entraînement.

## Requête

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID du job d'entraînement.
</ParamField>

<ParamField body="model_name" type="string" required>
  Nouveau nom de modèle. Longueur : 1 à 64 caractères. Utilisez des lettres, des chiffres, des tirets ou des tirets bas.
</ParamField>

<RequestExample>

```bash cURL
curl -X PATCH https://api.pioneer.ai/felix/training-jobs/YOUR_TRAINING_JOB_ID/model-name \
  -H "X-API-Key: $PIONEER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model_name": "my-model-name"}'
```

</RequestExample>

## Réponse

<ResponseExample>

```json Response
{
  "success": true,
  "message": "Model name updated",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "model_name": "my-model-name"
}
```

</ResponseExample>

Des noms invalides renvoient `422`. Un job inconnu ou inaccessible renvoie `404`.
