`GET /v1/training/jobs/{job_id}/checkpoints/{checkpoint_id}/download`

Renvoie une URL présignée de stockage objet, à durée limitée, pour un checkpoint d’un job `interactive`. L’archive d’un checkpoint sampler contient les fichiers de l’adaptateur de décodeur. Pour l’artefact final de leur modèle, les jobs de configuration utilisent
[`GET /v1/training/jobs/{job_id}/download`](/fr/api-reference/training-jobs/download).

## Requête

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  `job_id` interactif renvoyé par `POST /v1/training/jobs/create-model`.
</ParamField>

<ParamField path="checkpoint_id" type="string" required>
  Identifiant du checkpoint renvoyé par la liste des checkpoints, tel que
  `weights/checkpoint-1` ou `sampler_weights/checkpoint-1`. Conservez le `/`
  dans le chemin ; n'encodez pas l'identifiant entier comme une URL.
</ParamField>

<RequestExample>

```bash cURL
CHECKPOINT_ID="sampler_weights/checkpoint-1"
curl "https://api.fastino.ai/v1/training/jobs/JOB_ID/checkpoints/$CHECKPOINT_ID/download" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Réponse

La réponse contient une URL présignée de stockage objet qui expire après 15 minutes.
Traitez cette URL comme un identifiant secret : ne la consignez pas dans les
logs, ne la partagez pas et ne la conservez pas.

<ResponseField name="success" type="boolean">
  Indique si la requête a réussi.
</ResponseField>

<ResponseField name="run_id" type="string">
  Job interactive auquel appartient le checkpoint.
</ResponseField>

<ResponseField name="checkpoint_id" type="string">
  Identifiant du checkpoint interactive téléchargeable.
</ResponseField>

<ResponseField name="download_url" type="string">
  URL présignée de stockage objet. Aucune clé API n’est requise pour la récupérer.
</ResponseField>

<ResponseField name="expires_in_seconds" type="integer">
  Durée de validité restante de l'URL présignée. Les nouveaux liens expirent après 900 secondes.
</ResponseField>

<ResponseField name="file_name" type="string">
  Nom de fichier `.tar` suggéré pour l'archive.
</ResponseField>

<ResponseExample>

```json Response
{
  "success": true,
  "run_id": "session-1:train:0",
  "checkpoint_id": "sampler_weights/checkpoint-1",
  "download_url": "SIGNED_ARCHIVE_URL",
  "expires_in_seconds": 900,
  "file_name": "session-1_train_0-sampler_weights-checkpoint-1.tar"
}
```

</ResponseExample>

Le téléchargement des checkpoints est activé par défaut. Une équipe dont l’accès au téléchargement a été explicitement désactivé reçoit `403`.

<Warning>
  Les adaptateurs de décodeur téléchargés utilisent la disposition des cellules d’entraînement Fastino. Ils ne sont actuellement compatibles ni avec PEFT standard ni avec vLLM standard ; leur chargement peut échouer ou omettre silencieusement des tenseurs entraînés. Utilisez Fastino pour échantillonner depuis un checkpoint sampler ou le déployer lorsque son modèle de base prend en charge le déploiement.
</Warning>

## Erreurs

| Statut | Signification |
| --- | --- |
| `400` | `checkpoint_id` n'est ni `weights/<name>` ni `sampler_weights/<name>`. |
| `403` | Le téléchargement des poids a été explicitement désactivé pour l’équipe. |
| `404` | Le job ou checkpoint est indisponible, ou le checkpoint n’a aucun fichier téléchargeable. |

La récupération de `download_url` renvoie une pièce jointe `application/x-tar`. L’URL présignée de stockage objet est l’identifiant d’accès et expire après le délai `expires_in_seconds` indiqué dans la réponse.
