---

Indique si un job a été facturé et, lorsqu'elles sont disponibles, la somme facturée ainsi que la durée GPU.

## Requête

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID du job d'entraînement.
</ParamField>

<RequestExample>

```bash cURL
curl https://api.pioneer.ai/felix/training-jobs/YOUR_TRAINING_JOB_ID/billing \
  -H "X-API-Key: $PIONEER_API_KEY"
```

</RequestExample>

## Réponse

<ResponseField name="job_id" type="string">
  UUID du job d'entraînement.
</ResponseField>

<ResponseField name="status" type="string">
  Statut persisté actuel du job.
</ResponseField>

<ResponseField name="started_at" type="string | null">
  Heure à laquelle le job a été distribué.
</ResponseField>

<ResponseField name="compute_started_at" type="string | null">
  Heure à laquelle le conteneur d'entraînement a commencé à s'exécuter.
</ResponseField>

<ResponseField name="completed_at" type="string | null">
  Heure à laquelle le job s'est terminé.
</ResponseField>

<ResponseField name="billed" type="boolean">
  Indique si un enregistrement de facturation existe.
</ResponseField>

<ResponseField name="request_id" type="string | null">
  ID de la requête de facturation associée.
</ResponseField>

<ResponseField name="charged_usd" type="string | null">
  Montant facturé en USD, représenté sous forme de chaîne décimale.
</ResponseField>

<ResponseField name="gpu_minutes" type="string | null">
  Minutes GPU facturées, représentées sous forme de chaîne décimale.
</ResponseField>

<ResponseField name="billed_at" type="string | null">
  Heure de création de l'enregistrement de facturation.
</ResponseField>

<ResponseExample>

```json Response
{
  "job_id": "YOUR_TRAINING_JOB_ID",
  "status": "complete",
  "started_at": "2026-09-22T20:00:00Z",
  "compute_started_at": "2026-09-22T20:01:00Z",
  "completed_at": "2026-09-22T20:31:00Z",
  "billed": true,
  "request_id": "REQUEST_ID",
  "charged_usd": "3.25",
  "gpu_minutes": "30.0",
  "billed_at": "2026-09-22T20:32:00Z"
}
```

</ResponseExample>

Un job inconnu ou inaccessible renvoie `404`.
