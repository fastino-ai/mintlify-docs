`GET /v1/training/jobs/{job_id}/deployments`

Cette opération est réservée aux jobs config ; après les contrôles habituels de fonctionnalité et d’autorisation, un ID de job interactif renvoie `400`. Le déploiement d’un checkpoint sampler indique sa progression initiale dans son `status` ; utilisez le `model_id` renvoyé avec cet endpoint pour lister les enregistrements de déploiement de ce modèle servi.

Lister les déploiements créés à partir d’une tâche d’entraînement ou qui lui sont associés.
