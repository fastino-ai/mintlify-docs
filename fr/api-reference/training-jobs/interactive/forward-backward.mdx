`POST /v1/training/jobs/{job_id}/forward-backward`

Met en file une passe forward-backward qui accumule les gradients et renvoie un `future_id`. Interrogez [Obtenir un future](/fr/api-reference/training-jobs/interactive/get-future) jusqu'à ce qu'il atteigne un statut terminal.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
