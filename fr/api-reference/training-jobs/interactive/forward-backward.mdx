`POST /v1/training/jobs/{job_id}/forward-backward`

Cette opération JSON native s'applique aux tâches d'entraînement interactives.

Met en file une passe avant-arrière qui accumule les gradients et renvoie `future_id`. Interrogez [Obtenir l'opération](/fr/api-reference/training-jobs/interactive/get-operation) jusqu'à un état final.

Consultez [Créer une boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle complet.
