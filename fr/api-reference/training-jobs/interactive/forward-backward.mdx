`POST /v1/training/jobs/{job_id}/forward-backward`

Met en file une passe avant-arrière qui accumule les gradients et renvoie un `future_id`. Interrogez [Obtenir une future](/fr/api-reference/training-jobs/interactive/get-future) jusqu'à un état terminal.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
