`POST /v1/training/jobs/{job_id}/load-weights`

Met en attente un chargement depuis `path` et renvoie un `future_id`. Utilisez un nom d'état ou le chemin `tinker://<job_id>/weights/<name>` de cette même tâche. Définissez `optimizer` pour restaurer l'état de l'optimiseur. Interrogez [Obtenir une future](/fr/api-reference/training-jobs/interactive/get-future) jusqu'à un état terminal.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
