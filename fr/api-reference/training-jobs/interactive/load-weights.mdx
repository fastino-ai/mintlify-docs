`POST /v1/training/jobs/{job_id}/load-weights`

Restaure l’un des checkpoints `weights/<name>` de cette tâche dans la même tâche, par exemple pour annuler une mauvaise mise à jour. Pour continuer dans une nouvelle tâche, passez son chemin comme `from_checkpoint` à [`POST /v1/training/jobs/create-model`](/fr/api-reference/training-jobs/interactive/create-model).

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID de la tâche interactive.
</ParamField>

<ParamField body="path" type="string" required>
  Le nom d’un checkpoint d’état enregistré par cette tâche, ou son chemin `tinker://<job_id>/weights/<name>`.
</ParamField>

<ParamField body="optimizer" type="boolean" default="false">
  Restaure aussi l’état de l’optimiseur.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/load-weights" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"path": "step-000100", "optimizer": true}'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "load"
}
```

</ResponseExample>

| Statut | Signification |
| --- | --- |
| `400` | `path` désigne le checkpoint d'un autre job ou un checkpoint sampler, ou le job a été arrêté. |
| `404` | Le job n'existe pas ou appartient à une autre équipe. |
