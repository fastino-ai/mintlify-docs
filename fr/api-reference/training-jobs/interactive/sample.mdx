`POST /v1/training/jobs/{job_id}/sample`

Génère des continuations d’un prompt tokenisé avec l’un des checkpoints `sampler` du job. L’échantillonnage reste disponible après l’arrêt du job. Lisez les tokens générés dans `result.sequences` du future terminé.

## Demande

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID du job interactif.
</ParamField>

<ParamField body="checkpoint" type="string" required>
  Le nom d’un checkpoint sampler enregistré par ce job, ou son chemin `tinker://<job_id>/sampler_weights/<name>`.
</ParamField>

<ParamField body="prompt_tokens" type="integer[]" required>
  ID des tokens du prompt produits par le tokenizer du modèle de base. Au moins un token.
</ParamField>

<ParamField body="num_samples" type="integer" default="1">
  Nombre de continuations, de `1` à `512`.
</ParamField>

<ParamField body="sampling_params" type="object">
  Paramètres de décodage.

  <Expandable title="properties">
    <ParamField body="max_tokens" type="integer" default="1024">
      Nombre maximal de tokens générés. Le prompt et `max_tokens` doivent tenir dans la limite d’échantillonnage du modèle. Qwen peut échantillonner jusqu’à `65,536` tokens, mais chaque donnée d’entraînement Qwen est limitée à `32,768` tokens.
    </ParamField>
    <ParamField body="temperature" type="number" default="1.0">
      Température d'échantillonnage.
    </ParamField>
    <ParamField body="top_p" type="number" default="1.0">
      Masse de probabilité d'échantillonnage du noyau.
    </ParamField>
    <ParamField body="top_k" type="integer" default="-1">
      Seuil top-k. `-1` le désactive.
    </ParamField>
    <ParamField body="stop" type="string | string[] | integer[]">
      Chaînes d’arrêt ou ID de tokens d’arrêt.
    </ParamField>
    <ParamField body="seed" type="integer">
      Seed d’échantillonnage.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="prompt_logprobs" type="boolean" default="false">
  Renvoie également la log-probabilité de chaque token du prompt.
</ParamField>

<ParamField body="topk_prompt_logprobs" type="integer" default="0">
  Renvoie les meilleures alternatives à chaque position d'invite.
</ParamField>

<ParamField body="topk_sample_logprobs" type="integer" default="0">
  Renvoie les k meilleures alternatives à chaque position générée.
</ParamField>

Le tableau numérique de tokens du prompt ci-dessous est uniquement un espace réservé à titre d’illustration. Tokenisez votre prompt réel avec le tokenizer du `base_model` du job.

<Note>
  Une équipe peut avoir au maximum `2,048` requêtes d’échantillonnage en cours. L’API renvoie `429` lorsque cette limite est atteinte ; attendez la fin des futures d’échantillonnage existants avant de réessayer.
</Note>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/sample" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "checkpoint": "step-000100",
    "prompt_tokens": [151644, 872, 198, 3838],
    "num_samples": 2,
    "sampling_params": {"max_tokens": 64, "temperature": 0.7}
  }'
```

</RequestExample>

## Réponse

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "sample"
}
```

</ResponseExample>

Chaque séquence du résultat terminé contient `tokens`, `logprobs`, `stop_reason` (`stop` ou `length`) et `topk_logprobs`. Décodez `tokens` avec le même tokenizer. Annulez un échantillonnage inachevé avec
[`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`](/fr/api-reference/training-jobs/interactive/cancel-future).

| Statut | Signification |
| --- | --- |
| `400` | `checkpoint` n'est pas valide, il s'agit d'un point de contrôle d'un autre travail ou d'un point de contrôle d'état, ou l'invite est trop longue. |
| `402` | L'équipe n'a plus de crédits ou n'a pas de configuration de paiement valide. |
| `404` | Le travail ou le point de contrôle n'existe pas, ou le travail appartient à une autre équipe. |
| `429` | L’équipe a déjà `2,048` requêtes d’échantillonnage en cours. Attendez la fin des futures d’échantillonnage existants avant de réessayer. |
| `422` | `checkpoint` ou `prompt_tokens` est manquant, ou le corps possède un champ inconnu. |
