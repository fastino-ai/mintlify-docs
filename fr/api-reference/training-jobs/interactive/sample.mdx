`POST /v1/training/jobs/{job_id}/sample`

Met en file un échantillonnage depuis `checkpoint` et renvoie un `future_id`. Utilisez un nom de checkpoint d'échantillonnage ou le chemin `tinker://<job_id>/sampler_weights/<name>` propre à ce job. L'échantillonnage reste disponible après l'arrêt du job interactif. Interrogez [Obtenir un future](/fr/api-reference/training-jobs/interactive/get-future) jusqu'à ce qu'il atteigne un statut terminal.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
