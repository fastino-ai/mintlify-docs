`POST /v1/training/jobs/{job_id}/sample`

Cette opération JSON native s'applique aux tâches d'entraînement interactives.

Met en file l'échantillonnage depuis un point `sampler_weights`. Il reste disponible après l'arrêt de la tâche. Interrogez [Obtenir l'opération](/fr/api-reference/training-jobs/interactive/get-operation) jusqu'à un état final.

Consultez [Créer une boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle complet.
