`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

Conserve un checkpoint pendant `ttl_seconds` à partir de maintenant, puis le
supprime. Omettez `ttl_seconds` ou envoyez `null` pour conserver le checkpoint
jusqu'à ce que vous le supprimiez. Renvoie `204 No Content`.

`kind` vaut `weights` ou `sampler_weights`.

<ParamField body="ttl_seconds" type="integer | null">
  De `3600` (1 heure) à `315360000` (10 ans), ou `null`.
</ParamField>

<RequestExample>

```bash cURL
curl -X PUT "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100/ttl" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"ttl_seconds": 604800}'
```

</RequestExample>

## Erreurs

| Statut | Signification |
| --- | --- |
| `400` | `ttl_seconds` est en dehors de la plage 3600–315360000. |
| `404` | Le job ou le checkpoint n'existe pas, ou appartient à une autre équipe. |
| `422` | Le corps contient un champ inconnu. |
