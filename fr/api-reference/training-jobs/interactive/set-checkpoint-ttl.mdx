`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

Conserve désormais un point de contrôle pour `ttl_seconds`, puis le supprime. Omettre
`ttl_seconds` ou envoyez `null` pour conserver le point de contrôle jusqu'à ce que vous le supprimiez. Renvoie `204 No Content`.

`kind` est `weights` ou `sampler_weights`.

<ParamField body="ttl_seconds" type="integer | null">
  De `3600` (1 heure) à `315360000` (10 ans), ou `null`.
</ParamField>

<RequestExample>

```bash cURL
curl -X PUT "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100/ttl" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"ttl_seconds": 604800}'
```

</RequestExample>

## Erreurs

| Statut | Signification |
| --- | --- |
| `400` | `ttl_seconds` se situe en dehors de 3600–315360000. |
| `404` | Le travail ou le point de contrôle n'existe pas ou appartient à une autre équipe. |
| `422` | Le corps contient un champ inconnu. |
