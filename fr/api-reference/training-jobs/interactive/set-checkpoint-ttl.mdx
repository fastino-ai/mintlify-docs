`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

Définit la durée de rétention d'un checkpoint `weights` ou `sampler_weights`. Un TTL nul conserve le checkpoint jusqu'à sa suppression.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
