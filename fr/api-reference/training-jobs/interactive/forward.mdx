`POST /v1/training/jobs/{job_id}/forward`

Cette opération JSON native s'applique aux tâches d'entraînement interactives.

Met en file une passe avant sans gradients et renvoie `future_id`. Interrogez [Obtenir l'opération](/fr/api-reference/training-jobs/interactive/get-operation) jusqu'à `completed`, `failed` ou `cancelled`.

Consultez [Créer une boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle complet.
