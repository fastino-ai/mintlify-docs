`POST /v1/training/jobs/{job_id}/forward`

Calcule la perte et les log-probabilités par token d’un lot sans accumuler de gradients.
Utilisez-le pour l’évaluation. Le corps, la réponse et le résultat sont ceux de
[`POST /v1/training/jobs/{job_id}/forward-backward`](/fr/api-reference/training-jobs/interactive/forward-backward) ;
le `type` de l’opération est `forward`.

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/forward" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "datums": [
      {
        "model_input": {"chunks": [{"type": "encoded_text", "tokens": [151644, 872, 198, 3838]}]},
        "loss_fn_inputs": {
          "target_tokens": {"data": [872, 198, 3838, 30], "dtype": "int64"}
        }
      }
    ]
  }'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "forward"
}
```

</ResponseExample>
