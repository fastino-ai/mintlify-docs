`POST /v1/training/jobs/{job_id}/forward`

Met en file une passe forward sans gradients et renvoie un `future_id`. Interrogez [Obtenir un future](/fr/api-reference/training-jobs/interactive/get-future) jusqu'à ce que le statut soit `completed`, `failed` ou `cancelled`.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
