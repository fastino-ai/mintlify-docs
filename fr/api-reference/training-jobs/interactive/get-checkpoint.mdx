`GET /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

Renvoie un checkpoint interactif. `kind` vaut `weights` ou `sampler_weights`.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
