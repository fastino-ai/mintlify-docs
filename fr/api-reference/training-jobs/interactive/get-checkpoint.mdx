`GET /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

Renvoie un point de contrôle. Pour répertorier tous les points de contrôle d'un travail, utilisez
[`GET /v1/training/jobs/{job_id}/checkpoints`](/fr/api-reference/training-jobs/checkpoints).

## Demande

<ParamField path="job_id" type="string" required>
  ID de travail interactif.
</ParamField>

<ParamField path="kind" type="string" required>
  `weights` pour un point de contrôle d'état ou `sampler_weights` pour un point de contrôle d'échantillonneur.
</ParamField>

<ParamField path="name" type="string" required>
  Nom du point de contrôle.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/sampler_weights/step-000100" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Réponse

<ResponseExample>

```json Response
{
  "checkpoint_id": "sampler_weights/step-000100",
  "checkpoint_type": "sampler",
  "time": "2026-10-14T12:00:00Z",
  "tinker_path": "tinker://SESSION_ID:train:0/sampler_weights/step-000100",
  "size_bytes": 268435456,
  "public": false,
  "user_metadata": null,
  "expires_at": "2026-10-15T12:00:00Z"
}
```

</ResponseExample>

`checkpoint_type` est `training` pour un point de contrôle d'état et `sampler` pour un
point de contrôle de l'échantillonneur. `expires_at` est `null` lorsque le point de contrôle n'a pas de durée de vie.
