`POST /v1/training/jobs/{job_id}/save-weights`

Enregistre l’état d’entraînement et de l’optimiseur dans un checkpoint `weights`.

Envoyez `name` et éventuellement `ttl_seconds`, puis interrogez la `future_id` renvoyée avant d’utiliser le checkpoint.
