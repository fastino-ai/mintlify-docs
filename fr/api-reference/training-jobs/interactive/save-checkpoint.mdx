`POST /v1/training/jobs/{job_id}/checkpoints`

Cette opération JSON native s'applique aux tâches d'entraînement interactives.

Met en file l'enregistrement d'un point et renvoie `operation_id`. `state` correspond à `weights` et `sampler` à `sampler_weights`. Interrogez [Obtenir l'opération](/fr/api-reference/training-jobs/interactive/get-operation) avant utilisation.

Consultez [Créer une boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle complet.
