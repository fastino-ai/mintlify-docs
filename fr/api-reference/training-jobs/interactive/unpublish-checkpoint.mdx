`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

Retire la publication d'un checkpoint et se termine de manière synchrone, sans corps de réponse.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
