`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

Demande l'annulation, dans la mesure du possible, d'une future d'échantillonnage en attente ou en cours. Seules les futures d'échantillonnage peuvent être annulées. Les futures d'entraînement s'exécutent dans l'ordre et ne peuvent pas être annulées.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
