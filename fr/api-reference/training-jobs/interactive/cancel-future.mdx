`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

L'annulation est la meilleure solution pour un futur `sample` en file d'attente ou en cours d'exécution. L'itinéraire
renvoie `204 No Content` lorsque la demande est acceptée. Annuler un terminal
un avenir ou un avenir de formation renvoie également `204` ; c'est un no-op réussi parce que
les opérations de formation se déroulent dans l’ordre et ne sont pas annulées.

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/futures/$FUTURE_ID/cancel" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Erreurs

| Statut | Signification |
| --- | --- |
| `404` | Le travail ou l'avenir n'existe pas ou appartient à une autre équipe. |
