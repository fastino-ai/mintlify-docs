`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

Annule, au mieux, une future sample en file ou en cours. Les opérations d’entraînement s’exécutent dans l’ordre et ne sont pas annulées. Renvoie `204 No Content`.

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/futures/$FUTURE_ID/cancel" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
