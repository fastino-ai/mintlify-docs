`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

Demande l'annulation, dans la mesure du possible, d'un future d'échantillonnage en file d'attente ou en cours. Seuls les futures d'échantillonnage peuvent être annulés. Les futures d'entraînement s'exécutent dans l'ordre et ne peuvent pas être annulés.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
