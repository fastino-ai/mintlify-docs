`GET /v1/training/jobs/{job_id}/futures/{future_id}`

Renvoie le statut et le résultat du future. Avec `wait=true`, la requête attend au maximum 25 secondes et peut tout de même renvoyer un statut non terminal. Interrogez jusqu'à obtenir `completed`, `failed` ou `cancelled`. Le service conserve un résultat pendant une heure. Une erreur HTTP signifie que le serveur a rejeté la requête. Un future en file d'attente peut aussi se terminer avec `status: "failed"` et un `error.message` ; traitez `error.category` comme une chaîne opaque.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
