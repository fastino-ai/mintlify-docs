`POST /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

Rend un checkpoint public ; son champ `public` passe à `true`. `kind` vaut `weights` ou `sampler_weights`. Renvoie `204 No Content`. Annulez avec [`DELETE .../publish`](/fr/api-reference/training-jobs/interactive/unpublish-checkpoint).

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/sampler_weights/step-000100/publish" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
