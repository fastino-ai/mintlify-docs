`POST /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

Publie un checkpoint `weights` ou `sampler_weights`. La publication n'accorde pas à une autre équipe l'autorisation de le charger.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
