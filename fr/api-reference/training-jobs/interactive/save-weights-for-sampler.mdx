`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

Enregistre les poids LoRA du job sous `sampler_weights/<name>`. Vous pouvez [échantillonner](/fr/api-reference/training-jobs/interactive/sample) à partir de ce checkpoint, y compris après l’arrêt du job, ou le [télécharger](/fr/api-reference/training-jobs/download-checkpoint) sous forme d’archive d’adaptateur. Le téléchargement d’un décodeur est un adaptateur PEFT Hugging Face standard pour le modèle de base public. Il ne contient pas d’état d’optimiseur : un job ne peut donc ni le charger ni démarrer à partir de lui. Pour cela, utilisez [`POST /v1/training/jobs/{job_id}/save-weights`](/fr/api-reference/training-jobs/interactive/save-weights).

L'enregistrement s'exécute dans l'ordre avec les autres appels du job.

## Requête

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID du job interactif.
</ParamField>

<ParamField body="name" type="string" required>
  1 à 128 caractères parmi `A-Z`, `a-z`, `0-9`, `.`, `_` et `-`.
</ParamField>

<ParamField body="ttl_seconds" type="integer | null">
  Supprimer automatiquement le checkpoint après ce nombre de secondes, de `3600`
  (1 heure) à `315360000` (10 ans). Omettez-le ou envoyez `null` pour conserver le checkpoint jusqu'à ce que vous le supprimiez. Les checkpoints actifs sont comptabilisés dans l'[utilisation du stockage](/fr/api-reference/training-jobs/interactive/storage-usage).
</ParamField>

<ParamField body="user_metadata" type="object">
  Métadonnées clé-valeur de type chaîne stockées avec le checkpoint.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/save-weights-for-sampler" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "step-000100", "ttl_seconds": 86400}'
```

</RequestExample>

## Réponse

<ResponseField name="future_id" type="string">
  Le future `save`.
</ResponseField>

<ResponseField name="checkpoint_id" type="string">
  `sampler_weights/<name>`.
</ResponseField>

<ResponseField name="path" type="string">
  Chemin complet du checkpoint.
</ResponseField>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "save",
  "checkpoint_id": "sampler_weights/step-000100",
  "path": "tinker://SESSION_ID:train:0/sampler_weights/step-000100"
}
```

</ResponseExample>

| Statut | Signification |
| --- | --- |
| `400` | Le nom contient des caractères non valides ou a une longueur non valide, le TTL est hors limites, ou le job a été arrêté. |
| `404` | Le job n'existe pas ou appartient à une autre équipe. |
| `422` | Le corps ne contient pas `name` ou comporte un champ inconnu. |
