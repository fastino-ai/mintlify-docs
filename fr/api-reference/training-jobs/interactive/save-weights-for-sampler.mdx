`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

Enregistre les poids LoRA de la tâche sous `sampler_weights/<name>`. Vous pouvez
[échantillon](/fr/api-reference/training-jobs/interactive/sample), également une fois le travail terminé.
arrêté, ou [télécharger](/fr/api-reference/training-jobs/download-checkpoint) comme
Fichiers PEFT LoRA. Il n'a pas d'état d'optimisation, donc une tâche ne peut pas le charger ou démarrer à partir de
ça; utiliser [`POST /v1/training/jobs/{job_id}/save-weights`](/fr/api-reference/training-jobs/interactive/save-weights)
pour ça.

La sauvegarde s'exécute dans l'ordre des autres appels du travail.

## Demande

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID de travail interactif.
</ParamField>

<ParamField body="name" type="string" required>
  1 à 128 caractères parmi `A-Z`, `a-z`, `0-9`, `.`, `_` et `-`.
</ParamField>

<ParamField body="ttl_seconds" type="integer | null">
  Supprimez automatiquement le point de contrôle après ce nombre de secondes, de `3600`
  (1 heure) à `315360000` (10 ans). Omettez-le ou envoyez `null` pour conserver le point de contrôle jusqu'à ce que vous le supprimiez. Les points de contrôle en direct sont pris en compte dans [l'utilisation du stockage](/fr/api-reference/training-jobs/interactive/storage-usage).
</ParamField>

<ParamField body="user_metadata" type="object">
  Chaîne de métadonnées clé-valeur stockées avec le point de contrôle.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/save-weights-for-sampler" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "step-000100", "ttl_seconds": 86400}'
```

</RequestExample>

## Réponse

<ResponseField name="future_id" type="string">
  Le futur `save`.
</ResponseField>

<ResponseField name="checkpoint_id" type="string">
  `sampler_weights/<name>`.
</ResponseField>

<ResponseField name="path" type="string">
  Chemin complet du point de contrôle.
</ResponseField>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "save",
  "checkpoint_id": "sampler_weights/step-000100",
  "path": "tinker://SESSION_ID:train:0/sampler_weights/step-000100"
}
```

</ResponseExample>

| Statut | Signification |
| --- | --- |
| `400` | Le nom comporte des caractères ou une longueur non valide, la durée de vie est hors plage ou la tâche a été arrêtée. |
| `404` | Le travail n'existe pas ou appartient à une autre équipe. |
| `422` | Le corps ne contient pas `name` ou comporte un champ inconnu. |
