`POST /v1/training/jobs/create-model`

Crée une tâche LoRA interactive à partir de `base_model`, ou de `from_checkpoint` avec le paramètre facultatif `load_optimizer`. La réponse contient le `job_id` et le `future_id` de création. Si vous restaurez un checkpoint, elle contient aussi `load_future_id`. Les clients JSON natifs n'envoient pas de valeurs `seq_id` ni de signaux de présence.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
