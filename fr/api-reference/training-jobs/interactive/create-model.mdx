`POST /v1/training/jobs/create-model`

Crée un job LoRA interactif à partir de `base_model`, ou depuis `from_checkpoint` avec le paramètre facultatif `load_optimizer`. La réponse inclut le `job_id` et le `future_id` de création. Si vous restaurez un checkpoint, elle inclut également `load_future_id`. Les clients JSON natifs n'envoient pas de valeurs `seq_id` ni de heartbeats.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
