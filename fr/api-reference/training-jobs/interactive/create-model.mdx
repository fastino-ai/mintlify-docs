`POST /v1/training/jobs/create-model`

Crée un job d’entraînement LoRA `interactive` sur un modèle de base décodeur, ou un nouveau job à partir d’un état d’entraînement enregistré. Votre application envoie ensuite chaque passe forward-backward, étape d’optimisation, checkpoint et requête d’échantillonnage. Les clients JSON natifs n’envoient ni valeurs `seq_id` ni heartbeats. Pour un entraînement géré à partir d’un dataset importé, utilisez [`POST /v1/training/jobs`](/fr/api-reference/training-jobs/create).

Le job est prêt lorsque son future `create` est terminé. Lisez-le avec [`GET /v1/training/jobs/{job_id}/futures/{future_id}`](/fr/api-reference/training-jobs/interactive/get-future).

Chaque équipe peut avoir au maximum `16` jobs interactifs actifs. Chaque job peut avoir au maximum `512` opérations en file simultanément. Le dépassement de l’une de ces limites renvoie `429`.

## Demande

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

Envoyez exactement un des `base_model` et `from_checkpoint`.

<ParamField body="base_model" type="string">
  `nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16`,
  `nvidia/NVIDIA-Nemotron-3.5-Super-VL-120B-A12B-NVFP4` ou `Qwen/Qwen3.6-35B-A3B`.
</ParamField>

<ParamField body="from_checkpoint" type="string">
  Le `path` renvoyé par [`save-weights`](/fr/api-reference/training-jobs/interactive/save-weights) pour l’un de vos jobs, par exemple `tinker://<job_id>/weights/<name>`. Le nouveau job reprend le modèle de base et les paramètres LoRA de ce checkpoint ; omettez donc `lora_config`. Les checkpoints sampler sont refusés.
</ParamField>

<ParamField body="load_optimizer" type="boolean" default="false">
  Définissez `load_optimizer` avec `from_checkpoint` pour restaurer l'état de l'optimiseur.
</ParamField>

<ParamField body="lora_config" type="object">
  Paramètres LoRA pour un nouveau travail.

  <Expandable title="properties">
    <ParamField body="rank" type="integer" default="32">
      Rang LoRA, de 1 à 32.
    </ParamField>
    <ParamField body="seed" type="integer">
      Graine d’initialisation de l’adaptateur.
    </ParamField>
    <ParamField body="train_attn" type="boolean" default="true">
      Entraînez les couches d’attention.
    </ParamField>
    <ParamField body="train_mlp" type="boolean" default="true">
      Entraînez les couches MLP.
    </ParamField>
    <ParamField body="train_unembed" type="boolean" default="true">
      Entraînez la couche de désintégration.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="optimizer_config" type="object">
  Famille d'optimiseurs. Seul `{"type": "adamw"}` est servi, ce qui correspond à la valeur par défaut.
</ParamField>

<ParamField body="project_id" type="string">
  Projet auquel appartiennent le job et son utilisation. Par défaut, votre projet par défaut.
</ParamField>

<ParamField body="user_metadata" type="object">
  Vos propres métadonnées JSON pour le travail.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/create-model" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "base_model": "Qwen/Qwen3.6-35B-A3B",
    "lora_config": {"rank": 32}
  }'
```

</RequestExample>

## Réponse

<ResponseField name="job_id" type="string">
  ID du job interactif. Utilisez-le avec chaque route `/v1/training/jobs/{job_id}`.
</ResponseField>

<ResponseField name="type" type="string">
  Toujours `interactive`.
</ResponseField>

<ResponseField name="base_model" type="string">
  Modèle de base du travail.
</ResponseField>

<ResponseField name="future_id" type="string">
  Le future `create` du job.
</ResponseField>

<ResponseField name="load_future_id" type="string | null">
  Avec `from_checkpoint`, le future qui charge le checkpoint.
</ResponseField>

<ResponseExample>

```json Response
{
  "job_id": "SESSION_ID:train:0",
  "type": "interactive",
  "base_model": "Qwen/Qwen3.6-35B-A3B",
  "future_id": "FUTURE_ID",
  "load_future_id": null
}
```

</ResponseExample>

## Erreurs

| Statut | Signification |
| --- | --- |
| `400` | Le modèle n'est pas servi, le rang est hors de portée, `from_checkpoint` est un point de contrôle d'échantillonneur ou `lora_config` a été envoyé avec `from_checkpoint`. |
| `402` | L'équipe n'a plus de crédits ou n'a pas de configuration de paiement valide. |
| `404` | La formation interactive n'est pas disponible pour l'équipe ou le point de contrôle n'existe pas. |
| `429` | L’équipe a déjà `16` jobs interactifs actifs. Arrêtez un job inactif avant de réessayer. |
| `422` | Les deux ou aucun des `base_model` et `from_checkpoint` n'ont été envoyés, ou le corps a un champ inconnu. |
