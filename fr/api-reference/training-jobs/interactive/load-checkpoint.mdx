`POST /v1/training/jobs/{job_id}/load-weights`

Cette opération JSON native s'applique aux tâches d'entraînement interactives.

Met en file le chargement de l'état depuis un point `weights`. L'optimiseur peut être restauré. Interrogez [Obtenir l'opération](/fr/api-reference/training-jobs/interactive/get-operation) jusqu'à un état final.

Consultez [Créer une boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle complet.
