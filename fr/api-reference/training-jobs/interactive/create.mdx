`POST /v1/training/jobs/interactive`

Cette opération JSON native s'applique aux tâches d'entraînement interactives.

Crée une tâche interactive avec `base_model`, ou avec `from_checkpoint` et `load_optimizer` facultatif. Les clients JSON natifs n'envoient ni `seq_id` ni battement de cœur.

Consultez [Créer une boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle complet.
