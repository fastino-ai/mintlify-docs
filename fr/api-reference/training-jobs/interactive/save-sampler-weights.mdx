`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

Enregistre un checkpoint `sampler_weights` pour l’échantillonnage.

Envoyez `name` et éventuellement `ttl_seconds`, puis interrogez la `future_id` renvoyée avant d’utiliser le checkpoint.
