`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

Enregistre les poids LoRA sous `name` pour l'échantillonnage et le téléchargement PEFT. La réponse acceptée contient un `future_id`, un ID de checkpoint `sampler_weights/<name>` et son chemin `tinker://`. Interrogez [Obtenir un future](/fr/api-reference/training-jobs/interactive/get-future) avant d'échantillonner ou de télécharger.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
