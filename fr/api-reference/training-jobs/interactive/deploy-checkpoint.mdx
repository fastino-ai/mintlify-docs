`POST /v1/training/jobs/{job_id}/checkpoints/sampler_weights/{name}/deploy`

Sert l’un des points de contrôle de l’échantillonneur du travail en tant que modèle formé. Appelez-le avec
[`POST /v1/chat/completions`](/fr/api-reference/inference/chat-completions) et
`"model": "<model_id>"`. La liste d'autorisation de déploiement actuelle contient uniquement Nemotron 3.5 Lightning.
(`nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16`). Retour d'autres bases
`400`.

Le `status` du modèle est `deploying` jusqu'à ce que le moteur de service l'ait chargé, puis
`deployed`. Déployer à nouveau le même point de contrôle renvoie le même modèle et son
l'état actuel, afin que vous puissiez répéter l'appel pour vérifier la progression. Si un précédent
La tentative a échoué, l'appel répété réessaye.

## Demande

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID de travail interactif.
</ParamField>

<ParamField path="name" type="string" required>
  Nom d'un point de contrôle d'échantillonneur enregistré avec
  [`save-weights-for-sampler`](/fr/api-reference/training-jobs/interactive/save-weights-for-sampler).
</ParamField>

<ParamField body="model_name" type="string">
  Jusqu'à 64 lettres, chiffres, traits d'union et traits de soulignement, commençant et se terminant par un
  lettre ou chiffre. Dérivé du nom du point de contrôle lorsqu'il est omis. Le corps est
  facultatif.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/sampler_weights/step-000100/deploy" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model_name": "support-replies-v1"}'
```

</RequestExample>

## Réponse

<ResponseField name="model_id" type="string">
  L'ID du modèle entraîné. Transmettez-le sous le nom `model` pour l'inférence.
</ResponseField>

<ResponseField name="job_id" type="string">
  La tâche interactive qui a enregistré le point de contrôle.
</ResponseField>

<ResponseField name="checkpoint_id" type="string">
  `sampler_weights/<name>`.
</ResponseField>

<ResponseField name="base_model" type="string">
  Le modèle de base du modèle.
</ResponseField>

<ResponseField name="project_id" type="string | null">
  Le projet du métier, s'il en possède un.
</ResponseField>

<ResponseField name="status" type="string">
  `deploying` ou `deployed`.
</ResponseField>

<ResponseExample>

```json Response
{
  "model_id": "MODEL_ID",
  "job_id": "SESSION_ID:train:0",
  "checkpoint_id": "sampler_weights/step-000100",
  "base_model": "nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16",
  "project_id": null,
  "status": "deploying"
}
```

</ResponseExample>

| Statut | Signification |
| --- | --- |
| `400` | Le modèle de base n'est pas Nemotron 3.5 Lightning, ou le point de contrôle n'est pas un adaptateur PEFT accepté par le moteur de service. |
| `404` | Le point de contrôle de la tâche ou de l'échantillonneur n'existe pas, appartient à une autre équipe ou ne contient aucun fichier. |
| `409` | Un autre modèle utilise déjà `model_name`, ou le modèle servi à partir de ce point de contrôle a été supprimé. Enregistrez les poids sous un nouveau nom pour les déployer à nouveau. |
| `422` | `model_name` n’est pas valide ou le corps comporte un champ inconnu. |
