`POST /v1/training/jobs/{job_id}/save-weights`

Enregistre les poids LoRA et l'état de l'optimiseur sous `name`. La réponse acceptée contient un `future_id`, un ID de checkpoint `weights/<name>` et son chemin `tinker://`. Interrogez [Obtenir une future](/fr/api-reference/training-jobs/interactive/get-future) avant de charger l'état ou de démarrer une autre tâche à partir de celui-ci.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
