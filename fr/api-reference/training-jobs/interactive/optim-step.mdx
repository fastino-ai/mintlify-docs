`POST /v1/training/jobs/{job_id}/optim-step`

Applies the gradients accumulated by forward-backward passes since the last
step, using AdamW. Calls run in the order the job receives them, so you
can queue this right after a forward-backward pass without waiting for it.

## Request

<ParamField header="X-API-Key" type="string" required>
  Your Fastino API key.
</ParamField>

<ParamField path="job_id" type="string" required>
  Interactive job ID.
</ParamField>

The JSON body is optional.

<ParamField body="adam_params" type="object">
  AdamW parameters. Omitted fields use their defaults.

  <Expandable title="properties">
    <ParamField body="learning_rate" type="number" default="0.0001">
      Learning rate, `>= 0`.
    </ParamField>
    <ParamField body="beta1" type="number" default="0.9">
      From `0` up to, but not including, `1`.
    </ParamField>
    <ParamField body="beta2" type="number" default="0.95">
      From `0` up to, but not including, `1`.
    </ParamField>
    <ParamField body="eps" type="number" default="1e-12">
      `> 0`.
    </ParamField>
    <ParamField body="weight_decay" type="number" default="0">
      `>= 0`.
    </ParamField>
    <ParamField body="grad_clip_norm" type="number" default="0">
      Gradient-norm clip, `>= 0`. `0` disables clipping.
    </ParamField>
  </Expandable>
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/optim-step" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"adam_params": {"learning_rate": 0.0001}}'
```

</RequestExample>

## Response

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "optim_step"
}
```

</ResponseExample>

The completed future's `result` holds the step's metrics.

| Status | Meaning |
| --- | --- |
| `400` | An Adam parameter is out of range, or the job was stopped. |
| `404` | The job doesn't exist or belongs to another team. |
| `422` | The body has an unknown field. |
