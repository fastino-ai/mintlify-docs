`POST /v1/training/jobs/{job_id}/optim-step`

Met en file une étape d'optimisation sur les gradients accumulés et renvoie un `future_id`. Le corps de la requête est facultatif. Interrogez [Obtenir un future](/fr/api-reference/training-jobs/interactive/get-future) jusqu'à ce qu'il atteigne un statut terminal.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
