`POST /v1/training/jobs/{job_id}/optim-step`

Applique avec AdamW les gradients accumulés par les passes forward-backward
depuis la dernière étape d'optimisation. Les opérations s'exécutent dans
l'ordre de réception par le job. Même si vous pouvez mettre cet appel en file
à l'avance, attendez que le future forward-backward soit `completed` : une
étape d'optimisation déjà en file peut encore s'exécuter si ce future devient
`failed` ou `cancelled`. Consultez la
[boucle d'entraînement](/fr/training/training-loop).

## Demande

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID du job interactif.
</ParamField>

Le corps JSON est facultatif.

<ParamField body="adam_params" type="object">
  Paramètres AdamW. Les champs omis utilisent leurs valeurs par défaut.

  <Expandable title="properties">
    <ParamField body="learning_rate" type="number" default="0.0001">
      Taux d'apprentissage, `>= 0`.
    </ParamField>
    <ParamField body="beta1" type="number" default="0.9">
      De `0` jusqu’à `1` non compris.
    </ParamField>
    <ParamField body="beta2" type="number" default="0.95">
      De `0` jusqu’à `1` non compris.
    </ParamField>
    <ParamField body="eps" type="number" default="1e-12">
      `> 0`.
    </ParamField>
    <ParamField body="weight_decay" type="number" default="0">
      `>= 0`.
    </ParamField>
    <ParamField body="grad_clip_norm" type="number" default="0">
      Seuil d’écrêtage de la norme du gradient, `>= 0`. `0` désactive l’écrêtage.
    </ParamField>
  </Expandable>
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/optim-step" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"adam_params": {"learning_rate": 0.0001}}'
```

</RequestExample>

## Réponse

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "optim_step"
}
```

</ResponseExample>

Le `result` du future terminé contient les métriques de l’étape.

| Statut | Signification |
| --- | --- |
| `400` | Un paramètre Adam est hors plage ou le travail a été arrêté. |
| `404` | Le job n’existe pas ou appartient à une autre équipe. |
| `422` | Le corps possède un champ inconnu. |
