`POST /v1/training/jobs/{job_id}/optim-step`

Cette opération JSON native s'applique aux tâches d'entraînement interactives.

Met en file une étape d'optimisation sur les gradients accumulés et renvoie `operation_id`. Le corps est facultatif. Interrogez [Obtenir l'opération](/fr/api-reference/training-jobs/interactive/get-operation) jusqu'à un état final.

Consultez [Créer une boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle complet.
