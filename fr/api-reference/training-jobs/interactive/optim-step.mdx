`POST /v1/training/jobs/{job_id}/optim-step`

Applique les dégradés accumulés par les passes avant-arrière depuis la dernière
étape, en utilisant AdamW. Les appels sont exécutés dans l'ordre dans lequel le travail les reçoit.
peut le mettre en file d'attente juste après un passage avant-arrière sans l'attendre.

## Demande

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID de travail interactif.
</ParamField>

Le corps JSON est facultatif.

<ParamField body="adam_params" type="object">
  Paramètres AdamW. Les champs omis utilisent leurs valeurs par défaut.

  <Expandable title="properties">
    <ParamField body="learning_rate" type="number" default="0.0001">
      Taux d'apprentissage, `>= 0`.
    </ParamField>
    <ParamField body="beta1" type="number" default="0.9">
      De `0` jusqu’à `1` non compris.
    </ParamField>
    <ParamField body="beta2" type="number" default="0.95">
      De `0` jusqu’à `1` non compris.
    </ParamField>
    <ParamField body="eps" type="number" default="1e-12">
      `> 0`.
    </ParamField>
    <ParamField body="weight_decay" type="number" default="0">
      `>= 0`.
    </ParamField>
    <ParamField body="grad_clip_norm" type="number" default="0">
      Clip de norme dégradé, `>= 0`. `0` désactive le découpage.
    </ParamField>
  </Expandable>
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/optim-step" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"adam_params": {"learning_rate": 0.0001}}'
```

</RequestExample>

## Réponse

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "optim_step"
}
```

</ResponseExample>

Le `result` du futur achevé contient les mesures de l'étape.

| Statut | Signification |
| --- | --- |
| `400` | Un paramètre Adam est hors plage ou le travail a été arrêté. |
| `404` | Le travail n'existe pas ou appartient à une autre équipe. |
| `422` | Le corps possède un champ inconnu. |
