`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

Cette opération JSON native s'applique aux tâches d'entraînement interactives.

Demande au mieux l'annulation d'une opération sample en attente ou en cours. Les opérations d'entraînement ne peuvent pas être annulées.

Consultez [Créer une boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle complet.
