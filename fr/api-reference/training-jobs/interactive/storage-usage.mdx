`GET /v1/training/usage`

Renvoie le stockage des checkpoints actifs des jobs interactifs de l’équipe, avec une ligne par projet et son coût mensuel estimé. Les champs de compatibilité `org_user_urn` et `user_name` contiennent l’ID de l’équipe ; `user_email` vaut `null`. Les checkpoints supprimés et expirés ne sont pas comptabilisés.

<ParamField query="project_id" type="string">
  Limiter au stockage de ce projet.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/usage" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

<ResponseExample>

```json Response
{
  "effective_rate_usd_per_gigabyte_month": 0.05,
  "data": [
    {
      "project_id": "PROJECT_ID",
      "org_user_urn": "TEAM_ID",
      "user_email": null,
      "user_name": "TEAM_ID",
      "checkpoint_count": 3,
      "size_bytes": 805306368,
      "size_gigabytes": 0.805306368,
      "estimated_monthly_cost_usd": 0.0402653184
    }
  ]
}
```

</ResponseExample>
