`GET /v1/training/usage`

Renvoie le stockage des checkpoints interactifs à l'échelle de l'équipe et son prix mensuel. Il n'indique ni l'utilisation du calcul ni la facturation totale.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
