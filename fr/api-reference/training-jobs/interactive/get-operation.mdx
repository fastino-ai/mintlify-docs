`GET /v1/training/jobs/{job_id}/operations/{operation_id}`

Cette opération JSON native s'applique aux tâches d'entraînement interactives.

Renvoie l'état et le résultat. `wait=true` attend au plus 25 secondes et peut renvoyer un état non final. Interrogez jusqu'à `completed`, `failed` ou `cancelled`. Une erreur HTTP indique un rejet ; une opération acceptée peut finir avec `status: "failed"` et `error.message`. Traitez `error.category` comme une chaîne opaque.

Consultez [Créer une boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle complet.
