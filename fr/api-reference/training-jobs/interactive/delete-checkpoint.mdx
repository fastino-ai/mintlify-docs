`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

Supprime un checkpoint `weights` ou `sampler_weights`. L'opération se termine de manière synchrone, sans corps de réponse. Les fichiers stockés peuvent être purgés ultérieurement.

Consultez [la boucle d'entraînement personnalisée](/fr/training/training-loop) pour le cycle de vie complet.
