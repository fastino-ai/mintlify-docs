`GET /v1/training/jobs/{job_id}`

Renvoie un job d'entraînement de configuration ou interactif visible par
l'équipe de l'appelant. Pour un workload RL, ce `job_id` est également l'ID
d'exécution d'entraînement SDK renvoyé par
`training_client.get_info().model_data.model_id`.

## Requête

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID canonique du job d'entraînement Fastino.
</ParamField>

<RequestExample>

```bash cURL
curl https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Réponse

<ResponseField name="id" type="string">
  ID canonique du job d'entraînement Fastino.
</ResponseField>

<ResponseField name="type" type="string">
  `config` lorsque Fastino exécute la boucle d'entraînement, ou `interactive`
  lorsque l'appelant contrôle la boucle via le SDK pris en charge.
</ResponseField>

<ResponseField name="status" type="string">
  Statut persisté du cycle de vie.
</ResponseField>

<ResponseField name="normalized_status" type="string | null">
  Statut stable pour la compatibilité client.
</ResponseField>

<ResponseField name="is_terminal_status" type="boolean | null">
  Indique si l'interrogation peut s'arrêter.
</ResponseField>

<ResponseField name="progress_percent" type="integer | null">
  Pourcentage d'achèvement actuel, de `0` à `100`.
</ResponseField>

<ResponseField name="current_epoch" type="integer | null">
  Époque actuelle indexée à partir de 1.
</ResponseField>

<ResponseField name="error_message" type="string | null">
  Détails de l'échec lorsqu'ils sont disponibles.
</ResponseField>

<ResponseField name="metrics" type="object | null">
  Métriques d'entraînement disponibles. Les clés courantes sont `final_training_loss`, `final_validation_loss` et `best_validation_loss`. Les métriques d'évaluation sont distinctes et ne sont pas garanties.
</ResponseField>

<ResponseField name="artifact_ready" type="boolean | null">
  Indique si un emplacement d'artefact est disponible.
</ResponseField>

<ResponseField name="is_deployable" type="boolean | null">
  Décision faisant autorité sur la disponibilité du déploiement.
</ResponseField>

<ResponseField name="deployability_reason" type="string | null">
  Raison pour laquelle le job n'est pas déployable.
</ResponseField>

Les enregistrements des jobs de configuration renvoient également leur
configuration soumise, les références de datasets, la progression, les
métriques et les métadonnées d'artefact. Les enregistrements des jobs
interactifs renvoient les champs applicables à l'entraînement contrôlé par
l'appelant. Ne supposez pas que les champs propres aux jobs de configuration
sont renseignés sur un job interactif.

<ResponseExample>

```json Response
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "type": "config",
  "status": "running",
  "normalized_status": "running",
  "is_terminal_status": false,
  "progress_percent": 40,
  "current_epoch": 2,
  "metrics": {
    "final_training_loss": 0.12,
    "final_validation_loss": 0.18,
    "best_validation_loss": 0.15
  },
  "artifact_ready": false,
  "is_deployable": false,
  "deployability_reason": "job_incomplete"
}
```

</ResponseExample>

Un job inconnu ou inaccessible renvoie `404`. Une valeur de chemin invalide
renvoie `422`.
