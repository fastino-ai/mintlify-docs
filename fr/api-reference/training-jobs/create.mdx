Les clients natifs créent une tâche `interactive` avec [`POST /v1/training/jobs/create-model`](/fr/api-reference/training-jobs/interactive/create-model). Les clients Tinker créent le même type via le SDK pris en charge.

`POST /v1/training/jobs`

<Warning>
  Cette API d'entraînement renommée est disponible dans le contrat de développement. Son déploiement en production n'est pas encore vérifié : la production peut renvoyer `404` pour `/v1/training/jobs`. Confirmez sa disponibilité pour votre équipe avant de lancer un entraînement payant.
</Warning>

Crée un job d'entraînement asynchrone `config` et renvoie son enregistrement.
Dans un job de configuration, vous fournissez un dataset et une configuration,
et Fastino exécute la boucle d'entraînement.

Les jobs de configuration entraînent les modèles encodeurs renvoyés par
`GET /v1/base-models?supports_training=true` qui disposent d'une route de
dispatch compatible pour les jobs de configuration. Les modèles de base
décodeurs renvoient `400` ; entraînez les décodeurs étape par étape avec un job interactif.

Pour contrôler la boucle étape par étape, créez un job `interactive` avec
[`POST /v1/training/jobs/create-model`](/fr/api-reference/training-jobs/interactive/create-model)
et suivez le [parcours de la boucle personnalisée](/fr/training/quickstart#custom-training-loop).
Après leur création, les deux types de jobs utilisent leurs ID canoniques avec
les opérations de cycle de vie documentées sous `/v1/training/jobs/{job_id}`.

Cet endpoint est limité à 20 requêtes par minute et par utilisateur.

## Requête

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  Clé de nouvelle tentative générée par le client, de 1 à 255 caractères ; un UUID est recommandé. Répéter la même clé et le même corps renvoie le job d'origine. Réutiliser la clé avec un autre corps renvoie `422`.
</ParamField>

<ParamField body="model_name" type="string" required>
  Nom d'affichage du modèle entraîné. Longueur : 1 à 100 caractères.
</ParamField>

<ParamField body="base_model" type="string" required>
  Un ID d'encodeur entraînable renvoyé par `GET /v1/base-models?supports_training=true`, ou un UUID de checkpoint pris en charge. Le `training_type` sélectionné doit disposer d'une route de dispatch compatible. Un modèle de base décodeur renvoie `400`.
</ParamField>

<ParamField body="datasets" type="object[]" required>
  Une ou plusieurs références de [datasets importés](/fr/concepts/datasets). Chaque élément nécessite `name` et peut inclure `version` ; les versions omises sont résolues vers la dernière version.
</ParamField>

<ParamField body="training_type" type="string" default="lora">
  `lora` ou `full`. Le modèle de base sélectionné doit prendre en charge le type demandé.
</ParamField>

<ParamField body="validation_data_percentage" type="number" default="0.2">
  Fraction réservée à la validation, de `0` à `0.9` par incréments de `0.01`.
</ParamField>

<ParamField body="nr_epochs" type="integer" default="100">
  Nombre maximal d'époques, de `1` à `10000` ; l'arrêt anticipé peut terminer plus tôt.
</ParamField>

<ParamField body="learning_rate" type="number">
  Taux d'apprentissage maximal de `1e-8` à `1`. Omettez-le pour utiliser la recette d'entraînement du modèle sélectionné.
</ParamField>

<ParamField body="batch_size" type="integer" default="4">
  Taille du batch par appareil de `1` à `256`. Il est préférable de l'omettre afin que le service d'entraînement puisse appliquer ou ramener en toute sécurité la valeur par défaut propre au modèle.
</ParamField>

<ParamField body="seed" type="integer">
  Seed de reproductibilité facultative de `0` à `2147483647`. Définissez `provider_name` sur `modal` lors de son utilisation. Une seed réduit une source de variation, mais ne garantit pas des exécutions GPU identiques bit à bit.
</ParamField>

<ParamField body="project_id" type="string">
  UUID du projet. S'il est omis, Fastino associe le job au projet par défaut de l'appelant.
</ParamField>

<Expandable title="Paramètres d'entraînement supplémentaires">
  <ParamField body="save_steps" type="integer" default="100">
    Enregistrer un checkpoint tous les N pas, avec N de `1` à `2147483647`.
  </ParamField>

  <ParamField body="profile_training" type="boolean" default="false">
    Conserver un artefact structuré de profil d'entraînement.
  </ParamField>

  <ParamField body="wandb_api_key" type="string">
    Clé API Weights & Biases facultative. Traitez-la comme un secret et ne la placez jamais dans le contrôle de version, les logs ou les exemples.
  </ParamField>

  <ParamField body="lora_r" type="integer">
    Rang LoRA de `1` à `256`. Omettez-le pour utiliser la recette du modèle.
  </ParamField>

  <ParamField body="lora_alpha" type="integer">
    Alpha LoRA positif, jusqu'à `2147483647`. Omettez-le pour utiliser la recette du modèle.
  </ParamField>

  <ParamField body="lora_dropout" type="number">
    Dropout LoRA de `0` (inclus) à `1` (exclu). Omettez-le pour utiliser la recette du modèle.
  </ParamField>

  <ParamField body="warmup_ratio" type="number">
    Fraction de warmup de `0` à `1`. `warmup_steps` a la priorité.
  </ParamField>

  <ParamField body="warmup_steps" type="integer">
    Nombre absolu de pas de warmup, de `1` à `2147483647`.
  </ParamField>

  <ParamField body="lr_scheduler_type" type="string" default="cosine">
    Programme du taux d'apprentissage : `constant`, `linear` ou `cosine`.
  </ParamField>

  <ParamField body="weight_decay" type="number" default="0.01">
    Weight decay AdamW non négatif.
  </ParamField>

  <ParamField body="early_stopping_patience" type="integer" default="3">
    Époques de validation sans amélioration avant l'arrêt, de `0` à `10000`. Définissez `0` pour désactiver.
  </ParamField>

  <ParamField body="early_stopping_min_delta" type="number" default="0.0001">
    Amélioration minimale non négative de la loss de validation considérée comme une progression.
  </ParamField>

  <ParamField body="provider_name" type="string">
    Fixer un fournisseur d'entraînement compatible. Omettez-le pour une sélection automatique.
  </ParamField>

  <ParamField body="encoder_learning_rate" type="number">
    Taux d'apprentissage de l'encodeur GLiNER de `1e-8` à `1`. Utilise `learning_rate` par défaut.
  </ParamField>

  <ParamField body="task_learning_rate" type="number">
    Taux d'apprentissage de la tête de tâche GLiNER de `1e-8` à `1`. Utilise `learning_rate` par défaut.
  </ParamField>

  <ParamField body="gradient_accumulation_steps" type="integer">
    Nombre positif d'accumulations de mini-batchs.
  </ParamField>

  <ParamField body="auto_data_sizing" type="boolean">
    Activer le dimensionnement automatique des datasets GLiNER.
  </ParamField>

  <ParamField body="min_samples_per_dataset" type="integer">
    Borne inférieure du dimensionnement automatique GLiNER, de `1` à `2147483647`.
  </ParamField>

  <ParamField body="max_samples_per_dataset" type="integer">
    Borne supérieure du dimensionnement automatique GLiNER, de `1` à `2147483647`.
  </ParamField>

  <ParamField body="samples_per_label" type="integer">
    Échelle par étiquette pour le dimensionnement automatique GLiNER, de `1` à `2147483647`.
  </ParamField>

  <ParamField body="min_training_steps" type="integer">
    Nombre minimal de pas d'optimiseur GLiNER, de `0` à `2147483647`.
  </ParamField>

  <ParamField body="eval_steps" type="integer">
    Intervalle de validation périodique GLiNER2, de `1` à `2147483647` pas d'optimiseur. Omettez-le pour valider uniquement en fin d'époque.
  </ParamField>

  <ParamField body="max_eval_samples" type="integer">
    Plafond par dataset pour la validation périodique GLiNER2, de `1` à `2147483647`. Omettez-le pour ne pas appliquer de plafond.
  </ParamField>

  <ParamField body="max_length" type="integer">
    Longueur d'entrée GLiNER maximale, de `1` à `2147483647` tokens. Omettez-la pour utiliser la limite de contexte du modèle.
  </ParamField>

  <ParamField body="max_gold_per_query" type="integer">
    Nombre maximal de spans gold conservés par requête GLiNER2, de `1` à `1024`. Omettez-le pour utiliser `32`.
  </ParamField>

  <ParamField body="on_capacity_exceeded" type="string">
    Comportement lorsque les spans gold dépassent `max_gold_per_query` : `raise`, `truncate_with_warning` ou `skip_sample`. Omettez-le pour utiliser `raise`.
  </ParamField>

  <ParamField body="training_algorithm" type="string" default="sft">
    Seul `sft` est pris en charge pour les jobs de configuration. Omettez-le pour utiliser la valeur par défaut.
  </ParamField>

</Expandable>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Idempotency-Key: YOUR_UNIQUE_RETRY_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model_name": "my-model-name",
    "base_model": "fastino/gliner2-multi-v1",
    "datasets": [{"name": "my-ready-dataset"}],
    "training_type": "lora",
    "nr_epochs": 5,
    "learning_rate": 5e-5,
    "validation_data_percentage": 0.2
  }'
```

</RequestExample>

## Réponse

Renvoie `200` avec l'enregistrement complet du job d'entraînement, y compris un
`id` UUID et le statut initial. L'exemple ci-dessous est abrégé ; la réponse réelle
contient tous les champs définis par `TrainingJobResponse`.

<ResponseExample>

```json Response
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "type": "config",
  "model_name": "my-model-name",
  "base_model": "fastino/gliner2-multi-v1",
  "status": "requested",
  "training_type": "lora",
  "nr_epochs": 5,
  "learning_rate": 5e-5,
  "validation_data_percentage": 0.2
}
```

</ResponseExample>

Conservez l'`id` renvoyé dans cette réponse. Vous l'utiliserez pour interroger
le statut, récupérer les métriques et les artefacts, et exécuter des inférences
sur le modèle entraîné.

Un corps mal formé renvoie `422`. Une combinaison valide mais indisponible de
modèle, dataset, type d'entraînement ou fournisseur renvoie une erreur `4xx`
propre à la requête.

La création peut renvoyer les conflits codés suivants :

| Statut | Signification |
| --- | --- |
| `409 duplicate_training_submission` | Un job identique est déjà actif. |
| `409 idempotency_key_job_deleted` | Le job créé à l'origine avec cette clé d'idempotence a été supprimé. Utilisez une nouvelle clé pour un nouveau job. |
| `409` | Un dataset référencé a été retiré entre la validation et l'insertion du job. Corrigez le dataset et réessayez avec une nouvelle clé. |

La même `Idempotency-Key` et un corps identique rejouent le job d'origine au lieu d'en créer un autre. Un corps différent avec la même clé renvoie `422`.

Un modèle de base décodeur renvoie `400` :

```json
{
  "detail": "Decoder training on this route is retired: 'Qwen/Qwen3.6-35B-A3B' cannot be trained here. Train decoders step by step with the training job routes under /v1/training/jobs (see https://docs.fastino.ai/training/quickstart)."
}
```

Pour entraîner un décodeur, créez un job interactif avec
[`POST /v1/training/jobs/create-model`](/fr/api-reference/training-jobs/interactive/create-model)
et suivez la [boucle d'entraînement personnalisée](/fr/training/quickstart#custom-training-loop).

## Autorisation

Nécessite le rôle Owner, Admin ou Editor de l’équipe. Les autres rôles reçoivent `403 Forbidden`.
