`POST /v1/training/jobs/{job_id}/sync`

Cette opération est réservée aux jobs config ; après les contrôles habituels de fonctionnalité et d’autorisation, un ID de job interactif renvoie `400`, tandis que les jobs interactifs exposent leur état actuel via `GET /v1/training/jobs/{job_id}` et les futures.

Cette page documente `POST /v1/training/jobs/{job_id}/sync`. La spécification OpenAPI est la source canonique pour les paramètres, les réponses et l'authentification.
