`POST /v1/training/jobs/{job_id}/terminate`

Cette opération est réservée aux jobs config ; après les contrôles habituels de fonctionnalité et d’autorisation, un ID de job interactif renvoie `400`, arrêtez donc plutôt un job interactif avec `POST /v1/training/jobs/{job_id}/stop`.

Arrête un job `config` actif et demande son annulation au fournisseur. Les
checkpoints et les artefacts existants sont conservés par défaut.

<Warning>
  Définir `delete_checkpoints` sur `true` supprime définitivement les
  checkpoints et les artefacts du job une fois l'annulation confirmée. Cette
  action est irréversible.
</Warning>

## Requête

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID du job d'entraînement.
</ParamField>

Le corps JSON est optionnel.

<ParamField body="delete_checkpoints" type="boolean" default="false">
  Supprimer définitivement les checkpoints et les artefacts une fois
  l'annulation confirmée.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID/terminate \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"delete_checkpoints": false}'
```

</RequestExample>

## Réponse

<ResponseExample>

```json 200 — terminated
{
  "success": true,
  "message": "Training job terminated. Checkpoints preserved (pass delete_checkpoints=true to remove them).",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "deleted_checkpoints": 0,
  "status": "terminated"
}
```

```json 202 — cancellation pending
{
  "success": true,
  "message": "Termination in progress. The job moves to 'terminated' once the provider confirms; checkpoints are preserved.",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "deleted_checkpoints": 0,
  "status": "stopping"
}
```

</ResponseExample>

Après une réponse `202`, interrogez
`GET /v1/training/jobs/{job_id}` ; ne répétez pas la requête de terminaison
pendant que l'annulation est en attente.

| Statut | Signification |
| --- | --- |
| `200` | Le job est terminé. |
| `202` | La terminaison est en cours pendant que le fournisseur confirme l'annulation. |
| `400` | `job_id` n'est pas un UUID valide de job config ou identifie un job interactif ; utilisez plutôt la route d'arrêt interactive. |
| `409 training_job_already_finished` | Le job a atteint un état terminal avant la terminaison. |
| `409 cancellation_unconfirmed` | L'annulation n'a pas été confirmée et peut être retentée. |
| `422` | Le corps JSON de la requête n'est pas valide. |

## Autorisation

Nécessite le rôle Owner, Admin ou Editor de l’équipe. Les autres rôles reçoivent `403 Forbidden`.
