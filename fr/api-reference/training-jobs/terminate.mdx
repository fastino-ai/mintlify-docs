`POST /v1/training-jobs/{job_id}/terminate`

Arrête le job du fournisseur s'il est actif et marque le job comme terminé. Par défaut, les checkpoints et artefacts existants sont conservés.

<Warning>
  Définir `delete_checkpoints` sur `true` supprime définitivement les checkpoints et artefacts du job. Cette action est irréversible.
</Warning>

## Requête

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID du job d'entraînement.
</ParamField>

<ParamField body="delete_checkpoints" type="boolean" default="false">
  Indique s'il faut supprimer définitivement tous les checkpoints et artefacts. Omettez ce champ ou définissez-le sur `false` pour les conserver.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training-jobs/YOUR_TRAINING_JOB_ID/terminate \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"delete_checkpoints": false}'
```

</RequestExample>

## Réponse

<ResponseExample>

```json Response
{
  "success": true,
  "message": "Training job terminated. Checkpoints preserved (pass delete_checkpoints=true to remove them).",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "deleted_checkpoints": 0
}
```

</ResponseExample>

Un job inconnu ou un job qui ne peut pas être terminé renvoie une erreur `4xx` spécifique à la requête.
