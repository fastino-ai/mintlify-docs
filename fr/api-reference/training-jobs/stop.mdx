`POST /v1/training/jobs/{job_id}/stop`

Arrête un job en cours et conserve les checkpoints créés avant l'arrêt.

Pour un job `interactive`, l'arrêt libère le job une fois ses opérations en
file terminées. Il n'accepte ensuite plus d'opérations d'entraînement, mais ses
checkpoints sampler restent échantillonnables et téléchargeables. Les jobs
interactifs ignorent le corps de la requête.

## Requête

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID d'un job config ou ID d'un job interactif.
</ParamField>

Le corps JSON est optionnel.

<ParamField body="reason" type="string">
  Raison pour laquelle le job a été arrêté.
</ParamField>

<ParamField body="scores" type="object">
  Métriques numériques utilisées pour prendre la décision d'arrêt.
</ParamField>

<ParamField body="checkpoint" type="string">
  Chemin ou pas du checkpoint associé à l'arrêt.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID/stop \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"reason": "Validation loss stopped improving"}'
```

</RequestExample>

## Réponse

<ResponseExample>

```json Response
{
  "success": true,
  "message": "Training job stopped",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "status": "stopped"
}
```

```json 202 — annulation en attente
{
  "success": true,
  "message": "Training job cancellation is still being confirmed.",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "status": "stopping"
}
```

```json Interactive job
{
  "success": true,
  "job_id": "SESSION_ID:train:0",
  "status": "stopped"
}
```

</ResponseExample>

Après une réponse `202`, interrogez
`GET /v1/training/jobs/{job_id}` ; ne répétez pas la requête d'arrêt pendant
que l'annulation est en attente.

| Statut | Signification |
| --- | --- |
| `200` | Le job est arrêté et les checkpoints existants restent disponibles. |
| `202` | La confirmation de l'annulation par le fournisseur est toujours en attente. |
| `400` | `job_id` n'est ni un UUID de job config ni un ID de job interactif. |
| `409 training_job_already_finished` | Le job a atteint un état terminal avant l'arrêt. |
| `422` | Le corps JSON de la requête n'est pas valide. |
