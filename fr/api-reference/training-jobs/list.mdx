`GET /v1/training/jobs`

Renvoie les jobs d'entraînement de configuration et interactifs visibles par le
compte authentifié.

Sans `type`, une page liste d'abord les jobs de configuration (du plus récent au
plus ancien), puis les jobs interactifs (du plus récent au plus ancien). Passez
`type=interactive` pour ne lister que les jobs interactifs.

## Requête

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField query="status" type="string">
  Filtrez les jobs config par statut persisté. Lorsque `status` est fourni, la réponse exclut les jobs interactifs.
</ParamField>

<ParamField query="type" type="string">
  Filtrer par `config` ou `interactive`.
</ParamField>

<ParamField query="project_id" type="string">
  Filtrer par ID de projet.
</ParamField>

<ParamField query="limit" type="integer" default="200">
  Taille de page, de `1` à `200`.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Nombre de jobs correspondants à ignorer.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs?type=config&status=complete&limit=50&offset=0" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Réponse

<ResponseField name="success" type="boolean">
  Indique si la requête a abouti.
</ResponseField>

<ResponseField name="training_jobs" type="object[]">
  Enregistrements des jobs d'entraînement pour cette page.
</ResponseField>

Les jobs de configuration utilisent `id`. Les jobs interactifs utilisent
`job_id` comme ID de chemin canonique et conservent la même valeur dans
`training_run_id` pour la compatibilité SDK. Ils incluent également `status`,
`stop_reason`, `error_message` et `is_terminal_status` ; interrogez le job avec
`job_id` jusqu'à ce que l'indicateur terminal soit true.

<ResponseField name="count" type="integer">
  Nombre de jobs dans cette page.
</ResponseField>

<ResponseField name="total" type="integer">
  Nombre total de jobs correspondants avant pagination.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  Indique si une autre page existe après celle-ci.
</ResponseField>

<ResponseExample>

```json Response
{
  "success": true,
  "training_jobs": [],
  "count": 0,
  "total": 0,
  "has_more": false
}
```

</ResponseExample>

Des valeurs de pagination invalides renvoient `422`.
