`DELETE /v1/training/jobs/{job_id}`

Supprime le job et ses artefacts stockés. Si le job est actif, le service demande d'abord son arrêt. La suppression se termine dans le même appel uniquement lorsque l'annulation est confirmée.

<Warning>
  La suppression est irréversible. Téléchargez d'abord tout ce dont vous avez besoin vers un stockage que vous contrôlez. La suppression retire les checkpoints et les artefacts stockés et libère les déploiements hébergés actifs.
</Warning>

## Requête

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID du job d'entraînement.
</ParamField>

<RequestExample>

```bash cURL
curl -X DELETE https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Réponse

<ResponseExample>

```json Response
{
  "success": true,
  "message": "Training job deleted successfully"
}
```

</ResponseExample>

Un job inconnu ou inaccessible renvoie `404`.

| Statut | Signification |
| --- | --- |
| `409 training_job_already_finished` | Le job s'est terminé ou a échoué avant la prise en compte de l'annulation. Consultez son état avant de décider de réessayer. |
| `409 cancellation_unconfirmed` | Le job est encore en cours d'arrêt. Interrogez `GET /v1/training/jobs/{job_id}`, puis réessayez ce `DELETE` une fois le job arrêté. La suppression ne se termine pas en arrière-plan. |

## Autorisation

Nécessite le rôle Owner, Admin ou Editor de l’équipe. Les autres rôles reçoivent `403 Forbidden`.
