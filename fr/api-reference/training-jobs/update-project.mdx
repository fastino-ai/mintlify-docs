`PATCH /v1/training/jobs/{job_id}`

Cette opération est réservée aux jobs config ; après les contrôles habituels de fonctionnalité et d’autorisation, un ID de job interactif renvoie `400`. Les clients Tinker existants peuvent réaffecter le projet de la session propriétaire via le SDK, ce qui met à jour le projet du job dans les listes et sa facturation ultérieure.

Met à jour uniquement le `project_id` du job.

## Requête

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID du job d'entraînement.
</ParamField>

<ParamField body="project_id" type="string | null">
  UUID du projet à affecter. Envoyez `null` pour désaffecter le job.
</ParamField>

<RequestExample>

```bash cURL
curl -X PATCH https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"project_id": "YOUR_PROJECT_ID"}'
```

</RequestExample>

## Réponse

Renvoie `200` avec `success` et `message`.

<ResponseExample>

```json Response
{
  "success": true,
  "message": "Training job updated"
}
```

</ResponseExample>

<Note>
  Cela modifie uniquement l'étiquette de projet du job d'entraînement. Cela ne déplace pas les déploiements, inférences ou exécutions d'évaluation associés.
</Note>

Des champs de requête inconnus, y compris d'autres champs de job d'entraînement, renvoient `422`. Un job ou un projet indisponible renvoie une erreur `4xx` spécifique à la requête.

## Autorisation

Nécessite le rôle Owner, Admin ou Editor de l’équipe. Les autres rôles reçoivent `403 Forbidden`.
