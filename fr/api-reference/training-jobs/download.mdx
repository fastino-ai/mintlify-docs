Renvoie une URL présignée pour l'artefact entraîné. Récupérez ensuite l'URL renvoyée séparément pour télécharger le fichier.

## Requête

<ParamField header="X-API-Key" type="string" required>
  Votre clé API Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID du job d'entraînement.
</ParamField>

<RequestExample>

```bash cURL
curl https://api.fastino.ai/v1/training-jobs/YOUR_TRAINING_JOB_ID/download \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Réponse

<ResponseField name="success" type="boolean">
  Indique si l'URL a été générée.
</ResponseField>

<ResponseField name="job_id" type="string">
  UUID du job d'entraînement.
</ResponseField>

<ResponseField name="download_url" type="string">
  URL présignée temporaire de l'artefact.
</ResponseField>

<ResponseField name="expires_in_seconds" type="integer">
  Durée de vie de l'URL. Par défaut : 3600 secondes.
</ResponseField>

<ResponseField name="file_name" type="string">
  Nom de fichier de téléchargement suggéré.
</ResponseField>

<ResponseExample>

```json Response
{
  "success": true,
  "job_id": "YOUR_TRAINING_JOB_ID",
  "download_url": "https://...",
  "expires_in_seconds": 3600,
  "file_name": "my-model-name-weights.zip",
  "message": "Download URL generated successfully"
}
```

</ResponseExample>

<Warning>
  L'URL présignée est un identifiant temporaire de type bearer. Ne la journalisez pas, ne la commitez pas, ne la persistez pas et ne la partagez pas. Téléchargez rapidement l'artefact et stockez-le conformément à votre politique de gestion des données.
</Warning>

Pour demander l'URL et télécharger l'artefact en une seule étape :

```bash
response=$(curl -fsS \
  https://api.fastino.ai/v1/training-jobs/YOUR_TRAINING_JOB_ID/download \
  -H "X-API-Key: $FASTINO_API_KEY")

curl -fL \
  -o "$(jq -r '.file_name' <<<"$response")" \
  "$(jq -r '.download_url' <<<"$response")"
```

Cet exemple nécessite `jq`.

Un job inconnu ou un job sans artefact téléchargeable renvoie une erreur `4xx` spécifique à la requête.
