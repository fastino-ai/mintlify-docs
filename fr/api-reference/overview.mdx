Utilisez cette page pour choisir une famille d’endpoints. OpenAPI définit les méthodes, chemins, authentification, champs et réponses ; les guides expliquent quand et pourquoi les utiliser.

## Authentification et conventions

Les endpoints Fastino natifs utilisent `X-API-Key: $FASTINO_API_KEY`. Les endpoints compatibles utilisent l’authentification indiquée sur leur page de référence. Consultez [Authentification](/fr/api-reference/authentication) et [Erreurs](/fr/api-reference/errors).

## Choisir un endpoint

| Tâche | Route canonique | Référence |
| --- | --- | --- |
| Décisions GLiDE | `POST /v1/systemone` | [Ouvrir la référence](/fr/api-reference/decision/systemone) |
| Inférence GLiNER et décodeur | `POST /v1/chat/completions` | [Ouvrir la référence](/fr/api-reference/inference/chat-completions) |
| Compatibilité OpenAI Responses | `POST /v1/responses` | [Ouvrir la référence](/fr/api-reference/inference/responses) |

| Grandes entrées GLiNER-2 | `POST /v1/gliner-2/async` + suivi du job | [Ouvrir la référence](/fr/api-reference/inference/gliner-2-async) |
| Capacités et entraînement actuels | `GET /v1/base-models` | [Ouvrir la référence](/fr/api-reference/models/base-models) |

## Guides par tâche

Pour une première décision GLiDE, utilisez le [Démarrage rapide](/fr/quickstart). Pour les workflows, consultez [Modèles de décision](/fr/concepts/glide), [API d’inférence](/fr/inference), [Préparation des jeux de données](/fr/concepts/datasets) ou [API d’entraînement](/fr/training).

Pour la liste complète des opérations lisible par machine, consultez l’[inventaire API](/fr/api-reference/inventory) ou [`openapi.json`](https://docs.fastino.ai/openapi.json).
