Utilisez ces contrats pour les détails des champs. Commencez par les guides de cycle de vie pour un workflow complet.

L'API REST publique comprend :

- La découverte des modèles de base et la gestion des jeux de données
- La création de jobs `config` gérés avec `POST /v1/training/jobs` pour les encodeurs GLiNER
- Les [jobs interactifs](/fr/api-reference/training-jobs/interactive/create-model) pour l'entraînement des décodeurs :
  `POST /v1/training/jobs/create-model`, puis passes forward-backward, étapes
  d'optimiseur, checkpoints et échantillonnage sous `/v1/training/jobs/{job_id}`
- Les opérations du cycle de vie canonique sous `/v1/training/jobs` pour les
  jobs `config` et `interactive`

Auto Train reste
en accès privé et n'a pas de contrat d'API public.
