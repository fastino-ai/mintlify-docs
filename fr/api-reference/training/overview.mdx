Utilisez ces contrats pour les détails des champs. Commencez par les guides de cycle de vie pour un workflow complet.

L'API REST publique comprend :

- La découverte des modèles de base et la gestion des jeux de données
- La création de jobs `config` gérés avec `POST /v1/training/jobs`
- Les opérations du cycle de vie canonique sous `/v1/training/jobs` pour les
  jobs `config` et `interactive`

Pour les opérations de modèle des boucles personnalisées, accédez à l'API
d'entraînement via le SDK Tinker pris en charge. L'interface HTTP du SDK à
`/v1/training/compat/tinker` est absente d'OpenAPI et ne constitue pas un
contrat REST pour des appels directs. Auto Train reste en accès privé et n'a
pas de contrat d'API public.
