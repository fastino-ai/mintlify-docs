`GET /v1/datasets/{name}`

Cette page documente `GET /v1/datasets/{name}`. La spécification OpenAPI est la source canonique pour les paramètres, les réponses et l'authentification.

## État du traitement

La réponse contient `success`, `versions` et `count`. Lors de l'interrogation
d'un import récent, faites correspondre exactement son `version_number`. Une
version n'est utilisable pour l'entraînement que lorsque son `status` est
`ready` ; les versions `failed` contiennent `processing_error`.
