`DELETE /v1/datasets/{name}`

Supprime logiquement un dataset et toutes ses versions stockées par nom. Cette
route ne supprime pas une seule version sélectionnée.

## Autorisation

Nécessite le rôle Owner, Admin ou Editor de l’équipe. Les autres rôles reçoivent `403 Forbidden`.
