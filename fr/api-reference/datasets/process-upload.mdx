`POST /v1/datasets/upload/process`

Cette page documente `POST /v1/datasets/upload/process`. La spécification OpenAPI est la source canonique pour les paramètres, les réponses et l'authentification.

## Traitement asynchrone

Une requête réussie renvoie `202` et met le traitement en file d'attente ; le
dataset n'est pas encore prêt. Interrogez
[`GET /v1/datasets/{name}`](/fr/api-reference/datasets/versions), sélectionnez
le `version_number` exact renvoyé lors de la création de l'URL d'import, puis
attendez que `status` soit `ready` ou `failed`. En cas d'échec, lisez
`processing_error` avant de corriger le fichier et d'importer une nouvelle version.

Un `503` indique que la vérification du stockage ou la mise en file a échoué
avant le traitement ; le même import peut être relancé.

## Autorisation

Nécessite le rôle Owner, Admin ou Editor de l’équipe. Les autres rôles reçoivent `403 Forbidden`.
