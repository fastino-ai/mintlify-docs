`POST /v1/datasets/upload/url`

Créez une URL d'import présignée pour un nouveau fichier de dataset.

## Importer le fichier

Importez les octets exacts du fichier vers `presigned_url` avant son expiration.
La requête signée exige `Content-Type: application/octet-stream` ; omettre cet
en-tête ou utiliser une autre valeur renvoie `403`.

```bash
curl --fail-with-body -X PUT \
  -H "Content-Type: application/octet-stream" \
  --upload-file training.jsonl "$PRESIGNED_URL"
```

Après l'import, transmettez le `dataset_id` renvoyé à
[`POST /v1/datasets/upload/process`](/fr/api-reference/datasets/process-upload).

## Autorisation

Nécessite le rôle Owner, Admin ou Editor de l’équipe. Les autres rôles reçoivent `403 Forbidden`.
