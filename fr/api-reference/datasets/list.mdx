`GET /v1/datasets`

Cette page documente `GET /v1/datasets`. La spécification OpenAPI est la source canonique pour les paramètres, les réponses et l'authentification.

## Comportement des résultats

Par défaut, la réponse contient la version la plus récente de chaque nom de
dataset et exclut les imports échoués. Utilisez `include_all_versions=true`
pour renvoyer toutes les versions ou `include_failed=true` pour inclure vos
imports échoués.

Les résultats les plus récents apparaissent en premier. `limit` vaut 200 par
défaut et au maximum ; utilisez `offset` pour demander les pages suivantes.
