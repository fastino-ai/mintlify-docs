Cet inventaire reflète toutes les opérations de `openapi.json`. Utilisez les guides pour l'intention et les exemples ; OpenAPI est le contrat canonique.

## Model Catalog

| Opération | Résumé |
| --- | --- |
| `GET /v1/base-models` | List Base Models |

## Inference History

| Opération | Résumé |
| --- | --- |
| `GET /v1/inferences` | List Inference History |
| `GET /v1/inferences/{inference_id}` | Get Inference Detail |
| `GET /v1/inferences/{inference_id}/feedback` | Get Inference Feedback |
| `POST /v1/inferences/{inference_id}/feedback` | Submit Inference Feedback |

## Datasets

| Opération | Résumé |
| --- | --- |

## Training Jobs

| Opération | Résumé |
| --- | --- |
| `GET /v1/training-jobs` | List Training Jobs |
| `POST /v1/training-jobs` | Create Training Job |
| `DELETE /v1/training-jobs/{job_id}` | Delete Training Job |
| `GET /v1/training-jobs/{job_id}` | Get Training Job |
| `PATCH /v1/training-jobs/{job_id}` | Update Training Job |
| `GET /v1/training-jobs/{job_id}/billing` | Get Training Job Billing |
| `GET /v1/training-jobs/{job_id}/checkpoints` | List Training Job Checkpoints |
| `POST /v1/training-jobs/{job_id}/checkpoints/{checkpoint_id}/deploy` | Deploy Checkpoint To Mme |
| `GET /v1/training-jobs/{job_id}/download` | Get download URL for trained model |
| `GET /v1/training-jobs/{job_id}/logs` | Get Training Job Logs |
| `PATCH /v1/training-jobs/{job_id}/model-name` | Update Training Job Model Name |
| `POST /v1/training-jobs/{job_id}/push-to-hub` | Push Training Job To Huggingface |
| `POST /v1/training-jobs/{job_id}/stop` | Stop Training Job |
| `POST /v1/training-jobs/{job_id}/sync` | Sync Training Job Status |
| `POST /v1/training-jobs/{job_id}/terminate` | Terminate Training Job |

## Deprecated

| Opération | Résumé |
| --- | --- |
| `GET /v1/training-jobs/{job_id}/deployments` | [Deprecated] Get deployments for a training job -- use /projects/{project_id}/deployments (obsolète) |
