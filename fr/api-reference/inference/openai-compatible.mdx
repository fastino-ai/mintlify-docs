Fastino expose des endpoints compatibles OpenAI permettant d'utiliser les méthodes prises en charge du SDK OpenAI avec les modèles Fastino. Définissez `base_url` sur `https://api.fastino.ai/v1`, authentifiez-vous avec votre clé d'API Fastino et transmettez comme `model` un ID renvoyé par `GET /v1/models` ou l'ID de votre job d'entraînement. Les champs propres à Fastino, comme `schema`, peuvent être transmis via `extra_body` dans le SDK Python ou inclus directement dans le corps JSON.

<Tip>
  Pour les méthodes prises en charge ci-dessous, une intégration OpenAI existante nécessite généralement uniquement un nouveau `base_url`, une clé d'API et un ID de modèle.
</Tip>

## Surface SDK prise en charge

| Méthode du SDK OpenAI | Endpoint Fastino | Streaming |
|---|---|---|
| `client.chat.completions.create(...)` | `POST /v1/chat/completions` | Oui |
| `client.responses.create(...)` | `POST /v1/responses` | Oui |
| `client.models.list()` | `GET /v1/models` | Non applicable |

<Warning>
  Fastino n'implémente pas toutes les API ni toutes les ressources du SDK OpenAI. Utilisez uniquement les méthodes répertoriées ci-dessus. L'ancien endpoint `POST /v1/completions` a été supprimé ; migrez les requêtes basées sur un prompt vers Chat Completions.
</Warning>

## Configurer le SDK OpenAI

Faites pointer le SDK vers l'URL de base de Fastino et fournissez votre clé d'API Fastino :

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai/v1"
)
```

```bash cURL (base URL)
# Set this as the base for all requests
https://api.fastino.ai/v1
```

</CodeGroup>

## Chat completions

`POST /v1/chat/completions` accepte les principaux champs d'OpenAI Chat Completions. Transmettez un ID de modèle pris en charge comme `model` et incluez les champs propres à Fastino, comme `schema`, dans le corps de la requête ou via `extra_body`.

<CodeGroup>

```python Python (OpenAI SDK)
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai/v1"
)

response = client.chat.completions.create(
    model="YOUR_TRAINING_JOB_ID",
    messages=[
        {
            "role": "user",
            "content": "Extract entities from: Apple launched the iPhone."
        }
    ],
    extra_body={
        "schema": {
            "entities": ["organization", "product"]
        }
    }
)

print(response.choices[0].message.content)
```

```bash cURL
curl -X POST https://api.fastino.ai/v1/chat/completions \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_TRAINING_JOB_ID",
    "messages": [
      {
        "role": "user",
        "content": "Extract entities from: Apple launched the iPhone."
      }
    ],
    "schema": {
      "entities": ["organization", "product"]
    }
  }'
```

</CodeGroup>

## Lister les modèles disponibles

Utilisez `GET /v1/models` pour récupérer la liste des modèles utilisables avec ces endpoints.

<CodeGroup>

```python Python (OpenAI SDK)
models = client.models.list()
for model in models.data:
    print(model.id)
```

```bash cURL
curl https://api.fastino.ai/v1/models \
  -H "X-API-Key: YOUR_API_KEY"
```

</CodeGroup>

## Streaming

Chat Completions et Responses prennent en charge le streaming. Définissez `stream=True` dans le SDK ou `"stream": true` dans le corps de la requête.

<CodeGroup>

```python Python (OpenAI SDK)
stream = client.chat.completions.create(
    model="YOUR_TRAINING_JOB_ID",
    messages=[{"role": "user", "content": "Summarize the following article: ..."}],
    stream=True
)

for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="")
```

```bash cURL
curl -X POST https://api.fastino.ai/v1/chat/completions \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_TRAINING_JOB_ID",
    "messages": [{"role": "user", "content": "Summarize the following article: ..."}],
    "stream": true
  }'
```

</CodeGroup>

## Transmettre des champs propres à Fastino

Le champ `schema` est une extension Fastino. Dans le SDK Python d'OpenAI, transmettez-le via `extra_body` afin qu'il soit inclus dans la requête sans affecter la validation du SDK. Dans une requête HTTP brute, incluez-le au niveau supérieur du corps JSON, à côté des champs standard comme `model` et `messages`.
