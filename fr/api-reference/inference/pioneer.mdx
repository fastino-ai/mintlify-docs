`POST /inference` a été supprimé.

Utilisez `POST /v1/chat/completions` pour l'inférence GLiNER hébergée. La requête actuelle utilise
`Authorization: Bearer $FASTINO_API_KEY` avec les champs de premier niveau `model`, `messages` et `schema`.

Consultez [`/v1/chat/completions`](/fr/inference/chat-completions) pour la requête, la réponse
et les instructions de migration de référence.
