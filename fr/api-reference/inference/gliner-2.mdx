`POST /v1/gliner-2`

Le panneau OpenAPI est la source de vérité pour tous les champs de requête et
de réponse. Utilisez le schéma GLiNER unifié et omettez le champ obsolète `task`.

## Requête d'extraction d'entités

```json
{
  "text": "Apple CEO Tim Cook introduced the iPhone in Cupertino.",
  "schema": {
    "entities": [
      {"name": "person", "description": "named individual"},
      {"name": "organization", "description": "business or institution"},
      {"name": "product", "description": "named commercial product"},
      {"name": "location", "description": "city, region, or place"}
    ]
  },
  "threshold": 0.5,
  "include_confidence": true,
  "include_spans": true
}
```

`schema` prend aussi en charge `classifications`, `structures` et `relations`.
Consultez le schéma complet et d'autres exemples sous
[`POST /v1/chat/completions`](/fr/api-reference/inference/chat-completions).

## Réponse réussie

```json
{
  "result": {
    "entities": [
      {
        "text": "Apple",
        "label": "organization",
        "score": 0.99,
        "start": 0,
        "end": 5
      }
    ]
  },
  "token_usage": 10
}
```
