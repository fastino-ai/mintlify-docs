`GET /v1/gliner-2/jobs/{job_id}`

Le panneau OpenAPI est la source de vérité pour le paramètre de chemin et tous
les champs de réponse. Utilisez la même clé API que lors de la soumission.

## Requête

```bash
curl "https://api.fastino.ai/v1/gliner-2/jobs/3f08a17f-777a-4aa6-8ec5-879df37775a8" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

## Réponse en attente

Continuez à interroger tant que `status` vaut `pending` ou `processing` :

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "pending",
  "result": null,
  "error": null,
  "token_usage": 1284307,
  "created_at": "2026-10-07T22:10:00+00:00",
  "completed_at": null
}
```

## Réponse terminée

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "complete",
  "result": {
    "entities": [
      {"text": "Apple", "label": "organization", "score": 0.99, "start": 0, "end": 5}
    ]
  },
  "error": null,
  "token_usage": 1284307,
  "created_at": "2026-10-07T22:10:00+00:00",
  "completed_at": "2026-10-07T22:13:42+00:00"
}
```

Une tâche échouée renvoie `status: "error"` et un message dans `error`.
Une tâche inconnue ou appartenant à un autre utilisateur renvoie `404`.
