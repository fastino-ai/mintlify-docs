`POST /v1/gliner-2/async`

Le panneau OpenAPI est la source de vérité pour tous les champs de requête et
de réponse `202`. Utilisez cet endpoint au-delà d'un million de tokens ou si la
requête risque de dépasser le délai synchrone.

## Exemple de requête

```json
{
  "text": "A very large document to process asynchronously...",
  "schema": {
    "entities": [
      {"name": "person", "description": "named individual"},
      {"name": "organization", "description": "business or institution"}
    ]
  },
  "threshold": 0.5,
  "include_confidence": true,
  "include_spans": true
}
```

## Réponse acceptée

L'exemple suivant abrège `message` ; le service renvoie un chemin d'interrogation
concret contenant l'identifiant de la tâche.

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "accepted",
  "estimated_tokens": 1284307,
  "message": "Job queued. ..."
}
```

Conservez `job_id`, puis interrogez avec la même clé API
[`GET /v1/gliner-2/jobs/{job_id}`](/fr/api-reference/inference/gliner-2-job-status).
