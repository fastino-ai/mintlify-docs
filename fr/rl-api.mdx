L'API RL exécute sur Fastino des workloads d'apprentissage par renforcement et
de post-entraînement personnalisé. Votre code contrôle le jeu de données, la
fonction de récompense, la stratégie de rollout et les critères d'arrêt.
Fastino exécute l'échantillonnage et l'entraînement du modèle.

<Note>
  L'API RL est en accès limité. Vérifiez que Fastino l'a activée pour votre
  équipe avant de planifier une migration en production.
</Note>

Utilisez le SDK Python officiel `tinker`. Une application Tinker existante peut
migrer vers Fastino sans remplacer sa boucle d'apprentissage.

## Ce que vous contrôlez

Votre application :

1. Échantillonne des réponses depuis la politique actuelle.
2. Évalue chaque réponse avec votre fonction de récompense.
3. Transforme les récompenses en avantages.
4. Envoie le lot d'entraînement à l'API RL.
5. Applique une étape d'optimisation et enregistre les checkpoints utiles.

Cette séparation permet de modifier la récompense ou l'algorithme
d'apprentissage sans gérer l'infrastructure du modèle.
