L'API RL de Fastino est un service hébergé d'entraînement et
d'échantillonnage. Le client Python pris en charge est le paquet `tinker`
configuré pour utiliser Fastino. Votre code contrôle le jeu de données, la
fonction de récompense, la stratégie de génération des réponses et les critères
d'arrêt. Fastino exécute l'échantillonnage et l'entraînement du modèle.

<Note>
  L'API RL est en accès limité. Vérifiez que Fastino l'a activée pour votre
  équipe avant de planifier une migration en production.
</Note>

Installer le paquet `tinker` ne donne pas accès à l'API RL de Fastino. Une
application existante utilisant le SDK peut conserver la forme de ses appels
uniquement si tous les éléments de la
[checklist de compatibilité](/fr/rl-api/compatibility) sont satisfaits.

Utilisez cette API lorsque votre application doit générer des réponses de façon
répétée, les évaluer et mettre à jour le modèle. Pour un fine-tuning géré à
partir d'un jeu de données préparé, utilisez
[l'API d'entraînement](/fr/training).

## Ce que vous contrôlez

Votre application :

1. Échantillonne des réponses depuis la politique actuelle.
2. Évalue chaque réponse avec votre fonction de récompense.
3. Transforme les récompenses en avantages.
4. Envoie le lot d'entraînement à l'API RL.
5. Applique une étape d'optimisation et enregistre les checkpoints utiles.

Cette séparation vous permet de contrôler la logique d'apprentissage sans gérer
l'infrastructure du modèle. Utilisez uniquement les opérations et les noms de
fonctions de perte intégrés documentés dans la référence de compatibilité.
