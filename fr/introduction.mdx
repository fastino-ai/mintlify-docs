Utilisez Fastino Agent pour affiner de manière autonome des modèles GLiNER adaptés à vos cas d'usage spécifiques. Exécutez l'inférence avec les modèles de base comme avec les modèles spécialisés affinés via notre API.

## Ce que vous pouvez faire avec Fastino

<CardGroup cols={2}>
  <Card title="Branchement direct, inférence comme d'habitude" icon="plug" href="/fr/inference">
    Faites pointer votre client OpenAI ou Anthropic existant vers Fastino pour exécuter l'inférence sur les modèles de base GLiNER.
  </Card>

  <Card title="Entraînement de modèles spécialistes" icon="brain" href="/guides/adaptive-inference">
    Fastino entraîne et évalue des modèles spécialistes GLiNER pour vous. Zéro MLOps de votre côté.
  </Card>

  <Card title="Apportez vos propres évaluations" icon="bolt" href="/guides/fine-tune-llm">
    Utilisez la suite d'évaluation intégrée de Fastino ou branchez la vôtre. Chaque entraînement génère également un rapport PDF complet avec le détail des évaluations, les étapes de déploiement et l'historique des checkpoints.
  </Card>

  <Card title="Téléchargez vos ressources" icon="download" href="/guides/adaptive-inference">
    Vos poids et vos jeux de données d'entraînement vous appartiennent. Téléchargez-les à tout moment pour les utiliser sur n'importe quelle autre plateforme ou poursuivre l'affinage sur votre propre infrastructure.
  </Card>
</CardGroup>

## Familles de modèles prises en charge

- **GLiNER 2.5 Multilingual** pour l'extraction structurée multilingue.
- **GLiNER2 et GLiGuard** pour l'extraction d'entités, la classification, les données structurées, la sécurité et les workflows liés aux données personnelles (PII).

Consultez [Modèles](/fr/concepts/models) pour connaître les IDs des modèles et leur disponibilité actuelle.
