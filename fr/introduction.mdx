Utilisez Fastino Agent pour affiner de manière autonome des modèles GLiNER adaptés à vos cas d'usage spécifiques. Exécutez l'inférence avec les modèles de base comme avec les modèles spécialisés affinés via notre API.

  <Card title="API d'entraînement" icon="database-zap" href="/fr/training">

  <Card title="API d'inférence" icon="sparkle" href="/fr/inference">

## Familles de modèles prises en charge

- **GLiNER 2.5 Multilingual** pour l'extraction structurée multilingue.
- **GLiNER2 et GLiGuard** pour l'extraction d'entités, la classification, les données structurées, la sécurité et les workflows liés aux données personnelles (PII).

Consultez [Modèles](/fr/concepts/models) pour connaître les IDs des modèles et leur disponibilité actuelle.
