GLiDE renvoie des décisions calibrées sans générer de texte. Envoyez un `state`
partagé et une ou plusieurs questions typées à `POST /v1/systemone`.

## Choisir un type de question

| Type | Utilisation |
| --- | --- |
| Noul | Vous avez besoin d'une probabilité oui/non |
| Choice | Vous avez besoin d'une réponse parmi 2–255 options définies par l'appelant |
| Score | Vous avez besoin d'un niveau ordonné et d'un score attendu |

La réponse conserve l'ordre des questions et renvoie des réponses typées avec
probabilités et confiance. Votre application décide d'accepter, différer ou utiliser
une solution de repli.

## Avant l'appel

1. Exportez votre clé sous `FASTINO_API_KEY`.
2. Placez les éléments à évaluer dans `state`.
3. Choisissez le type de question adapté à la décision.
4. Suivez la référence API pour les champs, limites, exemples et réponses exacts.
