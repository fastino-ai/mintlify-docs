Chaque recette est une requête fonctionnelle pour une tâche courante. Elle présente les schémas de requête et de réponse, une réponse réelle de l'API en production et du code qui exploite le résultat. Copiez une recette, remplacez les données par les vôtres et ajustez les critères ou les libellés.

Les recettes GLiNER couvrent les trois usages les plus courants de GLiNER 2.5 Multilingual : l'extraction d'entités, la classification et l'extraction de relations.
