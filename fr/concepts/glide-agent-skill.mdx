Le [skill d'agent Fastino GLiDE](https://api.fastino.ai/.well-known/agent-skills/fastino-glide/SKILL.md) aide Cursor, Claude Code et Codex à utiliser le modèle de décision GLiDE hébergé par Fastino pour classer, router et noter des décisions structurées, et à intégrer l'inférence GLiDE dans un projet.

## Installation

Exécutez cette commande depuis votre projet :

```bash
npx skills add https://api.fastino.ai --skill fastino-glide
```

Le programme d'installation vous permet de choisir les agents pris en charge qui recevront le skill.

Avant d'utiliser le skill, exposez votre clé API Fastino dans l'environnement de l'agent :

```bash
export FASTINO_API_KEY="..."
```

Invoquez-le ensuite explicitement avec `/fastino-glide`, ou demandez à votre agent une décision de classification, de routage ou de notation reposant sur GLiDE.

## Installation non interactive

Utilisez la commande correspondant à votre agent pour installer le skill dans le projet en cours sans invite :

<CodeGroup initialSelectedTab={0}>

```bash Cursor
npx skills add https://api.fastino.ai --skill fastino-glide -a cursor -y
```

```bash Claude Code
npx skills add https://api.fastino.ai --skill fastino-glide -a claude-code -y
```

```bash Codex
npx skills add https://api.fastino.ai --skill fastino-glide -a codex -y
```

```text Any agent
"Install the Fastino GLiDE agent skill. Follow the installation
instructions in Fastino's documentation at
https://docs.fastino.ai/concepts/glide-agent-skill. Use one
installation method appropriate for your agent environment. Then use
the Fastino GLiDE skill when working on this project, especially for
classification, routing, and scoring decisions with calibrated
probabilities instead of generated text."
```

</CodeGroup>

Pour Cursor, Claude Code et Codex, l'option `-a` sélectionne l'agent cible et `-y` accepte les invites d'installation, ce qui rend ces commandes adaptées aux scripts et à la CI.
