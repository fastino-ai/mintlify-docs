La [compétence d'agent GLiNER2](https://github.com/jaanavit/gliner2-skill) fournit à Cursor, Claude Code et Codex des instructions pour les workflows GLiNER2.5, GLiNER2 et GLiNER, notamment la sélection de modèle, la conception de schéma, l'extraction, la classification, les relations et le fine-tuning.

## Installation

Exécutez cette commande depuis votre projet :

```bash
npx skills add jaanavit/gliner2-skill
```

L'installeur vous permet de choisir quels agents pris en charge reçoivent la compétence.

## Installation non interactive

Utilisez la commande correspondant à votre agent pour installer la compétence dans le projet actuel sans invite :

<CodeGroup>

```bash Cursor
npx skills add jaanavit/gliner2-skill -a cursor -y
```

```bash Claude Code
npx skills add jaanavit/gliner2-skill -a claude-code -y
```

```bash Codex
npx skills add jaanavit/gliner2-skill -a codex -y
```

</CodeGroup>

L'option `-a` sélectionne l'agent cible et `-y` accepte les invites d'installation, ce qui rend ces commandes adaptées aux scripts et à la CI.
