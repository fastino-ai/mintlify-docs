Le [skill d'agent Fastino GLiNER](https://api.fastino.ai/.well-known/agent-skills/fastino-gliner/SKILL.md) aide Cursor, Claude Code et Codex à utiliser les API hébergées de Fastino pour l'extraction, la classification, la préparation de datasets, le fine-tuning, l'évaluation et l'inférence.

## Installation

Exécutez cette commande depuis votre projet :

```bash
npx skills add https://api.fastino.ai --skill fastino-gliner
```

Le programme d'installation vous permet de choisir à quels agents pris en charge appliquer le skill.

Avant d'utiliser le skill, exposez votre clé d'API Fastino à l'environnement de l'agent :

```bash
export FASTINO_API_KEY="..."
```

Invoquez-le ensuite explicitement avec `/fastino-gliner`, ou demandez à votre agent d'exécuter un flux d'extraction, de classification, de fine-tuning, d'évaluation ou d'inférence GLiNER hébergé.

## Installation non interactive

Utilisez la commande correspondant à votre agent pour installer le skill dans le projet en cours sans invite :

<CodeGroup>

```bash Cursor
npx skills add https://api.fastino.ai --skill fastino-gliner -a cursor -y
```

```bash Claude Code
npx skills add https://api.fastino.ai --skill fastino-gliner -a claude-code -y
```

```bash Codex
npx skills add https://api.fastino.ai --skill fastino-gliner -a codex -y
```

```text Any agent
Collez ce prompt dans votre agent de code :

"Install the Fastino GLiNER agent skill. Follow the installation
instructions in Fastino's documentation at
https://docs.fastino.ai/concepts/gliner-agent-skill. Use one
installation method appropriate for your agent environment. Then use
the Fastino GLiNER skill when working on this project, especially for
schema-driven information extraction, entity extraction,
classification, and relation extraction"
```

</CodeGroup>

Pour Cursor, Claude Code et Codex, l'option `-a` sélectionne l'agent cible et `-y` accepte les invites d'installation, ce qui rend ces commandes adaptées aux scripts et à la CI.
