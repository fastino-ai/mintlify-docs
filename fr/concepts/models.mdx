## Modèles entraînables

| ID du modèle | Entraînement | Longueur de contexte (tokens) |
| --- | --- | --- |
| `fastino/gliner2-multi-v1` | [Job de configuration](/fr/api-reference/training-jobs/create) | 8,192 |
| `fastino/GLiNER-2.5-Decide` | [Job de configuration](/fr/api-reference/training-jobs/create) | 8,192 |
| `nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16` | [Job interactif](/fr/api-reference/interactive-jobs/create) | 65,536 |
| `nvidia/NVIDIA-Nemotron-3-Super-120B-A12B-BF16` | [Job interactif](/fr/api-reference/interactive-jobs/create) | 32,768 |
| `Qwen/Qwen3.6-35B-A3B` | [Job interactif](/fr/api-reference/interactive-jobs/create) | 32,768 |

Les jobs de configuration fine-tunent des encodeurs GLiNER à partir d'un dataset. Les
jobs interactifs entraînent des adaptateurs LoRA sur des modèles décodeurs, étape
par étape, depuis votre code. Consultez l'[API d'entraînement](/fr/training).
