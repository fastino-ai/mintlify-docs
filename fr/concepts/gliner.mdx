GLiNER est une famille open source de petits modèles de langage pour une extraction d'informations efficace. GLiNER 2.5 est la génération actuelle et le choix par défaut pour les nouveaux travaux d'extraction.

## Quand utiliser GLiNER 2.5

Optez pour GLiNER 2.5 lorsque la tâche relève de l'extraction : vous avez besoin des spans littéraux, d'enregistrements structurés ou d'un graphe de relations issus du texte, et non d'une simple étiquette de décision.

- **Extraction d'entités** : extrayez des personnes, des organisations, des produits, des lieux ou des entités propres à un domaine (médicaments, posologies, clauses) à partir de texte libre, avec offsets de caractères et scores de confiance.
- **Enregistrements structurés** : transformez « Alice a acheté des pommes et Bob a acheté des oranges » en `[{"buyer": "Alice", "item": "apples"}, {"buyer": "Bob", "item": "oranges"}]`, en conservant le lien entre les champs de chaque instance.
- **Extraction de relations et de graphes de connaissances** : extrayez des graphes typés d'entités et de relations (`works_for`, `located_in`) pour la mémoire d'agents ou une base de connaissances.
- **Attributs de span** : associez à chaque entité extraite un attribut, comme le sentiment par personne, dans la même passe que l'extraction.
- **Documents longs** : traitez des contrats, des transcriptions et des rapports jusqu'à 4 096 mots, avec découpage automatique et réajustement des offsets pour les documents plus longs.
- **Plusieurs tâches à la fois** : combinez entités, classification, structures et relations dans un seul appel contraint par un schéma, au lieu d'enchaîner plusieurs requêtes au modèle.

Utilisez plutôt [GLiNER-2.5-Decide](/fr/concepts/gliner-2-5-decide) lorsque la tâche consiste à prendre une décision (une route, une étiquette, un score) plutôt qu'à obtenir le texte sous-jacent.

## Comment utiliser GLiNER 2.5

Appelez le checkpoint multilingue via l'endpoint d'inférence de Fastino compatible avec OpenAI. Placez le texte dans un message utilisateur et décrivez la tâche dans `schema` :

```bash
curl -X POST "https://api.fastino.ai/v1/chat/completions" \
  -H "Authorization: Bearer $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "fastino/gliner2.5-multi-v1",
    "messages": [
      { "role": "user", "content": "Apple CEO Tim Cook unveiled the iPhone 15 Pro in Cupertino." }
    ],
    "schema": {
      "entities": [
        { "name": "person", "description": "named individual" },
        { "name": "organization", "description": "business or institution name" },
        { "name": "product", "description": "named commercial product" },
        { "name": "location", "description": "city, region, or place" }
      ]
    }
  }'
```

Ajoutez les clés `classifications`, `structures` ou `relations` au même `schema` pour exécuter plusieurs tâches sur le même texte en un seul appel. Consultez la référence de l'[API d'inférence](/fr/inference) pour le contrat complet de requête et de réponse, y compris les enregistrements structurés et les schémas de relations.

## Comparer les générations de GLiNER

| | GLiNER2.5 | GLiNER2 | GLiNER |
| --- | --- | --- | --- |
| Architecture | Prédiction de frontières | Énumération de spans | Énumération de spans |
| Usage principal | Extraction structurée avec contraintes | Extraction d'entités et analyse structurée | NER à vocabulaire ouvert |
| Tailles de modèles | 74M small, 194M base, 287M multilingue | 205M base, 300M multilingue | 50M small, 90M medium |
| Contexte d'entrée | 4 096 mots | 2 048 tokens | 512 tokens |
| Longueur de span maximale | Aucune limite configurée | 8 mots | 12 mots |
| Classification de texte | Oui, avec contraintes inter-tâches | Oui | Non |
| Extraction structurée | Oui | Oui | Non |
| Extraction de relations | Oui | Oui | Non |
| Attributs de span | Oui | Non | Non |

GLiNER2.5 est le point de départ recommandé pour les nouveaux projets d'extraction. Utilisez GLiNER2 pour les intégrations existantes basées sur un schéma, et le GLiNER d'origine pour les checkpoints NER à vocabulaire ouvert construits sur le package de première génération.
