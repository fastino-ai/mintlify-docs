GLiNER est une famille open source de petits modèles de langage pour l'extraction d'informations efficace.

## GLiNER2.5

GLiNER2.5 remplace l'énumération d'empans par une architecture de prédiction de frontières. Il prend en charge des empans de toute longueur dans le contexte du modèle, l'extraction sur contexte long, l'extraction conjointe entités-relations, la classification avec contraintes et les attributs d'empan. Il reste léger et peut fonctionner sans GPU.

## Comparer les générations de GLiNER

| | GLiNER2.5 | GLiNER2 | GLiNER |
| --- | --- | --- | --- |
| Architecture | Prédiction de frontières | Énumération d'empans | Énumération d'empans |
| Usage principal | Extraction structurée tenant compte des contraintes | Extraction d'entités et parsing structuré | NER à vocabulaire ouvert |
| Tailles de modèle | 74M small, 194M base, 287M multilingue | 205M base, 300M multilingue | 50M small, 90M medium |
| Contexte d'entrée | 4,096 mots | 2,048 tokens | 512 tokens |
| Longueur d'empan maximale | Aucune limite configurée | 8 mots | 12 mots |
| Classification de texte | Oui, avec contraintes inter-tâches | Oui | Non |
| Extraction structurée | Oui | Oui | Non |
| Extraction de relations | Oui | Oui | Non |
| Attributs d'empan | Oui | Non | Non |

GLiNER2.5 est le point de départ recommandé pour tout nouveau projet d'extraction. Utilisez GLiNER2 pour les intégrations existantes basées sur un schéma, et le GLiNER original pour les checkpoints NER à vocabulaire ouvert construits sur le package de première génération.
