Installez la CLI Pioneer lorsque vous souhaitez accéder depuis le terminal aux tâches d'entraînement, aux artefacts de modèles, aux jeux de données et à l'agent interactif Pioneer.

<Info>
  La CLI Pioneer est publiée sous le nom `@fastino-ai/pioneer-cli` et fonctionne avec Bun `1.1.0` ou une version plus récente.
</Info>

## Prérequis

- macOS ou Linux
- Bun `1.1.0` ou une version plus récente
- Node.js et npm
- Une clé d'API Pioneer depuis [Clés d'API Pioneer](https://app.pioneer.ai/api-keys)

## Installer la CLI

<Steps>
  <Step title="Installer Bun">
    ```bash
    curl -fsSL https://bun.sh/install | bash
    ```

    Ouvrez un nouveau terminal une fois l'installation terminée, puis confirmez que Bun est disponible :

    ```bash
    bun --version
    ```
  </Step>
  <Step title="Installer la CLI Pioneer">
    ```bash
    npm install -g @fastino-ai/pioneer-cli
    ```
  </Step>
  <Step title="Vérifier la commande">
    ```bash
    pioneer --version
    pioneer --help
    ```
  </Step>
</Steps>

## Authentification

<Steps>
  <Step title="Créer une clé d'API">
    Créez une clé d'API dans le tableau de bord Pioneer, puis gardez-la à portée de main pour l'invite de connexion.
  </Step>
  <Step title="Se connecter en mode interactif">
    ```bash
    pioneer auth login
    ```

    La CLI valide la clé avant de l'enregistrer.
  </Step>
  <Step title="Confirmer votre session">
    ```bash
    pioneer auth status
    ```
  </Step>
</Steps>

<Note>
  La connexion interactive stocke votre clé d'API dans `~/.pioneer/config.json`. La CLI prend également en charge `PIONEER_API_KEY` pour la CI ou les sessions shell de courte durée.
</Note>

## Vérifier l'installation

Exécutez quelques commandes en lecture seule pour confirmer que la CLI peut joindre Pioneer :

```bash
pioneer --version
pioneer auth status
pioneer model base-models
pioneer dataset list
```

## Mettre à jour

```bash
npm install -g @fastino-ai/pioneer-cli@latest
pioneer --version
```

## Dépannage

<AccordionGroup>
  <Accordion title="pioneer: command not found" icon="circle-alert">
    Assurez-vous que le répertoire bin global de npm figure dans `PATH`.

    ```bash
    npm bin -g
    ```
  </Accordion>

  <Accordion title="env: bun: No such file or directory" icon="terminal">
    Installez Bun et ouvrez un nouveau terminal :

    ```bash
    curl -fsSL https://bun.sh/install | bash
    bun --version
    ```
  </Accordion>

  <Accordion title="L'authentification échoue" icon="key-round">
    Créez une nouvelle clé d'API dans le tableau de bord Pioneer, puis relancez la connexion interactive.

    ```bash
    pioneer auth login
    pioneer auth status
    ```
  </Accordion>
</AccordionGroup>
