本快速入门涵盖训练 API 的两种路径。希望由 Fastino 运行循环时，请使用托管训练。
当你的应用必须控制采样、奖励和模型更新时，请使用自定义训练循环。

## 1. 身份验证

1. 创建 [Fastino 账户](https://agent.fastino.ai/)。
2. 打开 [API 密钥](https://agent.fastino.ai/api-keys)页面。
3. 创建密钥，并在显示时复制。

将密钥存储在环境变量中：

<CodeGroup>

```bash macOS/Linux
export FASTINO_API_KEY="fast_sk_..."
```

```powershell Windows
$env:FASTINO_API_KEY = "fast_sk_..."
```

</CodeGroup>

以 `X-API-Key: $FASTINO_API_KEY` 发送此密钥。完整的身份验证契约请参阅
[身份验证](/cn/authentication)。

## 2. 选择路径

| 目标 | 路径 |
| --- | --- |
| 提供数据和配置，然后由 Fastino 运行训练 | [托管训练](#managed-training) |
| 在你的应用中控制采样、奖励和更新 | [自定义训练循环](#custom-training-loop) |

<span id="managed-training" />

## 托管训练

### 3. 准备数据集

[上传并处理训练数据集](/cn/concepts/datasets)，然后等待其版本变为 `ready`。

### 4. 选择模型

提交前查询实时目录：

```bash
curl "https://api.fastino.ai/v1/base-models?supports_training=true" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

保存所选模型的 ID。

### 5. 创建任务

```bash
curl -X POST "https://api.fastino.ai/v1/training/jobs" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  -d '{
    "model_name": "my-trained-model",
    "base_model": "MODEL_ID_FROM_CATALOG",
    "datasets": [
      {"name": "my-ready-dataset", "version": "VERSION_NUMBER"}
    ],
    "training_type": "lora"
  }'
```

保存返回的 `id`。它就是所有任务专属路由使用的 `job_id`。仅在重试完全相同的创建请求时复用同一个 `Idempotency-Key`。

### 6. 轮询任务

```bash
curl "https://api.fastino.ai/v1/training/jobs/JOB_ID" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

对于配置任务：

- `status` 是持久化的生命周期值，例如 `errored`。
- `normalized_status` 是稳定的轮询值，例如 `failed`。
- `is_terminal_status` 告知客户端何时停止轮询。
- `error_message` 在可用时说明失败原因。

继续轮询，直到 `is_terminal_status` 为 `true`，然后检查最终状态、检查点、日志和部署资格。

## 自定义训练循环

选择一种受支持的接口：

- 原生 JSON 客户端调用
  [`POST /v1/training/jobs/interactive`](/cn/api-reference/training-jobs/interactive/create)，
  在 `/v1/training/jobs/{job_id}` 下排队模型操作，并轮询返回的每个
  `operation_id`，直到状态变为 `completed`、`failed` 或 `cancelled`。
- 现有 Tinker 程序保留 `tinker==0.32.0`，并使用下面的设置。

原生客户端不发送 `seq_id` 或心跳。服务器分配操作顺序并保持内部会话处于活动状态。
带有 `wait=true` 的请求最多等待 25 秒，因此客户端必须继续轮询未终止的操作。原生路由
顺序请参阅[构建自定义训练循环](/cn/training/training-loop)。

### 原生 JSON 路径

1. 使用 `base_model`，或使用 `from_checkpoint` 和 `load_optimizer`，调用
   [`POST /v1/training/jobs/interactive`](/cn/api-reference/training-jobs/interactive/create)。
2. 通过[获取操作](/cn/api-reference/training-jobs/interactive/get-operation)轮询返回的创建
   `operation_id`，直到状态变为 `completed`、`failed` 或 `cancelled`。
3. 排队 [forward-backward](/cn/api-reference/training-jobs/interactive/forward-backward)
   和[优化器步骤](/cn/api-reference/training-jobs/interactive/optim-step)。在执行下一个依赖步骤
   之前，将每个 `operation_id` 轮询到终止状态。
4. [保存采样器权重](/cn/api-reference/training-jobs/interactive/save-checkpoint)，并将保存操作
   轮询到终止状态。
5. 通过共享的[停止操作](/cn/api-reference/training-jobs/stop)停止任务。
6. 停止后，[从已保存的检查点采样](/cn/api-reference/training-jobs/interactive/sample)，然后将
   采样操作轮询到终止状态。

只有已排队或正在运行的 sample 操作可以取消。HTTP 拒绝表示服务器没有将操作排队。
已排队的操作可能改为以 `status: "failed"` 结束。

### Tinker SDK 路径

Tinker 路径需要 Python 3.11 或更高版本。请勿构造私有兼容性子路由。

### 3. 安装经过测试的客户端

<CodeGroup>

```bash uv
uv init fastino-training
cd fastino-training
uv add "tinker==0.32.0"
```

```bash pip
mkdir fastino-training && cd fastino-training
python -m venv .venv
source .venv/bin/activate
pip install "tinker==0.32.0"
```

```powershell pip · Windows
mkdir fastino-training
cd fastino-training
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install "tinker==0.32.0"
```

</CodeGroup>

### 4. 配置客户端

每次请求令牌时都会执行 `TINKER_CREDENTIAL_CMD`，该命令必须打印一个非空凭据。

<CodeGroup>

```bash macOS/Linux
export TINKER_BASE_URL="https://api.fastino.ai/v1/training/compat/tinker"
export TINKER_CREDENTIAL_CMD='printf "%s\n" "$FASTINO_API_KEY"'
```

```powershell Windows
$env:TINKER_BASE_URL = "https://api.fastino.ai/v1/training/compat/tinker"
$env:TINKER_CREDENTIAL_CMD = 'powershell -NoProfile -Command "[Console]::Out.WriteLine($env:FASTINO_API_KEY)"'
```

</CodeGroup>

使用以 `fast_sk_` 开头的普通 Fastino 密钥。以 `tml-` 开头的凭据会被拒绝。
不要设置 `TINKER_API_KEY`。

### 5. 选择已启用的模型

调用 `ServiceClient.get_server_capabilities()` 选择已启用的模型。Capabilities
仅报告模型名称和上下文长度，不报告 LoRA 秩、优化器、损失函数、可选方法或操作限制。
Fastino 当前接受 1 到 32 的 LoRA 秩，默认值为 32。

<CodeGroup>

```bash macOS/Linux
export FASTINO_TRAINING_MODEL="<model from capabilities>"
export FASTINO_TRAINING_LORA_RANK="32"
```

```powershell Windows
$env:FASTINO_TRAINING_MODEL = "<model from capabilities>"
$env:FASTINO_TRAINING_LORA_RANK = "32"
```

</CodeGroup>

### 6. 创建任务并采样

创建 `quickstart.py`：

```python
import os

import tinker


service_client = tinker.ServiceClient()
outcome = "errored"
try:
    capabilities = service_client.get_server_capabilities()
    print(capabilities)

    training_client = service_client.create_lora_training_client(
        base_model=os.environ["FASTINO_TRAINING_MODEL"],
        rank=int(os.environ["FASTINO_TRAINING_LORA_RANK"]),
    )

    job_id = training_client.get_info().model_id
    print(f"TRAINING_JOB_ID={job_id}")

    checkpoint = training_client.save_weights_for_sampler(
        "quickstart-sampler",
        ttl_seconds=24 * 60 * 60,
    ).result()
    sampling_client = service_client.create_sampling_client(
        model_path=checkpoint.path
    )

    tokenizer = sampling_client.get_tokenizer()
    prompt_tokens = tokenizer.apply_chat_template(
        conversation=[
            {
                "role": "user",
                "content": "Explain the purpose of a reward function in one sentence.",
            }
        ],
        add_generation_prompt=True,
        return_dict=False,
    )
    result = sampling_client.sample(
        prompt=tinker.types.ModelInput.from_ints(prompt_tokens),
        num_samples=1,
        sampling_params=tinker.types.SamplingParams(max_tokens=64),
    ).result()

    print(tokenizer.decode(result.sequences[0].tokens))
except KeyboardInterrupt:
    outcome = "interrupted"
    raise
else:
    outcome = "success"
finally:
    service_client.close(outcome).result()
```

运行脚本：

```bash
python quickstart.py
```

复制 `TRAINING_JOB_ID=` 后打印的值。

### 7. 验证规范任务

<CodeGroup>

```bash macOS/Linux
export TRAINING_JOB_ID="<ID printed by quickstart.py>"
curl --fail-with-body \
  -H "X-API-Key: $FASTINO_API_KEY" \
  "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID"
```

```powershell Windows
$env:TRAINING_JOB_ID = "<ID printed by quickstart.py>"
Invoke-RestMethod `
  -Headers @{ "X-API-Key" = "$env:FASTINO_API_KEY" } `
  -Uri "https://api.fastino.ai/v1/training/jobs/$env:TRAINING_JOB_ID"
```

</CodeGroup>

响应描述的任务与 `create_lora_training_client(...)` 创建的任务相同。继续使用 SDK
客户端执行模型操作，并使用规范任务 API 执行有文档说明的任务读取。原生 JSON 客户端
使用公开的交互式操作页面。
