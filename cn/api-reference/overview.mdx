本指南将带你以最快的方式完成可用的 Fastino 集成。完成后，你将成功发起一次推理调用，并了解 API 的整体结构。你只需要一个 Fastino 账户和一个终端。

<Steps>
  <Step title="注册并获取 API 密钥">
    在 [Fastino](https://fastino.ai) 创建账户。

    登录后，前往 **Settings → API Keys** 并生成新密钥。请将其复制并妥善保存，因为关闭对话框后将无法再次查看。

    <Warning>
      请勿将 API 密钥提交到版本控制中。请使用环境变量或密钥管理工具，而不是在源文件中硬编码。
    </Warning>

    将密钥设置为环境变量，以便下面的示例可以直接运行：

    ```bash
    export FASTINO_API_KEY="your_api_key_here"
    ```
  </Step>

  <Step title="列出可用的基础模型（可选）">
    使用 `GET /v1/base-models` 浏览 Fastino 提供的模型。

    <CodeGroup>

    ```bash curl
    curl https://api.fastino.ai/v1/base-models \
      -H "X-API-Key: $FASTINO_API_KEY"
    ```

    ```python Python
    import os
    import requests

    response = requests.get(
        "https://api.fastino.ai/v1/base-models",
        headers={"X-API-Key": os.environ["FASTINO_API_KEY"]},
    )
    response.raise_for_status()
    print(response.json())
    ```

    ```javascript JavaScript
    const response = await fetch(
      "https://api.fastino.ai/v1/base-models",
      {
        headers: {
          "X-API-Key": process.env.FASTINO_API_KEY
        }
      }
    );

    if (!response.ok) {
      throw new Error(`Model request failed: ${response.status}`);
    }

    console.log(await response.json());
    ```

    </CodeGroup>

    响应会列出可传递给 `/v1/chat/completions` 的模型 ID。例如，`fastino/gliner2-base-v1` 是用于抽取任务的 GLiNER 基础模型。
  </Step>

  <Step title="发起第一次推理调用">
    调用 `POST /v1/chat/completions`，并传入模型、消息以及定义抽取内容的 schema。本示例使用 GLiNER 从一个句子中抽取命名实体。

    <CodeGroup>

    ```bash curl
    curl -X POST "https://api.fastino.ai/v1/chat/completions" \
      -H "Authorization: Bearer $FASTINO_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "fastino/gliner2.5-multi-v1",
        "messages": [
          {
            "role": "user",
            "content": "Apple announced the MacBook Pro at WWDC in Cupertino."
          }
        ],
        "schema": {
          "entities": [
            {
              "name": "organization",
              "description": "business or institution name"
            },
            {
              "name": "product",
              "description": "named commercial product"
            },
            {
              "name": "event",
              "description": "named conference or event"
            },
            {
              "name": "location",
              "description": "city, region, or place"
            }
          ]
        },
        "threshold": 0.5
      }'
    ```

    ```python Python
    import json
    import os

    import requests

    response = requests.post(
        "https://api.fastino.ai/v1/chat/completions",
        headers={
            "Authorization": f"Bearer {os.environ['FASTINO_API_KEY']}",
            "Content-Type": "application/json",
        },
        json={
            "model": "fastino/gliner2.5-multi-v1",
            "messages": [
                {
                    "role": "user",
                    "content": "Apple announced the MacBook Pro at WWDC in Cupertino.",
                }
            ],
            "schema": {
                "entities": [
                    {"name": "organization", "description": "business or institution name"},
                    {"name": "product", "description": "named commercial product"},
                    {"name": "event", "description": "named conference or event"},
                    {"name": "location", "description": "city, region, or place"},
                ]
            },
            "threshold": 0.5,
        },
    )
    response.raise_for_status()

    result = response.json()
    entities = json.loads(result["choices"][0]["message"]["content"])
    print(json.dumps(entities, indent=2))
    ```

    ```javascript JavaScript
    const response = await fetch(
      "https://api.fastino.ai/v1/chat/completions",
      {
        method: "POST",
        headers: {
          Authorization: `Bearer ${process.env.FASTINO_API_KEY}`,
          "Content-Type": "application/json",
        },
        body: JSON.stringify({
          model: "fastino/gliner2.5-multi-v1",
          messages: [
            {
              role: "user",
              content: "Apple announced the MacBook Pro at WWDC in Cupertino.",
            },
          ],
          schema: {
            entities: [
              { name: "organization", description: "business or institution name" },
              { name: "product", description: "named commercial product" },
              { name: "event", description: "named conference or event" },
              { name: "location", description: "city, region, or place" },
            ],
          },
          threshold: 0.5,
        }),
      }
    );

    if (!response.ok) {
      throw new Error(`Inference failed: ${response.status} ${await response.text()}`);
    }

    const result = await response.json();
    const entities = JSON.parse(result.choices[0].message.content);
    console.log(JSON.stringify(entities, null, 2));
    ```

    </CodeGroup>

    对于 GLiNER 等编码器模型，`schema` 对象用于定义任务，可包含：

    - `entities` — 用于命名实体抽取的实体定义
    - `classifications` — 用于文本分类的 `{task, labels}` 定义
    - `structures` — 用于 JSON 抽取的结构化记录定义
    - `relations` — 关系定义

    对于解码器模型，请省略 `schema`，并发送普通的聊天消息。

    <Note>
      `model` 必须是支持推理的基础模型 ID，或者是已完成且可部署的训练任务的 UUID。训练完成后，请先部署所选工件，再使用该任务 UUID 进行推理。
    </Note>
  </Step>

  <Step title="启动训练任务（可选）">
    当你准备好使用自己的数据进行微调时，请启动训练任务：

    <CodeGroup>

    ```bash curl
    curl -X POST https://api.fastino.ai/v1/training-jobs \
      -H "X-API-Key: $FASTINO_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model_name": "my-ner-model",
        "base_model": "fastino/gliner2-base-v1",
        "datasets": [{"name": "my-dataset"}],
        "training_type": "lora",
        "nr_epochs": 5,
        "learning_rate": 5e-5
      }'
    ```

    ```python Python
    import os
    import requests

    response = requests.post(
        "https://api.fastino.ai/v1/training-jobs",
        headers={
            "X-API-Key": os.environ["FASTINO_API_KEY"],
            "Content-Type": "application/json",
        },
        json={
            "model_name": "my-ner-model",
            "base_model": "fastino/gliner2-base-v1",
            "datasets": [{"name": "my-dataset"}],
            "training_type": "lora",
            "nr_epochs": 5,
            "learning_rate": 5e-5,
        },
    )
    response.raise_for_status()
    print(response.json())
    ```

    </CodeGroup>

    响应中包含任务 `id`。轮询 `GET /v1/training-jobs/{id}` 以检查其状态。任务达到 `complete` 后，请先部署所选工件，再将任务 ID 作为 `/v1/chat/completions` 中的 `model` 使用。

    任务状态依次为 `requested` → `running` → `complete`，或以 `failed` 或 `stopped` 结束。
  </Step>
</Steps>

## 从 Pioneer API 源迁移

如果现有的训练或推理集成调用的是 `https://api.pioneer.ai`，请将其基础 URL 更新为 `https://api.fastino.ai`。

训练路由现在使用 `/v1` 前缀。例如，`/felix/training-jobs` 现在变为 `/v1/training-jobs`，其针对特定任务的操作也保留在这一新路由族下。

兼容 OpenAI 的推理路由本身已以 `/v1` 开头，并保持现有路径不变：`/v1/chat/completions` 仍为 `/v1/chat/completions`，而不是 `/v1/v1/chat/completions`。

直接 API 集成应使用 `FASTINO_API_KEY` 并搭配新生成的 `fast_sk_` 密钥；旧版 `pio_sk_` 密钥已停用。`X-API-Key` 和 Bearer 认证方式均继续有效。
