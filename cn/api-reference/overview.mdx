使用本页选择端点系列。OpenAPI 规范负责方法、路径、身份验证、请求字段和响应架构；指南说明何时以及为何使用它们。

## 身份验证与约定

Fastino 原生端点使用 `X-API-Key: $FASTINO_API_KEY`。兼容端点使用其精确参考页中说明的身份验证。请参阅[身份验证](/cn/api-reference/authentication)和[错误](/cn/api-reference/errors)。

首次进行 GLiDE 决策，请使用[快速入门](/cn/quickstart)。工作流指导请参阅[决策模型](/cn/concepts/glide)、[推理 API](/cn/inference)、[数据集准备](/cn/concepts/datasets)或[训练 API](/cn/training)。
