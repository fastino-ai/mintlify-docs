`POST /v1/gliner-2`

此页面记录 `POST /v1/gliner-2`。OpenAPI 面板是所有请求和响应字段的事实来源。
使用统一的 GLiNER schema；省略已弃用的 `task` 字段。

## 实体提取请求

```json
{
  "text": "Apple CEO Tim Cook introduced the iPhone in Cupertino.",
  "schema": {
    "entities": [
      {"name": "person", "description": "named individual"},
      {"name": "organization", "description": "business or institution"},
      {"name": "product", "description": "named commercial product"},
      {"name": "location", "description": "city, region, or place"}
    ]
  },
  "threshold": 0.5,
  "include_confidence": true,
  "include_spans": true
}
```

`schema` 还支持 `classifications`、`structures` 和 `relations`。完整 schema
和多个示例请参阅 [`POST /v1/chat/completions`](/cn/api-reference/inference/chat-completions)。

## 成功响应

```json
{
  "result": {
    "entities": [
      {
        "text": "Apple",
        "label": "organization",
        "score": 0.99,
        "start": 0,
        "end": 5
      }
    ]
  },
  "token_usage": 10
}
```
