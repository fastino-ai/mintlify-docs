Fastino 提供兼容 Anthropic 的 Messages 端点，让你可以通过 Anthropic SDK 运行 GLiNER 模型。将 `base_url` 设置为 `https://api.fastino.ai`，使用 Fastino API 密钥进行认证，并将 `GET /v1/models` 返回的 GLiNER 模型 ID 或 GLiNER 训练任务 ID 用作模型名称。Anthropic SDK 会自行追加 `/v1/messages`。

## 支持的 SDK 功能

| Anthropic SDK 方法 | Fastino 端点 | GLiNER 结果 |
|---|---|---|
| `client.messages.create(...)` | `POST /v1/messages` | `message.content[0].text` 中的结构化 JSON |

<Warning>
  GLiNER 推理返回一个结构化结果，不支持 `stream=True` 或 `client.messages.stream(...)`。Fastino 并未实现所有 Anthropic API 或 SDK 资源。
</Warning>

## 配置 Anthropic SDK

在构造客户端时传入你的 Fastino API 密钥和基础 URL：

<CodeGroup>

```python Python
import anthropic

client = anthropic.Anthropic(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai"
)
```

</CodeGroup>

## 创建消息

`POST /v1/messages` 接受 Anthropic Messages 的核心字段。将 `model` 设置为受支持的 GLiNER 模型 ID，包含 `messages` 数组，并通过 `extra_body` 传入抽取或分类 `schema`。

### 请求参数

<ParamField body="model" type="string" required>
  训练任务 ID（例如 `job_abc123`）或基础模型 ID。这是处理你请求的模型。
</ParamField>

<ParamField body="max_tokens" type="number" required>
  Anthropic SDK 为保持请求兼容性而要求此字段。GLiNER 返回结构化输出，而不是生成 token。
</ParamField>

<ParamField body="messages" type="object[]" required>
  对话消息。每个对象包含一个 `role`（`"user"` 或 `"assistant"`）和一个 `content` 字符串。
</ParamField>

<ParamField body="schema" type="object">
  Fastino 特有的抽取 schema。定义 `entities`、`classifications`、`structures` 或 `relations` 以控制模型抽取的内容。完整的 schema 文档请参阅 [Fastino 推理](/cn/api-reference/inference/pioneer)。
</ParamField>

### 示例

<CodeGroup>

```python Python (Anthropic SDK)
import anthropic

client = anthropic.Anthropic(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai"
)

message = client.messages.create(
    model="YOUR_TRAINING_JOB_ID",
    max_tokens=1024,
    messages=[
        {
            "role": "user",
            "content": "Extract entities from: Apple launched the iPhone."
        }
    ],
    extra_body={
        "schema": {
            "entities": ["organization", "product"]
        }
    }
)

print(message.content[0].text)
```

```bash cURL
curl -X POST https://api.fastino.ai/v1/messages \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_TRAINING_JOB_ID",
    "max_tokens": 1024,
    "messages": [
      {
        "role": "user",
        "content": "Extract entities from: Apple launched the iPhone."
      }
    ],
    "schema": {
      "entities": ["organization", "product"]
    }
  }'
```

</CodeGroup>

## 重试 425 响应

模型临时预热期间，首次请求可能返回 `425`。在 `/v1/messages` 上，该响应带有 `x-should-retry: false`，因此官方 Anthropic SDK 不会自动重试。响应体使用 Anthropic 错误格式，`error.type` 为 `"invalid_request_error"`；参见 [425 - 过早 (Too Early)](/cn/api-reference/errors#425-过早-too-early)。

捕获该错误，等待 `Retry-After` 秒（如果缺少该响应头则等待 30 秒），然后重新发送相同的请求：

```python Python (Anthropic SDK)
import time
import anthropic

MAX_RETRIES = 5

for attempt in range(MAX_RETRIES + 1):
    try:
        message = client.messages.create(
            model="YOUR_TRAINING_JOB_ID",
            max_tokens=1024,
            messages=[{"role": "user", "content": "Extract entities from: Apple launched the iPhone."}],
            extra_body={"schema": {"entities": ["organization", "product"]}},
        )
        break
    except anthropic.APIStatusError as error:
        if error.status_code != 425 or attempt == MAX_RETRIES:
            raise
        retry_after = error.response.headers.get("retry-after", "")
        time.sleep(int(retry_after) if retry_after.isdigit() else 30)
```

## 流式传输

GLiNER 推理不支持流式传输。请使用不带 `stream=True` 的 `client.messages.create(...)`；API 会在处理输入后返回完整的结构化结果。
