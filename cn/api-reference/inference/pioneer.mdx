`POST /inference` 已被移除。

请使用 `POST /v1/chat/completions` 进行托管的 GLiNER 推理。当前请求使用
`Authorization: Bearer $FASTINO_API_KEY`，并包含顶层的 `model`、`messages` 和 `schema`
字段。

有关标准的请求、响应和迁移指南，请参阅 [`/v1/chat/completions`](/cn/inference/chat-completions)。
