`GET /v1/gliner-2/jobs/{job_id}`

此页面记录 `GET /v1/gliner-2/jobs/{job_id}`。OpenAPI 面板是路径参数和所有响应字段的事实来源。
请使用提交作业时使用的同一 API 密钥。

## 请求

```bash
curl "https://api.fastino.ai/v1/gliner-2/jobs/3f08a17f-777a-4aa6-8ec5-879df37775a8" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

## 等待中的响应

当 `status` 为 `pending` 或 `processing` 时继续轮询：

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "pending",
  "result": null,
  "error": null,
  "token_usage": 1284307,
  "created_at": "2026-10-07T22:10:00+00:00",
  "completed_at": null
}
```

## 完成响应

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "complete",
  "result": {
    "entities": [
      {"text": "Apple", "label": "organization", "score": 0.99, "start": 0, "end": 5}
    ]
  },
  "error": null,
  "token_usage": 1284307,
  "created_at": "2026-10-07T22:10:00+00:00",
  "completed_at": "2026-10-07T22:13:42+00:00"
}
```

失败的作业返回 `status: "error"`，并在 `error` 中提供消息。未知或属于其他用户的作业返回 `404`。
