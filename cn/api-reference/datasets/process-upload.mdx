`POST /v1/datasets/upload/process`

此页面记录 `POST /v1/datasets/upload/process`。请求参数、响应架构和认证要求以 OpenAPI 规范为准。

## 异步处理

成功请求返回 `202` 并将处理任务加入队列；这不表示数据集已经就绪。轮询
[`GET /v1/datasets/{name}`](/cn/api-reference/datasets/versions)，选择创建上传 URL
时返回的准确 `version_number`，直到其 `status` 变为 `ready` 或 `failed`。
如果失败，请先读取 `processing_error`，再修正文件并上传新版本。

`503` 表示在处理开始前存储验证或排队失败，可以重试处理同一上传。

## 授权

需要团队的 Owner、Admin 或 Editor 角色。其他角色会收到 `403 Forbidden`。
