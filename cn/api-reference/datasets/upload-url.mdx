`POST /v1/datasets/upload/url`

此页面记录 `POST /v1/datasets/upload/url`。请求参数、响应架构和认证要求以 OpenAPI 规范为准。

## 上传文件

请在 `presigned_url` 过期前上传文件的精确字节。签名请求要求
`Content-Type: application/octet-stream`；省略该请求头或使用其他值会返回 `403`。

```bash
curl --fail-with-body -X PUT \
  -H "Content-Type: application/octet-stream" \
  --upload-file training.jsonl "$PRESIGNED_URL"
```

上传成功后，将返回的 `dataset_id` 传给
[`POST /v1/datasets/upload/process`](/cn/api-reference/datasets/process-upload)。

## 授权

需要团队的 Owner、Admin 或 Editor 角色。其他角色会收到 `403 Forbidden`。
