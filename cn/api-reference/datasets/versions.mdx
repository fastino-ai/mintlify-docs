`GET /v1/datasets/{name}`

此页面记录 `GET /v1/datasets/{name}`。请求参数、响应架构和认证要求以 OpenAPI 规范为准。

## 处理状态

响应包含 `success`、`versions` 和 `count`。轮询最近的上传时，请精确匹配
`version_number`。只有 `status` 为 `ready` 的版本才能用于训练；`failed`
版本包含 `processing_error`。
