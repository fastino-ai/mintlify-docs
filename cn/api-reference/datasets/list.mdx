`GET /v1/datasets`

此页面记录 `GET /v1/datasets`。请求参数、响应架构和认证要求以 OpenAPI 规范为准。

## 结果行为

默认情况下，响应仅包含每个数据集名称的最新版本，并排除失败的上传。设置
`include_all_versions=true` 可返回所有版本；设置 `include_failed=true` 可包含你自己的失败上传。

结果按时间从新到旧排列。`limit` 默认为 200，且最大为 200；使用 `offset` 请求后续页面。
