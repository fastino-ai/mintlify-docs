`POST /v1/training/jobs/{job_id}/load-weights`

将该任务的某个 `weights/<name>` 检查点恢复到同一任务中，例如回滚一次不理想的更新。若要在新任务中继续，请将其路径作为 `from_checkpoint` 传给 [`POST /v1/training/jobs/create-model`](/cn/api-reference/interactive-jobs/create)。

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  交互式任务 ID。
</ParamField>

<ParamField body="path" type="string" required>
  该任务保存的状态检查点名称，或其 `tinker://<job_id>/weights/<name>` 路径。
</ParamField>

<ParamField body="optimizer" type="boolean" default="false">
  同时恢复优化器状态。
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/load-weights" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"path": "step-000100", "optimizer": true}'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "load"
}
```

</ResponseExample>
