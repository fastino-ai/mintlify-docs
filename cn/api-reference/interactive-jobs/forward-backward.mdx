`POST /v1/training/jobs/{job_id}/forward-backward`

计算一批 token 级 datum 的损失并累积梯度，下一次[优化器步骤](/cn/api-reference/interactive-jobs/optim-step)
会应用这些梯度。每个执行工作的调用都会返回一个 future。请使用 [`GET /v1/training/jobs/{job_id}/futures/{future_id}`](/cn/api-reference/interactive-jobs/get-future) 读取结果。
[`POST /v1/training/jobs/{job_id}/forward`](/cn/api-reference/interactive-jobs/forward) 接受相同的请求体，但不计算梯度。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  交互式任务 ID。
</ParamField>

<ParamField body="datums" type="object[]" required>
  一个或多个训练样本，请使用基础模型的 tokenizer 自行分词。每个 datum 包含
  `model_input`（`{"chunks": [{"type": "encoded_text", "tokens": [...]}]}`，共 N 个 token）和
  `loss_fn_inputs`（每个张量为 `{"data": [...], "dtype": "int64" | "float32"}`，各含 N 个值）：
  必填的 `target_tokens`（`int64`）；可选的 `weights`（`float32`，提示位置为 `0`，补全位置为 `1`）；
  除 `cross_entropy` 外的所有损失函数都需要 `logprobs` 和 `advantages`（`float32`）。
</ParamField>

<ParamField body="loss_fn" type="string" default="cross_entropy">
  `cross_entropy`、`importance_sampling`、`ppo`、`cispo` 或 `dro`。
</ParamField>

<ParamField body="loss_fn_config" type="object">
  损失函数设置。`ppo` 和 `cispo` 接受 `clip_low_threshold` 与 `clip_high_threshold`；`dro` 接受 `beta`。
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/forward-backward" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "loss_fn": "cross_entropy",
    "datums": [
      {
        "model_input": {"chunks": [{"type": "encoded_text", "tokens": [151644, 872, 198, 3838]}]},
        "loss_fn_inputs": {
          "target_tokens": {"data": [872, 198, 3838, 30], "dtype": "int64"},
          "weights": {"data": [0, 0, 1, 1], "dtype": "float32"}
        }
      }
    ]
  }'
```

</RequestExample>
