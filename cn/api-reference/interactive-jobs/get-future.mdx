`GET /v1/training/jobs/{job_id}/futures/{future_id}`

读取 future，直到其 `status` 为 `completed`、`failed` 或 `cancelled`。结果保留一小时。
使用 `wait=true` 时，请求最多等待 25 秒。

- `type`：`create`、`load`、`forward`、`forward_backward`、`optim_step`、`save` 或 `sample`。
- `result`（`completed` 时）：forward 类操作返回 `loss_fn_outputs` 和 `metrics`；`sample` 返回
  `sequences`（每项含 `tokens`、`logprobs`、`stop_reason`）；`save` 返回检查点路径。
- `error`（`failed` 或 `cancelled` 时）：`message` 和 `category`（`user` 或 `server`）。

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/futures/$FUTURE_ID?wait=true" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
