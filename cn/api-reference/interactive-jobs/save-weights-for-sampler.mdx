`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

以 `sampler_weights/<name>` 保存任务的 LoRA 权重。可以从中[采样](/cn/api-reference/interactive-jobs/sample)（任务停止后同样可以），或作为 PEFT LoRA 文件[下载](/cn/api-reference/training-jobs/download-checkpoint)。它不含优化器状态，因此任务无法加载它或从它启动；如需这样做，请使用 [`POST /v1/training/jobs/{job_id}/save-weights`](/cn/api-reference/interactive-jobs/save-weights)。

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  交互式任务 ID。
</ParamField>

<ParamField body="name" type="string" required>
  1–128 个字符，取自 `A-Z`、`a-z`、`0-9`、`.`、`_` 和 `-`。
</ParamField>

<ParamField body="ttl_seconds" type="integer | null">
  在指定秒数后自动删除检查点，范围为 `3600`（1 小时）到 `315360000`（10 年）。省略则保留到你删除为止。
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/save-weights-for-sampler" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "step-000100", "ttl_seconds": 86400}'
```

</RequestExample>

响应包含 `save` future 的 `future_id`、`checkpoint_id` 和 `path`。

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "save",
  "checkpoint_id": "sampler_weights/step-000100",
  "path": "tinker://SESSION_ID:train:0/sampler_weights/step-000100"
}
```

</ResponseExample>
