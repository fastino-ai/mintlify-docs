`POST /v1/training/jobs/{job_id}/save-weights`

以 `weights/<name>` 保存任务的 LoRA 权重和优化器状态。可以将其[加载](/cn/api-reference/interactive-jobs/load-weights)回同一任务，或从它[创建新任务](/cn/api-reference/interactive-jobs/create)。要采样或下载权重，请改用 [`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`](/cn/api-reference/interactive-jobs/save-weights-for-sampler) 保存。

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  交互式任务 ID。
</ParamField>

<ParamField body="name" type="string" required>
  1–128 个字符，取自 `A-Z`、`a-z`、`0-9`、`.`、`_` 和 `-`。
</ParamField>

<ParamField body="ttl_seconds" type="integer | null">
  在指定秒数后自动删除检查点，范围为 `3600`（1 小时）到 `315360000`（10 年）。省略则保留到你删除为止。
</ParamField>

<ParamField body="overwrite" type="boolean" default="false">
  替换同名的状态检查点。
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/save-weights" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "step-000100"}'
```

</RequestExample>

响应包含 `save` future 的 `future_id`、`checkpoint_id` 和 `path`。创建任务时，将 `path` 作为 `from_checkpoint` 传入。

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "save",
  "checkpoint_id": "weights/step-000100",
  "path": "tinker://SESSION_ID:train:0/weights/step-000100"
}
```

</ResponseExample>
