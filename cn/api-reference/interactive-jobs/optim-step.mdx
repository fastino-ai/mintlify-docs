`POST /v1/training/jobs/{job_id}/optim-step`

使用 AdamW 应用自上一步以来 forward-backward 累积的梯度。任务按接收顺序运行 operation，
因此可以在 forward-backward 之后立即排队，无需等待。

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  交互式任务 ID。
</ParamField>

<ParamField body="adam_params" type="object">
  可选的 AdamW 参数：`learning_rate`（默认 `0.0001`）、`beta1`（`0.9`）、`beta2`（`0.95`）、
  `eps`（`1e-12`）、`weight_decay`（`0`）、`grad_clip_norm`（`0`，即不裁剪）。
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/optim-step" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"adam_params": {"learning_rate": 0.0001}}'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "optim_step"
}
```

</ResponseExample>
