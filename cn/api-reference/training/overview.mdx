使用这些契约查看字段级细节。构建端到端训练流程时，请从生命周期指南开始。

公共 REST API 包括：

- 基础模型发现和数据集管理
- 使用 `POST /v1/training/jobs` 创建托管式 `config` 任务
- 在 `/v1/training/jobs` 下管理 `config` 和 `interactive` 任务的规范生命周期

对于自定义循环的模型操作，请通过受支持的 Tinker SDK 访问训练 API。
SDK 在 `/v1/training/compat/tinker` 使用的 HTTP 接口不会出现在 OpenAPI 中，
也不是供客户直接编写请求的 REST 契约。Auto Train 仍为私有访问且没有公共 API 契约。
