使用这些契约查看字段级细节。构建端到端训练流程时，请从生命周期指南开始。

公共 REST API 包括：

- 基础模型发现和数据集管理
- 使用 `POST /v1/training/jobs` 为 GLiNER 编码器创建托管式 `config` 任务
- 面向解码器训练的[交互式任务](/cn/api-reference/training-jobs/interactive/create-model)：先调用
  `POST /v1/training/jobs/create-model`，再在 `/v1/training/jobs/{job_id}` 下执行 forward-backward、优化器步骤、检查点和采样
- 在 `/v1/training/jobs` 下管理 `config` 和 `interactive` 任务的规范生命周期

Auto Train 仍为私有访问且没有公共 API 契约。
