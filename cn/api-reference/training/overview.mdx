使用这些契约查看字段级细节。构建端到端训练流程时，请从生命周期指南开始。

公共 REST API 包括：

- 基础模型发现和数据集管理
- 使用 `POST /v1/training/jobs` 创建托管式 `config` 任务
- 在 `/v1/training/jobs` 下管理 `config` 和 `interactive` 任务的规范生命周期

原生 JSON 客户端使用 OpenAPI 中 `/v1/training/jobs` 和 `/v1/training/usage` 下的公共操作。现有 Tinker 客户端保留 `tinker==0.32.0`，并仅设置 `TINKER_BASE_URL=https://api.fastino.ai/v1/training/compat/tinker` 和 `TINKER_CREDENTIAL_CMD`。请勿构造私有兼容性子路由。
