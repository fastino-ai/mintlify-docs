每个实战示例都是针对一项常见任务的可运行请求。示例展示请求和响应 schema、来自线上 API 的真实响应，以及根据结果执行操作的代码。复制一个示例，换成你自己的数据，再调整 criteria 或标签即可。

GLiNER 实战示例涵盖团队使用 GLiNER 2.5 Multilingual 最常见的三种方式：实体提取、分类和关系抽取。
