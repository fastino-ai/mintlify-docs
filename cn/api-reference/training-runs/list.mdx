`GET /v1/training-runs`

按从新到旧的顺序返回已认证调用方可见的训练运行。训练运行是您通过兼容 Tinker 的 SDK 创建并逐步驱动的训练。将 SDK 的 `base_url` 设置为 `https://api.fastino.ai/v1/training-runs/sdk`，并使用您的 Fastino API 密钥进行身份验证。您可以看到自己的运行，以及团队在您有权访问的项目中的运行。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField query="limit" type="integer" default="20">
  每页大小。取值会被限制在 `1` 到 `1000` 之间。
</ParamField>

<ParamField query="offset" type="integer" default="0">
  要跳过的运行数量。
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training-runs?limit=20&offset=0" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## 响应

<ResponseField name="success" type="boolean">
  请求是否成功。
</ResponseField>

<ResponseField name="training_runs" type="object[]">
  本页的训练运行。每个运行包含[获取训练运行](/cn/api-reference/training-runs/get)中描述的字段。
</ResponseField>

<ResponseField name="count" type="integer">
  本页中的运行数量。
</ResponseField>

<ResponseField name="total" type="integer">
  分页前可见运行的总数。
</ResponseField>

<ResponseField name="has_more" type="boolean">
  此页之后是否还有下一页。
</ResponseField>
