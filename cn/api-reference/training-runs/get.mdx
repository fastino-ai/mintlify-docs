`GET /v1/training-runs/{run_id}`

返回调用方可见的单个训练运行，以及其最新的训练状态检查点和采样检查点。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="run_id" type="string" required>
  训练运行 ID。即兼容 Tinker 的 SDK 在创建训练客户端时返回的模型 ID，格式为 `SESSION_ID:train:N`。
</ParamField>

<RequestExample>

```bash cURL
curl https://api.fastino.ai/v1/training-runs/YOUR_RUN_ID \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## 响应

<ResponseField name="training_run_id" type="string">
  训练运行 ID。
</ResponseField>

<ResponseField name="base_model" type="string">
  该运行训练的基础模型。
</ResponseField>

<ResponseField name="model_owner" type="string">
  拥有该运行的团队 ID。
</ResponseField>

<ResponseField name="is_lora" type="boolean">
  该运行是否训练 LoRA 适配器。
</ResponseField>

<ResponseField name="corrupted" type="boolean">
  该运行的训练状态是否不可用，且无法再执行训练步骤。
</ResponseField>

<ResponseField name="lora_rank" type="integer | null">
  LoRA 秩（当该运行训练 LoRA 适配器时）。
</ResponseField>

<ResponseField name="last_request_time" type="string">
  该运行最近一次 SDK 请求的 ISO 8601 时间戳。
</ResponseField>

<ResponseField name="last_checkpoint" type="object | null">
  最新的训练状态检查点，或 `null`。检查点字段见[列出训练运行检查点](/cn/api-reference/training-runs/list-checkpoints)。
</ResponseField>

<ResponseField name="last_sampler_checkpoint" type="object | null">
  最新的采样权重检查点，或 `null`。
</ResponseField>

<ResponseField name="user_metadata" type="object | null">
  创建运行时附加的字符串键值元数据。
</ResponseField>
