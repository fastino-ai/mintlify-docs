`POST /v1/training/jobs`

创建一个异步 `config` 训练任务并返回其任务记录。在配置任务中，您提供数据集和配置，由 Fastino 运行训练循环。如需逐步控制训练循环，请按照[自定义训练循环路径](/cn/training/decoder-quickstart)操作：该路径通过 [`POST /v1/training/jobs/create-model`](/cn/api-reference/training-jobs/interactive/create-model) 或受支持的 Tinker SDK 创建 `interactive` 任务。此端点不会创建交互式任务。创建完成后，两种任务类型都使用各自的规范 ID 调用文档中所述的 `/v1/training/jobs/{job_id}` 生命周期操作。

配置任务可训练由 `GET /v1/base-models?supports_training=true` 返回、且具有兼容配置任务调度路由的编码器模型。解码器基础模型会返回 `400`；请改用交互式任务逐步训练解码器。

此端点限制为每个用户每分钟 20 次请求。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  客户端生成的重试键，长度为 1–255 个字符，建议使用 UUID。使用相同键和请求体重试会返回原任务；同一键配合不同请求体会返回 `422`。
</ParamField>

<ParamField body="model_name" type="string" required>
  训练模型的显示名称。长度：1–100 个字符。
</ParamField>

<ParamField body="base_model" type="string" required>
  `GET /v1/base-models?supports_training=true` 返回的可训练编码器 ID，或受支持的检查点 UUID。所选 `training_type` 必须具有兼容的调度路由。解码器基础模型会返回 `400`。
</ParamField>

<ParamField body="datasets" type="object[]" required>
  一个或多个[已上传数据集](/cn/concepts/datasets)引用。每项需要 `name`，可包含 `version`；省略 version 时会解析为最新版本。
</ParamField>

<ParamField body="training_type" type="string" default="lora">
  `lora` 或 `full`。所选基础模型必须支持所请求的训练类型。
</ParamField>

<ParamField body="validation_data_percentage" type="number" default="0.2">
  用于验证的留出比例，取值范围从 `0` 到 `0.9`，步长为 `0.01`。
</ParamField>

<ParamField body="nr_epochs" type="integer" default="100">
  最大 epoch 数，范围为 `1` 到 `10000`；早停可能会更早结束。
</ParamField>

<ParamField body="learning_rate" type="number">
  峰值学习率，范围为 `1e-8` 到 `1`。省略时使用所选模型的训练配方。
</ParamField>

<ParamField body="batch_size" type="integer" default="4">
  单设备批大小，范围为 `1` 到 `256`。建议省略此项，让训练服务应用或安全地限制到模型特定的默认值。
</ParamField>

<ParamField body="seed" type="integer">
  可选的可复现性种子，取值从 `0` 到 `2147483647`。使用时请将 `provider_name` 设为 `modal`。种子可以减少一种变化源，但并不保证 GPU 运行结果按位一致。
</ParamField>

<ParamField body="project_id" type="string">
  项目 UUID。省略时，Fastino 会将任务关联到调用者的默认项目。
</ParamField>

<Expandable title="其他训练参数">
  <ParamField body="save_steps" type="integer" default="100">
    每 N 步保存一次检查点，N 的范围为 `1` 到 `2147483647`。
  </ParamField>

  <ParamField body="profile_training" type="boolean" default="false">
    持久化一个结构化的训练性能剖析工件。
  </ParamField>

  <ParamField body="wandb_api_key" type="string">
    可选的 Weights & Biases API 密钥。请将其视为机密信息，切勿放入源代码、日志或示例中。
  </ParamField>

  <ParamField body="lora_r" type="integer">
    LoRA 秩，范围为 `1` 到 `256`。省略时使用模型配方。
  </ParamField>

  <ParamField body="lora_alpha" type="integer">
    正整数 LoRA alpha，最大为 `2147483647`。省略时使用模型配方。
  </ParamField>

  <ParamField body="lora_dropout" type="number">
    LoRA dropout，范围从 `0`（含）到 `1`（不含）。省略时使用模型配方。
  </ParamField>

  <ParamField body="warmup_ratio" type="number">
    预热比例，取值从 `0` 到 `1`。`warmup_steps` 优先生效。
  </ParamField>

  <ParamField body="warmup_steps" type="integer">
    绝对预热步数，范围为 `1` 到 `2147483647`。
  </ParamField>

  <ParamField body="lr_scheduler_type" type="string" default="cosine">
    学习率调度：`constant`、`linear` 或 `cosine`。
  </ParamField>

  <ParamField body="weight_decay" type="number" default="0.01">
    非负的 AdamW 权重衰减。
  </ParamField>

  <ParamField body="early_stopping_patience" type="integer" default="3">
    停止前允许验证 epoch 未改进的次数，范围为 `0` 到 `10000`。设为 `0` 可禁用。
  </ParamField>

  <ParamField body="early_stopping_min_delta" type="number" default="0.0001">
    视为有进展的非负最小验证损失改进量。
  </ParamField>

  <ParamField body="provider_name" type="string">
    锁定兼容的训练提供方。省略时会自动选择。
  </ParamField>

  <ParamField body="encoder_learning_rate" type="number">
    GLiNER 编码器学习率，范围为 `1e-8` 到 `1`。缺省时回退到 `learning_rate`。
  </ParamField>

  <ParamField body="task_learning_rate" type="number">
    GLiNER 任务头学习率，范围为 `1e-8` 到 `1`。缺省时回退到 `learning_rate`。
  </ParamField>

  <ParamField body="gradient_accumulation_steps" type="integer">
    正整数的小批量累积次数，最大为 `2147483647`。
  </ParamField>

  <ParamField body="auto_data_sizing" type="boolean">
    启用 GLiNER 数据集自动调整规模。
  </ParamField>

  <ParamField body="min_samples_per_dataset" type="integer">
    GLiNER 自动调整规模下限，范围为 `1` 到 `2147483647`。
  </ParamField>

  <ParamField body="max_samples_per_dataset" type="integer">
    GLiNER 自动调整规模上限，范围为 `1` 到 `2147483647`。
  </ParamField>

  <ParamField body="samples_per_label" type="integer">
    GLiNER 每个标签的自动调整规模系数，范围为 `1` 到 `2147483647`。
  </ParamField>

  <ParamField body="min_training_steps" type="integer">
    GLiNER 最小优化器步数，范围为 `0` 到 `2147483647`。
  </ParamField>

  <ParamField body="eval_steps" type="integer">
    GLiNER2 周期验证间隔，范围为 `1` 到 `2147483647` 个优化器步。省略时仅在 epoch 结束时验证。
  </ParamField>

  <ParamField body="max_eval_samples" type="integer">
    GLiNER2 周期验证中每个数据集的样本上限，范围为 `1` 到 `2147483647`。省略时不设上限。
  </ParamField>

  <ParamField body="max_length" type="integer">
    GLiNER 最大输入长度，范围为 `1` 到 `2147483647` 个 token。省略时使用模型上下文限制。
  </ParamField>

  <ParamField body="max_gold_per_query" type="integer">
    GLiNER2 每个查询保留的 gold span 上限，范围为 `1` 到 `1024`。省略时使用 `32`。
  </ParamField>

  <ParamField body="on_capacity_exceeded" type="string">
    GLiNER2 在 gold span 超过 `max_gold_per_query` 时的行为：`raise`、`truncate_with_warning` 或 `skip_sample`。省略时使用 `raise`。
  </ParamField>

  <ParamField body="training_algorithm" type="string" default="sft">
    配置任务仅支持 `sft`。省略则使用默认值。
  </ParamField>

</Expandable>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Idempotency-Key: YOUR_UNIQUE_RETRY_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model_name": "my-model-name",
    "base_model": "fastino/gliner2-base-v1",
    "datasets": [{"name": "my-ready-dataset"}],
    "training_type": "lora",
    "nr_epochs": 5,
    "learning_rate": 5e-5,
    "validation_data_percentage": 0.2
  }'
```

</RequestExample>

## 响应

返回 `200` 及完整的训练任务记录，其中包含 UUID `id` 和初始状态。以下示例经过缩略；实际响应包含 `TrainingJobResponse` 定义的所有字段。

<ResponseExample>

```json Response
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "type": "config",
  "model_name": "my-model-name",
  "base_model": "fastino/gliner2-base-v1",
  "status": "requested",
  "training_type": "lora",
  "nr_epochs": 5,
  "learning_rate": 5e-5,
  "validation_data_percentage": 0.2
}
```

</ResponseExample>

请保存此响应中的 `id`。您将用它来轮询状态、获取指标和工件，以及对训练后的模型运行推理。

请求体格式错误会返回 `422`。有效但不可用的模型、数据集、训练类型或提供方组合会返回请求相关的 `4xx` 错误。

创建操作可能返回以下带错误码的冲突：

| 状态 | 含义 |
| --- | --- |
| `409 duplicate_training_submission` | 已有相同任务处于活动状态。 |
| `409 idempotency_key_job_deleted` | 此幂等键最初创建的任务已删除。新任务请使用新键。 |
| `409` | 引用的数据集在验证与插入任务之间被停用。请处理该数据集问题后使用新键重试。 |

相同 `Idempotency-Key` 和完全相同的请求体会重放原任务，而不是创建新任务。同一键配合不同请求体会返回 `422`。

解码器基础模型会返回 `400`：

```json
{
  "detail": "Decoder training on this route is retired: 'Qwen/Qwen3.6-35B-A3B' cannot be trained here. Train decoders step by step with the training job routes under /v1/training/jobs (see https://docs.fastino.ai/training/quickstart)."
}
```

要训练解码器，请使用 [`POST /v1/training/jobs/create-model`](/cn/api-reference/training-jobs/interactive/create-model)
创建交互式任务，并按照[自定义训练循环](/cn/training/decoder-quickstart)操作。
