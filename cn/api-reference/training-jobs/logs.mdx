---
title: "获取训练日志"
sidebarTitle: "获取日志"
description: "获取 Fastino 训练任务输出日志的时间点快照。"
api: "GET /v1/training-jobs/{job_id}/logs"
noindex: true
---

返回结构化的 stdout 和 stderr 条目。此端点不流式传输;要跟随运行中的任务,请轮询该端点。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  训练任务 UUID。
</ParamField>

<RequestExample>

```bash cURL
curl https://api.fastino.ai/v1/training-jobs/YOUR_TRAINING_JOB_ID/logs \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## 响应

<ResponseField name="job_id" type="string">
  训练任务 UUID。
</ResponseField>

<ResponseField name="logs" type="object[]">
  日志条目。每个条目包含 `id`、`job_id`、`timestamp`、`level`、`message` 和 `source`。
</ResponseField>

<ResponseField name="total_logs" type="integer">
  返回的条目数量。
</ResponseField>

<ResponseExample>

```json Response
{
  "job_id": "YOUR_TRAINING_JOB_ID",
  "logs": [
    {
      "id": "LOG_ID",
      "job_id": "YOUR_TRAINING_JOB_ID",
      "timestamp": "2026-09-22T20:00:00Z",
      "level": "INFO",
      "message": "Epoch 2 completed",
      "source": "trainer"
    }
  ],
  "total_logs": 1
}
```

</ResponseExample>

未知或无法访问的任务返回 `404`。
