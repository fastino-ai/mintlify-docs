`GET /v1/training/jobs/{job_id}/logs`

返回结构化的 `stdout`、`stderr` 和 `system` 条目。此端点不流式传输；要跟踪运行中的任务，请轮询该端点。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  训练任务 UUID。
</ParamField>

<RequestExample>

```bash cURL
curl https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID/logs \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## 响应

<ResponseField name="job_id" type="string">
  训练任务 UUID。
</ResponseField>

<ResponseField name="logs" type="object[]">
  日志条目。每个条目包含 `id`、`job_id`、`timestamp`、`level`、`message` 和 `source`。Fastino 发出的来源为 `stdout`、`stderr` 或 `system`。API schema 将此字段表示为字符串，而不是封闭枚举。
</ResponseField>

<ResponseField name="total_logs" type="integer">
  返回的条目数量。
</ResponseField>

<ResponseExample>

```json Response
{
  "job_id": "YOUR_TRAINING_JOB_ID",
  "logs": [
    {
      "id": "LOG_ID",
      "job_id": "YOUR_TRAINING_JOB_ID",
      "timestamp": "2026-09-22T20:00:00Z",
      "level": "INFO",
      "message": "Epoch 2 completed",
      "source": "stdout"
    }
  ],
  "total_logs": 1
}
```

</ResponseExample>

未知或无法访问的任务返回 `404`。
