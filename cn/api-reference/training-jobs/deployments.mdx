`GET /v1/training/jobs/{job_id}/deployments`

此操作仅适用于配置任务；通过常规功能和权限检查后，使用交互式任务 ID 会返回 `400`。sampler 检查点部署会在其 `status` 中报告初始进度；请将返回的 `model_id` 用于此端点，以列出该服务模型的部署记录。

列出由训练任务创建或与其关联的部署。
