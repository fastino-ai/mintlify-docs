`POST /v1/training/jobs/{job_id}/checkpoints/{checkpoint_id}/deploy`

将一个可部署的检查点部署到托管的多模型推理端点。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  训练任务 UUID。
</ParamField>

<ParamField path="checkpoint_id" type="string" required>
  由检查点列表端点返回的检查点 ID。
</ParamField>

<RequestExample>

```bash cURL
curl -X POST \
  https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID/checkpoints/CHECKPOINT_ID/deploy \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## 响应

<ResponseExample>

```json Response
{
  "success": true,
  "message": "Checkpoint deployed successfully",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "checkpoint_id": "CHECKPOINT_ID",
  "deployment_path": "PROVIDER_MODEL_PATH",
  "mme_path": "PROVIDER_MODEL_PATH"
}
```

</ResponseExample>

`deployment_path` 是规范的已部署对象路径。`mme_path` 是已弃用的兼容性别名。

未知的任务或检查点返回 `404`。不可部署的检查点返回请求相关的 `4xx` 错误。

## 授权

由于此操作会更改实时部署，因此需要团队的 Owner 或 Admin 角色。其他角色会收到 `403 Forbidden`。
