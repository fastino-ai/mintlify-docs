`GET /v1/training/jobs/{job_id}/checkpoints/{checkpoint_id}/download`

返回 `interactive` 任务中某个检查点的短时有效预签名对象存储 URL。sampler 检查点的归档包含解码器适配器文件。配置任务使用
[`GET /v1/training/jobs/{job_id}/download`](/cn/api-reference/training-jobs/download)
下载最终模型工件。

## 请求

<ParamField header="X-API-Key" type="string" required>
  你的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  `POST /v1/training/jobs/create-model` 返回的交互式任务 `job_id`。
</ParamField>

<ParamField path="checkpoint_id" type="string" required>
  检查点列表返回的检查点标识符，例如 `weights/checkpoint-1` 或
  `sampler_weights/checkpoint-1`。请在路径中保留 `/`，不要对整个标识符进行
  URL 编码。
</ParamField>

<RequestExample>

```bash cURL
CHECKPOINT_ID="sampler_weights/checkpoint-1"
curl "https://api.fastino.ai/v1/training/jobs/JOB_ID/checkpoints/$CHECKPOINT_ID/download" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## 响应

响应包含一个 15 分钟后过期的预签名对象存储 URL。请将该 URL 视为凭据：不要记录、分享或持久化存储。

<ResponseField name="success" type="boolean">
  请求是否成功。
</ResponseField>

<ResponseField name="run_id" type="string">
  拥有该检查点的交互式任务。
</ResponseField>

<ResponseField name="checkpoint_id" type="string">
  可下载的交互式检查点标识符。
</ResponseField>

<ResponseField name="download_url" type="string">
  预签名对象存储 URL。获取该 URL 时无需 API 密钥。
</ResponseField>

<ResponseField name="expires_in_seconds" type="integer">
  预签名 URL 的剩余有效期。新链接在 900 秒后过期。
</ResponseField>

<ResponseField name="file_name" type="string">
  归档文件的建议 `.tar` 文件名。
</ResponseField>

<ResponseExample>

```json Response
{
  "success": true,
  "run_id": "session-1:train:0",
  "checkpoint_id": "sampler_weights/checkpoint-1",
  "download_url": "SIGNED_ARCHIVE_URL",
  "expires_in_seconds": 900,
  "file_name": "session-1_train_0-sampler_weights-checkpoint-1.tar"
}
```

</ResponseExample>

检查点下载默认启用。下载访问被明确禁用的团队会收到 `403`。

## 加载解码器适配器

解码器的 sampler 检查点会下载为面向公开基础模型的标准 Hugging Face PEFT 适配器。归档包含 `adapter_config.json`、包含全部已训练张量的 `adapter_model.safetensors`，以及附带加载代码的 `README.md`：

```python
from peft import PeftModel
from transformers import AutoModelForCausalLM

base = AutoModelForCausalLM.from_pretrained("Qwen/Qwen3.6-35B-A3B", dtype="auto")
model = PeftModel.from_pretrained(base, "path/to/extracted/archive")
```

Fastino 使用 transformers 5.19.0 和 peft 0.21.2 测试这些适配器，未在 vLLM 上测试。训练了 Mamba `out_proj` 的 Nemotron 3.5 Lightning 适配器需要在 PEFT 加载前添加一行启用代码，归档中的 `README.md` 给出了该代码。只有 sampler 检查点会被转换：训练状态检查点以 Fastino 内部布局下载。

## 错误

| 状态 | 含义 |
| --- | --- |
| `400` | `checkpoint_id` 不是 `weights/<name>` 或 `sampler_weights/<name>`。 |
| `403` | 团队的权重下载已被明确禁用。 |
| `404` | 任务或检查点不可用，或检查点没有可下载文件。 |

获取 `download_url` 会返回 `application/x-tar` 附件。预签名对象存储 URL 本身就是凭据，并会在响应的 `expires_in_seconds` 后过期。
