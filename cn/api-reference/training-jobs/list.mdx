`GET /v1/training/jobs`

返回已认证账户可见的配置训练任务和交互式训练任务。

未指定 `type` 时，每页先列出配置任务（从新到旧），再列出交互式任务（从新到旧）。传入 `type=interactive` 只列出交互式任务。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField query="status" type="string">
  按持久化状态筛选配置任务。提供 `status` 后，响应不会包含交互式任务。
</ParamField>

<ParamField query="type" type="string">
  按 `config` 或 `interactive` 筛选。
</ParamField>

<ParamField query="project_id" type="string">
  按项目 ID 筛选。
</ParamField>

<ParamField query="limit" type="integer" default="200">
  分页大小,取值从 `1` 到 `200`。
</ParamField>

<ParamField query="offset" type="integer" default="0">
  要跳过的匹配任务数量。
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs?type=config&status=complete&limit=50&offset=0" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## 响应

<ResponseField name="success" type="boolean">
  请求是否成功。
</ResponseField>

<ResponseField name="training_jobs" type="object[]">
  本页的训练任务记录。
</ResponseField>

配置任务记录使用 `id`。交互式任务记录使用 `job_id` 作为规范路径 ID，并在
`training_run_id` 中保留相同值以兼容 SDK。交互式记录还包括 `status`、
`stop_reason`、`error_message` 和 `is_terminal_status`；使用 `job_id`
轮询任务，直到终止标志为 true。

<ResponseField name="count" type="integer">
  本页任务数量。
</ResponseField>

<ResponseField name="total" type="integer">
  分页前匹配到的任务总数。
</ResponseField>

<ResponseField name="has_more" type="boolean">
  本页之后是否还有下一页。
</ResponseField>

<ResponseExample>

```json Response
{
  "success": true,
  "training_jobs": [],
  "count": 0,
  "total": 0,
  "has_more": false
}
```

</ResponseExample>

无效的分页值返回 `422`。
