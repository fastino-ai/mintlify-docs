`GET /v1/training/jobs`

返回已认证账户可见的配置训练任务和交互式训练任务。

未指定 `type` 时，配置任务和交互式任务按 `created_at` 从新到旧交错排列。如果两个任务的时间戳相同，则配置任务排在前面。传入 `type=interactive` 只列出交互式任务。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField query="status" type="string">
  按状态筛选两种任务。交互式任务支持 `creating`、`active`、`stopping`、`stopped` 和 `failed`；`running` 也会匹配 `active`，而 `errored` 和 `error` 会匹配 `failed`。`running`、`errored`、`error`、`stopped` 和 `failed` 可以匹配两种任务。`creating`、`active` 和 `stopping` 仅匹配交互式任务；其他配置任务状态仅匹配配置任务。对于配置任务，`status=complete` 会返回持久化状态为 `complete`、`artifact_ready` 或 `deployed` 的任务。
</ParamField>

<ParamField query="type" type="string">
  按 `config` 或 `interactive` 筛选。
</ParamField>

<ParamField query="project_id" type="string">
  按项目 ID 筛选。
</ParamField>

<ParamField query="limit" type="integer" default="200">
  分页大小,取值从 `1` 到 `200`。
</ParamField>

<ParamField query="offset" type="integer" default="0">
  要跳过的匹配任务数量。
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs?type=config&status=complete&limit=50&offset=0" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## 响应

<ResponseField name="success" type="boolean">
  请求是否成功。
</ResponseField>

<ResponseField name="training_jobs" type="object[]">
  本页的训练任务记录。
</ResponseField>

每条记录都包含 `id` 和 `created_at`。交互式记录还会在 `job_id` 和
`training_run_id` 中重复 `id` 以兼容 API 和 SDK，并包含 `status`、
`stop_reason`、`error_message` 和 `is_terminal_status`。使用 `id`
轮询交互式任务，直到终止标志为 true。

`type: "config"` 且 `source: "interactive_checkpoint"` 的记录是从交互式 sampler 检查点创建的服务模型。其配置训练字段（包括轮数、批次大小、学习率和验证比例）均为 `null`。

<ResponseField name="count" type="integer">
  本页任务数量。
</ResponseField>

<ResponseField name="total" type="integer">
  分页前匹配到的任务总数。
</ResponseField>

<ResponseField name="has_more" type="boolean">
  本页之后是否还有下一页。
</ResponseField>

<ResponseExample>

```json Response
{
  "success": true,
  "training_jobs": [],
  "count": 0,
  "total": 0,
  "has_more": false
}
```

</ResponseExample>

无效的分页值返回 `422`。

有关完整的持久化状态集合，请参阅[训练 API 概览](/cn/training)。
