`POST /v1/training/jobs/{job_id}/sync`

此操作仅适用于配置任务；通过常规功能和权限检查后，使用交互式任务 ID 会返回 `400`，交互式任务请通过 `GET /v1/training/jobs/{job_id}` 和 future 查看当前状态。

此页面记录 `POST /v1/training/jobs/{job_id}/sync`。请求参数、响应架构和认证要求以 OpenAPI 规范为准。
