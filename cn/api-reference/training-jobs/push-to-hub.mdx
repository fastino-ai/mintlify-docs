`POST /v1/training/jobs/{job_id}/push-to-hub`

此操作仅适用于配置任务；通过常规功能和权限检查后，使用交互式任务 ID 会返回 `400`，交互式任务没有 Push to Hub 操作。

此页面记录 `POST /v1/training/jobs/{job_id}/push-to-hub`。请求参数、响应架构和认证要求以 OpenAPI 规范为准。
