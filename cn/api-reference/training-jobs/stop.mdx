`POST /v1/training/jobs/{job_id}/stop`

停止一个运行中的任务，并保留停止前创建的检查点。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  配置任务 UUID 或交互式任务 ID。
</ParamField>

### 配置任务

配置任务的 JSON 请求体为可选。

<ParamField body="reason" type="string">
  任务被停止的原因。
</ParamField>

<ParamField body="scores" type="object">
  用于做出停止决定的数值指标。
</ParamField>

<ParamField body="checkpoint" type="string">
  与停止相关联的检查点路径或步数。
</ParamField>

### 交互式任务

不要发送请求体。该操作会立即返回 `success`、`job_id` 和 `status`。任务不再接受
训练调用，但其 sampler 检查点仍可用于采样和下载。

### 配置任务请求示例

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID/stop \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"reason": "Validation loss stopped improving"}'
```

### 交互式任务请求示例

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs/SESSION_ID:train:0/stop \
  -H "X-API-Key: $FASTINO_API_KEY"
```

## 配置任务响应

<ResponseExample>

```json Response
{
  "success": true,
  "message": "Training job stopped",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "status": "stopped"
}
```

```json 202 — 正在等待取消
{
  "success": true,
  "message": "Training job cancellation is still being confirmed.",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "status": "stopping"
}
```

</ResponseExample>

`message` 字段、`202` 响应、轮询规则和配置任务特有错误仅适用于配置任务。配置任务返回
`202` 后，请轮询 `GET /v1/training/jobs/{job_id}`。等待确认取消期间不要重复停止请求。

## 交互式任务响应

交互式停止会立即返回 `200`，无需轮询。

```json Interactive job
{
  "success": true,
  "job_id": "SESSION_ID:train:0",
  "status": "stopped"
}
```

## 配置任务状态

| 状态 | 含义 |
| --- | --- |
| `200` | 任务已停止，现有检查点仍然可用。 |
| `202` | 仍在确认提供方取消操作。 |
| `400` | 配置任务 ID 或请求无效。 |
| `409 training_job_already_finished` | 任务在停止前已进入最终状态。 |
| `422` | 配置任务 JSON 请求体无效。 |
