`POST /v1/training/jobs/{job_id}/stop`

<Warning>
  重命名后的 `/v1/training/jobs` 接口已在开发环境验证，但尚未在生产环境验证。生产环境可能返回 `404`。
</Warning>

停止一个运行中的任务，并保留在停止之前创建的检查点。对于交互式任务，请求会立即返回并拒绝新调用。已排队的操作可能会在资源释放前完成，用量也可能持续到资源释放。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  配置任务 UUID 或交互式任务 ID。
</ParamField>

### 配置任务

配置任务的 JSON 请求体为可选。

<ParamField body="reason" type="string">
  任务被停止的原因。
</ParamField>

<ParamField body="scores" type="object">
  用于做出停止决定的数值指标。
</ParamField>

<ParamField body="checkpoint" type="string">
  与停止相关联的检查点路径或步数。
</ParamField>

### 交互式任务

不要发送请求体。响应包含已验证的公共字段 `success`、`job_id` 和 `status`。

### 配置任务请求示例

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID/stop \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"reason": "Validation loss stopped improving"}'
```

</RequestExample>

### 交互式任务请求示例


<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs/YOUR_INTERACTIVE_JOB_ID/stop \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## 配置任务响应

<ResponseExample>

```json Response
{
  "success": true,
  "message": "Training job stopped successfully. Checkpoints preserved.",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "status": "stopped"
}
```

```json 202 — 正在等待取消
{
  "success": true,
  "message": "Cancellation in progress. The job moves to 'stopped' once the provider confirms; checkpoints are preserved.",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "status": "stopping"
}
```

</ResponseExample>

`message` 字段、`202` 响应和轮询规则仅适用于配置任务。配置任务收到 `202` 后，请轮询
`GET /v1/training/jobs/{job_id}`。在等待确认取消期间，请勿重复发送停止请求。

## 交互式任务响应

交互式任务使用同一操作，但不发送请求体。响应包含公共字段 `success`、`job_id` 和
`status`。交互式客户端不得要求仅配置任务具有的 `message` 字段。

```json Response
{
  "success": true,
  "job_id": "YOUR_INTERACTIVE_JOB_ID",
  "status": "stopped"
}
```

## 配置任务状态

以下状态和错误详情仅适用于配置任务。

| 状态 | 含义 |
| --- | --- |
| `200` | 任务已停止，现有检查点仍然可用。 |
| `202` | 正在等待提供方确认取消操作。 |
| `400` | 配置任务 ID 或请求无效。 |
| `409 training_job_already_finished` | 任务在停止前已进入最终状态。 |
| `409 cancellation_unconfirmed` | 提供方未确认取消。请读取任务状态，然后在适当时重试。 |
| `422` | 配置任务的 JSON 请求体无效。 |

## 配置任务授权

对于配置任务，此操作需要团队的 Owner、Admin 或 Editor 角色。其他角色会收到 `403 Forbidden`。原生交互式处理器使用交互式运行时的调用者授权；不要从此共享路径推断配置任务 RBAC。
