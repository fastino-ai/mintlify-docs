`POST /v1/training/jobs/{job_id}/load-weights`

从 `path` 排队加载并返回 `future_id`。请使用状态名称或此作业自己的 `tinker://<job_id>/weights/<name>` 路径。设置 `optimizer` 可恢复优化器状态。轮询[获取 future](/cn/api-reference/training-jobs/interactive/get-future)，直到其达到终态。

有关端到端生命周期，请参阅[自定义训练循环](/cn/training/training-loop)。
