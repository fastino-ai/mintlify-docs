`POST /v1/training/jobs/create-model`

此原生 JSON 操作用于交互式训练任务。

使用 `base_model` 创建交互式任务，或使用 `from_checkpoint` 和可选的 `load_optimizer` 创建任务。原生 JSON 客户端不发送 `seq_id` 或心跳。

端到端生命周期请参阅[自定义训练循环](/cn/training/training-loop)。
