`GET /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

返回一个检查点。要列出作业的所有检查点，请使用
[`GET /v1/training/jobs/{job_id}/checkpoints`](/cn/api-reference/training-jobs/checkpoints)。

## 请求

<ParamField path="job_id" type="string" required>
  交互式作业 ID。
</ParamField>

<ParamField path="kind" type="string" required>
  `weights` 用于状态检查点，或 `sampler_weights` 用于采样器检查点。
</ParamField>

<ParamField path="name" type="string" required>
  检查点名称。
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/sampler_weights/step-000100" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## 回应

<ResponseExample>

```json Response
{
  "checkpoint_id": "sampler_weights/step-000100",
  "checkpoint_type": "sampler",
  "time": "2026-10-14T12:00:00Z",
  "tinker_path": "tinker://SESSION_ID:train:0/sampler_weights/step-000100",
  "size_bytes": 268435456,
  "public": false,
  "user_metadata": null,
  "expires_at": "2026-10-15T12:00:00Z"
}
```

</ResponseExample>

`checkpoint_type` 对于状态检查点是 `training`，对于状态检查点是 `sampler`
采样器检查点。当检查点没有 TTL 时，`expires_at` 是 `null`。
