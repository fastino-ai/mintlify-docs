`GET /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

此原生 JSON 操作用于交互式训练任务。

返回一个交互式检查点。`kind` 为 `weights` 或 `sampler_weights`。

端到端生命周期请参阅[自定义训练循环](/cn/training/training-loop)。
