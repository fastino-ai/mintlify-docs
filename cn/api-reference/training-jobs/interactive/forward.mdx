`POST /v1/training/jobs/{job_id}/forward`

排队执行不计算梯度的前向传播，并返回 `future_id`。轮询[获取 future](/cn/api-reference/training-jobs/interactive/get-future)，直到状态为 `completed`、`failed` 或 `cancelled`。

有关端到端生命周期，请参阅[自定义训练循环](/cn/training/training-loop)。
