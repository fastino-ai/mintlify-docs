`POST /v1/training/jobs/{job_id}/forward`

此原生 JSON 操作用于交互式训练任务。

排队执行不计算梯度的前向操作并返回 `future_id`。轮询[获取操作](/cn/api-reference/training-jobs/interactive/get-operation)，直到状态为 `completed`、`failed` 或 `cancelled`。

端到端生命周期请参阅[自定义训练循环](/cn/training/training-loop)。
