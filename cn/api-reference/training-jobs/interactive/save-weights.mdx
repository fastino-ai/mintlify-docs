`POST /v1/training/jobs/{job_id}/save-weights`

将 LoRA 权重和优化器状态以 `name` 保存。接受后的响应包含 `future_id`、`weights/<name>` 检查点 ID 及其 `tinker://` 路径。在加载该状态或基于它启动另一个作业之前，请先轮询[获取 future](/cn/api-reference/training-jobs/interactive/get-future)。

有关端到端生命周期，请参阅[自定义训练循环](/cn/training/training-loop)。
