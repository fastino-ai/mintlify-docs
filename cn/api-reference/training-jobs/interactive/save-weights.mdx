`POST /v1/training/jobs/{job_id}/save-weights`

将作业的 LoRA 权重和优化器状态保存为 `weights/<name>`。你可以
[加载](/cn/api-reference/training-jobs/interactive/load-weights)它回到同一个作业，
或从中[开始一项新工作](/cn/api-reference/training-jobs/interactive/create-model)。来样
或下载权重，将其保存为
[`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`](/cn/api-reference/training-jobs/interactive/save-weights-for-sampler)
相反。

保存与作业的其他调用按顺序运行。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  交互式作业 ID。
</ParamField>

<ParamField body="name" type="string" required>
  `A-Z`、`a-z`、`0-9`、`.`、`_` 和 `-` 中的 1–128 个字符。
</ParamField>

<ParamField body="ttl_seconds" type="integer | null">
  在这么多秒后自动删除检查点，来自 `3600`
  （1 小时）到 `315360000`（10 年）。省略它或发送 `null` 以保留检查点，直到您将其删除。实时检查点会计入[存储使用](/cn/api-reference/training-jobs/interactive/storage-usage)。
</ParamField>

<ParamField body="overwrite" type="boolean" default="false">
  替换同名的状态检查点。
</ParamField>

<ParamField body="user_metadata" type="object">
  与检查点一起存储的字符串键值元数据。
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/save-weights" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "step-000100"}'
```

</RequestExample>

## 回应

<ResponseField name="future_id" type="string">
  `save` 未来。
</ResponseField>

<ResponseField name="checkpoint_id" type="string">
  `weights/<name>`。
</ResponseField>

<ResponseField name="path" type="string">
  完整的检查点路径。创建作业时将其传递为 `from_checkpoint`。
</ResponseField>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "save",
  "checkpoint_id": "weights/step-000100",
  "path": "tinker://SESSION_ID:train:0/weights/step-000100"
}
```

</ResponseExample>

|状态 |意义|
| ---| ---|
| `400` |名称包含无效字符或长度、TTL 超出范围或作业已停止。 |
| `404` |该职位不存在或属于另一个团队。 |
| `422` |主体缺失 `name` 或具有未知字段。 |
