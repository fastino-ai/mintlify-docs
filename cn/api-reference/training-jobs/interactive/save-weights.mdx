`POST /v1/training/jobs/{job_id}/save-weights`

将任务的 LoRA 权重和优化器状态保存为 `weights/<name>`。您可以将其[加载](/cn/api-reference/training-jobs/interactive/load-weights)回同一个任务，或基于它[创建新任务](/cn/api-reference/training-jobs/interactive/create-model)。如需采样或下载权重，请改用 [`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`](/cn/api-reference/training-jobs/interactive/save-weights-for-sampler) 保存。

保存操作与任务的其他调用按顺序运行。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  交互式任务 ID。
</ParamField>

<ParamField body="name" type="string" required>
  1–128 个字符，取自 `A-Z`、`a-z`、`0-9`、`.`、`_` 和 `-`。
</ParamField>

<ParamField body="ttl_seconds" type="integer | null">
  在指定秒数后自动删除检查点，取值范围为 `3600`（1 小时）到 `315360000`（10 年）。省略此项或发送 `null`，检查点将一直保留，直到您将其删除。未删除的检查点会计入[存储用量](/cn/api-reference/training-jobs/interactive/storage-usage)。
</ParamField>

<ParamField body="overwrite" type="boolean" default="false">
  替换同名的状态检查点。
</ParamField>

<ParamField body="user_metadata" type="object">
  与检查点一同存储的字符串键值元数据。
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/save-weights" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "step-000100"}'
```

</RequestExample>

## 响应

<ResponseField name="future_id" type="string">
  `save` future。
</ResponseField>

<ResponseField name="checkpoint_id" type="string">
  `weights/<name>`。
</ResponseField>

<ResponseField name="path" type="string">
  完整的检查点路径。创建任务时将其作为 `from_checkpoint` 传入。
</ResponseField>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "save",
  "checkpoint_id": "weights/step-000100",
  "path": "tinker://SESSION_ID:train:0/weights/step-000100"
}
```

</ResponseExample>

| 状态 | 含义 |
| --- | --- |
| `400` | 名称包含无效字符或长度不符合要求、TTL 超出范围，或任务已停止。 |
| `404` | 任务不存在或属于其他团队。 |
| `422` | 请求体缺少 `name` 或包含未知字段。 |
