`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

删除一个检查点。它会立即停止计入存储用量，文件稍后清除。`kind` 为 `weights` 或 `sampler_weights`。成功时返回 `204 No Content`。

<RequestExample>

```bash cURL
curl -X DELETE "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
