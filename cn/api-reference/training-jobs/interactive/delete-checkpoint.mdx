`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

删除 `weights` 或 `sampler_weights` 检查点。操作同步完成，且没有响应体。存储的文件可能会在稍后清除。

有关端到端生命周期，请参阅[自定义训练循环](/cn/training/training-loop)。
