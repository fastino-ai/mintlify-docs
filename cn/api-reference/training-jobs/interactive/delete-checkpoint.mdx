`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

此原生 JSON 操作用于交互式训练任务。

删除 `weights` 或 `sampler_weights` 检查点。操作同步完成且无响应体。存储文件可能稍后清除。

端到端生命周期请参阅[自定义训练循环](/cn/training/training-loop)。
