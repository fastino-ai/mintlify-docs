`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

对于排队中或运行中的 `sample` future，取消操作会尽力而为。请求被接受时，该路由返回 `204 No Content`。取消已结束的 future 或训练 future 同样返回 `204`；这属于成功的空操作，因为训练操作按顺序运行，不会被取消。

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/futures/$FUTURE_ID/cancel" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## 错误

| 状态 | 含义 |
| --- | --- |
| `404` | 任务或 future 不存在，或属于其他团队。 |
