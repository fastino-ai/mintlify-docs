`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

此原生 JSON 操作用于交互式训练任务。

设置 `weights` 或 `sampler_weights` 检查点的保留期。空 TTL 会保留检查点直到删除。

端到端生命周期请参阅[自定义训练循环](/cn/training/training-loop)。
