`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

为 `weights` 或 `sampler_weights` 检查点设置保留期。TTL 为 null 时，检查点将保留到被删除为止。

有关端到端生命周期，请参阅[自定义训练循环](/cn/training/training-loop)。
