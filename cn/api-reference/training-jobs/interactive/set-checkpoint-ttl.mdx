`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

从现在开始保留 `ttl_seconds` 的检查点，然后将其删除。省略
`ttl_seconds` 或发送 `null` 保留检查点，直到您将其删除。返回 `204 No Content`。

`kind` 是 `weights` 或 `sampler_weights`。

<ParamField body="ttl_seconds" type="integer | null">
  从 `3600`（1 小时）到 `315360000`（10 年）或 `null`。
</ParamField>

<RequestExample>

```bash cURL
curl -X PUT "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100/ttl" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"ttl_seconds": 604800}'
```

</RequestExample>

## 错误

|状态 |意义|
| ---| ---|
| `400` | `ttl_seconds` 位于 3600–315360000 之外。 |
| `404` |该作业或检查点不存在，或者属于另一个团队。 |
| `422` |体内蕴藏着未知的领域。 |
