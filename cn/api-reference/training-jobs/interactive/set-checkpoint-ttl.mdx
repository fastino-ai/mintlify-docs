`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

从现在起将检查点保留 `ttl_seconds` 秒，之后将其删除。发送 `ttl_seconds: null` 可清除过期时间，使检查点一直保留到您将其删除为止。返回 `204 No Content`。

`kind` 为 `weights` 或 `sampler_weights`。

<ParamField body="ttl_seconds" type="integer | null" required>
  取值范围为 `3600`（1 小时）到 `315360000`（10 年），或为 `null`。
</ParamField>

<RequestExample>

```bash cURL
curl -X PUT "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100/ttl" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"ttl_seconds": 604800}'
```

</RequestExample>

## 错误

| 状态 | 含义 |
| --- | --- |
| `400` | `ttl_seconds` 超出 3600–315360000 的范围。 |
| `404` | 任务或检查点不存在，或属于其他团队。 |
| `422` | 缺少 `ttl_seconds`，或请求体包含未知字段。 |
