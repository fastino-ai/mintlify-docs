`POST /v1/training/jobs/create-model`

使用 `base_model` 创建交互式 LoRA 作业，或使用 `from_checkpoint` 和可选的 `load_optimizer` 设置创建。响应包含 `job_id` 和创建操作的 `future_id`。如果恢复检查点，响应还包含 `load_future_id`。原生 JSON 客户端不发送 `seq_id` 值或心跳。

有关端到端生命周期，请参阅[自定义训练循环](/cn/training/training-loop)。
