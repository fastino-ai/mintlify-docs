`POST /v1/training/jobs/create-model`

在解码器基础模型上创建 `interactive` LoRA 训练任务，或创建一个从已保存训练状态恢复的新任务。随后，你的应用会发送每次前向-反向传播、优化器步骤、检查点保存和采样操作。原生 JSON 客户端无需发送 `seq_id` 或心跳。若要使用上传的数据集进行托管训练，请使用 [`POST /v1/training/jobs`](/cn/api-reference/training-jobs/create)。

任务会在其 `create` future 完成后就绪。通过 [`GET /v1/training/jobs/{job_id}/futures/{future_id}`](/cn/api-reference/training-jobs/interactive/get-future) 读取该 future。

每个团队最多可以有 `16` 个活动的交互式任务。每个任务一次最多可排队 `512` 个操作。超过任一限制都会返回 `429`。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

准确发送 `base_model` 和 `from_checkpoint` 之一。

<ParamField body="base_model" type="string">
  `nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16`，
  `nvidia/NVIDIA-Nemotron-3.5-Super-VL-120B-A12B-NVFP4`，或`Qwen/Qwen3.6-35B-A3B`。
</ParamField>

<ParamField body="from_checkpoint" type="string">
  [`save-weights`](/cn/api-reference/training-jobs/interactive/save-weights) 为你的某个任务返回的 `path`，例如 `tinker://<job_id>/weights/<name>`。新任务沿用该检查点的基础模型和 LoRA 设置，因此请省略 `lora_config`。不接受 sampler 检查点。
</ParamField>

<ParamField body="load_optimizer" type="boolean" default="false">
  与 `from_checkpoint` 一起设置 `load_optimizer`，以恢复优化器状态。
</ParamField>

<ParamField body="lora_config" type="object">
  新作业的 LoRA 设置。

  <Expandable title="properties">
    <ParamField body="rank" type="integer" default="32">
      LoRA 排名，从 1 到 32。
    </ParamField>
    <ParamField body="seed" type="integer">
      适配器初始化种子。
    </ParamField>
    <ParamField body="train_attn" type="boolean" default="true">
      训练注意力层。
    </ParamField>
    <ParamField body="train_mlp" type="boolean" default="true">
      训练 MLP 层。
    </ParamField>
    <ParamField body="train_unembed" type="boolean" default="true">
      训练非嵌入层。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="optimizer_config" type="object">
  优化器家族。仅提供 `{"type": "adamw"}`，这是默认值。
</ParamField>

<ParamField body="project_id" type="string">
  任务及其用量所属的项目。默认为你的默认项目。
</ParamField>

<ParamField body="user_metadata" type="object">
  您自己的作业 JSON 元数据。
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/create-model" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "base_model": "Qwen/Qwen3.6-35B-A3B",
    "lora_config": {"rank": 32}
  }'
```

</RequestExample>

## 响应

<ResponseField name="job_id" type="string">
  交互式任务 ID。用于所有 `/v1/training/jobs/{job_id}` 路由。
</ResponseField>

<ResponseField name="type" type="string">
  始终为 `interactive`。
</ResponseField>

<ResponseField name="base_model" type="string">
  作业的基本模型。
</ResponseField>

<ResponseField name="future_id" type="string">
  任务的 `create` future。
</ResponseField>

<ResponseField name="load_future_id" type="string | null">
  使用 `from_checkpoint` 时，加载检查点的 future。
</ResponseField>

<ResponseExample>

```json Response
{
  "job_id": "SESSION_ID:train:0",
  "type": "interactive",
  "base_model": "Qwen/Qwen3.6-35B-A3B",
  "future_id": "FUTURE_ID",
  "load_future_id": null
}
```

</ResponseExample>

## 错误

|状态 |意义|
| ---| ---|
| `400` |模型未提供服务、排名超出范围、`from_checkpoint` 是采样器检查点，或者 `lora_config` 与 `from_checkpoint` 一起发送。 |
| `402` |团队积分用完或没有有效的付款设置。 |
| `404` | 团队无法使用交互式训练，或检查点不存在。 |
| `429` | 团队已有 `16` 个活动的交互式任务。请停止一个空闲任务后重试。 |
| `422` | `base_model` 和 `from_checkpoint` 均发送或均未发送，或者正文具有未知字段。 |
