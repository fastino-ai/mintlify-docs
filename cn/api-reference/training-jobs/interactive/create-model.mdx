`POST /v1/training/jobs/create-model`

在解码器基础模型或新模型上创建 `interactive` LoRA 训练作业
从保存的训练状态播种作业。然后您的应用程序发送每个
前向-后向传递、优化器步骤、检查点和样本。原生 JSON
客户端不发送 `seq_id` 值或心跳。对于管理培训
上传的数据集，使用[`POST /v1/training/jobs`](/cn/api-reference/training-jobs/create)。

一旦 `create` 未来完成，这项工作就准备好了。阅读它与
[`GET /v1/training/jobs/{job_id}/futures/{future_id}`](/cn/api-reference/training-jobs/interactive/get-future)。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

准确发送 `base_model` 和 `from_checkpoint` 之一。

<ParamField body="base_model" type="string">
  `nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16`，
  `nvidia/NVIDIA-Nemotron-3-Super-120B-A12B-BF16`，或`Qwen/Qwen3.6-35B-A3B`。
</ParamField>

<ParamField body="from_checkpoint" type="string">
  `path` [`save-weights`](/cn/api-reference/training-jobs/interactive/save-weights)
  因您的一项工作而返回，例如 `tinker://<job_id>/weights/<name>`。的
  新作业采用该检查点的基本模型和 LoRA 设置，因此省略
  `lora_config`。采样器检查点被拒绝。
</ParamField>

<ParamField body="load_optimizer" type="boolean" default="false">
  将 `load_optimizer` 设置为 `from_checkpoint` 以恢复优化器状态。
</ParamField>

<ParamField body="lora_config" type="object">
  新作业的 LoRA 设置。

  <Expandable title="properties">
    <ParamField body="rank" type="integer" default="32">
      LoRA 排名，从 1 到 32。
    </ParamField>
    <ParamField body="seed" type="integer">
      适配器初始化种子。
    </ParamField>
    <ParamField body="train_attn" type="boolean" default="true">
      训练注意力层。
    </ParamField>
    <ParamField body="train_mlp" type="boolean" default="true">
      训练 MLP 层。
    </ParamField>
    <ParamField body="train_unembed" type="boolean" default="true">
      训练非嵌入层。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="optimizer_config" type="object">
  优化器家族。仅提供 `{"type": "adamw"}`，这是默认值。
</ParamField>

<ParamField body="project_id" type="string">
  项目所属的作业及其用途。默认为您的默认项目。
</ParamField>

<ParamField body="user_metadata" type="object">
  您自己的作业 JSON 元数据。
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/create-model" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "base_model": "Qwen/Qwen3.6-35B-A3B",
    "lora_config": {"rank": 32}
  }'
```

</RequestExample>

## 回应

<ResponseField name="job_id" type="string">
  交互式作业 ID。将其用于每条 `/v1/training/jobs/{job_id}` 路线。
</ResponseField>

<ResponseField name="type" type="string">
  始终为 `interactive`。
</ResponseField>

<ResponseField name="base_model" type="string">
  作业的基本模型。
</ResponseField>

<ResponseField name="future_id" type="string">
  这项工作的未来是 `create`。
</ResponseField>

<ResponseField name="load_future_id" type="string | null">
  使用 `from_checkpoint`，加载检查点的未来。
</ResponseField>

<ResponseExample>

```json Response
{
  "job_id": "SESSION_ID:train:0",
  "type": "interactive",
  "base_model": "Qwen/Qwen3.6-35B-A3B",
  "future_id": "FUTURE_ID",
  "load_future_id": null
}
```

</ResponseExample>

## 错误

|状态 |意义|
| ---| ---|
| `400` |模型未提供服务、排名超出范围、`from_checkpoint` 是采样器检查点，或者 `lora_config` 与 `from_checkpoint` 一起发送。 |
| `402` |团队积分用完或没有有效的付款设置。 |
| `404` |团队无法进行交互式培训，或者检查点不存在。 |
| `422` | `base_model` 和 `from_checkpoint` 均发送或均未发送，或者正文具有未知字段。 |
