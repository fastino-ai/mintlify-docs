`POST /v1/training/jobs/{job_id}/checkpoints`

此原生 JSON 操作用于交互式训练任务。

排队保存检查点并返回 `operation_id`。保存类型 `state` 映射到 `weights`，`sampler` 映射到 `sampler_weights`。使用前轮询[获取操作](/cn/api-reference/training-jobs/interactive/get-operation)。

端到端生命周期请参阅[自定义训练循环](/cn/training/training-loop)。
