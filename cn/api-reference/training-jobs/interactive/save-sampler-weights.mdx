`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

将 LoRA 权重以 `name` 保存，用于采样和 PEFT 下载。接受后的响应包含 `future_id`、`sampler_weights/<name>` 检查点 ID 及其 `tinker://` 路径。在采样或下载之前，请先轮询[获取 future](/cn/api-reference/training-jobs/interactive/get-future)。

有关端到端生命周期，请参阅[自定义训练循环](/cn/training/training-loop)。
