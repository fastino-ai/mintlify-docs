`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

使用 `name` 保存 LoRA 权重，以便采样和下载 PEFT 文件。已接受的响应包含 `future_id`、`sampler_weights/<name>` 检查点 ID 及其 `tinker://` 路径。在采样或下载之前，请轮询[获取 future](/cn/api-reference/training-jobs/interactive/get-future)。

有关端到端生命周期，请参阅[自定义训练循环](/cn/training/training-loop)。
