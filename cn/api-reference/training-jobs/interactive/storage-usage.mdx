`GET /v1/training/usage`

按项目返回团队当前的交互式任务检查点存储量（每个项目一行），以及预估的月度费用。兼容性字段 `org_user_urn` 和 `user_name` 包含团队 ID；`user_email` 为 `null`。已删除和已过期的检查点不计入。

<ParamField query="project_id" type="string">
  仅返回此项目的存储量。
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/usage" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

<ResponseExample>

```json Response
{
  "effective_rate_usd_per_gigabyte_month": 0.05,
  "data": [
    {
      "project_id": "PROJECT_ID",
      "org_user_urn": "TEAM_ID",
      "user_email": null,
      "user_name": "TEAM_ID",
      "checkpoint_count": 3,
      "size_bytes": 805306368,
      "size_gigabytes": 0.805306368,
      "estimated_monthly_cost_usd": 0.0402653184
    }
  ]
}
```

</ResponseExample>
