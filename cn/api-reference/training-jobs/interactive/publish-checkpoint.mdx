`POST /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

发布 `weights` 或 `sampler_weights` 检查点。发布并不会授予其他团队加载该检查点的权限。

有关端到端生命周期，请参阅[自定义训练循环](/cn/training/training-loop)。
