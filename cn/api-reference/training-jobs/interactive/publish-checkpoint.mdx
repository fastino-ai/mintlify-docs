`POST /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

此原生 JSON 操作用于交互式训练任务。

发布 `weights` 或 `sampler_weights` 检查点。发布不会授予其他团队加载权限。

端到端生命周期请参阅[自定义训练循环](/cn/training/training-loop)。
