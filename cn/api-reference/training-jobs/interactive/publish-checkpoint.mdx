`POST /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

将检查点标记为公开，其 `public` 字段变为 `true`。`kind` 为 `weights` 或 `sampler_weights`。成功时返回 `204 No Content`。使用 [`DELETE .../publish`](/cn/api-reference/training-jobs/interactive/unpublish-checkpoint) 撤销。

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/sampler_weights/step-000100/publish" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
