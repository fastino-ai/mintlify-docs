`POST /v1/training/jobs/{job_id}/forward-backward`

排队执行累积梯度的前向反向传播，并返回 `future_id`。轮询[获取 future](/cn/api-reference/training-jobs/interactive/get-future)，直到达到终态。

有关端到端生命周期，请参阅[自定义训练循环](/cn/training/training-loop)。
