`POST /v1/training/jobs/{job_id}/forward-backward`

此原生 JSON 操作用于交互式训练任务。

排队执行累积梯度的前向和反向操作并返回 `operation_id`。轮询[获取操作](/cn/api-reference/training-jobs/interactive/get-operation)直到终止状态。

端到端生命周期请参阅[自定义训练循环](/cn/training/training-loop)。
