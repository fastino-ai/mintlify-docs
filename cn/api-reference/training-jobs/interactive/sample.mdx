`POST /v1/training/jobs/{job_id}/checkpoints/sampler_weights/{name}/sample`

此原生 JSON 操作用于交互式训练任务。

排队从 `sampler_weights` 检查点采样并返回 `operation_id`。交互式任务停止后仍可采样。轮询[获取操作](/cn/api-reference/training-jobs/interactive/get-operation)直到终止状态。

端到端生命周期请参阅[自定义训练循环](/cn/training/training-loop)。
