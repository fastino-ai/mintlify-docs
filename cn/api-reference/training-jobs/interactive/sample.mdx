`POST /v1/training/jobs/{job_id}/sample`

从 `checkpoint` 排队采样并返回 `future_id`。请使用采样器检查点名称或此作业自己的 `tinker://<job_id>/sampler_weights/<name>` 路径。交互式作业停止后仍可采样。轮询[获取 future](/cn/api-reference/training-jobs/interactive/get-future)，直到达到终态。

有关端到端生命周期，请参阅[自定义训练循环](/cn/training/training-loop)。
