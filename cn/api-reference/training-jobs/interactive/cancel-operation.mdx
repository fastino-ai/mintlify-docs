`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

此原生 JSON 操作用于交互式训练任务。

尽力取消已排队或正在运行的 sample 操作。训练操作不能取消。

端到端生命周期请参阅[自定义训练循环](/cn/training/training-loop)。
