`GET /v1/training/jobs/{job_id}/futures/{future_id}`

返回 future 状态和结果。使用 `wait=true` 时，请求最多等待 25 秒，并且仍可能返回非终态。轮询直到状态为 `completed`、`failed` 或 `cancelled`。服务将结果保留一小时。HTTP 错误表示服务器拒绝了请求。排队的 future 也可能以 `status: "failed"` 和 `error.message` 结束；请将 `error.category` 视为不透明字符串。

有关端到端生命周期，请参阅[自定义训练循环](/cn/training/training-loop)。
