`GET /v1/training/jobs/{job_id}/futures/{future_id}`

交互式任务中每个执行实际工作的调用都会返回一个 `future_id`。请轮询该 future，直到其 `status` 变为 `completed`、`failed` 或 `cancelled`。使用 `wait=true` 时，每个请求最多等待 25 秒；超时后仍可能返回尚未结束的 future。结果会保留一小时。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  交互式任务 ID。
</ParamField>

<ParamField path="future_id" type="string" required>
  工作加入队列时返回的 future ID。
</ParamField>

<ParamField query="wait" type="boolean" default="false">
  对于尚未完成的 future，最多等待 25 秒后再响应。请重复发送请求，直到其完成。
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/futures/$FUTURE_ID?wait=true" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## 响应

<ResponseField name="future_id" type="string">
  该 future。
</ResponseField>

<ResponseField name="job_id" type="string">
  该任务。
</ResponseField>

<ResponseField name="type" type="string">
  `create`、`load`、`forward`、`forward_backward`、`optim_step`、`save` 或 `sample`。
</ResponseField>

<ResponseField name="status" type="string">
  `pending`、`running`、`completed`、`failed` 或 `cancelled`。
</ResponseField>

<ResponseField name="queue_state" type="string | null">
  未完成时为 `active`；GPU 容量预热期间为 `paused_capacity`。
</ResponseField>

<ResponseField name="queue_state_reason" type="string | null">
  当 `queue_state` 为 `paused_capacity` 时，提供人类可读的容量说明；否则为 `null`。
</ResponseField>

<ResponseField name="result" type="any">
  状态为 `completed` 时：

  - `forward` 和 `forward_backward`：`loss_fn_outputs`（每个数据项对应一组张量，例如 `logprobs`）以及 `metrics`。
  - `sample`：`sequences`，每个序列包含 `tokens`、`logprobs` 和 `stop_reason`；如有请求，还包含 `prompt_logprobs`。
  - `save`：检查点路径。
  - 其他类型：一条确认信息。
</ResponseField>

<ResponseField name="error" type="object | null">
  状态为 `failed` 或 `cancelled` 时：包含 `message` 和 `category`（`user` 表示请求本身有问题，`server` 表示 Fastino 端出现问题）。
</ResponseField>

| 状态 | 含义 |
| --- | --- |
| `404` | 任务或 future 不存在，或属于其他团队。 |
| `410` | 操作已丢失，或其保留的结果已过期。请重新提交该操作；已过期的结果无法恢复。 |
