`GET /v1/training/jobs/{job_id}/futures/{future_id}`

Every interactive-job call that does work returns a `future_id`. Read the
future until its `status` is `completed`, `failed`, or `cancelled`.
Use `wait=true` to wait at most 25 seconds per request. Continue polling a nonterminal future. Use `wait=true` to wait at most 25 seconds per request. Continue polling a nonterminal future. ## Request

<ParamField header="X-API-Key" type="string" required>
  Your Fastino API key.
</ParamField>

<ParamField path="job_id" type="string" required>
  Interactive job ID.
</ParamField>

<ParamField path="future_id" type="string" required>
  Future ID returned when the work was queued.
</ParamField>

<ParamField query="wait" type="boolean" default="false">
  Wait up to 25 seconds for an unfinished future before answering. Repeat
  the request until it finishes.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/futures/$FUTURE_ID?wait=true" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Response

<ResponseField name="future_id" type="string">
  The future.
</ResponseField>

<ResponseField name="job_id" type="string">
  The job.
</ResponseField>

<ResponseField name="type" type="string">
  `create`, `load`, `forward`, `forward_backward`, `optim_step`, `save`, or `sample`.
</ResponseField>

<ResponseField name="status" type="string">
  `pending`, `running`, `completed`, `failed`, or `cancelled`.
</ResponseField>

<ResponseField name="queue_state" type="string | null">
  While unfinished: `active`, or `paused_capacity` while GPU capacity warms up.
</ResponseField>

<ResponseField name="result" type="any">
  Once `completed`:

  - `forward` and `forward_backward`: `loss_fn_outputs` (one entry of tensors per
    datum, such as `logprobs`) and `metrics`.
  - `sample`: `sequences`, each with `tokens`, `logprobs`, and `stop_reason`,
    plus `prompt_logprobs` when requested.
  - `save`: the checkpoint path.
  - Other types: an acknowledgement.
</ResponseField>

<ResponseField name="error" type="object | null">
  When `failed` or `cancelled`: `message`, and `category` (`user` for a problem
  with the request, `server` for a Fastino problem).
</ResponseField>
