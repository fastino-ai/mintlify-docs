`GET /v1/training/jobs/{job_id}/futures/{future_id}`

此原生 JSON 操作用于交互式训练任务。

返回操作状态和结果。`wait=true` 最多等待 25 秒，仍可能返回非终止状态。持续轮询到 `completed`、`failed` 或 `cancelled`。HTTP 错误表示服务器拒绝请求；已排队的操作也可能以 `status: "failed"` 和 `error.message` 结束。将 `error.category` 视为不透明字符串。

端到端生命周期请参阅[自定义训练循环](/cn/training/training-loop)。
