`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

取消检查点的发布。请求同步完成，且没有响应体。

有关端到端生命周期，请参阅[自定义训练循环](/cn/training/training-loop)。
