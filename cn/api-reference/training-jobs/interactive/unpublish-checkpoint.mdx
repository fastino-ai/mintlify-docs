`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

将已发布的检查点重新设为私有。`kind` 为 `weights` 或 `sampler_weights`。成功时返回 `204 No Content`。

<RequestExample>

```bash cURL
curl -X DELETE "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/sampler_weights/step-000100/publish" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
