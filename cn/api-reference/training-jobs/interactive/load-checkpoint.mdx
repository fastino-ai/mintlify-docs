`POST /v1/training/jobs/{job_id}/checkpoints/weights/{name}/load`

此原生 JSON 操作用于交互式训练任务。

排队从 `weights` 检查点加载训练状态并返回 `operation_id`。请求可以恢复优化器状态。轮询[获取操作](/cn/api-reference/training-jobs/interactive/get-operation)直到终止状态。

端到端生命周期请参阅[自定义训练循环](/cn/training/training-loop)。
