`POST /v1/training/jobs/{job_id}/optim-step`

此原生 JSON 操作用于交互式训练任务。

排队应用已累积梯度的优化器步骤并返回 `operation_id`。请求体可选。轮询[获取操作](/cn/api-reference/training-jobs/interactive/get-operation)直到终止状态。

端到端生命周期请参阅[自定义训练循环](/cn/training/training-loop)。
