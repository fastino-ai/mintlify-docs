`POST /v1/training/jobs/{job_id}/optim-step`

对累积的梯度排队执行优化器步骤，并返回 `future_id`。请求正文可选。轮询[获取 future](/cn/api-reference/training-jobs/interactive/get-future)，直到达到终态。

有关端到端生命周期，请参阅[自定义训练循环](/cn/training/training-loop)。
