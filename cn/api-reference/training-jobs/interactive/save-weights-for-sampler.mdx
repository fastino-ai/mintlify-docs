`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

将任务的 LoRA 权重保存为 `sampler_weights/<name>`。您可以基于它进行[采样](/cn/api-reference/training-jobs/interactive/sample)（任务停止后也可以），或将其作为适配器归档[下载](/cn/api-reference/training-jobs/download-checkpoint)。解码器的下载内容是面向公开基础模型的标准 Hugging Face PEFT 适配器。它不包含优化器状态，因此任务无法加载它，也无法从它开始训练；如需这样做，请使用 [`POST /v1/training/jobs/{job_id}/save-weights`](/cn/api-reference/training-jobs/interactive/save-weights)。

保存操作与任务的其他调用按顺序运行。

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  交互式任务 ID。
</ParamField>

<ParamField body="name" type="string" required>
  1–128 个字符，取自 `A-Z`、`a-z`、`0-9`、`.`、`_` 和 `-`。
</ParamField>

<ParamField body="ttl_seconds" type="integer | null">
  在指定秒数后自动删除检查点，取值范围为 `3600`（1 小时）到 `315360000`（10 年）。省略此项或发送 `null`，检查点将一直保留，直到您将其删除。未删除的检查点会计入[存储用量](/cn/api-reference/training-jobs/interactive/storage-usage)。
</ParamField>

<ParamField body="user_metadata" type="object">
  与检查点一同存储的字符串键值元数据。
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/save-weights-for-sampler" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "step-000100", "ttl_seconds": 86400}'
```

</RequestExample>

## 响应

<ResponseField name="future_id" type="string">
  `save` future。
</ResponseField>

<ResponseField name="checkpoint_id" type="string">
  `sampler_weights/<name>`。
</ResponseField>

<ResponseField name="path" type="string">
  完整的检查点路径。
</ResponseField>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "save",
  "checkpoint_id": "sampler_weights/step-000100",
  "path": "tinker://SESSION_ID:train:0/sampler_weights/step-000100"
}
```

</ResponseExample>

| 状态 | 含义 |
| --- | --- |
| `400` | 名称包含无效字符或长度不符合要求、TTL 超出范围，或任务已停止。 |
| `404` | 任务不存在或属于其他团队。 |
| `422` | 请求体缺少 `name` 或包含未知字段。 |
