---
title: "终止训练任务"
sidebarTitle: "终止任务"
description: "终止 Fastino 训练任务并删除其所有检查点。"
api: "POST /felix/training-jobs/{job_id}/terminate"
noindex: true
---

如果提供方任务仍处于活动状态,则将其停止,删除每一个检查点,并将任务标记为已终止。

<Warning>
  终止操作不可撤销。如果您需要保留检查点,请使用停止端点。
</Warning>

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  训练任务 UUID。
</ParamField>

```bash
curl -X POST https://api.pioneer.ai/felix/training-jobs/YOUR_TRAINING_JOB_ID/terminate \
  -H "X-API-Key: YOUR_API_KEY"
```

## 响应

```json
{
  "success": true,
  "message": "Training job terminated",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "deleted_checkpoints": 3
}
```

未知任务或无法终止的任务返回请求相关的 `4xx` 错误。
