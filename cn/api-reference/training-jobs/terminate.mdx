`POST /v1/training/jobs/{job_id}/terminate`

此操作仅适用于配置任务；通过常规功能和权限检查后，使用交互式任务 ID 会返回 `400`，请改用 `POST /v1/training/jobs/{job_id}/stop` 停止交互式任务。

停止活动的 `config` 任务，并请求提供方取消。默认保留现有检查点和工件。

<Warning>
  将 `delete_checkpoints` 设为 `true` 会在确认取消后永久删除任务的检查点和工件。此操作无法撤销。
</Warning>

## 请求

<ParamField header="X-API-Key" type="string" required>
  您的 Fastino API 密钥。
</ParamField>

<ParamField path="job_id" type="string" required>
  训练任务 UUID。
</ParamField>

JSON 请求体为可选。

<ParamField body="delete_checkpoints" type="boolean" default="false">
  在确认取消后永久删除检查点和工件。
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID/terminate \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"delete_checkpoints": false}'
```

</RequestExample>

## 响应

<ResponseExample>

```json 200 — terminated
{
  "success": true,
  "message": "Training job terminated. Checkpoints preserved (pass delete_checkpoints=true to remove them).",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "deleted_checkpoints": 0,
  "status": "terminated"
}
```

```json 202 — cancellation pending
{
  "success": true,
  "message": "Termination in progress. The job moves to 'terminated' once the provider confirms; checkpoints are preserved.",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "deleted_checkpoints": 0,
  "status": "stopping"
}
```

</ResponseExample>

收到 `202` 后，请轮询 `GET /v1/training/jobs/{job_id}`；在取消等待确认期间，请勿重复发送终止请求。

| 状态 | 含义 |
| --- | --- |
| `200` | 任务已终止。 |
| `202` | 终止正在进行中，等待提供方确认取消。 |
| `400` | `job_id` 不是有效的配置任务 UUID，或它标识交互式任务；请改用交互式停止路由。 |
| `409 training_job_already_finished` | 任务在终止前已进入最终状态。 |
| `409 cancellation_unconfirmed` | 取消未得到确认，可以重试。 |
| `422` | JSON 请求体无效。 |

## 授权

需要团队的 Owner、Admin 或 Editor 角色。其他角色会收到 `403 Forbidden`。
