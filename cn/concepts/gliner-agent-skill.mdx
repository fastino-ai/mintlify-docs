[Fastino GLiNER 智能体技能](https://api.fastino.ai/.well-known/agent-skills/fastino-gliner/SKILL.md) 帮助 Cursor、Claude Code 和 Codex 使用 Fastino 托管的 API 完成抽取、分类、数据集准备、微调、评估和推理。

## 安装

在你的项目中运行以下命令：

```bash
npx skills add https://api.fastino.ai --skill fastino-gliner
```

安装程序会让你选择要将该技能应用到哪些受支持的智能体。

在使用该技能之前，先将 Fastino API 密钥暴露到智能体的环境中：

```bash
export FASTINO_API_KEY="..."
```

然后通过 `/fastino-gliner` 显式调用它，或者让你的智能体执行一个托管的 GLiNER 抽取、分类、微调、评估或推理工作流。

## 非交互式安装

使用与你的智能体对应的命令，将该技能安装到当前项目中，不会出现任何提示：

<CodeGroup initialSelectedTab={0}>

```bash Cursor
npx skills add https://api.fastino.ai --skill fastino-gliner -a cursor -y
```

```bash Claude Code
npx skills add https://api.fastino.ai --skill fastino-gliner -a claude-code -y
```

```bash Codex
npx skills add https://api.fastino.ai --skill fastino-gliner -a codex -y
```

对于 Cursor、Claude Code 和 Codex，`-a` 选项用于选择目标智能体，`-y` 用于自动接受安装提示，因此这些命令适用于脚本和 CI。
