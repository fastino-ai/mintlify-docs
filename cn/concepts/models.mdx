Fastino 提供用于结构化抽取的 GLiNER 模型。

## GLiNER 2.5

| 模型 ID | 模型 |
| --- | --- |
| `fastino/gliner2.5-multi-v1` | GLiNER 2.5 多语言 |
| `fastino/gliner2.5-decide` | GLiNER 2.5 Decide |

## GLiNER2 与 GLiGuard

| 模型 ID | 模型 |
| --- | --- |
| `fastino/gliner2-base-v1` | GLiNER2 Base |
| `fastino/gliner2-large-v1` | GLiNER2 Large |
| `fastino/gliner2-multi-v1` | GLiNER2 多语言 |
| `fastino/gliner2-multi-large-v1` | GLiNER2 多语言 Large |
| `fastino/gliguard-LLMGuardrails-300M` | GLiGuard LLM Guardrails |
| `fastino/gliner2-privacy-filter-PII-multi` | GLiNER2 Privacy Filter PII |
| `fastino/gliguard-PII-multi` | GLiGuard PII 多语言 |

使用 `GET /v1/base-models` 查看当前可用的模型。
