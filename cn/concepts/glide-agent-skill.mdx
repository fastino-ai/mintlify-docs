[Fastino GLiDE 智能体技能](https://api.fastino.ai/.well-known/agent-skills/fastino-glide/SKILL.md) 帮助 Cursor、Claude Code 和 Codex 使用 Fastino 托管的 GLiDE 决策模型对结构化决策进行分类、路由和评分，并将 GLiDE 推理集成到项目中。

## 安装

在你的项目中运行以下命令：

```bash
npx skills add https://api.fastino.ai --skill fastino-glide
```

安装程序允许你选择哪些受支持的智能体接收该技能。

在使用该技能之前，将你的 Fastino API 密钥暴露给智能体的环境：

```bash
export FASTINO_API_KEY="..."
```

然后通过 `/fastino-glide` 显式调用它，或者让你的智能体基于 GLiDE 做出分类、路由或评分决策。

## 非交互式安装

使用与你的智能体对应的命令，将该技能安装到当前项目中，不会出现任何提示：

<CodeGroup initialSelectedTab={0}>

```bash Cursor
npx skills add https://api.fastino.ai --skill fastino-glide -a cursor -y
```

```bash Claude Code
npx skills add https://api.fastino.ai --skill fastino-glide -a claude-code -y
```

```bash Codex
npx skills add https://api.fastino.ai --skill fastino-glide -a codex -y
```

```text Any agent

instructions in Fastino's documentation at

installation method appropriate for your agent environment. Then use

```

</CodeGroup>

对于 Cursor、Claude Code 和 Codex，`-a` 选项用于选择目标智能体，`-y` 用于自动接受安装提示，因此这些命令适用于脚本和 CI。
