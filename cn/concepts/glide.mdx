GLiDE（Generalized Lightweight Decision Engine）是一款思考型[决策模型](/cn/concepts/decision-models)。它根据一个或多个具名问题评估你提供的应用状态，并针对你定义的结果返回结构化答案、概率和置信度。

GLiDE 的价格为**每 100 万输入 token 0.15 美元**。输出 token **免费（0 美元）**。
有关当前费率，请参阅[定价](/cn/pricing)。

## 为什么选择 GLiDE

GLiDE 会先快速评估，再为不确定的决策投入额外推理。同一套接口既适用于常规分类，也适用于涉及算术、代码追踪、时间逻辑、政策解读或多项相关事实的决策。

与生成式模型不同，GLiDE 不会以自由格式文本撰写答案。你的应用定义允许的结果，并可直接根据返回的概率分布和置信度采取行动。

## 何时使用 GLiDE

| 使用场景 | 决策示例 |
| --- | --- |
| 智能体和工具路由 | 在考虑权限和先前结果后选择下一步操作 |
| 高风险操作控制 | 执行、转入沙箱、请求批准或阻止某项操作 |
| 事件响应 | 监控、重启、回滚、隔离或升级 |
| 合同和政策 | 应用交叉引用、日期、阈值和例外条款 |
| 模型输出验证 | 接受、拒绝或要求修改 |
| 日常分类 | 路由工单、审核内容或评估紧急程度 |

对于开放式写作、对话、摘要或代码生成，请改用生成式模型。
