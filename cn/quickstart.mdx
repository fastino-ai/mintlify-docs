本指南带你走完接入 Fastino 的最快路径。读完本文后，你将完成一次成功的推理调用，并了解 API 的结构。你只需要一个 Fastino 账号和一个终端。

<Steps>
  <Step title="注册并获取 API 密钥">
    在 [Fastino](https://agent.fastino.ai/) 上创建账号。

    登录后，前往 **Settings → API Keys** 并生成一个新的密钥。请将其复制到安全的地方，因为关闭对话框后你将无法再次查看它。

    <Warning>
      不要把 API 密钥提交到版本控制中。请使用环境变量或密钥管理工具，而不要把它硬编码在源文件里。
    </Warning>

    将密钥设置为环境变量，这样下面的示例可以直接运行：

    ```bash
    export FASTINO_API_KEY="your_api_key_here"
    ```
  </Step>
  <Step title="列出可用的基础模型（可选）">
    你可以浏览 Fastino 上可用的模型。使用 `GET /v1/base-models` 查看完整目录。

    <CodeGroup>

    ```bash curl
    curl https://api.fastino.ai/v1/base-models \
      -H "X-API-Key: $FASTINO_API_KEY"
    ```

    ```python Python
    import os
    import requests
    
    response = requests.get(
        "https://api.fastino.ai/v1/base-models",
        headers={"X-API-Key": os.environ["FASTINO_API_KEY"]}
    )
    print(response.json())
    ```

    ```javascript JavaScript
    const response = await fetch(
      "https://api.fastino.ai/v1/base-models",
      {
        headers: {
          "X-API-Key": process.env.FASTINO_API_KEY
        }
      }
    );
    const data = await response.json();
    console.log(data);
    ```

    </CodeGroup>

    响应中列出了可传给 `/v1/chat/completions` 的模型 ID。例如，`fastino/gliner2-base-v1` 是用于 NER 任务的 GLiNER 基础模型。
  </Step>
  <Step title="运行你的第一次推理调用">
    调用 `POST /v1/chat/completions`，并传入模型、消息以及定义你要抽取内容的 schema。下面的示例使用 GLiNER 基础模型从一句话中抽取命名实体。

    <CodeGroup>

    ```bash curl
    curl -X POST "https://api.fastino.ai/v1/chat/completions" \
      -H "Authorization: Bearer $FASTINO_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "fastino/gliner2.5-multi-v1",
        "messages": [
          {
            "role": "user",
            "content": "Apple announced the MacBook Pro at WWDC in Cupertino."
          }
        ],
        "schema": {
          "entities": [
            {
              "name": "organization",
              "description": "business or institution name"
            },
            {
              "name": "product",
              "description": "named commercial product"
            },
            {
              "name": "event",
              "description": "named conference or event"
            },
            {
              "name": "location",
              "description": "city, region, or place"
            }
          ]
        },
        "threshold": 0.5
      }'
    ```

    ```python Python
    import json
    import os
    
    import requests
    
    response = requests.post(
        "https://api.fastino.ai/v1/chat/completions",
        headers={
            "Authorization": f"Bearer {os.environ['FASTINO_API_KEY']}",
            "Content-Type": "application/json",
        },
        json={
            "model": "fastino/gliner2.5-multi-v1",
            "messages": [
                {
                    "role": "user",
                    "content": "Apple announced the MacBook Pro at WWDC in Cupertino.",
                }
            ],
            "schema": {
                "entities": [
                    {"name": "organization", "description": "business or institution name"},
                    {"name": "product", "description": "named commercial product"},
                    {"name": "event", "description": "named conference or event"},
                    {"name": "location", "description": "city, region, or place"},
                ]
            },
            "threshold": 0.5,
        },
    )
    
    response.raise_for_status()
    result = response.json()
    entities = json.loads(result["choices"][0]["message"]["content"])
    
    print(json.dumps(entities, indent=2))
    ```

    ```javascript JavaScript
    const response = await fetch(
      "https://api.fastino.ai/v1/chat/completions",
      {
        method: "POST",
        headers: {
          Authorization: `Bearer ${process.env.FASTINO_API_KEY}`,
          "Content-Type": "application/json",
        },
        body: JSON.stringify({
          model: "fastino/gliner2.5-multi-v1",
          messages: [
            {
              role: "user",
              content: "Apple announced the MacBook Pro at WWDC in Cupertino.",
            },
          ],
          schema: {
            entities: [
              { name: "organization", description: "business or institution name" },
              { name: "product", description: "named commercial product" },
              { name: "event", description: "named conference or event" },
              { name: "location", description: "city, region, or place" },
            ],
          },
          threshold: 0.5,
        }),
      }
    );
    
    if (!response.ok) {
      throw new Error(`Inference failed: ${response.status} ${await response.text()}`);
    }
    
    const result = await response.json();
    const entities = JSON.parse(result.choices[0].message.content);
    
    console.log(JSON.stringify(entities, null, 2));
    ```

    </CodeGroup>

    对于编码器模型（GLiNER），`schema` 对象定义任务，可以包含 `entities`、`classifications`、`structures` 和 `relations`：

    - `entities` — 用于 NER 的实体类型字符串列表
    - `classifications` — 用于文本分类的 `{task, labels}` 对象列表
    - `structures` — 用于 JSON 抽取的结构定义字典
    - `relations` — 关系定义列表

    对于解码器模型（LLM），省略 `schema`，直接发送普通的聊天消息即可。

    <Note>
      `model` 必须是支持推理的基础模型 ID，或是已完成且可部署的训练作业的 UUID。训练完成后，需先部署所选的产物，才能使用该作业 UUID 进行推理。
    </Note>
  </Step>
  <Step title="启动训练作业（可选）">
    当你准备好用自己的数据进行微调时，启动一个训练作业。

    <CodeGroup>

    ```bash curl
    curl -X POST https://api.fastino.ai/v1/training-jobs \
      -H "X-API-Key: $FASTINO_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model_name": "my-ner-model",
        "base_model": "fastino/gliner2-base-v1",
        "datasets": [{"name": "my-dataset"}],
        "training_type": "lora",
        "nr_epochs": 5,
        "learning_rate": 5e-5
      }'
    ```

    ```python Python
    import os
    import requests
    
    response = requests.post(
        "https://api.fastino.ai/v1/training-jobs",
        headers={
            "X-API-Key": os.environ["FASTINO_API_KEY"],
            "Content-Type": "application/json"
        },
        json={
            "model_name": "my-ner-model",
            "base_model": "fastino/gliner2-base-v1",
            "datasets": [{"name": "my-dataset"}],
            "training_type": "lora",
            "nr_epochs": 5,
            "learning_rate": 5e-5
        }
    )
    print(response.json())
    # {"id": "uuid-of-training-job", "status": "requested"}
    ```

    </CodeGroup>

    响应中包含作业 `id`。轮询 `GET /v1/training-jobs/{id}` 以查看状态。作业达到 `complete` 后，在 `/v1/chat/completions` 调用中将该作业 ID 用作 `model`。

    作业状态值：`requested` → `running` → `complete`（或 `failed` / `stopped`）。
  </Step>
</Steps>
