## 设置你的 API 密钥

1. **创建一个 [Fastino](https://agent.fastino.ai/) 账号**
2. **获取你的 API 密钥**，前往 [Settings](https://agent.fastino.ai/api-keys)

将密钥设置为环境变量，这样下面的示例可以直接运行：

<CodeGroup>

```bash macOS/Linux
export FASTINO_API_KEY="your_api_key_here"
```

```powershell Windows
setx FASTINO_API_KEY "your_api_key_here"
```

</CodeGroup>

## 运行你的第一次推理调用

调用 `POST /v1/systemone`，并传入 `model`、描述情况的 `state`，以及一个或多个类型化的 `questions`。GLiDE 直接返回经过校准的概率和标签，无需解析生成的文本。下面的示例提出了一个是/否（`noul`）问题。

GLiDE 的价格为**每 100 万输入 token 0.15 美元**。输出 token **免费（0 美元）**。
有关当前推理费率，请参阅[定价](/cn/pricing)。

<Tabs>
  <Tab title="cURL">
    **运行 GLiDE 决策调用**：

    ```bash
    curl -X POST "https://api.fastino.ai/v1/systemone" \
      -H "X-API-Key: $FASTINO_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "fastino/GLiDE",
        "state": "Refund request: the receipt is attached, the purchase was 10 days ago, and refunds are allowed within 30 days.",
        "questions": {
          "refund_allowed": {
            "type": "noul",
            "instructions": "Does this request qualify for a refund?",
            "criteria": { "true": "Qualifies", "false": "Does not qualify" }
          }
        }
      }'
    ```
  </Tab>

  <Tab title="Python">
    **运行 GLiDE 决策调用**：

    ```python
    import os
    import requests

    response = requests.post(
        "https://api.fastino.ai/v1/systemone",
        headers={
            "X-API-Key": os.environ["FASTINO_API_KEY"],
            "Content-Type": "application/json",
        },
        json={
            "model": "fastino/GLiDE",
            "state": "Refund request: the receipt is attached, the purchase was 10 days ago, and refunds are allowed within 30 days.",
            "questions": {
                "refund_allowed": {
                    "type": "noul",
                    "instructions": "Does this request qualify for a refund?",
                    "criteria": {"true": "Qualifies", "false": "Does not qualify"},
                }
            },
        },
    )

    response.raise_for_status()
    print(response.json())
    ```
  </Tab>

  <Tab title="JavaScript">
    **运行 GLiDE 决策调用**：

    ```javascript
    const response = await fetch(
      "https://api.fastino.ai/v1/systemone",
      {
        method: "POST",
        headers: {
          "X-API-Key": process.env.FASTINO_API_KEY,
          "Content-Type": "application/json",
        },
        body: JSON.stringify({
          model: "fastino/GLiDE",
          state: "Refund request: the receipt is attached, the purchase was 10 days ago, and refunds are allowed within 30 days.",
          questions: {
            refund_allowed: {
              type: "noul",
              instructions: "Does this request qualify for a refund?",
              criteria: { true: "Qualifies", false: "Does not qualify" },
            },
          },
        }),
      }
    );

    if (!response.ok) {
      throw new Error(`Inference failed: ${response.status} ${await response.text()}`);
    }

    const result = await response.json();
    console.log(JSON.stringify(result, null, 2));
    ```
  </Tab>
</Tabs>

成功的响应如下所示：

```json
{
  "model": "glide",
  "answers": {
    "refund_allowed": {
      "type": "noul",
      "noul": 0.99767683794902,
      "confidence": 0.9953536758980399
    }
  },
  "usage": { "input_tokens": 89, "output_tokens": 1 },
  "token_usage": 90
}
```

`answers.refund_allowed.noul` 表示答案为“是”的概率。`0.999` 是一个很强的符合条件信号。接下来可查看 [Noul](/cn/concepts/glide-noul)、[Choice](/cn/concepts/glide-choice) 和 [Score](/cn/concepts/glide-score) 参考，或使用[路由指南](/cn/guides/glide-routing)将置信度转换为操作。

<Accordion title="需要抽取实体？使用 GLiNER 2.5">
  如果你需要的是片段级抽取（NER、分类、结构化记录）而不是决策，请调用 `POST /v1/chat/completions`，并传入模型、消息以及定义你要抽取内容的 schema：

  ```bash
  curl -X POST "https://api.fastino.ai/v1/chat/completions" \
    -H "Authorization: Bearer $FASTINO_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "fastino/gliner2.5-multi-v1",
      "messages": [
        {
          "role": "user",
          "content": "Apple announced the MacBook Pro at WWDC in Cupertino."
        }
      ],
      "schema": {
        "entities": [
          { "name": "organization", "description": "business or institution name" },
          { "name": "product", "description": "named commercial product" },
          { "name": "event", "description": "named conference or event" },
          { "name": "location", "description": "city, region, or place" }
        ]
      },
      "threshold": 0.5
    }'
  ```

  对于编码器模型（GLiNER），`schema` 对象定义任务，可以包含 `entities`、`classifications`、`structures` 和 `relations`。对于解码器模型（LLM），省略 `schema`，直接发送普通的聊天消息即可。完整的接口约定、Python/JavaScript 示例和错误码请参阅[推理 API](/cn/inference/chat-completions)。
</Accordion>
