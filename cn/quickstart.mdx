## 设置你的 API 密钥

1. **创建一个 [Fastino](https://agent.fastino.ai/) 账号**
2. **获取你的 API 密钥**，前往 [Settings](https://agent.fastino.ai/api-keys)

请将密钥复制到安全的地方，因为关闭对话框后你将无法再次查看它。

<Warning>
  不要把 API 密钥提交到版本控制中。请使用环境变量或密钥管理工具，而不要把它硬编码在源文件里。
</Warning>

将密钥设置为环境变量，这样下面的示例可以直接运行：

<CodeGroup>

```bash macOS/Linux
export FASTINO_API_KEY="your_api_key_here"
```

```powershell Windows
setx FASTINO_API_KEY "your_api_key_here"
```

</CodeGroup>

## 列出可用的模型（可选）

你可以浏览 Fastino 上可用的模型。使用 `GET /v1/base-models` 查看完整目录。

<Tabs>
  <Tab title="cURL">
    **列出可用的模型**：

    ```bash
    curl https://api.fastino.ai/v1/base-models \
      -H "X-API-Key: $FASTINO_API_KEY"
    ```
  </Tab>

  <Tab title="Python">
    **列出可用的模型**：

    ```python
    import os
    import requests

    response = requests.get(
        "https://api.fastino.ai/v1/base-models",
        headers={"X-API-Key": os.environ["FASTINO_API_KEY"]}
    )
    print(response.json())
    ```
  </Tab>

  <Tab title="JavaScript">
    **列出可用的模型**：

    ```javascript
    const response = await fetch(
      "https://api.fastino.ai/v1/base-models",
      {
        headers: {
          "X-API-Key": process.env.FASTINO_API_KEY
        }
      }
    );
    const data = await response.json();
    console.log(data);
    ```
  </Tab>
</Tabs>

响应中列出了可传给 `/v1/systemone` 或 `/v1/chat/completions` 的模型 ID。例如，`fastino/gliner2-base-v1` 是用于 NER 任务的 GLiNER 基础模型。

## 运行你的第一次推理调用

调用 `POST /v1/systemone`，并传入 `model`、描述情况的 `state`，以及一个或多个类型化的 `questions`。GLiDE 直接返回经过校准的概率和标签，无需解析生成的文本。下面的示例提出了一个是/否（`noul`）问题。

<Tabs>
  <Tab title="cURL">
    **运行 GLiDE 决策调用**：

    ```bash
    curl -X POST "https://api.fastino.ai/v1/systemone" \
      -H "X-API-Key: $FASTINO_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "fastino/glide",
        "state": "Refund request: the receipt is attached, the purchase was 10 days ago, and refunds are allowed within 30 days.",
        "questions": {
          "refund_allowed": {
            "type": "noul",
            "instructions": "Does this request qualify for a refund?",
            "criteria": { "true": "Qualifies", "false": "Does not qualify" }
          }
        }
      }'
    ```
  </Tab>

  <Tab title="Python">
    **运行 GLiDE 决策调用**：

    ```python
    import os
    import requests

    response = requests.post(
        "https://api.fastino.ai/v1/systemone",
        headers={
            "X-API-Key": os.environ["FASTINO_API_KEY"],
            "Content-Type": "application/json",
        },
        json={
            "model": "fastino/glide",
            "state": "Refund request: the receipt is attached, the purchase was 10 days ago, and refunds are allowed within 30 days.",
            "questions": {
                "refund_allowed": {
                    "type": "noul",
                    "instructions": "Does this request qualify for a refund?",
                    "criteria": {"true": "Qualifies", "false": "Does not qualify"},
                }
            },
        },
    )

    response.raise_for_status()
    print(response.json())
    ```
  </Tab>

  <Tab title="JavaScript">
    **运行 GLiDE 决策调用**：

    ```javascript
    const response = await fetch(
      "https://api.fastino.ai/v1/systemone",
      {
        method: "POST",
        headers: {
          "X-API-Key": process.env.FASTINO_API_KEY,
          "Content-Type": "application/json",
        },
        body: JSON.stringify({
          model: "fastino/glide",
          state: "Refund request: the receipt is attached, the purchase was 10 days ago, and refunds are allowed within 30 days.",
          questions: {
            refund_allowed: {
              type: "noul",
              instructions: "Does this request qualify for a refund?",
              criteria: { true: "Qualifies", false: "Does not qualify" },
            },
          },
        }),
      }
    );

    if (!response.ok) {
      throw new Error(`Inference failed: ${response.status} ${await response.text()}`);
    }

    const result = await response.json();
    console.log(JSON.stringify(result, null, 2));
    ```
  </Tab>
</Tabs>

成功的响应如下所示：

```json
{
  "model": "glide",
  "answers": {
    "refund_allowed": {
      "type": "noul",
      "noul": 0.9989566626894673,
      "confidence": 0.9979133253789345
    }
  },
  "usage": { "input_tokens": 443, "output_tokens": 62 },
  "token_usage": 505
}
```

`answers.refund_allowed.noul` 表示答案为“是”的概率。`0.999` 是一个很强的符合条件信号。关于 `choice` 和 `score` 问题类型、基于置信度的路由以及完整的基本类型参考，请参阅[决策模型](/cn/concepts/decision-models)。

<Accordion title="需要抽取实体？通过 /v1/chat/completions 使用 GLiNER">
  如果你需要的是片段级抽取（NER、分类、结构化记录）而不是决策，请调用 `POST /v1/chat/completions`，并传入模型、消息以及定义你要抽取内容的 schema：

  ```bash
  curl -X POST "https://api.fastino.ai/v1/chat/completions" \
    -H "Authorization: Bearer $FASTINO_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "fastino/gliner2.5-multi-v1",
      "messages": [
        {
          "role": "user",
          "content": "Apple announced the MacBook Pro at WWDC in Cupertino."
        }
      ],
      "schema": {
        "entities": [
          { "name": "organization", "description": "business or institution name" },
          { "name": "product", "description": "named commercial product" },
          { "name": "event", "description": "named conference or event" },
          { "name": "location", "description": "city, region, or place" }
        ]
      },
      "threshold": 0.5
    }'
  ```

  对于编码器模型（GLiNER），`schema` 对象定义任务，可以包含 `entities`、`classifications`、`structures` 和 `relations`。对于解码器模型（LLM），省略 `schema`，直接发送普通的聊天消息即可。完整的接口约定、Python/JavaScript 示例和错误码请参阅[推理 API](/cn/inference)。

  <Note>
    `model` 必须是支持推理的基础模型 ID，或是已完成且可部署的训练作业的 UUID。训练完成后，需先部署所选的产物，才能使用该作业 UUID 进行推理。
  </Note>
</Accordion>

## 启动训练作业（可选）

当你准备好用自己的数据进行微调时，启动一个训练作业。

<Tabs>
  <Tab title="cURL">
    **启动训练作业**：

    ```bash
    curl -X POST https://api.fastino.ai/v1/training-jobs \
      -H "X-API-Key: $FASTINO_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model_name": "my-ner-model",
        "base_model": "fastino/gliner2-base-v1",
        "datasets": [{"name": "my-dataset"}],
        "training_type": "lora",
        "nr_epochs": 5,
        "learning_rate": 5e-5
      }'
    ```
  </Tab>

  <Tab title="Python">
    **启动训练作业**：

    ```python
    import os
    import requests

    response = requests.post(
        "https://api.fastino.ai/v1/training-jobs",
        headers={
            "X-API-Key": os.environ["FASTINO_API_KEY"],
            "Content-Type": "application/json"
        },
        json={
            "model_name": "my-ner-model",
            "base_model": "fastino/gliner2-base-v1",
            "datasets": [{"name": "my-dataset"}],
            "training_type": "lora",
            "nr_epochs": 5,
            "learning_rate": 5e-5
        }
    )
    print(response.json())
    # {"id": "uuid-of-training-job", "status": "requested"}
    ```
  </Tab>
</Tabs>

响应中包含作业 `id`。轮询 `GET /v1/training-jobs/{id}` 以查看状态。作业达到 `complete` 后，在 `/v1/chat/completions` 调用中将该作业 ID 用作 `model`。

作业状态值：`requested` → `running` → `complete`（或 `failed` / `stopped`）。
