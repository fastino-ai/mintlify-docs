训练任务 API 管理微调任务的完整生命周期。所有端点都使用 `/v1/training-jobs` 路由族，并要求在 `X-API-Key` 头中提供 API 密钥。

**API 基础 URL：** `https://api.fastino.ai`

```bash
export FASTINO_API_KEY="fast_sk_..."
```

在每个训练请求中发送该密钥：

```http
X-API-Key: $FASTINO_API_KEY
```

在创建任务之前，请立即调用 `GET /v1/base-models?supports_training=true`。它是可训练模型 ID 的实时权威来源。
提交任务之前，请先[准备并上传训练数据集](/cn/concepts/datasets)，并等待其处理后的版本变为就绪。

<Warning>
  旧版 `/felix/training-jobs` 路由族已停用。新的集成和迁移后的集成请使用 `/v1/training-jobs`。
</Warning>

## 状态生命周期

训练任务响应包含：

- `status`：持久化的任务状态。
- `normalized_status`：用于客户端轮询的稳定状态。
- `is_terminal_status`：是否可以停止轮询。
- `error_message`：可用时的失败信息。
- `is_deployable`：训练完成的工件是否通过部署校验。
- `deployability_reason`：工件不可部署的原因。

在轮询客户端中优先使用 `normalized_status` 和 `is_terminal_status`。

| 持久化状态 | 说明 |
| --- | --- |
| `requested` | 任务已被接受，正在等待调度或资源预置。 |
| `running` | 训练正在进行中。 |
| `complete` | 训练已成功完成。工件准备可能仍在继续。 |
| `normalizing` | Fastino 正在准备训练好的工件。 |
| `artifact_ready` | 训练工件已就绪。 |
| `deployed` | 工件已完成部署。 |
| `paused` | 任务或其流水线已暂停。 |
| `errored` | 训练、调度或工件准备失败。 |
| `stopped` | 任务已停止，同时保留现有检查点。 |
| `terminated` | 任务已终止，其检查点已被删除。 |

## 端点

| 方法 | 端点 | 用途 |
| --- | --- | --- |
| `POST` | [`/v1/training-jobs`](/cn/api-reference/training-jobs/create) | 创建训练任务 |
| `GET` | [`/v1/training-jobs`](/cn/api-reference/training-jobs/list) | 列出训练任务 |
| `GET` | [`/v1/training-jobs/{job_id}`](/cn/api-reference/training-jobs/get) | 获取状态、配置和指标 |
| `PATCH` | [`/v1/training-jobs/{job_id}`](/cn/api-reference/training-jobs/update-project) | 分配或取消分配项目 |
| `PATCH` | [`/v1/training-jobs/{job_id}/model-name`](/cn/api-reference/training-jobs/update-model-name) | 重命名训练后的模型 |
| `GET` | [`/v1/training-jobs/{job_id}/logs`](/cn/api-reference/training-jobs/logs) | 获取训练日志快照 |
| `GET` | [`/v1/training-jobs/{job_id}/billing`](/cn/api-reference/training-jobs/billing) | 获取计费结果 |
| `GET` | [`/v1/training-jobs/{job_id}/deployments`](/cn/api-reference/training-jobs/deployments) | 列出从该任务创建的部署 |
| `POST` | [`/v1/training-jobs/{job_id}/stop`](/cn/api-reference/training-jobs/stop) | 停止任务并保留检查点 |
| `POST` | [`/v1/training-jobs/{job_id}/terminate`](/cn/api-reference/training-jobs/terminate) | 停止任务并删除检查点 |
| `POST` | [`/v1/training-jobs/{job_id}/sync`](/cn/api-reference/training-jobs/sync) | 从训练提供方刷新状态 |
| `POST` | [`/v1/training-jobs/{job_id}/push-to-hub`](/cn/api-reference/training-jobs/push-to-hub) | 将已完成的工件推送到 Hugging Face Hub |
| `GET` | [`/v1/training-jobs/{job_id}/checkpoints`](/cn/api-reference/training-jobs/checkpoints) | 列出检查点 |
| `POST` | [`/v1/training-jobs/{job_id}/checkpoints/{checkpoint_id}/deploy`](/cn/api-reference/training-jobs/deploy-checkpoint) | 部署检查点 |
| `GET` | [`/v1/training-jobs/{job_id}/download`](/cn/api-reference/training-jobs/download) | 获取临时的权重下载 URL |
| `DELETE` | [`/v1/training-jobs/{job_id}`](/cn/api-reference/training-jobs/delete) | 删除任务及其检查点 |
