## 推理

| 模型 | 每 100 万输入 token 价格 | 每 100 万输出 token 价格 |
| --- | --- | --- |
| GLiDE | \$0.15 | \$0 |
| GLiNER-2.5-Decide | \$0.03 | \$0 |
| GLiNER 2.5 | \$0.03 | \$0 |
| GLiNER2 | \$0.03 | \$0 |
| GLiGuard LLM Guardrails | \$0.15 | \$0.15 |
| GLiNER2 Privacy Filter PII | \$0.03 | \$0 |
| GLiGuard PII Multi | \$0.15 | \$0.15 |

GLiDE 响应会为其结构化答案报告 `usage.output_tokens`，但这些输出 token 的价格为 \$0；仅输入 token 按所列费率计费。

请参阅[模型目录](/cn/concepts/models)，查看各模型 ID 对应的价格。

## 训练

### 配置任务

使用托管配置任务微调 GLiNER 模型的费用为每 GPU 分钟 \$0.07（每 GPU 小时 \$4.20）。

### 交互式任务

Token 价格取决于模型和操作。价格均按每 100 万 token 计算。

| 模型 | 训练 | 采样输入 | 缓存的采样输入 | 采样输出 |
| --- | --- | --- | --- | --- |
| Nemotron 3 Super<br />`nvidia/NVIDIA-Nemotron-3-Super-120B-A12B-BF16` | \$0.96 | \$0.16 | \$0.032 | \$0.72 |
| Nemotron 3.5 Lightning<br />`nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16` | \$0.30 | \$0.05 | \$0.01 | \$0.35 |
| Qwen3.6 35B A3B<br />`Qwen/Qwen3.6-35B-A3B` | \$0.35 | \$0.08 | \$0.016 | \$0.35 |

训练包括前向和前向/反向 token。采样输入、缓存输入和输出 token 分别计费。

在你持续使用 Fastino 的过程中可以随时充值额度，从而让你的推理和训练工作流持续运行。
