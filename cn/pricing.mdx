## 训练

配置任务按 GPU 时间计费。交互式任务按 token 计费。

### 配置任务

使用托管配置任务微调 GLiNER 模型的费用为每 GPU 分钟 \$0.07（每 GPU 小时 \$4.20）。

### 交互式任务

Token 价格以美元计，单位为每 100 万 token。

| 模型 | 预填充（未缓存） | 预填充（已缓存） | 采样 | 训练 |
| --- | --- | --- | --- | --- |
| Nemotron 3.5 Super VL | \$0.16 | \$0.04 | \$0.72 | \$0.96 |
| Nemotron 3.5 Lightning | \$0.05 | \$0.01 | \$0.35 | \$0.30 |
| Qwen3.6-35B-A3B | \$0.08 | \$0.01 | \$0.35 | \$0.35 |

训练价格涵盖前向和前向/反向 token。采样会对未缓存的预填充 token、缓存读取 token 和生成的输出 token 分别计费。交互式检查点存储价格为 \$0.05 / GB·月，按天计量。

## 推理

| 模型 | 每 100 万输入 token 价格 | 每 100 万输出 token 价格 |
| --- | --- | --- |
| Nemotron 3.5 Super VL | \$0.08 | \$0.45 |
| GLiDE | \$0.15 | \$0 |
| GLiNER-2.5-Decide | \$0.03 | \$0 |
| GLiNER 2.5 | \$0.03 | \$0 |
| GLiNER2 | \$0.03 | \$0 |
| GLiGuard LLM Guardrails | \$0.15 | \$0.15 |
| GLiNER2 Privacy Filter PII | \$0.03 | \$0 |
| GLiGuard PII Multi | \$0.15 | \$0.15 |

GLiDE 响应会为其结构化答案报告 `usage.output_tokens`，但这些输出 token 的价格为 \$0；仅输入 token 按所列费率计费。

请参阅[模型目录](/cn/concepts/models)，查看各模型 ID 对应的价格。

在你持续使用 Fastino 的过程中可以随时充值额度，从而让你的推理和训练工作流持续运行。
