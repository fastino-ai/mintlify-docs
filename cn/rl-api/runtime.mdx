工作负载连接成功后，如果你需要分析其生命周期或故障，请使用本参考。

## Future 和会话

已提交的操作会返回 Tinker future。API 支持获取 future、等待、报告队列状态和取消采样。

已接受的操作可能会报告 `paused_capacity`。请将其视为正在等待的工作，而不是
被拒绝的请求。

已完成的 future 结果会保留一小时。请及时解析并持久化结果。

取消操作仅适用于采样操作。单个训练操作提交后无法取消。

应用完成后，请关闭 `ServiceClient`。关闭客户端会释放活跃运行，但不会删除保留的
检查点。

请求按 Fastino 团队隔离。一个密钥无法检查或操作其他团队的会话、运行或检查点。

## 检查点和运行管理

SDK REST 客户端支持：

- 列出训练运行
- 获取一个训练运行
- 列出某个运行或团队的检查点
- 检查检查点权重元数据
- 将权重复制到新运行中
- 删除检查点
- 发布或取消发布检查点
- 设置或清除检查点的生存时间
- 报告当前检查点存储用量

发布操作只会更改团队内部的检查点元数据。它不会创建公开列表、允许其他 Fastino
团队加载检查点、更改服务行为或授予访问权限。请勿将跨团队分发纳入自动化工作流。

训练状态路径使用：

```text
tinker://<run-id>/weights/<name>
```

采样器权重路径使用：

```text
tinker://<run-id>/sampler_weights/<name>
```

状态检查点包含恢复训练所需的信息，包括优化器配置。采样器检查点用于推理和 rollout
生成，无法恢复优化器状态。可靠的恢复还需要持久的本地循环元数据，例如数据集游标和已完成的步骤。

## 限制

采样、前向和前向-反向调用各自有独立的单次调用序列限制。每项限制都可能低于模型的上下文窗口，Fastino
可以在不更改 SDK 的情况下调整这些限制。请将无效长度响应视为请求构造错误：

1. 缩短提示词或补全长度。
2. 拆分大型训练批次。
3. 使用有效请求重试，而不是重复发送同一个无效正文。

不要在可复用的智能体逻辑中硬编码未记录的单次调用限制。Tinker SDK 会对训练批次
进行分块。如果请求过大，请拆分批次，并使用新的有效请求重试。

## 重试语义

SDK 会让同一训练运行中的操作保持顺序。重试相同操作会返回原始 future，不会重复
应用更新。即使原始提交响应丢失，仍可获取该 future。

重试时不要修改请求。不要让多个独立进程修改同一个 `TrainingClient`。

## 计费行为

| 工作 | 计量单位 |
| --- | --- |
| 采样 | 输入、缓存输入和输出 token |
| `forward` 和 `forward_backward` | 训练 token |
| 检查点 | 随时间累计的存储字节数 |
| 创建客户端或模型 | 不计量 token |
| `optim_step` | 不计量 token |
| 保存或加载请求 | 除存储的检查点用量外，不计量 token |

用量归属于会话的 Fastino 项目。未指定项目时，使用团队的默认项目。

## 错误

| 现象 | 可能原因 | 操作 |
| --- | --- | --- |
| 功能调用返回 `404 Not Found` | 基础 URL 错误或未启用 RL API 访问权限 | 确认 `/tinker` 后缀，然后联系 Fastino |
| 身份验证错误 | 缺少 `tml-` 封装或 Fastino 密钥无效 | 使用当前 `fast_sk_...` 密钥重新构建 `TINKER_API_KEY` |
| 计费工作返回 `402 Payment Required` | Fastino 计费或支出准入拒绝了请求 | 解决账户计费问题后再重试 |
| 模型未提供 | 源模型不在 Fastino 的 RL 目录中 | 从 `get_server_capabilities()` 中选择模型 |
| Rank 被拒绝 | 请求的 LoRA rank 大于 32 | 使用 32 或更低的 rank |
| 损失函数被拒绝 | 损失函数名称不在支持集合中 | 使用已记录的五种损失函数之一 |
| Future 报告 `paused_capacity` | 运行正在等待容量 | 按照 SDK 的退避策略继续轮询 |
| Future 结果返回 `410` | 结果已过期或结果不可用 | 不要重新提交结果未知的训练变更；请从最新的显式状态检查点恢复 |
| 运行无法恢复实时状态 | 活跃运行无法继续 | 从最新的显式状态检查点恢复 |

支持的模型、方法、损失函数和不支持的功能请参阅
[Tinker 兼容性](/cn/rl-api/compatibility)。
