使用本参考判断现有 Tinker 应用能否在不更改算法的情况下通过 Fastino 运行。

## 客户端契约

| 项目 | 值 |
| --- | --- |
| Python 软件包 | `tinker` |
| 测试版本 | `0.32.0` |
| 支持的最低版本 | `0.25.0` |
| 基础 URL | `https://api.fastino.ai/tinker` |
| 凭据 | `tml-` 后跟 Fastino `fast_sk_...` 密钥 |
| 团队访问权限 | 通过身份验证的 Fastino 团队可获得限量访问权限 |

使用此预览版进行开发时，请固定 `tinker==0.32.0`。

## 模型

| 基础模型 | 上下文窗口 | 最大 LoRA rank |
| --- | ---: | ---: |
| `Qwen/Qwen3.6-35B-A3B` | 32,768 | 32 |
| `nvidia/NVIDIA-Nemotron-3-Super-120B-A12B-BF16` | 32,768 | 32 |
| `nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16` | 65,536 | 32 |

选择模型之前，请调用 `get_server_capabilities()`。功能响应是当前可用性和上下文窗口
的权威依据。

## 训练操作

| 功能 | 支持情况 |
| --- | --- |
| 创建 LoRA 训练客户端 | 支持 |
| `forward` | 支持 |
| `forward_backward` | 支持 |
| `optim_step` | 支持 |
| 保存或加载训练状态 | 支持 |
| 从已保存状态创建新客户端 | 支持 |
| 保存采样器权重 | 支持 |
| 从训练权重创建采样客户端 | 支持 |
| 卸载或释放运行 | 支持 |
| LoRA 以外的训练布局 | 不支持 |

支持的优化器系列是通过 SDK `AdamParams` 使用的 AdamW。

### 损失函数

- `cross_entropy`
- `importance_sampling`
- `ppo`
- `cispo`
- `dro`

[使用可验证奖励进行训练](/cn/rl-api/verifiable-rewards)中的 on-policy 循环使用
`importance_sampling`。

## 采样操作

| 功能 | 支持情况 |
| --- | --- |
| 从基础模型采样 | 支持 |
| 从具名采样器权重采样 | 支持 |
| 从当前训练权重采样 | 支持 |
| 请求多个样本 | 支持 |
| 计算 token 对数概率 | 支持 |
| 取消排队中的采样 future | 支持 |
| 图像或多模态提示词块 | 不支持 |
| `target_prompt_logprobs` | 不支持 |
| `prompt_alt_tokens_k` | 不支持 |

当前模型接受编码后的文本 token 块。采样需要 `SamplingClient`。

## 其他差异

| 功能 | 行为 |
| --- | --- |
| 会话 trace 导出 | 不支持 |
| SDK 审计端点 | 不返回条目 |
| 跨团队加载检查点 | 不支持 |
| OpenAPI 发现 | RL 路由有意不包含在公共 OpenAPI 文档中 |

请使用应用日志和 Fastino 项目用量记录进行运维归因。

Future、检查点、重试、计费、限制和错误请参阅
[运行时行为和错误](/cn/rl-api/runtime)。
