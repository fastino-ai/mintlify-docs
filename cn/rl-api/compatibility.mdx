使用本页判断现有 Tinker 程序能否在不更改算法的情况下通过 Fastino 的 RL API 运行。

## 客户端契约

| 项目 | 值 |
| --- | --- |
| Python 软件包 | `tinker` |
| 测试版本 | `0.32.0` |
| 支持的最低版本 | `0.25.0` |
| 基础 URL | `https://api.fastino.ai/tinker` |
| 凭据 | `tml-` 后跟 Fastino `fast_sk_...` 密钥 |
| 团队访问权限 | 由通过身份验证的 Fastino 团队的 RL API 访问权限控制 |

生产环境请固定使用测试版本：

```bash
pip install "tinker==0.32.0"
```

## 模型目录

| 基础模型 | 上下文窗口 | 最大 LoRA rank | 行为 |
| --- | ---: | ---: | --- |
| `Qwen/Qwen3.6-35B-A3B` | 32,768 | 32 | 默认训练布局 |
| `nvidia/NVIDIA-Nemotron-3-Super-120B-A12B-BF16` | 32,768 | 32 | 不带后缀的模型 ID 会解析到快速层级 |
| `nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16` | 65,536 | 32 | 完整的 Tinker 兼容 LoRA 布局 |

Nemotron 3 Super 也接受 `:fast` 后缀。当启用 attention，并禁用 MLP 和
unembedding 训练时，会通过其 LoRA 训练标志选择仅 attention 的运行。

始终在运行时查询 `get_server_capabilities()`。该响应是模型可用性和上下文窗口的权威依据。

## 训练操作

| 功能 | 支持情况 |
| --- | --- |
| 创建 LoRA 训练客户端 | 支持；不支持其他训练布局 |
| `forward` | 支持 |
| `forward_backward` | 支持 |
| `optim_step` | 支持 |
| 保存训练状态 | 支持 |
| 加载训练状态 | 支持 |
| 从已保存状态创建新客户端 | 支持 |
| 保存采样器权重 | 支持 |
| 保存权重并获取临时采样客户端 | 支持 |
| 卸载或释放运行 | 支持 |

支持的优化器系列为 `adamw`。SDK `AdamParams` 值提供步骤参数。

### 损失函数

接受的损失函数名称为：

- `cross_entropy`
- `importance_sampling`
- `ppo`
- `cispo`
- `dro`

对于基于采样对数概率和优势值进行训练的标准 on-policy 实战示例循环，请使用 `importance_sampling`。

## 采样操作

| 功能 | 支持情况 |
| --- | --- |
| 从基础模型采样 | 支持 |
| 从具名采样器权重采样 | 支持 |
| 从临时训练权重采样 | 支持 |
| 请求多个样本 | 支持 |
| 计算 token 对数概率 | 支持 |
| 取消排队中的采样 future | 支持 |
| 图像或多模态提示词块 | 不支持；当前模型仅支持文本 |
| `target_prompt_logprobs` | 不支持 |
| `prompt_alt_tokens_k` | 不支持 |

从当前训练策略采样通常从 `save_weights_and_get_sampling_client()` 开始。

提示词使用编码后的文本 token 块。不支持直接无状态采样。请根据基础模型、具名采样器检查点或当前训练权重创建 `SamplingClient`。

## Future 和会话

已提交的操作会返回 Tinker future。API 支持获取 future、等待、报告队列状态和取消采样。

Fastino 放置或恢复运行时，已接受的操作可能会报告 `paused_capacity`。请将其视为正在等待的工作，而不是被拒绝的请求。

已完成的 future 结果会保留一小时。请及时解析并持久化结果。请求元数据会保留更长时间，但不能替代已过期的结果正文。

取消操作仅适用于采样操作。单个训练操作提交后无法取消。

SDK 会自动发送会话心跳。五分钟内没有心跳的会话会被视为过期，其实时资源可能被释放。应用完成后，请显式关闭 `ServiceClient`。

请求按 Fastino 团队隔离。一个密钥无法检查或操作其他团队的会话、运行或检查点。

## 检查点和运行管理

SDK REST 客户端支持：

- 列出训练运行
- 获取一个训练运行
- 列出某个运行或团队的检查点
- 检查检查点权重元数据
- 将权重复制到新运行中
- 删除检查点
- 发布或取消发布检查点
- 设置或清除检查点的生存时间
- 报告当前检查点存储用量

发布操作会切换检查点元数据。目前，它不会让其他 Fastino
团队能够加载该检查点。请勿将跨团队分发纳入自动化工作流。

训练状态路径使用：

```text
tinker://<run-id>/weights/<name>
```

采样器权重路径使用：

```text
tinker://<run-id>/sampler_weights/<name>
```

状态检查点包含恢复训练所需的信息，包括优化器配置。采样器检查点用于推理和 rollout
生成，无法恢复优化器状态。可靠的恢复还需要持久的本地循环元数据，例如数据集游标和已完成的步骤。

## 限制

功能响应会报告每个模型的最大上下文长度，模型目录将 LoRA rank 限制为 32。

采样、前向和前向-反向调用各自有独立的单次调用序列限制。每项限制都可能低于模型的上下文窗口，Fastino
可以在不更改 SDK 契约的情况下独立调整它们。请将无效长度响应视为请求构造错误：

1. 缩短提示词或补全长度。
2. 拆分大型训练批次。
3. 使用有效请求重试，而不是重复发送同一个无效正文。

不要在可复用的智能体逻辑中硬编码未记录的单次调用限制。

采样和前向-反向请求正文应保持在 32 MiB 或以下。这是当前的 HTTP
默认值，也是前向-反向请求解压后的上限。服务请求设置可以独立更改。如果自定义客户端代码收到请求大小错误，请在提交前拆分批次。Tinker SDK
通常会对训练批次执行这种分块。

## 重试语义

同一训练运行中的操作按序列 ID 排序。

- 使用相同的运行、序列 ID 和请求正文重试会返回原始操作。
- 使用相同序列 ID 但不同正文会返回错误。
- 原始提交响应丢失后，仍可获取 future。

这使网络重试不会重复应用同一个优化器变更。它并不意味着修改后的请求可以安全复用同一序列。

## 计费行为

| 工作 | 计量单位 |
| --- | --- |
| 采样 | 输入、缓存输入和输出 token |
| `forward` 和 `forward_backward` | 训练 token |
| 检查点 | 随时间累计的存储字节数 |
| 创建客户端或模型 | 不计量 token |
| `optim_step` | 不计量 token |
| 保存或加载请求 | 除存储的检查点用量外，不计量 token |

用量归属于会话的 Fastino 项目。未指定项目时，使用团队的默认项目。

## 已知差异

### Trace 导出

不支持导出会话 trace。请求会报告导出失败，而不会返回 trace 数据。

### 审计日志

SDK 审计端点不返回任何条目。请使用你自己的应用日志和 Fastino 项目用量记录进行运维归因。

### 模型可用性

RL API 不会完整复刻其他 Tinker 环境中可用的每个模型。请使用功能响应和上方列出的受支持模型 ID。

### OpenAPI 发现

RL 路由不包含在 Fastino 的公共 OpenAPI 文档中。这是有意为之，因为公共客户端契约是
Tinker SDK。原生 Fastino 路由仍由
[API 参考](/cn/api-reference/inference/overview)记录。

## 常见故障解读

| 现象 | 可能原因 | 操作 |
| --- | --- | --- |
| 功能调用返回 `404 Not Found` | 基础 URL 错误或未启用 RL API 访问权限 | 确认 `/tinker` 后缀，然后联系 Fastino |
| 身份验证错误 | 缺少 `tml-` 封装或 Fastino 密钥无效 | 使用当前 `fast_sk_...` 密钥重新构建 `TINKER_API_KEY` |
| 计费工作返回 `402 Payment Required` | Fastino 计费或支出准入拒绝了请求 | 解决账户计费问题后再重试 |
| 模型未提供 | 源模型不在 Fastino 的 RL 目录中 | 从 `get_server_capabilities()` 中选择模型 |
| Rank 被拒绝 | 请求的 LoRA rank 大于 32 | 使用 32 或更低的 rank |
| 损失函数被拒绝 | 损失函数名称不在支持集合中 | 使用已记录的五种损失函数之一 |
| 相同序列、不同正文 | 客户端排序冲突 | 按顺序创建新操作；不要重写历史记录 |
| Future 报告 `paused_capacity` | 运行正在等待资源放置、启动或恢复 | 按照 SDK 的退避策略继续轮询 |
| Future 结果返回 `410` | 结果正文已过期或其效果已丢失 | 让 SDK 重新提交；如果变更结果仍不明确，请从最新检查点恢复 |
| 运行无法恢复实时状态 | 持久重放或基础设施恢复失败 | 从最新的显式状态检查点恢复 |

有关面向任务的迁移流程，请参阅[从 Tinker 迁移](/cn/rl-api/migrate-from-tinker)。
