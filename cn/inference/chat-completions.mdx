GLiNER 将文本转换为受 schema 约束的数据。它适用于实体提取、分类、结构化记录、
关系抽取和受约束的多任务决策。需要结构化选择或排序时，请改用
[GLiDE](/cn/inference/systemone)。

## 选择端点

| 工作负载 | 端点 | 参考 |
| --- | --- | --- |
| 托管模型和微调模型 | `POST /v1/chat/completions` | [请求、响应、schema 和示例](/cn/api-reference/inference/chat-completions) |
| 原生同步 GLiNER-2 | `POST /v1/gliner-2` | [请求、响应和示例](/cn/api-reference/inference/gliner-2) |
| 超过一百万 token 的原生输入 | `POST /v1/gliner-2/async` | [提交异步作业](/cn/api-reference/inference/gliner-2-async) |
| 轮询原生异步作业 | `GET /v1/gliner-2/jobs/{job_id}` | [读取作业状态和结果](/cn/api-reference/inference/gliner-2-job-status) |

大多数集成应从 `POST /v1/chat/completions` 开始。它支持兼容 OpenAI 的
`model` 和 `messages` 信封、微调模型 ID、持久化推理历史以及完整的 GLiNER schema。

## 调用之前

1. 将密钥导出为 `FASTINO_API_KEY`。
2. 查询 `GET /v1/base-models?supports_inference=true&task_type=encoder`。
3. 确认所选模型的 `encoder_features` 支持所需的 schema 功能。
4. 按照完整 API 参考操作，不要推断字段或结果形状。
