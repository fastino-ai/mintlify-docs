GLiDE 返回校准决策，而不生成文本。向 `POST /v1/systemone` 发送一个共享
`state` 和一个或多个类型化问题。

## 选择问题类型

| 类型 | 使用场景 |
| --- | --- |
| Noul | 需要 yes/no 概率 |
| Choice | 需要从调用方定义的 2–255 个选项中选择一个答案 |
| Score | 需要有序级别和期望分数 |

响应保持问题顺序，并返回包含概率和置信度的类型化答案。应用程序决定接受、
延迟处理还是使用后备方案。

## 调用之前

1. 将密钥导出为 `FASTINO_API_KEY`。
2. 将待评估的证据放入 `state`。
3. 选择与决策匹配的问题类型。
4. 按照 API 参考中的准确字段、限制、请求示例和响应形状操作。
