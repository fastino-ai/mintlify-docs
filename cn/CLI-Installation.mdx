如果你希望在终端中访问训练任务、模型产物、数据集以及交互式 Pioneer 代理，请安装 Pioneer CLI。

<Info>
  Pioneer CLI 以 `@fastino-ai/pioneer-cli` 的形式发布，需要 Bun `1.1.0` 或更高版本才能运行。
</Info>

## 要求

- macOS 或 Linux
- Bun `1.1.0` 或更高版本
- Node.js 和 npm
- 从 [Pioneer API 密钥](https://app.pioneer.ai/api-keys)获取的 Pioneer API 密钥

## 安装 CLI

<Steps>
  <Step title="安装 Bun">
    ```bash
    curl -fsSL https://bun.sh/install | bash
    ```

    安装程序完成后打开一个新的终端，然后确认 Bun 可用：

    ```bash
    bun --version
    ```
  </Step>
  <Step title="安装 Pioneer CLI">
    ```bash
    npm install -g @fastino-ai/pioneer-cli
    ```
  </Step>
  <Step title="验证命令">
    ```bash
    pioneer --version
    pioneer --help
    ```
  </Step>
</Steps>

## 身份验证

<Steps>
  <Step title="创建 API 密钥">
    在 Pioneer 控制台中创建 API 密钥，并准备好在登录提示时使用。
  </Step>
  <Step title="交互式登录">
    ```bash
    pioneer auth login
    ```

    CLI 会在保存密钥之前对其进行验证。
  </Step>
  <Step title="确认会话">
    ```bash
    pioneer auth status
    ```
  </Step>
</Steps>

<Note>
  交互式登录会将你的 API 密钥存储在 `~/.pioneer/config.json` 中。CLI 也支持使用 `PIONEER_API_KEY`，适用于 CI 或短期 shell 会话。
</Note>

## 检查安装

运行几个只读命令，确认 CLI 可以连接到 Pioneer：

```bash
pioneer --version
pioneer auth status
pioneer model base-models
pioneer dataset list
```

## 更新

```bash
npm install -g @fastino-ai/pioneer-cli@latest
pioneer --version
```

## 故障排除

<AccordionGroup>
  <Accordion title="pioneer: command not found" icon="circle-alert">
    确保全局 npm bin 目录在 `PATH` 中。

    ```bash
    npm bin -g
    ```
  </Accordion>

  <Accordion title="env: bun: No such file or directory" icon="terminal">
    安装 Bun 并打开一个新的终端：

    ```bash
    curl -fsSL https://bun.sh/install | bash
    bun --version
    ```
  </Accordion>

  <Accordion title="身份验证失败" icon="key-round">
    在 Pioneer 控制台中创建一个新的 API 密钥，然后重新运行交互式登录。

    ```bash
    pioneer auth login
    pioneer auth status
    ```
  </Accordion>
</AccordionGroup>
