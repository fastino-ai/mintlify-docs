将你的 OpenAI 或 Anthropic 客户端指向 Pioneer。我们识别你当前模型的短板，然后训练更准确、更便宜、更快的专家模型。

## 使用 Pioneer 你可以做什么

<CardGroup cols={2}>
  <Card title="即插即用，像平常一样推理" icon="plug" href="/cn/concepts/inference">
    将你现有的 OpenAI 或 Anthropic 客户端指向 Pioneer——相同的 API，相同的代码。无需迁移。
  </Card>

  <Card title="自动短板检测" icon="chart-bar" href="/guides/adaptive-inference">
    Pioneer 按用例聚类你的流量，精准定位当前模型在准确性、成本或延迟上的欠缺。
  </Card>

  <Card title="专家模型训练" icon="brain" href="/guides/fine-tune-llm">
    Pioneer 代替你训练并评估 Nemotron 3.5 Lightning 和 GLiNER 专家模型。你无需任何 MLOps。
  </Card>

  <Card title="路由由你掌控" icon="bolt" href="/guides/adaptive-inference">
    Pioneer 展示每个专家模型的提升、成本和延迟数据。你决定何时以及如何将流量路由到这些模型。
  </Card>
</CardGroup>

## 你睡觉时，模型自己重训。

<CardGroup cols={2}>
  <Card title="自适应推理" icon="rotate" href="/guides/adaptive-inference">
    Pioneer 的持续改进闭环。从你的线上生产失败中挖掘高信号样本，自动重新训练专家模型，并在相同端点后推广改进后的检查点。无需重新部署。
  </Card>

  <Card title="下载你的资产" icon="download" href="/guides/adaptive-inference">
    你的权重和训练数据集归你所有。随时下载——带到任何其他平台，或在你自己的基础设施上进一步微调。
  </Card>

  <Card title="使用你自己的评估" icon="chart-bar" href="/concepts/evaluations">
    使用 Pioneer 内置的评估套件，或接入你自己的评估。每次重训练在推广任何流量之前都会先跑基准测试。
  </Card>

  <Card title="完整审计轨迹" icon="file-text" href="/guides/adaptive-inference">
    每次自适应推理运行都会生成完整的 PDF 报告——包含训练数据、评估差异、推出阶段和检查点历史。
  </Card>
</CardGroup>

## 支持的模型系列

- **GLiNER 2.5 Multilingual** 用于多语种结构化抽取。
- **GLiNER2 和 GLiGuard** 用于实体抽取、分类、结构化数据、安全性和 PII 工作流。
- **Nemotron 3.5 Lightning** 提供通用、Healthcare 和 Finance 变体。

模型 ID 和当前可用性请参见 [Models](/cn/concepts/models)。
