使用 Fastino Agent 针对你的特定用例自主微调 GLiNER 模型。通过我们的 API，你可以同时使用基础模型和经过微调的专用模型运行推理。

## 使用 Fastino 你可以做什么

<CardGroup cols={2}>
  <Card title="即插即用，像平常一样推理" icon="plug" href="/cn/inference">
    将你现有的 OpenAI 或 Anthropic 客户端指向 Fastino，即可在 GLiNER 基础模型上运行推理。
  </Card>

  <Card title="专家模型训练" icon="brain" href="/guides/adaptive-inference">
    Fastino 代替你训练并评估 GLiNER 专家模型。你无需任何 MLOps。
  </Card>

  <Card title="使用你自己的评估" icon="bolt" href="/guides/fine-tune-llm">
    使用 Fastino 内置的评估套件，或接入你自己的评估。每次训练运行还会生成一份完整的 PDF 报告，包含评估详情、推出阶段和检查点历史。
  </Card>

  <Card title="下载你的资产" icon="download" href="/guides/adaptive-inference">
    你的权重和训练数据集归你所有。你可以随时下载，带到任何其他平台，或在你自己的基础设施上进一步微调。
  </Card>
</CardGroup>

## 支持的模型系列

- **GLiNER 2.5 Multilingual** 用于多语种结构化抽取。
- **GLiNER2 和 GLiGuard** 用于实体抽取、分类、结构化数据、安全性和 PII 工作流。

模型 ID 和当前可用性请参见 [Models](/cn/concepts/models)。
