Fastino 提供两种推理约定。请根据所需的结果选择端点，然后遵循该端点的请求和响应结构。
两者的字段不可互换。

<CardGroup cols={2}>
  <Card title="使用 GLiDE 做出决策" icon="sparkle" href="/cn/inference/systemone">
    使用 `state` 和带类型的 `questions` 调用 `POST /v1/systemone`。获得带有概率和置信度的
    Noul、Choice 或 Score 答案。
  </Card>

  <Card title="运行 GLiNER 或 LLM" icon="braces" href="/cn/inference/chat-completions">
    使用 `messages` 调用 `POST /v1/chat/completions`。添加 `schema` 即可进行 GLiNER 提取、
    分类、结构化提取或关系抽取。
  </Card>
</CardGroup>

| 如果你需要…… | 模型系列 | 端点 | 请求结构 | 从何处读取结果 |
| --- | --- | --- | --- | --- |
| 做出是/否判断、路由到某个选项，或在有序量表上评分 | GLiDE | [`POST /v1/systemone`](/cn/inference/systemone) | `model`、`state`、`questions` | `answers.<question_key>` |
| 提取片段、对文本分类、构建记录或抽取关系 | GLiNER | [`POST /v1/chat/completions`](/cn/inference/chat-completions) | `model`、`messages`、`schema` | 从 `choices[0].message.content` 解析出的 JSON |
| 使用解码器 LLM 生成文本 | 解码器模型 | [`POST /v1/chat/completions`](/cn/inference/chat-completions) | `model`、`messages` | `choices[0].message.content` |

<Warning>
  不要将 GLiDE 请求发送到 `/v1/chat/completions`，也不要将 `messages` 或 GLiNER
  `schema` 发送到 `/v1/systemone`。GLiDE 使用 `fastino/glide`、`state` 和 `questions`。
</Warning>

## GLiDE 路径

如果你是从**决策模型**页面过来的，请按以下顺序阅读：

1. [GLiDE](/cn/concepts/glide)：判断该模型是否适合你的使用场景。
2. [GLiDE 参考](/cn/concepts/decision-models)：了解 `state`、`questions`、限制、
   置信度以及如何组合多个问题。
3. [Noul](/cn/concepts/glide-noul)、[Choice](/cn/concepts/glide-choice) 或
   [Score](/cn/concepts/glide-score)：选择应用所需的答案形式。
4. [GLiDE 推理](/cn/inference/systemone)：复制完整的请求并集成
   `POST /v1/systemone`。

## 身份验证

在 [Fastino 设置](https://agent.fastino.ai/api-keys)中创建 API 密钥，然后将其提供给
你的应用：

```bash
export FASTINO_API_KEY="fast_sk_..."
```

GLiDE 示例使用 `X-API-Key`：

```http
X-API-Key: $FASTINO_API_KEY
Content-Type: application/json
```

API 也接受 `Authorization: Bearer $FASTINO_API_KEY`。与 OpenAI 兼容的示例使用
这种形式。请选择一种身份验证方式，并在集成中始终如一地使用。

## 冷启动与重试

空闲或新部署的模型可能会冷启动。请将读取超时设置为至少 300 秒，并对 `425`、`429` 和
`503` 响应使用有上限的退避重试。当响应中包含 `Retry-After` 时，请遵循该值。

已超时的请求仍可能预热部署，从而让下一次请求成功。对于身份验证、计费、校验或未知模型等错误，
请在解决根本问题之前不要重试。
