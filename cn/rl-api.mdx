RL API 是 Fastino 面向强化学习和自定义后训练的可编程接口。它实现了 Tinker SDK
契约，因此你可以迁移现有的 Tinker 训练循环，也可以从开源 Tinker 实战示例开始。

<Note>
  RL API 目前为限量开放。在规划生产迁移之前，请确认 Fastino 已为你的团队启用此功能。
</Note>

训练循环由你掌控：

1. 从当前策略中采样响应。
2. 使用奖励函数为每个响应评分。
3. 将奖励转换为优势值。
4. 将训练批次发送到 RL API。
5. 执行优化器步骤并为结果创建检查点。

Fastino 负责管理这一循环背后的训练与采样基础设施。数据集、奖励函数、rollout
策略和停止条件仍由你的代码掌控。

<Tip>
  已经在使用 Tinker？保留现有 SDK 调用，只需设置 Fastino 端点和 API
  密钥。请从[从 Tinker 迁移](/cn/rl-api/migrate-from-tinker)开始。
</Tip>

## 为什么使用 RL API

- **沿用现有代码。** 客户端就是官方 `tinker` Python 软件包。
- **定义任意程序化奖励。** 可对数学、代码、工具使用、结构化输出或你自己的环境进行评分。
- **将编排与计算分离。** 学习算法保留在你的应用中，模型操作由 Fastino 执行。
- **从持久检查点恢复。** 保存权重或优化器状态，稍后恢复运行。
- **通过 Fastino 跟踪用量。** 训练、采样和检查点存储与其他 Fastino
  工作负载共用同一账户和项目计费边界。

## 开始之前

你需要：

- 一个以 `fast_sk_` 开头的 Fastino API 密钥
- 为你的 Fastino 团队启用 RL API 访问权限
- Python 3.11 或更高版本
- 使用 `tinker==0.32.0` 作为经过测试的客户端契约

RL API 有意与 Fastino 的 OpenAPI 参考文档分开记录。RL 操作请使用这些页面和
Tinker SDK 类型。原生 Fastino HTTP API 请使用 [API 参考](/cn/api-reference/inference/overview)。
