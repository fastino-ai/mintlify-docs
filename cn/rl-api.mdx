Fastino 的 RL API 是托管式训练与采样服务。其支持的 Python 客户端是配置为使用
Fastino 的 `tinker` 软件包。你的代码负责数据集、奖励函数、响应生成策略和停止条件。
Fastino 负责模型采样和训练。

<Note>
  RL API 目前为限量开放。在规划生产迁移之前，请确认 Fastino 已为你的团队启用
  RL API。
</Note>

安装 `tinker` 软件包并不代表你已获得 Fastino RL API 的访问权限。只有当
[兼容性检查清单](/cn/rl-api/compatibility)中的每一项都通过时，现有 SDK
应用才能保留原有的调用形式。

当应用需要反复生成响应、对响应评分并更新模型时，请使用此 API。如果你要基于准备好
的数据集进行托管式微调，请使用[训练 API](/cn/training)。

## 工作原理

你的应用负责：

1. 从当前策略中采样响应。
2. 使用奖励函数为每个响应评分。
3. 将奖励转换为优势值。
4. 将训练批次发送到 RL API。
5. 执行优化器步骤，并保存有用的检查点。

这种分工让你无需管理模型基础设施，也能掌控学习逻辑。请仅使用兼容性参考中记录的
操作和内置损失函数名称。
