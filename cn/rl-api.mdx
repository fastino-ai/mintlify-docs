RL API 在 Fastino 上运行强化学习和自定义后训练工作负载。你的代码负责数据集、
奖励函数、rollout 策略和停止条件。Fastino 负责模型采样和训练。

<Note>
  RL API 目前为限量开放。在规划生产迁移之前，请确认 Fastino 已为你的团队启用
  RL API。
</Note>

请使用官方 `tinker` Python SDK。现有 Tinker 应用可以迁移到 Fastino，无需替换
学习循环。

## 你负责的部分

你的应用负责：

1. 从当前策略中采样响应。
2. 使用奖励函数为每个响应评分。
3. 将奖励转换为优势值。
4. 将训练批次发送到 RL API。
5. 执行优化器步骤，并保存有用的检查点。

这种分工让你可以更改奖励或训练算法，而无需管理模型基础设施。
