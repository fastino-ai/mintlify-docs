## 仅重试临时故障

使用有界指数退避、遵守 `Retry-After`，并设置固定的尝试次数或时间上限。

## 重试条件

| 状态 | 含义 | 操作 |
| --- | --- | --- |
| `425` | 所选模型正在预热 | 按照服务器提供的延迟后重试 |
| `429` | 达到速率限制 | 遵守 `Retry-After` 后重试 |
| `503` | 服务暂时不可用 | 使用有界退避重试 |
| `529` | Anthropic 兼容端点过载 | 手动重试；Anthropic SDK 不会自动重试此响应 |

在修正请求之前，不要重试身份验证、计费、验证、模型不存在或请求格式错误。

## 安全重试清单

- 创建训练任务和其他支持的变更操作时使用幂等键。
- 重放幂等请求时保持相同的请求正文。
- 使用抖动并设置最大延迟。
- 记录最终状态和请求 ID，但绝不记录 API 密钥。

完整的错误响应格式和解决方法请参阅 [错误](/cn/troubleshooting/errors).
