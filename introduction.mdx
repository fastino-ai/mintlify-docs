Start with **GLiDE** to get structured decisions - classification, routing, and scoring - back as calibrated probabilities in a single call, no generated text to parse. Learn how [decision models](/concepts/decision-models) differ from generative LLMs and when to use each. Reach for **GLiNER** when you need span-level extraction, use the Training API for managed fine-tuning, or use the **RL API** when your application controls the reward and learning loop.

## Supported model families

- **GLiDE** for decisions: classification, routing, and scoring with calibrated probabilities instead of generated text.
- **GLiNER-2.5-Decide** for English classification: intent, routing, sentiment, priority, moderation, and ordinal scoring.
- **GLiNER 2.5 Multilingual** for multilingual structured extraction.
- **GLiNER2 and GLiGuard** for entity extraction, classification, structured data, safety, and PII workflows.

See [Models](/concepts/models) for model IDs and current availability.
