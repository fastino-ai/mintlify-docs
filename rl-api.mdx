Fastino's RL API is a hosted training and sampling service. Its supported Python
client is the `tinker` package, configured to use Fastino. Your code owns the
dataset, reward function, response-generation strategy, and stopping criteria.
Fastino runs model sampling and training.

<Note>
  The RL API is in limited access. Confirm that Fastino has enabled it for your
  team before planning a production migration.
</Note>

Installing the `tinker` package does not grant access to Fastino's RL API.
An existing SDK application may keep its call shapes only when every item in
the [compatibility checklist](/rl-api/compatibility) passes.

Use this API when your application must repeatedly generate responses, score
them, and update the model. For managed fine-tuning from a prepared dataset,
use the [Training API](/training).

## What you control

Your application:

1. Samples responses from the current policy.
2. Scores each response with your reward function.
3. Turns rewards into advantages.
4. Sends the training batch to the RL API.
5. Applies an optimizer step and saves useful checkpoints.

This separation lets you own the learning logic without managing model
infrastructure. Use only the operations and built-in loss names documented in
the compatibility reference.
