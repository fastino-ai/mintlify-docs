The RL API runs reinforcement learning and custom post-training workloads on
Fastino. Your code owns the dataset, reward function, rollout strategy, and
stopping criteria. Fastino runs model sampling and training.

<Note>
  The RL API is in limited access. Confirm that Fastino has enabled it for your
  team before planning a production migration.
</Note>

Use the official `tinker` Python SDK. Existing Tinker applications can move to
Fastino without replacing their learning loop.

## What you control

Your application:

1. Samples responses from the current policy.
2. Scores each response with your reward function.
3. Turns rewards into advantages.
4. Sends the training batch to the RL API.
5. Applies an optimizer step and saves useful checkpoints.

This separation lets you change the reward or training algorithm without
managing model infrastructure.
