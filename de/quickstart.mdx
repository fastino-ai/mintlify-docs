## Ihren API-Schlüssel einrichten

1. **Erstellen Sie ein [Fastino](https://agent.fastino.ai/)-Konto**
2. **Rufen Sie Ihren API-Schlüssel** unter [Settings](https://agent.fastino.ai/api-keys) ab

Setzen Sie Ihren Schlüssel als Umgebungsvariable, damit die folgenden Beispiele unverändert funktionieren:

<CodeGroup>

```bash macOS/Linux
export FASTINO_API_KEY="your_api_key_here"
```

```powershell Windows
setx FASTINO_API_KEY "your_api_key_here"
```

</CodeGroup>

## Ihren ersten Inferenzaufruf ausführen

Rufen Sie `POST /v1/systemone` mit einem `model`, einem `state`, der die Situation beschreibt, und einer oder mehreren typisierten `questions` auf. GLiDE gibt kalibrierte Wahrscheinlichkeiten und Labels direkt zurück. Es gibt keinen generierten Text, der geparst werden muss. Das folgende Beispiel stellt eine einzelne Ja/Nein-Frage (`noul`).

GLiDE kostet **0,15 \$ pro 1 Million Eingabe-Tokens**. Ausgabe-Tokens sind **kostenlos (0 \$)**.
Die aktuellen Inferenzpreise finden Sie unter [Preise](/de/pricing).

<Tabs>
  <Tab title="cURL">
    **So führen Sie einen GLiDE-Entscheidungsaufruf aus**:

    ```bash
    curl -X POST "https://api.fastino.ai/v1/systemone" \
      -H "X-API-Key: $FASTINO_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "fastino/GLiDE",
        "state": "Refund request: the receipt is attached, the purchase was 10 days ago, and refunds are allowed within 30 days.",
        "questions": {
          "refund_allowed": {
            "type": "noul",
            "instructions": "Does this request qualify for a refund?",
            "criteria": { "true": "Qualifies", "false": "Does not qualify" }
          }
        }
      }'
    ```
  </Tab>

  <Tab title="Python">
    **So führen Sie einen GLiDE-Entscheidungsaufruf aus**:

    ```python
    import os
    import requests

    response = requests.post(
        "https://api.fastino.ai/v1/systemone",
        headers={
            "X-API-Key": os.environ["FASTINO_API_KEY"],
            "Content-Type": "application/json",
        },
        json={
            "model": "fastino/GLiDE",
            "state": "Refund request: the receipt is attached, the purchase was 10 days ago, and refunds are allowed within 30 days.",
            "questions": {
                "refund_allowed": {
                    "type": "noul",
                    "instructions": "Does this request qualify for a refund?",
                    "criteria": {"true": "Qualifies", "false": "Does not qualify"},
                }
            },
        },
    )

    response.raise_for_status()
    print(response.json())
    ```
  </Tab>

  <Tab title="JavaScript">
    **So führen Sie einen GLiDE-Entscheidungsaufruf aus**:

    ```javascript
    const response = await fetch(
      "https://api.fastino.ai/v1/systemone",
      {
        method: "POST",
        headers: {
          "X-API-Key": process.env.FASTINO_API_KEY,
          "Content-Type": "application/json",
        },
        body: JSON.stringify({
          model: "fastino/GLiDE",
          state: "Refund request: the receipt is attached, the purchase was 10 days ago, and refunds are allowed within 30 days.",
          questions: {
            refund_allowed: {
              type: "noul",
              instructions: "Does this request qualify for a refund?",
              criteria: { true: "Qualifies", false: "Does not qualify" },
            },
          },
        }),
      }
    );

    if (!response.ok) {
      throw new Error(`Inference failed: ${response.status} ${await response.text()}`);
    }

    const result = await response.json();
    console.log(JSON.stringify(result, null, 2));
    ```
  </Tab>
</Tabs>

Eine erfolgreiche Antwort sieht so aus:

```json
{
  "model": "glide",
  "answers": {
    "refund_allowed": {
      "type": "noul",
      "noul": 0.99767683794902,
      "confidence": 0.9953536758980399
    }
  },
  "usage": { "input_tokens": 89, "output_tokens": 1 },
  "token_usage": 90
}
```

`answers.refund_allowed.noul` ist die Wahrscheinlichkeit, dass die Antwort „Ja“ lautet. `0.999` ist ein starkes Signal dafür, dass die Anfrage die Voraussetzungen erfüllt. Fahren Sie mit den Referenzen zu [Noul](/de/concepts/glide-noul), [Choice](/de/concepts/glide-choice) und [Score](/de/concepts/glide-score) fort, oder verwenden Sie den [Routing-Leitfaden](/de/guides/glide-routing), um Konfidenz in eine Aktion umzusetzen.

<Accordion title="Möchten Sie stattdessen Entitäten extrahieren? Nutzen Sie GLiNER 2.5">
  Wenn Sie statt einer Entscheidung eine Extraktion auf Span-Ebene benötigen (NER, Klassifikation, strukturierte Datensätze), rufen Sie `POST /v1/chat/completions` mit einem Modell, einer Nachricht und einem Schema auf, das definiert, was Sie extrahieren möchten:

  ```bash
  curl -X POST "https://api.fastino.ai/v1/chat/completions" \
    -H "Authorization: Bearer $FASTINO_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "fastino/gliner2.5-multi-v1",
      "messages": [
        {
          "role": "user",
          "content": "Apple announced the MacBook Pro at WWDC in Cupertino."
        }
      ],
      "schema": {
        "entities": [
          { "name": "organization", "description": "business or institution name" },
          { "name": "product", "description": "named commercial product" },
          { "name": "event", "description": "named conference or event" },
          { "name": "location", "description": "city, region, or place" }
        ]
      },
      "threshold": 0.5
    }'
  ```

  Bei Encoder-Modellen (GLiNER) definiert das Objekt `schema` die Aufgabe und kann `entities`, `classifications`, `structures` und `relations` enthalten. Bei Decoder-Modellen (LLMs) lassen Sie `schema` weg und senden eine normale Chat-Nachricht. Den vollständigen Vertrag, Python-/JavaScript-Beispiele und Fehlercodes finden Sie in der [Inferenz-API](/de/inference/chat-completions).
</Accordion>

## Ihren ersten Trainingsjob ausführen

Verwaltetes Training stimmt einen GLiNER-Encoder mit einem verarbeiteten
Datensatz fein ab. [Laden Sie zuerst einen Datensatz hoch und warten Sie, bis
seine Version `ready` ist](/de/concepts/datasets). Erstellen Sie dann einen
Config-Job und fragen Sie seinen Status ab:

```bash
curl -X POST "https://api.fastino.ai/v1/training/jobs" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  -d '{
    "model_name": "my-first-model",
    "base_model": "fastino/gliner2-multi-v1",
    "datasets": [
      {"name": "YOUR_READY_DATASET", "version": "VERSION_NUMBER"}
    ],
    "training_type": "lora"
  }'

# Ersetzen Sie JOB_ID durch die oben zurückgegebene id.
curl "https://api.fastino.ai/v1/training/jobs/JOB_ID" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

Fragen Sie den Job ab, bis `is_terminal_status` den Wert `true` hat. Für
Decoder-Training oder zusätzliche Konfiguration fahren Sie mit dem
[Training-API-Schnellstart](/de/training/quickstart) fort.
