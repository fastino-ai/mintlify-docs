```text
POST https://api.fastino.ai/v1/systemone
```

Dies ist der Inferenzendpunkt für **GLiDE**. Senden Sie einen nicht leeren `state` und eine oder mehrere benannte,
typisierte `questions`; lesen Sie strukturierte Entscheidungen aus `answers`. GLiDE verwendet weder
`/v1/chat/completions` noch `messages` oder ein GLiNER-`schema`.

## Authentifizieren

Erstellen Sie einen API-Schlüssel in den [Fastino-Einstellungen](https://agent.fastino.ai/api-keys) und setzen Sie dann:

```bash
export FASTINO_API_KEY="fast_sk_..."
```

Senden Sie ihn bei jeder Anfrage mit:

```http
X-API-Key: $FASTINO_API_KEY
Content-Type: application/json
```

`Authorization: Bearer $FASTINO_API_KEY` wird ebenfalls akzeptiert. Verwenden Sie einen Stil konsistent.

## Einen Fragetyp wählen

Jede Frage ist Single-Label und gibt Wahrscheinlichkeiten zurück. Wählen Sie das Primitiv anhand der
Antwortform, die Ihr Code benötigt:

| Primitiv | Verwenden, wenn | `criteria`-Form | Primäres Ergebnis |
| --- | --- | --- | --- |
| [Noul](/de/concepts/glide-noul) | Die Antwort Ja oder Nein lautet | Optional `{"true": "...", "false": "..."}`; Standard ist Yes/No | `noul`, die Wahrscheinlichkeit für true |
| [Choice](/de/concepts/glide-choice) | Genau eine ungeordnete Option gewinnen soll | Objekt, das Optionsschlüssel auf Beschreibungen abbildet | `choice` plus `probabilities` |
| [Score](/de/concepts/glide-score) | Die Antwort auf eine geordnete Skala gehört | Geordnetes Array von Stufenbeschreibungen | `score`, `expected_level` und `probabilities` |

Es gibt kein Multi-Label-Primitiv. Stellen Sie mehrere unabhängig benannte Fragen in einer Anfrage,
wenn Sie mehrere Urteile über denselben State benötigen.

## Anfrage

<ParamField body="model" type="string" required>
  Verwenden Sie `fastino/glide`. Die Antwort gibt den Engine-Namen als `glide` zurück.
</ParamField>

<ParamField body="state" type="string | object | array" required>
  Die nicht leere Situation, die bewertet werden soll. Verwenden Sie einen String für eine Passage, ein Objekt für beschriftete
  Felder oder ein Array für eine geordnete Abfolge von Nachrichten oder Datensätzen.
</ParamField>

<ParamField body="questions" type="object" required>
  Ein nicht leeres Objekt mit von Ihnen gewählten Namen als Schlüsseln. Jeder Wert muss `type` und
  `instructions` enthalten; Choice und Score erfordern zusätzlich `criteria`. Dieselben Schlüssel erscheinen unter
  `answers` in der Antwort.
</ParamField>


### Vollständige Anfrage

```bash
curl --max-time 300 -s https://api.fastino.ai/v1/systemone \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "fastino/glide",
    "state": "Refund request: the receipt is attached, the purchase was 10 days ago, and refunds are allowed within 30 days.",
    "questions": {
      "refund_allowed": {
        "type": "noul",
        "instructions": "Does this request qualify for a refund?",
        "criteria": { "true": "Qualifies", "false": "Does not qualify" }
      }
    }
  }'
```

## Antwort

```json
{
  "model": "glide",
  "answers": {
    "refund_allowed": {
      "type": "noul",
      "noul": 0.99767683794902,
      "confidence": 0.9953536758980399
    }
  },
  "usage": { "input_tokens": 89, "output_tokens": 1 }
}
```

`answers` verwendet die Fragenschlüssel aus Ihrer Anfrage. Für dieses Noul gilt:

- `noul` ist die Wahrscheinlichkeit, dass das `true`-Kriterium zutrifft. Es ist kein boolescher Wert.
- `confidence` ist die Sicherheit bezüglich eines der beiden Ergebnisse: `|2 × noul − 1|`.
- Passen Sie die Schwellenwerte für Aktionen anhand repräsentativer Daten an. Gehen Sie nicht davon aus, dass `0.5` der richtige
  geschäftliche Schwellenwert ist.

Choice und Score geben andere Felder zurück. Die genauen Antwortformen und Integrationsbeispiele finden Sie
auf den jeweiligen Primitiv-Seiten.

## Limits und nicht unterstützte Formen

- Jeder gerenderte Frage-Prompt (`state` plus die jeweilige Frage) muss in **40.000
  Token** passen.
- Choice und Score akzeptieren höchstens **255 Optionen oder Stufen**.
- `usage.input_tokens` summiert die internen Durchläufe für alle Fragen und kann daher 40.000 überschreiten,
  obwohl jeder einzelne gerenderte Prompt passt.
- Eine Anfrage bewertet einen gemeinsamen `state`; legen Sie mehrere Fragen unter `questions` ab.
- `/v1/systemone` unterstützt kein Streaming und akzeptiert keinen Batch unabhängiger States.
- GLiDE unterstützt derzeit keine IDs feinabgestimmter Bereitstellungen.

Hinweise zu State-Formen, Konfidenzformeln und eine gemischte Choice/Score-Anfrage finden Sie in der
[GLiDE-Referenz](/de/concepts/decision-models).

## Fehler

| Status | Wahrscheinliche Ursache | Maßnahme |
| --- | --- | --- |
| `400` | Der Prompt überschreitet das Kontextfenster oder eine andere Inferenzeingabe ist ungültig | Kürzen Sie den State oder korrigieren Sie die Frage |
| `401` | Fehlender, falsch formatierter oder ungültiger API-Schlüssel | Exportieren Sie einen gültigen `fast_sk_...`-Schlüssel |
| `402` | Unzureichende Credits, erforderliche Finanzierung oder ein vom Eigentümer festgelegtes tägliches/monatliches Ausgabenlimit | Fügen Sie Credits hinzu oder passen Sie das Ausgabenlimit an |
| `403` | Ablehnung wegen Zahlungsmethode, Kartenverifizierung, Kreditlimit oder Kontorichtlinie | Erfüllen Sie die Abrechnungs- oder Kontoanforderung |
| `404` | Unbekanntes Modell oder ein Modell, das nur Chat Completions unterstützt | Verwenden Sie `fastino/glide` |
| `422` | Ein Pflichtfeld fehlt, ein Wert hat die falsche Form oder ein zusätzliches Feld wurde gesendet | Lesen und korrigieren Sie die Validierungsdetails auf Feldebene |
| `425` | Bereitstellung wird aufgewärmt | Wiederholen Sie den Vorgang nach der angegebenen Verzögerung |
| `429` | Rate- oder Kapazitätslimit | Beachten Sie `Retry-After` und wiederholen Sie mit Backoff |
| `503` | Vorübergehender Anbieter- oder Serving-Fehler | Wiederholen Sie den Vorgang, bevor Sie ihn als endgültig betrachten |

Verwenden Sie ein Lese-Timeout von mindestens 300 Sekunden und begrenztes Backoff für `425`, `429` und `503`.
Wiederholen Sie `401`, `402`, `403`, `404` oder `422` nicht, ohne das zugrunde liegende Problem zu beheben.
