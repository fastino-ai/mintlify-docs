`POST /v1/training/jobs/{job_id}/forward-backward`

Berechnet den Loss eines Batches von Datums auf Token-Ebene und sammelt die Gradienten. Der
nächste [Optimiererschritt](/de/api-reference/interactive-jobs/optim-step) wendet sie an. Jeder Aufruf, der Arbeit ausführt, gibt ein Future zurück. Lesen Sie sein Ergebnis mit [`GET /v1/training/jobs/{job_id}/futures/{future_id}`](/de/api-reference/interactive-jobs/get-future).
[`POST /v1/training/jobs/{job_id}/forward`](/de/api-reference/interactive-jobs/forward) nimmt
denselben Body an und berechnet den Loss ohne Gradienten.

## Anfrage

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID des interaktiven Jobs.
</ParamField>

<ParamField body="datums" type="object[]" required>
  Ein oder mehrere Trainingsbeispiele, die Sie selbst mit dem Tokenizer des Basismodells
  tokenisieren. Jedes Datum hat `model_input` (`{"chunks": [{"type": "encoded_text", "tokens": [...]}]}`,
  N Token) und `loss_fn_inputs` (Tensoren `{"data": [...], "dtype": "int64" | "float32"}` mit N
  Werten): `target_tokens` (`int64`, erforderlich); `weights` (`float32`, `0` im Prompt und `1` in
  der Antwort); `logprobs` und `advantages` (`float32`), erforderlich für jeden Loss außer
  `cross_entropy`.
</ParamField>

<ParamField body="loss_fn" type="string" default="cross_entropy">
  `cross_entropy`, `importance_sampling`, `ppo`, `cispo` oder `dro`.
</ParamField>

<ParamField body="loss_fn_config" type="object">
  Loss-Einstellungen. `ppo` und `cispo` nehmen `clip_low_threshold` und `clip_high_threshold`;
  `dro` nimmt `beta`.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/forward-backward" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "loss_fn": "cross_entropy",
    "datums": [
      {
        "model_input": {"chunks": [{"type": "encoded_text", "tokens": [151644, 872, 198, 3838]}]},
        "loss_fn_inputs": {
          "target_tokens": {"data": [872, 198, 3838, 30], "dtype": "int64"},
          "weights": {"data": [0, 0, 1, 1], "dtype": "float32"}
        }
      }
    ]
  }'
```

</RequestExample>
