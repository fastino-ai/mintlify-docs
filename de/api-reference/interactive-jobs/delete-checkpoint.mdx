`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

Löscht einen Checkpoint. Er zählt sofort nicht mehr zum Speicher; seine Dateien werden später entfernt. `kind` ist `weights` oder `sampler_weights`. Gibt `204 No Content` zurück.

<RequestExample>

```bash cURL
curl -X DELETE "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
