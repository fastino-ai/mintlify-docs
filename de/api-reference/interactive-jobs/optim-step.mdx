`POST /v1/training/jobs/{job_id}/optim-step`

Wendet die seit dem letzten Schritt durch Forward-Backward-Durchläufe gesammelten Gradienten mit
AdamW an. Der Job führt Operationen in der Reihenfolge des Eingangs aus, daher können Sie ihn
direkt nach einem Forward-Backward-Durchlauf einreihen, ohne zu warten.

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID des interaktiven Jobs.
</ParamField>

<ParamField body="adam_params" type="object">
  Optionale AdamW-Parameter: `learning_rate` (Standard `0.0001`), `beta1` (`0.9`), `beta2`
  (`0.95`), `eps` (`1e-12`), `weight_decay` (`0`) und `grad_clip_norm` (`0` deaktiviert das Clipping).
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/optim-step" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"adam_params": {"learning_rate": 0.0001}}'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "optim_step"
}
```

</ResponseExample>
