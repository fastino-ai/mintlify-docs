`POST /v1/training/jobs/{job_id}/save-weights`

Speichert LoRA-Gewichte und Optimiererzustand des Jobs als `weights/<name>`. Sie können ihn wieder in denselben Job [laden](/de/api-reference/interactive-jobs/load-weights) oder daraus [einen neuen Job starten](/de/api-reference/interactive-jobs/create). Zum Samplen oder Herunterladen speichern Sie Gewichte mit [`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`](/de/api-reference/interactive-jobs/save-weights-for-sampler).

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID des interaktiven Jobs.
</ParamField>

<ParamField body="name" type="string" required>
  1–128 Zeichen aus `A-Z`, `a-z`, `0-9`, `.`, `_` und `-`.
</ParamField>

<ParamField body="ttl_seconds" type="integer | null">
  Löscht den Checkpoint nach so vielen Sekunden automatisch, von `3600` (1 Stunde) bis
  `315360000` (10 Jahre). Weglassen, um ihn bis zum Löschen zu behalten.
</ParamField>

<ParamField body="overwrite" type="boolean" default="false">
  Einen Zustands-Checkpoint gleichen Namens ersetzen.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/save-weights" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "step-000100"}'
```

</RequestExample>

Die Antwort enthält die `future_id` des `save`-Futures, `checkpoint_id` und `path`. Übergeben Sie `path` beim Erstellen eines Jobs als `from_checkpoint`.

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "save",
  "checkpoint_id": "weights/step-000100",
  "path": "tinker://SESSION_ID:train:0/weights/step-000100"
}
```

</ResponseExample>
