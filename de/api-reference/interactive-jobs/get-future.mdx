`GET /v1/training/jobs/{job_id}/futures/{future_id}`

Lesen Sie das Future, bis ihr `status` `completed`, `failed` oder `cancelled` ist. Ergebnisse
bleiben eine Stunde erhalten. Mit `wait=true` wartet die Anfrage bis zu 25 Sekunden.

- `type`: `create`, `load`, `forward`, `forward_backward`, `optim_step`, `save` oder `sample`.
- `result` (bei `completed`): `loss_fn_outputs` und `metrics` für Forward; `sequences` (jeweils
  mit `tokens`, `logprobs` und `stop_reason`) für `sample`; der Checkpoint-Pfad für `save`.
- `error` (bei `failed` oder `cancelled`): `message` und `category` (`user` oder `server`).

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/futures/$FUTURE_ID?wait=true" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
