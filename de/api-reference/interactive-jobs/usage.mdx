`GET /v1/training/usage`

Gibt den aktuellen Checkpoint-Speicher der interaktiven Jobs des Teams pro Projekt und Nutzer mit den geschätzten Monatskosten zurück. Gelöschte und abgelaufene Checkpoints zählen nicht. Der optionale Parameter `project_id` filtert nach Projekt.

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/usage" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

<ResponseExample>

```json Response
{
  "effective_rate_usd_per_gigabyte_month": 0.1,
  "data": [
    {
      "project_id": "PROJECT_ID",
      "org_user_urn": "USER_URN",
      "user_email": "you@example.com",
      "user_name": "You",
      "checkpoint_count": 3,
      "size_bytes": 805306368,
      "size_gigabytes": 0.75,
      "estimated_monthly_cost_usd": 0.075
    }
  ]
}
```

</ResponseExample>
