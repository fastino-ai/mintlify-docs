`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

Behält einen Checkpoint ab jetzt `ttl_seconds` lang und löscht ihn dann, von `3600` (1 Stunde) bis `315360000` (10 Jahre). Senden Sie `null`, um ihn bis zum Löschen zu behalten. `kind` ist `weights` oder `sampler_weights`. Gibt `204 No Content` zurück.

<RequestExample>

```bash cURL
curl -X PUT "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100/ttl" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"ttl_seconds": 604800}'
```

</RequestExample>
