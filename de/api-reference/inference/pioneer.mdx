`POST /inference` wurde entfernt.

Verwenden Sie `POST /v1/chat/completions` für gehostete GLiNER-Inferenz. Die aktuelle Anfrage verwendet
`Authorization: Bearer $FASTINO_API_KEY` mit den Feldern `model`, `messages` und `schema` auf oberster Ebene.

Unter [`/v1/chat/completions`](/de/inference/chat-completions) finden Sie die maßgebliche Anfrage, Antwort
und Migrationsanleitung.
