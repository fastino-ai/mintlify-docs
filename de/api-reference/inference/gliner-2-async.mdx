`POST /v1/gliner-2/async`

Diese Seite dokumentiert `POST /v1/gliner-2/async`. Das OpenAPI-Panel ist die
verbindliche Quelle für alle Anfragefelder und Felder der `202`-Antwort. Verwenden
Sie diesen Endpunkt für mehr als eine Million Token oder mögliche Zeitüberschreitungen.

## Anfragebeispiel

```json
{
  "text": "A very large document to process asynchronously...",
  "schema": {
    "entities": [
      {"name": "person", "description": "named individual"},
      {"name": "organization", "description": "business or institution"}
    ]
  },
  "threshold": 0.5,
  "include_confidence": true,
  "include_spans": true
}
```

## Annahmeantwort

Das folgende Beispiel kürzt `message`; der Dienst liefert einen konkreten
Abfragepfad mit der zurückgegebenen Job-ID.

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "accepted",
  "estimated_tokens": 1284307,
  "message": "Job queued. ..."
}
```

Speichern Sie `job_id` und fragen Sie anschließend mit demselben API-Schlüssel
[`GET /v1/gliner-2/jobs/{job_id}`](/de/api-reference/inference/gliner-2-job-status) ab.
