Fastino stellt eine Reihe OpenAI-kompatibler Endpunkte bereit, sodass Sie Ihren bestehenden OpenAI-SDK-Code mit minimalen Änderungen für Ihre feinabgestimmten Fastino-Modelle verwenden können. Setzen Sie `base_url` auf `https://api.fastino.ai/v1`, authentifizieren Sie sich mit Ihrem Fastino-API-Schlüssel und übergeben Sie Ihre Trainingsjob-ID als `model`. Fastino-spezifische Felder wie `schema` können im Python SDK über `extra_body` übergeben oder direkt in den JSON-Body aufgenommen werden.

<Tip>
  Wenn Sie bereits eine OpenAI-Integration haben, sind für den Wechsel zu Fastino nur zwei Änderungen nötig: Aktualisieren Sie `base_url` und setzen Sie Ihren Fastino-API-Schlüssel ein. Alles andere - SDK-Methoden, Streaming, Nachrichtenformat - bleibt gleich.
</Tip>

## Endpunkte

| Methode | Pfad | Beschreibung |
|---|---|---|
| `POST` | `/v1/chat/completions` | Chat Completions |
| `POST` | `/v1/responses` | Responses API |
| `GET` | `/v1/models` | Verfügbare Modelle auflisten |

<Warning>
  Das veraltete `POST /v1/completions` wurde entfernt. Migrieren Sie promptbasierte Anfragen zu `POST /v1/chat/completions` und senden Sie den Prompt als User-Nachricht.
</Warning>

## Das OpenAI SDK konfigurieren

Richten Sie das SDK auf die Basis-URL von Fastino aus und geben Sie Ihren Fastino-API-Schlüssel an:

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai/v1"
)
```

```bash cURL (base URL)
# Set this as the base for all requests
https://api.fastino.ai/v1
```

</CodeGroup>

## Chat Completions

`POST /v1/chat/completions` akzeptiert dieselbe Anfragestruktur wie die OpenAI Chat Completions API. Übergeben Sie Ihre Trainingsjob-ID als `model` und fügen Sie Fastino-spezifische Felder wie `schema` in den Anfrage-Body oder über `extra_body` ein.

<CodeGroup>

```python Python (OpenAI SDK)
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai/v1"
)

response = client.chat.completions.create(
    model="YOUR_TRAINING_JOB_ID",
    messages=[
        {
            "role": "user",
            "content": "Extract entities from: Apple launched the iPhone."
        }
    ],
    extra_body={
        "schema": {
            "entities": ["organization", "product"]
        }
    }
)

print(response.choices[0].message.content)
```

```bash cURL
curl -X POST https://api.fastino.ai/v1/chat/completions \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_TRAINING_JOB_ID",
    "messages": [
      {
        "role": "user",
        "content": "Extract entities from: Apple launched the iPhone."
      }
    ],
    "schema": {
      "entities": ["organization", "product"]
    }
  }'
```

</CodeGroup>

## Verfügbare Modelle auflisten

Verwenden Sie `GET /v1/models`, um die Liste der Modelle abzurufen, die Sie mit diesen Endpunkten nutzen können.

<CodeGroup>

```python Python (OpenAI SDK)
models = client.models.list()
for model in models.data:
    print(model.id)
```

```bash cURL
curl https://api.fastino.ai/v1/models \
  -H "X-API-Key: YOUR_API_KEY"
```

</CodeGroup>

## Streaming

Alle Completions-Endpunkte unterstützen Streaming. Setzen Sie `stream=True` im SDK oder `"stream": true` im Anfrage-Body.

<CodeGroup>

```python Python (OpenAI SDK)
stream = client.chat.completions.create(
    model="YOUR_TRAINING_JOB_ID",
    messages=[{"role": "user", "content": "Summarize the following article: ..."}],
    stream=True
)

for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="")
```

```bash cURL
curl -X POST https://api.fastino.ai/v1/chat/completions \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_TRAINING_JOB_ID",
    "messages": [{"role": "user", "content": "Summarize the following article: ..."}],
    "stream": true
  }'
```

</CodeGroup>

## Fastino-spezifische Felder übergeben

Das Feld `schema` ist eine Fastino-Erweiterung. Übergeben Sie es im OpenAI Python SDK über `extra_body`, damit es in die Anfrage aufgenommen wird, ohne die SDK-Validierung zu beeinträchtigen. Fügen Sie es in einer direkten HTTP-Anfrage auf der obersten Ebene des JSON-Bodys neben Standardfeldern wie `model` und `messages` ein.
