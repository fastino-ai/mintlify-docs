`GET /v1/gliner-2/jobs/{job_id}`

Fragen Sie einen asynchronen GLiNER-2-Job ab, bis er abgeschlossen oder fehlgeschlagen ist. Verwenden Sie denselben
API-Schlüssel, mit dem der Job übermittelt wurde; Jobs sind auf den authentifizierten Benutzer beschränkt.

Das OpenAPI-Panel auf dieser Seite ist die verbindliche Quelle für den Pfadparameter `job_id` und
alle Antwortfelder.

## Anfragebeispiel

```bash
curl "https://api.fastino.ai/v1/gliner-2/jobs/3f08a17f-777a-4aa6-8ec5-879df37775a8" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

## Antwort während der Verarbeitung

Fragen Sie weiter ab, solange `status` den Wert `pending` oder `processing` hat:

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "pending",
  "result": null,
  "error": null,
  "token_usage": 1284307,
  "created_at": "2026-10-07T22:10:00+00:00",
  "completed_at": null
}
```

## Abgeschlossene Antwort

Beenden Sie die Abfrage, wenn `status` den Wert `complete` hat. `result` folgt dem Schema aus der
Übermittlungsanfrage:

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "complete",
  "result": {
    "entities": [
      {
        "text": "Apple",
        "label": "organization",
        "score": 0.99,
        "start": 0,
        "end": 5
      }
    ]
  },
  "error": null,
  "token_usage": 1284307,
  "created_at": "2026-10-07T22:10:00+00:00",
  "completed_at": "2026-10-07T22:13:42+00:00"
}
```

## Fehlerantwort

Ein beendeter Job kann `status: "error"` mit einer Meldung in `error` melden:

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "error",
  "result": null,
  "error": "The input could not be processed",
  "token_usage": 1284307,
  "created_at": "2026-10-07T22:10:00+00:00",
  "completed_at": "2026-10-07T22:10:08+00:00"
}
```

Ein unbekannter Job oder ein Job, der einem anderen Benutzer gehört, liefert `404`.
