`GET /v1/gliner-2/jobs/{job_id}`

Diese Seite dokumentiert `GET /v1/gliner-2/jobs/{job_id}`. Das OpenAPI-Panel ist
die verbindliche Quelle für den Pfadparameter und alle Antwortfelder. Verwenden
Sie denselben API-Schlüssel wie bei der Übermittlung.

## Anfrage

```bash
curl "https://api.fastino.ai/v1/gliner-2/jobs/3f08a17f-777a-4aa6-8ec5-879df37775a8" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

## Ausstehende Antwort

Fragen Sie weiter ab, solange `status` `pending` oder `processing` ist:

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "pending",
  "result": null,
  "error": null,
  "token_usage": 1284307,
  "created_at": "2026-10-07T22:10:00+00:00",
  "completed_at": null
}
```

## Abgeschlossene Antwort

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "complete",
  "result": {
    "entities": [
      {"text": "Apple", "label": "organization", "score": 0.99, "start": 0, "end": 5}
    ]
  },
  "error": null,
  "token_usage": 1284307,
  "created_at": "2026-10-07T22:10:00+00:00",
  "completed_at": "2026-10-07T22:13:42+00:00"
}
```

Fehlgeschlagene Aufträge liefern `status: "error"` und eine Meldung in `error`.
Unbekannte oder fremde Aufträge liefern `404`.
