`POST /v1/gliner-2`

Diese Seite dokumentiert `POST /v1/gliner-2`. Das OpenAPI-Panel ist die
verbindliche Quelle für alle Anfrage- und Antwortfelder. Verwenden Sie das
vereinheitlichte GLiNER-Schema und lassen Sie das veraltete Feld `task` weg.

## Anfrage zur Entitätsextraktion

```json
{
  "text": "Apple CEO Tim Cook introduced the iPhone in Cupertino.",
  "schema": {
    "entities": [
      {"name": "person", "description": "named individual"},
      {"name": "organization", "description": "business or institution"},
      {"name": "product", "description": "named commercial product"},
      {"name": "location", "description": "city, region, or place"}
    ]
  },
  "threshold": 0.5,
  "include_confidence": true,
  "include_spans": true
}
```

`schema` unterstützt auch `classifications`, `structures` und `relations`.
Das vollständige Schema und weitere Beispiele finden Sie unter
[`POST /v1/chat/completions`](/de/api-reference/inference/chat-completions).

## Erfolgreiche Antwort

```json
{
  "result": {
    "entities": [
      {
        "text": "Apple",
        "label": "organization",
        "score": 0.99,
        "start": 0,
        "end": 5
      }
    ]
  },
  "token_usage": 10
}
```
