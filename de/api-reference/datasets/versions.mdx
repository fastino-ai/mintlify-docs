`GET /v1/datasets/{name}`

Diese Seite dokumentiert `GET /v1/datasets/{name}`. Die OpenAPI-Spezifikation ist die verbindliche Quelle für Parameter, Antworten und Authentifizierung.

## Verarbeitungsstatus

Die Antwort enthält `success`, `versions` und `count`. Gleichen Sie beim
Abfragen eines neuen Uploads die `version_number` exakt ab. Eine Version kann
erst mit `status` `ready` für das Training verwendet werden; bei `failed`
enthält sie `processing_error`.
