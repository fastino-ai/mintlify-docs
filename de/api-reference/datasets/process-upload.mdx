`POST /v1/datasets/upload/process`

Diese Seite dokumentiert `POST /v1/datasets/upload/process`. Die OpenAPI-Spezifikation ist die verbindliche Quelle für Parameter, Antworten und Authentifizierung.

## Asynchrone Verarbeitung

Eine erfolgreiche Anfrage gibt `202` zurück und reiht die Verarbeitung ein;
der Datensatz ist damit noch nicht bereit. Fragen Sie
[`GET /v1/datasets/{name}`](/de/api-reference/datasets/versions) ab, wählen Sie
die beim Erstellen der Upload-URL zurückgegebene `version_number` exakt aus und
warten Sie auf `status` `ready` oder `failed`. Lesen Sie bei einem Fehler
`processing_error`, bevor Sie die Datei korrigieren und eine neue Version hochladen.

`503` bedeutet, dass Speicherprüfung oder Einreihung vor Verarbeitungsbeginn
fehlgeschlagen ist. Derselbe Upload kann erneut verarbeitet werden.

## Autorisierung

Erfordert die Teamrolle Owner, Admin oder Editor. Andere Rollen erhalten `403 Forbidden`.
