`DELETE /v1/datasets/{name}`

Löscht einen Datensatz und alle gespeicherten Versionen anhand des Namens
logisch. Diese Route löscht nicht nur eine ausgewählte Version.

## Autorisierung

Erfordert die Teamrolle Owner, Admin oder Editor. Andere Rollen erhalten `403 Forbidden`.
