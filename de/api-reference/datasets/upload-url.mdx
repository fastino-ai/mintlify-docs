`POST /v1/datasets/upload/url`

Diese Seite dokumentiert `POST /v1/datasets/upload/url`. Die OpenAPI-Spezifikation ist die verbindliche Quelle für Parameter, Antworten und Authentifizierung.

## Datei hochladen

Laden Sie vor Ablauf der `presigned_url` die exakten Dateibytes hoch. Die
signierte Anfrage erfordert `Content-Type: application/octet-stream`; ohne
diesen Header oder mit einem anderen Wert wird `403` zurückgegeben.

```bash
curl --fail-with-body -X PUT \
  -H "Content-Type: application/octet-stream" \
  --upload-file training.jsonl "$PRESIGNED_URL"
```

Übergeben Sie nach erfolgreichem Upload die zurückgegebene `dataset_id` an
[`POST /v1/datasets/upload/process`](/de/api-reference/datasets/process-upload).

## Autorisierung

Erfordert die Teamrolle Owner, Admin oder Editor. Andere Rollen erhalten `403 Forbidden`.
