`POST /v1/training/jobs/{job_id}/save-weights`

Speichert die LoRA-Gewichte und den Optimizer-Zustand unter `name`. Die akzeptierte Antwort enthält eine `future_id`, eine Checkpoint-ID `weights/<name>` und deren `tinker://`-Pfad. Fragen Sie [Interaktives Future abrufen](/de/api-reference/training-jobs/interactive/get-future) ab, bevor Sie den Zustand laden oder daraus einen weiteren Job starten.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
