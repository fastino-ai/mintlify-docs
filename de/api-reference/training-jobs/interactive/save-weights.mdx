`POST /v1/training/jobs/{job_id}/save-weights`

Speichert die LoRA-Gewichte und den Optimiererzustand unter `name`. Die angenommene Antwort enthält eine `future_id`, eine Checkpoint-ID `weights/<name>` und den zugehörigen `tinker://`-Pfad. Fragen Sie [Future abrufen](/de/api-reference/training-jobs/interactive/get-future) ab, bevor Sie den Zustand laden oder einen anderen Job daraus starten.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
