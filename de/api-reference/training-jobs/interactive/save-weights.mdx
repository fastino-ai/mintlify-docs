`POST /v1/training/jobs/{job_id}/save-weights`

Speichert die LoRA-Gewichte und den Optimizer-Zustand des Jobs als
`weights/<name>`. Sie können ihn wieder in denselben Job
[laden](/de/api-reference/training-jobs/interactive/load-weights) oder von ihm aus
[einen neuen Job starten](/de/api-reference/training-jobs/interactive/create-model).
Um aus Gewichten zu samplen oder sie herunterzuladen, speichern Sie sie
stattdessen mit
[`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`](/de/api-reference/training-jobs/interactive/save-weights-for-sampler).

Das Speichern wird in der Reihenfolge der übrigen Aufrufe des Jobs ausgeführt.

## Anfrage

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID des interaktiven Jobs.
</ParamField>

<ParamField body="name" type="string" required>
  1–128 Zeichen aus `A-Z`, `a-z`, `0-9`, `.`, `_` und `-`.
</ParamField>

<ParamField body="ttl_seconds" type="integer | null">
  Löscht den Checkpoint automatisch nach dieser Anzahl von Sekunden, von `3600`
  (1 Stunde) bis `315360000` (10 Jahre). Lassen Sie das Feld weg oder senden Sie
  `null`, um den Checkpoint zu behalten, bis Sie ihn löschen. Bestehende
  Checkpoints zählen zur [Speichernutzung](/de/api-reference/training-jobs/interactive/storage-usage).
</ParamField>

<ParamField body="overwrite" type="boolean" default="false">
  Ersetzt einen Zustands-Checkpoint mit demselben Namen.
</ParamField>

<ParamField body="user_metadata" type="object">
  String-Schlüssel-Wert-Metadaten, die mit dem Checkpoint gespeichert werden.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/save-weights" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "step-000100"}'
```

</RequestExample>

## Antwort

<ResponseField name="future_id" type="string">
  Das `save`-Future.
</ResponseField>

<ResponseField name="checkpoint_id" type="string">
  `weights/<name>`.
</ResponseField>

<ResponseField name="path" type="string">
  Vollständiger Checkpoint-Pfad. Übergeben Sie ihn als `from_checkpoint`, wenn Sie einen Job erstellen.
</ResponseField>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "save",
  "checkpoint_id": "weights/step-000100",
  "path": "tinker://SESSION_ID:train:0/weights/step-000100"
}
```

</ResponseExample>

| Status | Bedeutung |
| --- | --- |
| `400` | Der Name enthält ungültige Zeichen oder hat eine ungültige Länge, die TTL liegt außerhalb des gültigen Bereichs, oder der Job wurde gestoppt. |
| `404` | Der Job existiert nicht oder gehört zu einem anderen Team. |
| `422` | Im Body fehlt `name`, oder er enthält ein unbekanntes Feld. |
