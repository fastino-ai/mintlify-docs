`POST /v1/training/jobs/{job_id}/save-weights`

Speichert die LoRA-Gewichte und den Optimierungsstatus des Jobs als `weights/<name>`. Du kannst
[Laden](/de/api-reference/training-jobs/interactive/load-weights) es zurück in denselben Job,
oder [einen neuen Job starten](/de/api-reference/training-jobs/interactive/create-model) daraus. Zum Probieren
oder laden Sie Gewichte herunter und speichern Sie sie mit
[`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`](/de/api-reference/training-jobs/interactive/save-weights-for-sampler)
stattdessen.

Die Speicherung wird der Reihe nach mit den anderen Aufrufen des Jobs ausgeführt.

## Anfrage

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField path="job_id" type="string" required>
  Interaktive Job-ID.
</ParamField>

<ParamField body="name" type="string" required>
  1–128 Zeichen aus `A-Z`, `a-z`, `0-9`, `.`, `_` und `-`.
</ParamField>

<ParamField body="ttl_seconds" type="integer | null">
  Löschen Sie den Prüfpunkt nach dieser Anzahl von Sekunden automatisch von `3600`
  (1 Stunde) bis `315360000` (10 Jahre). Lassen Sie es weg oder senden Sie `null`, um den Prüfpunkt beizubehalten, bis Sie ihn löschen. Live-Prüfpunkte werden auf [Speichernutzung](/de/api-reference/training-jobs/interactive/storage-usage) angerechnet .
</ParamField>

<ParamField body="overwrite" type="boolean" default="false">
  Ersetzen Sie einen Statuskontrollpunkt mit demselben Namen.
</ParamField>

<ParamField body="user_metadata" type="object">
  String-Schlüsselwert-Metadaten, die mit dem Prüfpunkt gespeichert werden.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/save-weights" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "step-000100"}'
```

</RequestExample>

## Antwort

<ResponseField name="future_id" type="string">
  Die Zukunft `save`.
</ResponseField>

<ResponseField name="checkpoint_id" type="string">
  `weights/<name>`.
</ResponseField>

<ResponseField name="path" type="string">
  Vollständiger Checkpoint-Pfad. Übergeben Sie es als `from_checkpoint`, wenn Sie einen Job erstellen.
</ResponseField>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "save",
  "checkpoint_id": "weights/step-000100",
  "path": "tinker://SESSION_ID:train:0/weights/step-000100"
}
```

</ResponseExample>

| Status | Bedeutung |
| --- | --- |
| `400` | Der Name enthält ungültige Zeichen oder eine ungültige Länge, die TTL liegt außerhalb des gültigen Bereichs oder der Job wurde gestoppt. |
| `404` | Der Job existiert nicht oder gehört zu einem anderen Team. |
| `422` | Dem Text fehlt `name` oder er hat ein unbekanntes Feld. |
