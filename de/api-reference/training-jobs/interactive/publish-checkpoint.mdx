`POST /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

Diese native JSON-Operation gilt für interaktive Trainingsjobs.

Veröffentlicht einen `weights`- oder `sampler_weights`-Checkpoint. Die Veröffentlichung gewährt anderen Teams keinen Ladezugriff.

Den vollständigen Lebenszyklus beschreibt [Benutzerdefinierten Trainingsablauf erstellen](/de/training/training-loop).
