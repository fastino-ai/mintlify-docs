`POST /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

Markiert einen Checkpoint als öffentlich; sein Feld `public` wird `true`. `kind` ist `weights` oder `sampler_weights`. Gibt `204 No Content` zurück. Rückgängig mit [`DELETE .../publish`](/de/api-reference/training-jobs/interactive/unpublish-checkpoint).

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/sampler_weights/step-000100/publish" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
