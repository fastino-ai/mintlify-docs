`POST /v1/training/jobs/{job_id}/checkpoints/weights/{name}/load`

Diese native JSON-Operation gilt für interaktive Trainingsjobs.

Stellt das Laden des Trainingszustands aus einem `weights`-Checkpoint in die Warteschlange. Der Optimierer kann wiederhergestellt werden. Fragen Sie [Vorgang abrufen](/de/api-reference/training-jobs/interactive/get-operation) bis zu einem Endstatus ab.

Den vollständigen Lebenszyklus beschreibt [Benutzerdefinierten Trainingsablauf erstellen](/de/training/training-loop).
