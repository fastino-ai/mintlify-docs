`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

Speichert die LoRA-Gewichte unter `name` für Sampling und PEFT-Download. Die akzeptierte Antwort enthält eine `future_id`, eine Checkpoint-ID `sampler_weights/<name>` und deren `tinker://`-Pfad. Fragen Sie [Interaktives Future abrufen](/de/api-reference/training-jobs/interactive/get-future) ab, bevor Sie samplen oder herunterladen.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
