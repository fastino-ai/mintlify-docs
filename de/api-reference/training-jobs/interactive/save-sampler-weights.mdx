`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

Speichert die LoRA-Gewichte unter `name` für Sampling und PEFT-Downloads. Die angenommene Antwort enthält eine `future_id`, eine Checkpoint-ID `sampler_weights/<name>` und den zugehörigen `tinker://`-Pfad. Fragen Sie [Future abrufen](/de/api-reference/training-jobs/interactive/get-future) vor dem Sampling oder Download ab.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
