---
title: "Veröffentlichung eines interaktiven Checkpoints aufheben"
sidebarTitle: "Veröffentlichung aufheben"
description: "Heben Sie die Veröffentlichung eines Checkpoints eines interaktiven Trainingsjobs auf, indem Sie DELETE an seinen Veröffentlichungspfad senden. Die Anfrage wird synchron und ohne Antwortinhalt abgeschlossen."
api: "DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish"
---

`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

Hebt die Veröffentlichung eines Checkpoints auf und wird synchron ohne Antwortinhalt abgeschlossen.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
