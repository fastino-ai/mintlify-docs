`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

Diese native JSON-Operation gilt für interaktive Trainingsjobs.

Hebt die Veröffentlichung eines Checkpoints synchron ohne Antwortinhalt auf.

Den vollständigen Lebenszyklus beschreibt [Benutzerdefinierten Trainingsablauf erstellen](/de/training/training-loop).
