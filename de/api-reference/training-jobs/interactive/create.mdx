`POST /v1/training/jobs/interactive`

Diese native JSON-Operation gilt für interaktive Trainingsjobs.

Erstellt einen interaktiven Job mit `base_model` oder mit `from_checkpoint` und optionalem `load_optimizer`. Native JSON-Clients senden weder `seq_id` noch Heartbeats.

Den vollständigen Lebenszyklus beschreibt [Benutzerdefinierten Trainingsablauf erstellen](/de/training/training-loop).
