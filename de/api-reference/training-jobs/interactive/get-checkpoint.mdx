`GET /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

Gibt einen Prüfpunkt zurück. Um alle Prüfpunkte eines Jobs aufzulisten, verwenden Sie
[`GET /v1/training/jobs/{job_id}/checkpoints`](/de/api-reference/training-jobs/checkpoints).

## Anfrage

<ParamField path="job_id" type="string" required>
  Interaktive Job-ID.
</ParamField>

<ParamField path="kind" type="string" required>
  `weights` für einen Statusprüfpunkt oder `sampler_weights` für einen Probenprüfpunkt.
</ParamField>

<ParamField path="name" type="string" required>
  Prüfpunktname.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/sampler_weights/step-000100" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Antwort

<ResponseExample>

```json Response
{
  "checkpoint_id": "sampler_weights/step-000100",
  "checkpoint_type": "sampler",
  "time": "2026-10-14T12:00:00Z",
  "tinker_path": "tinker://SESSION_ID:train:0/sampler_weights/step-000100",
  "size_bytes": 268435456,
  "public": false,
  "user_metadata": null,
  "expires_at": "2026-10-15T12:00:00Z"
}
```

</ResponseExample>

`checkpoint_type` ist `training` für einen Statuskontrollpunkt und `sampler` für einen
Probenehmer-Kontrollpunkt. `expires_at` ist `null`, wenn der Prüfpunkt keine TTL hat.
