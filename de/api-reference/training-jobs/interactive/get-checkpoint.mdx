---

`GET /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

Gibt einen interaktiven Checkpoint zurück. `kind` ist `weights` oder `sampler_weights`.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
