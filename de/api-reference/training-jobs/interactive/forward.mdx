`POST /v1/training/jobs/{job_id}/forward`

Berechnet Loss und Log-Wahrscheinlichkeiten pro Token eines Batches, ohne Gradienten zu sammeln.
Nutzen Sie es zur Evaluierung. Body, Antwort und Ergebnis entsprechen
[`POST /v1/training/jobs/{job_id}/forward-backward`](/de/api-reference/training-jobs/interactive/forward-backward);
der `type` der Operation ist `forward`.

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/forward" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "datums": [
      {
        "model_input": {"chunks": [{"type": "encoded_text", "tokens": [151644, 872, 198, 3838]}]},
        "loss_fn_inputs": {
          "target_tokens": {"data": [872, 198, 3838, 30], "dtype": "int64"}
        }
      }
    ]
  }'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "forward"
}
```

</ResponseExample>
