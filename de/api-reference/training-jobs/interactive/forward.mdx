`POST /v1/training/jobs/{job_id}/forward`

Reiht einen Forward-Durchlauf ohne Gradienten ein und gibt eine `future_id` zurück. Fragen Sie [Interaktives Future abrufen](/de/api-reference/training-jobs/interactive/get-future) ab, bis der Status `completed`, `failed` oder `cancelled` ist.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
