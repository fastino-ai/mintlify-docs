`POST /v1/training/jobs/{job_id}/forward`

Stellt einen Forward-Pass ohne Gradienten in die Warteschlange und gibt eine `future_id` zurück. Fragen Sie [Future abrufen](/de/api-reference/training-jobs/interactive/get-future) ab, bis der Status `completed`, `failed` oder `cancelled` ist.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
