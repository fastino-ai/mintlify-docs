`POST /v1/training/jobs/{job_id}/forward`

Diese native JSON-Operation gilt für interaktive Trainingsjobs.

Stellt einen Vorwärtslauf ohne Gradienten in die Warteschlange und gibt eine `future_id` zurück. Fragen Sie [Vorgang abrufen](/de/api-reference/training-jobs/interactive/get-operation) bis `completed`, `failed` oder `cancelled` ab.

Den vollständigen Lebenszyklus beschreibt [Benutzerdefinierten Trainingsablauf erstellen](/de/training/training-loop).
