`GET /v1/training/jobs/{job_id}/futures/{future_id}`

Gibt den Status und das Ergebnis des Futures zurück. Mit `wait=true` wartet die Anfrage höchstens 25 Sekunden und kann weiterhin einen nicht terminalen Status zurückgeben. Fragen Sie ab, bis `completed`, `failed` oder `cancelled` erreicht ist. Der Dienst bewahrt ein Ergebnis eine Stunde lang auf. Ein HTTP-Fehler bedeutet, dass der Server die Anfrage abgelehnt hat. Ein eingereihtes Future kann stattdessen mit `status: "failed"` und einer `error.message` enden. Behandeln Sie `error.category` als undurchsichtige Zeichenfolge.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
