`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

Behält einen Checkpoint ab jetzt für `ttl_seconds` und löscht ihn danach. Senden
Sie `ttl_seconds: null`, um den Ablaufzeitpunkt zu entfernen und den Checkpoint
bis zu seiner Löschung zu behalten. Gibt `204 No Content` zurück.

`kind` ist `weights` oder `sampler_weights`.

<ParamField body="ttl_seconds" type="integer | null" required>
  Von `3600` (1 Stunde) bis `315360000` (10 Jahre) oder `null`.
</ParamField>

<RequestExample>

```bash cURL
curl -X PUT "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100/ttl" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"ttl_seconds": 604800}'
```

</RequestExample>

## Fehler

| Status | Bedeutung |
| --- | --- |
| `400` | `ttl_seconds` liegt außerhalb von 3600–315360000. |
| `404` | Der Job oder Checkpoint existiert nicht oder gehört zu einem anderen Team. |
| `422` | `ttl_seconds` fehlt oder der Body enthält ein unbekanntes Feld. |
