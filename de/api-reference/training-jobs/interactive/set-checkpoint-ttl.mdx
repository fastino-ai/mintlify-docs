`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

Legt die Aufbewahrungsdauer für einen `weights`- oder `sampler_weights`-Checkpoint fest. Eine TTL von null bewahrt den Checkpoint bis zur Löschung auf.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
