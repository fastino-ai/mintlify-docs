`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

Keeps a checkpoint for `ttl_seconds` from now, then deletes it. Send `null` to
keep it until you delete it. Returns `204 No Content`.

`kind` is `weights` or `sampler_weights`.

<ParamField body="ttl_seconds" type="integer | null" required>
  From `3600` (1 hour) to `315360000` (10 years), or `null`.
</ParamField>

<RequestExample>

```bash cURL
curl -X PUT "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100/ttl" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"ttl_seconds": 604800}'
```

</RequestExample>
