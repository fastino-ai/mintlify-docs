`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

Behält ab sofort einen Prüfpunkt für `ttl_seconds` bei und löscht ihn dann. Weglassen
`ttl_seconds` oder senden Sie `null`, um den Prüfpunkt beizubehalten, bis Sie ihn löschen. Gibt `204 No Content` zurück.

`kind` ist `weights` oder `sampler_weights`.

<ParamField body="ttl_seconds" type="integer | null">
  Von `3600` (1 Stunde) bis `315360000` (10 Jahre) oder `null`.
</ParamField>

<RequestExample>

```bash cURL
curl -X PUT "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100/ttl" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"ttl_seconds": 604800}'
```

</RequestExample>

## Fehler

| Status | Bedeutung |
| --- | --- |
| `400` | `ttl_seconds` liegt außerhalb von 3600–315360000. |
| `404` | Der Job oder Prüfpunkt existiert nicht oder gehört zu einem anderen Team. |
| `422` | Der Text enthält ein unbekanntes Feld. |
