`POST /v1/training/jobs/{job_id}/optim-step`

Stellt einen Optimizer-Schritt für die akkumulierten Gradienten in die Warteschlange und gibt eine `future_id` zurück. Der Anfragetext ist optional. Fragen Sie [Future abrufen](/de/api-reference/training-jobs/interactive/get-future) bis zu einem terminalen Status ab.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
