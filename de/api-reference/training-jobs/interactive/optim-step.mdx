`POST /v1/training/jobs/{job_id}/optim-step`

Reiht einen Optimizer-Schritt über akkumulierte Gradienten ein und gibt eine `future_id` zurück. Der Anfrageinhalt ist optional. Fragen Sie [Interaktives Future abrufen](/de/api-reference/training-jobs/interactive/get-future) ab, bis ein terminaler Status erreicht ist.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
