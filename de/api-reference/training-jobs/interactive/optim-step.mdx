`POST /v1/training/jobs/{job_id}/optim-step`

Wendet die durch Vorwärts-Rückwärts-Durchläufe seit dem letzten akkumulierten Gradienten an
Schritt mit AdamW. Anrufe werden in der Reihenfolge ausgeführt, in der der Job sie erhält, also Sie
kann dies direkt nach einem Vorwärts-Rückwärts-Durchlauf in die Warteschlange stellen, ohne darauf warten zu müssen.

## Anfrage

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField path="job_id" type="string" required>
  Interaktive Job-ID.
</ParamField>

Der JSON-Body ist optional.

<ParamField body="adam_params" type="object">
  AdamW-Parameter. Ausgelassene Felder verwenden ihre Standardwerte.

  <Expandable title="properties">
    <ParamField body="learning_rate" type="number" default="0.0001">
      Lernrate, `>= 0`.
    </ParamField>
    <ParamField body="beta1" type="number" default="0.9">
      Von `0` bis (ausschließlich) `1`.
    </ParamField>
    <ParamField body="beta2" type="number" default="0.95">
      Von `0` bis (ausschließlich) `1`.
    </ParamField>
    <ParamField body="eps" type="number" default="1e-12">
      `> 0`.
    </ParamField>
    <ParamField body="weight_decay" type="number" default="0">
      `>= 0`.
    </ParamField>
    <ParamField body="grad_clip_norm" type="number" default="0">
      Clip mit Steigungsnorm, `>= 0`. `0` deaktiviert das Clipping.
    </ParamField>
  </Expandable>
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/optim-step" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"adam_params": {"learning_rate": 0.0001}}'
```

</RequestExample>

## Antwort

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "optim_step"
}
```

</ResponseExample>

`result` des abgeschlossenen Futures enthält die Metriken des Schritts.

| Status | Bedeutung |
| --- | --- |
| `400` | Ein Adam-Parameter liegt außerhalb des gültigen Bereichs oder der Job wurde gestoppt. |
| `404` | Der Job existiert nicht oder gehört zu einem anderen Team. |
| `422` | Der Körper hat ein unbekanntes Feld. |
