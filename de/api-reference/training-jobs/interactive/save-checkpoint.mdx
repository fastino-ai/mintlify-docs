`POST /v1/training/jobs/{job_id}/checkpoints`

Diese native JSON-Operation gilt für interaktive Trainingsjobs.

Stellt das Speichern eines Checkpoints in die Warteschlange und gibt eine `operation_id` zurück. `state` wird zu `weights`, `sampler` zu `sampler_weights`. Fragen Sie [Vorgang abrufen](/de/api-reference/training-jobs/interactive/get-operation) vor der Verwendung ab.

Den vollständigen Lebenszyklus beschreibt [Benutzerdefinierten Trainingsablauf erstellen](/de/training/training-loop).
