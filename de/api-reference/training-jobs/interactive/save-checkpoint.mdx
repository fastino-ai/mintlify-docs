`POST /v1/training/jobs/{job_id}/save-weights`

Speichert den Trainings- und Optimiererzustand als `weights`-Checkpoint.

Senden Sie `name` und optional `ttl_seconds`. Fragen Sie die zurückgegebene `future_id` ab, bevor Sie den Checkpoint verwenden.
