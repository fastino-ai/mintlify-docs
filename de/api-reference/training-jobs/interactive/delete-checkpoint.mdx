`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

Löscht einen `weights`- oder `sampler_weights`-Checkpoint. Der Vorgang wird synchron und ohne Antwortinhalt abgeschlossen. Gespeicherte Dateien können später bereinigt werden.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
