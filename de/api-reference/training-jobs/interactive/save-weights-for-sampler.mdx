`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

Speichert die LoRA-Gewichte des Jobs als `sampler_weights/<name>`. Sie können
daraus [samplen](/de/api-reference/training-jobs/interactive/sample), auch nachdem
der Job gestoppt wurde, oder ihn als PEFT-LoRA-Dateien
[herunterladen](/de/api-reference/training-jobs/download-checkpoint). Er enthält
keinen Optimizer-Zustand, daher kann ein Job ihn weder laden noch von ihm aus
starten; verwenden Sie dafür
[`POST /v1/training/jobs/{job_id}/save-weights`](/de/api-reference/training-jobs/interactive/save-weights).

Das Speichern wird in der Reihenfolge der übrigen Aufrufe des Jobs ausgeführt.

## Anfrage

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID des interaktiven Jobs.
</ParamField>

<ParamField body="name" type="string" required>
  1–128 Zeichen aus `A-Z`, `a-z`, `0-9`, `.`, `_` und `-`.
</ParamField>

<ParamField body="ttl_seconds" type="integer | null">
  Löscht den Checkpoint automatisch nach dieser Anzahl von Sekunden, von `3600`
  (1 Stunde) bis `315360000` (10 Jahre). Lassen Sie das Feld weg oder senden Sie
  `null`, um den Checkpoint zu behalten, bis Sie ihn löschen. Bestehende
  Checkpoints zählen zur [Speichernutzung](/de/api-reference/training-jobs/interactive/storage-usage).
</ParamField>

<ParamField body="user_metadata" type="object">
  String-Schlüssel-Wert-Metadaten, die mit dem Checkpoint gespeichert werden.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/save-weights-for-sampler" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "step-000100", "ttl_seconds": 86400}'
```

</RequestExample>

## Antwort

<ResponseField name="future_id" type="string">
  Das `save`-Future.
</ResponseField>

<ResponseField name="checkpoint_id" type="string">
  `sampler_weights/<name>`.
</ResponseField>

<ResponseField name="path" type="string">
  Vollständiger Checkpoint-Pfad.
</ResponseField>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "save",
  "checkpoint_id": "sampler_weights/step-000100",
  "path": "tinker://SESSION_ID:train:0/sampler_weights/step-000100"
}
```

</ResponseExample>

| Status | Bedeutung |
| --- | --- |
| `400` | Der Name enthält ungültige Zeichen oder hat eine ungültige Länge, die TTL liegt außerhalb des gültigen Bereichs, oder der Job wurde gestoppt. |
| `404` | Der Job existiert nicht oder gehört zu einem anderen Team. |
| `422` | Im Body fehlt `name`, oder er enthält ein unbekanntes Feld. |
