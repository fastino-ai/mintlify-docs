`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

Speichert die LoRA-Gewichte des Jobs als `sampler_weights/<name>`. Du kannst
[Beispiel](/de/api-reference/training-jobs/interactive/sample) daraus, auch nach dem Auftrag
gestoppt, oder [herunterladen](/de/api-reference/training-jobs/download-checkpoint) als
PEFT LoRA-Dateien. Es hat keinen Optimierungsstatus, sodass ein Job es nicht laden oder von dort aus starten kann
es; verwenden Sie [`POST /v1/training/jobs/{job_id}/save-weights`](/de/api-reference/training-jobs/interactive/save-weights)
dafür.

Die Speicherung wird der Reihe nach mit den anderen Aufrufen des Jobs ausgeführt.

## Anfrage

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField path="job_id" type="string" required>
  Interaktive Job-ID.
</ParamField>

<ParamField body="name" type="string" required>
  1–128 Zeichen aus `A-Z`, `a-z`, `0-9`, `.`, `_` und `-`.
</ParamField>

<ParamField body="ttl_seconds" type="integer | null">
  Löschen Sie den Prüfpunkt nach dieser Anzahl von Sekunden automatisch von `3600`
  (1 Stunde) bis `315360000` (10 Jahre). Lassen Sie es weg oder senden Sie `null`, um den Prüfpunkt beizubehalten, bis Sie ihn löschen. Live-Prüfpunkte werden auf [Speichernutzung](/de/api-reference/training-jobs/interactive/storage-usage) angerechnet .
</ParamField>

<ParamField body="user_metadata" type="object">
  String-Schlüsselwert-Metadaten, die mit dem Prüfpunkt gespeichert werden.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/save-weights-for-sampler" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "step-000100", "ttl_seconds": 86400}'
```

</RequestExample>

## Antwort

<ResponseField name="future_id" type="string">
  Die Zukunft `save`.
</ResponseField>

<ResponseField name="checkpoint_id" type="string">
  `sampler_weights/<name>`.
</ResponseField>

<ResponseField name="path" type="string">
  Vollständiger Checkpoint-Pfad.
</ResponseField>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "save",
  "checkpoint_id": "sampler_weights/step-000100",
  "path": "tinker://SESSION_ID:train:0/sampler_weights/step-000100"
}
```

</ResponseExample>

| Status | Bedeutung |
| --- | --- |
| `400` | Der Name enthält ungültige Zeichen oder eine ungültige Länge, die TTL liegt außerhalb des gültigen Bereichs oder der Job wurde gestoppt. |
| `404` | Der Job existiert nicht oder gehört zu einem anderen Team. |
| `422` | Dem Text fehlt `name` oder er hat ein unbekanntes Feld. |
