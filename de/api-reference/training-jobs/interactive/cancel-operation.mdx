`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

Diese native JSON-Operation gilt für interaktive Trainingsjobs.

Fordert nach bestem Bemühen den Abbruch eines wartenden oder laufenden sample-Vorgangs an. Trainingsvorgänge können nicht abgebrochen werden.

Den vollständigen Lebenszyklus beschreibt [Benutzerdefinierten Trainingsablauf erstellen](/de/training/training-loop).
