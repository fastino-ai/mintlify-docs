`GET /v1/training/jobs/{job_id}/futures/{future_id}`

Diese native JSON-Operation gilt für interaktive Trainingsjobs.

Gibt Status und Ergebnis zurück. `wait=true` wartet höchstens 25 Sekunden und kann einen nicht abgeschlossenen Status liefern. Fragen Sie bis `completed`, `failed` oder `cancelled` ab. Ein HTTP-Fehler bedeutet Ablehnung; ein angenommener Vorgang kann mit `status: "failed"` und `error.message` enden. Behandeln Sie `error.category` als undurchsichtige Zeichenfolge.

Den vollständigen Lebenszyklus beschreibt [Benutzerdefinierten Trainingsablauf erstellen](/de/training/training-loop).
