`GET /v1/training/operations/{idempotency_key}`

Senden Sie den ursprünglichen Schlüssel eines nativen interaktiven POST oder einer Encoder-Job-Erstellung. Schlüssel sind teambezogen. `not_found` bedeutet, dass kein Beleg sichtbar ist; das gilt auch während der Annahme eines nativen Aufrufs, bevor sein Job erfasst ist, und beweist nicht, dass der Aufruf nie ankam.

Ein Beleg mit `accepted` bestätigt, dass der Job erfasst wurde, nicht die erfolgreiche Ausführung. Falls ein Future vorhanden ist, lesen Sie das Ergebnis über das ursprüngliche Future. Stop hat kein Future; Encoder-Erstellungen liefern nur den Job.

Bei ungewissem Ergebnis einer nativen Anfrage wiederholen Sie Body, Route und Schlüssel unverändert. Eine andere Anfrage mit demselben Schlüssel liefert 422; ein laufender Erstaufruf liefert 409. Verwenden Sie für absichtlich neue Arbeit einen neuen Schlüssel. Dieser Endpunkt garantiert keine Aufbewahrungs- oder Ablaufdauer.

<ParamField header="X-API-Key" type="string" required>
  Fastino API key.
</ParamField>

<ParamField path="idempotency_key" type="string" required>
  Idempotency-Key.
</ParamField>
