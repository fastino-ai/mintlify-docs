`POST /v1/training/jobs/{job_id}/forward-backward`

Stellt einen Forward-Backward-Pass in die Warteschlange, der Gradienten akkumuliert, und gibt eine `future_id` zurück. Fragen Sie [Future abrufen](/de/api-reference/training-jobs/interactive/get-future) bis zu einem terminalen Status ab.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
