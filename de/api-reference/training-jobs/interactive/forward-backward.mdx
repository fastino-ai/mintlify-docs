`POST /v1/training/jobs/{job_id}/forward-backward`

Reiht einen Forward-Backward-Durchlauf ein, der Gradienten akkumuliert, und gibt eine `future_id` zurück. Fragen Sie [Interaktives Future abrufen](/de/api-reference/training-jobs/interactive/get-future) ab, bis ein terminaler Status erreicht ist.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
