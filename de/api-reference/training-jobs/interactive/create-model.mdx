`POST /v1/training/jobs/create-model`

Erstellt einen interaktiven LoRA-Job aus `base_model` oder aus `from_checkpoint` mit der optionalen Einstellung `load_optimizer`. Die Antwort enthält die `job_id` und die `future_id` für die Erstellung. Beim Wiederherstellen eines Checkpoints enthält sie auch die `load_future_id`. Native JSON-Clients senden keine `seq_id`-Werte oder Heartbeats.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
