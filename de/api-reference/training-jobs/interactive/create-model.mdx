`POST /v1/training/jobs/create-model`

Erstellt einen `interactive` LoRA-Trainingsauftrag für ein Decoder-Basismodell oder ein neues
Job, der aus einem gespeicherten Trainingszustand stammt. Ihre Bewerbung verschickt dann jeder
Vorwärts-Rückwärts-Durchlauf, Optimierungsschritt, Prüfpunkt und Stichprobe. Natives JSON
Clients senden keine `seq_id`-Werte oder Heartbeats. Für geführtes Training von
Für einen hochgeladenen Datensatz verwenden Sie [`POST /v1/training/jobs`](/de/api-reference/training-jobs/create).

Der Auftrag ist fertig, sobald seine `create`-Zukunft abgeschlossen ist. Lesen Sie es mit
[`GET /v1/training/jobs/{job_id}/futures/{future_id}`](/de/api-reference/training-jobs/interactive/get-future).

## Anfrage

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

Senden Sie genau eines von `base_model` und `from_checkpoint`.

<ParamField body="base_model" type="string">
  `nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16`,
  `nvidia/NVIDIA-Nemotron-3-Super-120B-A12B-BF16` oder `Qwen/Qwen3.6-35B-A3B`.
</ParamField>

<ParamField body="from_checkpoint" type="string">
  Der `path`, der [`save-weights`](/de/api-reference/training-jobs/interactive/save-weights)
  für einen Ihrer Jobs zurückgegeben, z. B. `tinker://<job_id>/weights/<name>`. Die
  Der neue Job übernimmt das Basismodell und die LoRA-Einstellungen dieses Prüfpunkts, also weglassen
  `lora_config`. Probenprüfpunkte werden abgelehnt.
</ParamField>

<ParamField body="load_optimizer" type="boolean" default="false">
  Setzen Sie `load_optimizer` mit `from_checkpoint`, um den Optimiererstatus wiederherzustellen.
</ParamField>

<ParamField body="lora_config" type="object">
  LoRA-Einstellungen für einen neuen Job.

  <Expandable title="properties">
    <ParamField body="rank" type="integer" default="32">
      LoRA-Rang, von 1 bis 32.
    </ParamField>
    <ParamField body="seed" type="integer">
      Adapter-Initialisierungs-Seed.
    </ParamField>
    <ParamField body="train_attn" type="boolean" default="true">
      Aufmerksamkeitsschichten trainieren.
    </ParamField>
    <ParamField body="train_mlp" type="boolean" default="true">
      Trainieren Sie MLP-Ebenen.
    </ParamField>
    <ParamField body="train_unembed" type="boolean" default="true">
      Trainieren Sie die Ebene zum Aufheben der Einbettung.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="optimizer_config" type="object">
  Optimiererfamilie. Es wird nur `{"type": "adamw"}` bereitgestellt, was die Standardeinstellung ist.
</ParamField>

<ParamField body="project_id" type="string">
  Projekt, zu dem der Job und seine Verwendung gehören. Standardmäßig wird Ihr Standardprojekt verwendet.
</ParamField>

<ParamField body="user_metadata" type="object">
  Ihre eigenen JSON-Metadaten für den Job.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/create-model" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "base_model": "Qwen/Qwen3.6-35B-A3B",
    "lora_config": {"rank": 32}
  }'
```

</RequestExample>

## Antwort

<ResponseField name="job_id" type="string">
  Interaktive Job-ID. Verwenden Sie es mit jeder `/v1/training/jobs/{job_id}`-Route.
</ResponseField>

<ResponseField name="type" type="string">
  Immer `interactive`.
</ResponseField>

<ResponseField name="base_model" type="string">
  Basismodell des Jobs.
</ResponseField>

<ResponseField name="future_id" type="string">
  Die Zukunft des Jobs `create`.
</ResponseField>

<ResponseField name="load_future_id" type="string | null">
  Mit `from_checkpoint` die Zukunft, die den Checkpoint lädt.
</ResponseField>

<ResponseExample>

```json Response
{
  "job_id": "SESSION_ID:train:0",
  "type": "interactive",
  "base_model": "Qwen/Qwen3.6-35B-A3B",
  "future_id": "FUTURE_ID",
  "load_future_id": null
}
```

</ResponseExample>

## Fehler

| Status | Bedeutung |
| --- | --- |
| `400` | Das Modell wird nicht bereitgestellt, der Rang liegt außerhalb des Bereichs, `from_checkpoint` ist ein Sampler-Prüfpunkt oder `lora_config` wurde mit `from_checkpoint` gesendet. |
| `402` | Das Team hat kein Guthaben oder keine gültige Zahlungseinrichtung. |
| `404` | Dem Team steht kein interaktives Training zur Verfügung oder der Kontrollpunkt existiert nicht. |
| `422` | `base_model` und `from_checkpoint` wurden beide oder keine gesendet, oder der Text enthält ein unbekanntes Feld. |
