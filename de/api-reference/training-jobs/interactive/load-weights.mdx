`POST /v1/training/jobs/{job_id}/load-weights`

Reiht einen Ladevorgang aus `path` ein und gibt eine `future_id` zurück. Verwenden Sie einen Zustandsnamen oder den eigenen Pfad `tinker://<job_id>/weights/<name>` dieses Jobs. Setzen Sie `optimizer`, um den Optimizer-Zustand wiederherzustellen. Fragen Sie [Interaktives Future abrufen](/de/api-reference/training-jobs/interactive/get-future) ab, bis ein terminaler Status erreicht ist.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
