`POST /v1/training/jobs/{job_id}/load-weights`

Stellt einen Ladevorgang aus `path` in die Warteschlange und gibt eine `future_id` zurück. Verwenden Sie einen Zustandsnamen oder den eigenen Pfad `tinker://<job_id>/weights/<name>` dieses Jobs. Setzen Sie `optimizer`, um den Optimiererzustand wiederherzustellen. Fragen Sie [Future abrufen](/de/api-reference/training-jobs/interactive/get-future) bis zu einem terminalen Status ab.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
