`GET /v1/training/usage`

Gibt den Live-Kontrollpunktspeicher für interaktive Jobs des Teams zurück, pro Projekt und
Benutzer mit den geschätzten monatlichen Kosten. Bei gelöschten und abgelaufenen Kontrollpunkten ist dies nicht der Fall
zählen.

<ParamField query="project_id" type="string">
  Nur der Speicher dieses Projekts.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/usage" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

<ResponseExample>

```json Response
{
  "effective_rate_usd_per_gigabyte_month": 0.1,
  "data": [
    {
      "project_id": "PROJECT_ID",
      "org_user_urn": "USER_URN",
      "user_email": "you@example.com",
      "user_name": "You",
      "checkpoint_count": 3,
      "size_bytes": 805306368,
      "size_gigabytes": 0.75,
      "estimated_monthly_cost_usd": 0.075
    }
  ]
}
```

</ResponseExample>
