`GET /v1/training/usage`

Gibt den aktuell belegten Checkpoint-Speicher der interaktiven Jobs des Teams mit einer Zeile pro Projekt und den geschätzten monatlichen Kosten zurück. Die Kompatibilitätsfelder `org_user_urn` und `user_name` enthalten die Team-ID; `user_email` ist `null`. Gelöschte und abgelaufene Checkpoints werden nicht gezählt.

<ParamField query="project_id" type="string">
  Nur den Speicher dieses Projekts.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/usage" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

<ResponseExample>

```json Response
{
  "effective_rate_usd_per_gigabyte_month": 0.05,
  "data": [
    {
      "project_id": "PROJECT_ID",
      "org_user_urn": "TEAM_ID",
      "user_email": null,
      "user_name": "TEAM_ID",
      "checkpoint_count": 3,
      "size_bytes": 805306368,
      "size_gigabytes": 0.805306368,
      "estimated_monthly_cost_usd": 0.0402653184
    }
  ]
}
```

</ResponseExample>
