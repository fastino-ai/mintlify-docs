`GET /v1/training/usage`

Gibt den aktuell belegten Checkpoint-Speicher der interaktiven Jobs des Teams
pro Projekt und Benutzer zurück, zusammen mit den geschätzten monatlichen Kosten.
Gelöschte und abgelaufene Checkpoints werden nicht gezählt.

<ParamField query="project_id" type="string">
  Nur den Speicher dieses Projekts.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/usage" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

<ResponseExample>

```json Response
{
  "effective_rate_usd_per_gigabyte_month": 0.05,
  "data": [
    {
      "project_id": "PROJECT_ID",
      "org_user_urn": "USER_URN",
      "user_email": "you@example.com",
      "user_name": "You",
      "checkpoint_count": 3,
      "size_bytes": 805306368,
      "size_gigabytes": 0.75,
      "estimated_monthly_cost_usd": 0.0375
    }
  ]
}
```

</ResponseExample>
