`GET /v1/training/usage`

Gibt den teamweiten Speicher interaktiver Checkpoints und dessen monatlichen Preis zurück. Rechennutzung oder Gesamtabrechnung werden nicht gemeldet.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
