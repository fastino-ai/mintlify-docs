`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

Bricht eine eingereihte oder laufende sample-Future nach bestem Bemühen ab. Trainingsoperationen laufen in Reihenfolge und werden nicht abgebrochen. Gibt `204 No Content` zurück.

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/futures/$FUTURE_ID/cancel" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
