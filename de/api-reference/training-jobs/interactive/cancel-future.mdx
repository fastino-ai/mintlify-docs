`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

Fordert nach bestem Bemühen den Abbruch eines eingereihten oder laufenden Sample-Futures an. Nur Sample-Futures können abgebrochen werden. Trainings-Futures werden der Reihe nach ausgeführt und können nicht abgebrochen werden.

Den gesamten Lebenszyklus beschreibt [die benutzerdefinierte Trainingsschleife](/de/training/training-loop).
