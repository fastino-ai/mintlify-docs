`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

Für eine in der Warteschlange befindliche oder laufende `sample`-Zukunft ist die Stornierung die beste Lösung. Die Route
gibt `204 No Content` zurück, wenn die Anfrage angenommen wird. Stornieren eines Terminals
Zukunft oder eine Trainingszukunft gibt ebenfalls `204` zurück; Es ist ein erfolgreiches No-Op, weil
Der Trainingsbetrieb läuft ordnungsgemäß und wird nicht abgesagt.

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/futures/$FUTURE_ID/cancel" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Fehler

| Status | Bedeutung |
| --- | --- |
| `404` | Der Job oder die Zukunft existiert nicht oder gehört zu einem anderen Team. |
