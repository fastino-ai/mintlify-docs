`POST /v1/training/jobs/{job_id}/stop`

Stoppt einen laufenden Job und erhält die vor dem Stopp erstellten Checkpoints.

Bei einem `interactive`-Job gibt der Stopp den Job frei, sobald seine
eingereihten Operationen abgeschlossen sind. Danach nimmt er keine
Trainingsoperationen mehr an, seine Sampler-Checkpoints lassen sich aber weiter
samplen und herunterladen. Interaktive Jobs ignorieren den Request-Body.

## Request

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID eines Config-Jobs oder ID eines interaktiven Jobs.
</ParamField>

Der JSON-Body ist optional.

<ParamField body="reason" type="string">
  Grund für das Stoppen des Jobs.
</ParamField>

<ParamField body="scores" type="object">
  Numerische Metriken, auf denen die Stopp-Entscheidung basierte.
</ParamField>

<ParamField body="checkpoint" type="string">
  Checkpoint-Pfad oder -Schritt, der dem Stopp zugeordnet ist.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID/stop \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"reason": "Validation loss stopped improving"}'
```

</RequestExample>

## Response

<ResponseExample>

```json Response
{
  "success": true,
  "message": "Training job stopped",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "status": "stopped"
}
```

```json 202 — Abbruch ausstehend
{
  "success": true,
  "message": "Training job cancellation is still being confirmed.",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "status": "stopping"
}
```

```json Interactive job
{
  "success": true,
  "job_id": "SESSION_ID:train:0",
  "status": "stopped"
}
```

</ResponseExample>

Fragen Sie nach einer `202`-Antwort
`GET /v1/training/jobs/{job_id}` ab. Wiederholen Sie den Stopp-Request nicht,
solange der Abbruch aussteht.

| Status | Bedeutung |
| --- | --- |
| `200` | Der Job ist gestoppt und vorhandene Checkpoints bleiben verfügbar. |
| `202` | Die Bestätigung des Anbieterabbruchs steht noch aus. |
| `400` | `job_id` ist weder eine Config-Job-UUID noch eine ID eines interaktiven Jobs. |
| `409 training_job_already_finished` | Der Job hat vor dem Stopp einen Endzustand erreicht. |
| `422` | Der JSON-Request-Body ist ungültig. |
