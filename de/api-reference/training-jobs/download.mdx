`GET /v1/training/jobs/{job_id}/download`

Dieser Vorgang ist nur für Config-Jobs verfügbar; nach den üblichen Funktions- und Berechtigungsprüfungen gibt eine interaktive Job-ID `400` zurück, laden Sie daher stattdessen einen benannten Checkpoint mit `GET /v1/training/jobs/{job_id}/checkpoints/{checkpoint_id}/download` herunter.

Gibt eine vorsignierte URL für das trainierte Artefakt zurück. Rufen Sie die zurückgegebene URL separat auf, um die Datei herunterzuladen.

## Request

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID des Trainingsjobs.
</ParamField>

<RequestExample>

```bash cURL
curl https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID/download \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Response

<ResponseField name="success" type="boolean">
  Gibt an, ob die URL erzeugt wurde.
</ResponseField>

<ResponseField name="job_id" type="string">
  UUID des Trainingsjobs.
</ResponseField>

<ResponseField name="download_url" type="string">
  Temporäre vorsignierte Artefakt-URL.
</ResponseField>

<ResponseField name="expires_in_seconds" type="integer">
  Gültigkeitsdauer der URL. Der Standardwert beträgt 3600 Sekunden.
</ResponseField>

<ResponseField name="file_name" type="string">
  Vorgeschlagener Name der Download-Datei im Format `gliner2-model-<first-8-job-id-characters>.tar.gz`.
</ResponseField>

<ResponseExample>

```json Response
{
  "success": true,
  "job_id": "YOUR_TRAINING_JOB_ID",
  "download_url": "https://...",
  "expires_in_seconds": 3600,
  "file_name": "gliner2-model-a1b2c3d4.tar.gz",
  "message": "Download URL generated successfully"
}
```

</ResponseExample>

<Warning>
  Die vorsignierte URL ist ein temporäres Bearer-Credential. Loggen, committen, persistieren oder teilen Sie sie nicht. Laden Sie das Artefakt zeitnah herunter und speichern Sie es gemäß Ihrer Datenrichtlinie.
</Warning>

So fordern Sie die URL an und laden das Artefakt in einem Workflow herunter:

```bash
response=$(curl -fsS \
  https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID/download \
  -H "X-API-Key: $FASTINO_API_KEY")

curl -fL \
  -o "$(jq -r '.file_name' <<<"$response")" \
  "$(jq -r '.download_url' <<<"$response")"
```

Für dieses Beispiel wird `jq` benötigt.

Gewichte-Downloads sind standardmäßig aktiviert. Ein Team, dessen Download-Zugriff ausdrücklich deaktiviert wurde, erhält `403`.

| Status | Bedeutung |
| --- | --- |
| `400` | Bei einem Config-Job ist das Training nicht abgeschlossen oder das Modellartefakt noch nicht bereit; warten Sie und versuchen Sie es erneut. Verwenden Sie bei einer interaktiven Job-ID stattdessen die Download-Route für benannte Checkpoints. |
| `401` | Eine verzögerte Abrechnungsprüfung erfordert eine Zahlungsmethode. Fügen Sie sie in den Abrechnungseinstellungen hinzu. |
| `403` | Gewichte-Downloads wurden für das Team ausdrücklich deaktiviert. |
| `404` | Der Job ist unbekannt oder nicht zugänglich. |
