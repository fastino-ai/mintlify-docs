`GET /v1/training/jobs/{job_id}/checkpoints/{checkpoint_id}/download`

Gibt eine kurzlebige, vorab signierte Objektspeicher-URL für einen Checkpoint eines `interactive`-Jobs zurück. Das Archiv eines Sampler-Checkpoints enthält die Decoder-Adapterdateien. Config-Jobs verwenden für ihr endgültiges Modellartefakt
[`GET /v1/training/jobs/{job_id}/download`](/de/api-reference/training-jobs/download).

## Request

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField path="job_id" type="string" required>
  Von `POST /v1/training/jobs/create-model` zurückgegebene interaktive `job_id`.
</ParamField>

<ParamField path="checkpoint_id" type="string" required>
  Von der Checkpoint-Liste zurückgegebene Checkpoint-Kennung, beispielsweise
  `weights/checkpoint-1` oder `sampler_weights/checkpoint-1`. Behalten Sie den
  `/` im Pfad bei; kodieren Sie nicht die gesamte Kennung als URL.
</ParamField>

<RequestExample>

```bash cURL
CHECKPOINT_ID="sampler_weights/checkpoint-1"
curl "https://api.fastino.ai/v1/training/jobs/JOB_ID/checkpoints/$CHECKPOINT_ID/download" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Response

Die Antwort enthält eine vorab signierte Objektspeicher-URL, die nach 15 Minuten abläuft.
Behandeln Sie die URL wie Anmeldedaten: Protokollieren, teilen oder speichern
Sie sie nicht dauerhaft.

<ResponseField name="success" type="boolean">
  Gibt an, ob die Anfrage erfolgreich war.
</ResponseField>

<ResponseField name="run_id" type="string">
  Interactive-Job, dem der Checkpoint gehört.
</ResponseField>

<ResponseField name="checkpoint_id" type="string">
  Kennung des herunterladbaren Interactive-Checkpoints.
</ResponseField>

<ResponseField name="download_url" type="string">
  Vorab signierte Objektspeicher-URL. Zum Abrufen ist kein API-Schlüssel erforderlich.
</ResponseField>

<ResponseField name="expires_in_seconds" type="integer">
  Verbleibende Gültigkeit der vorab signierten URL. Neue Links laufen nach 900 Sekunden ab.
</ResponseField>

<ResponseField name="file_name" type="string">
  Vorgeschlagener `.tar`-Dateiname für das Archiv.
</ResponseField>

<ResponseExample>

```json Response
{
  "success": true,
  "run_id": "session-1:train:0",
  "checkpoint_id": "sampler_weights/checkpoint-1",
  "download_url": "SIGNED_ARCHIVE_URL",
  "expires_in_seconds": 900,
  "file_name": "session-1_train_0-sampler_weights-checkpoint-1.tar"
}
```

</ResponseExample>

Checkpoint-Downloads sind standardmäßig aktiviert. Ein Team, dessen Download-Zugriff ausdrücklich deaktiviert wurde, erhält `403`.

## Decoder-Adapter laden

Der Sampler-Checkpoint eines Decoders wird als Standard-Hugging-Face-PEFT-Adapter für das öffentliche Basismodell heruntergeladen. Das Archiv enthält `adapter_config.json`, `adapter_model.safetensors` mit allen trainierten Tensoren und eine `README.md` mit Ladecode:

```python
from peft import PeftModel
from transformers import AutoModelForCausalLM

base = AutoModelForCausalLM.from_pretrained("Qwen/Qwen3.6-35B-A3B", dtype="auto")
model = PeftModel.from_pretrained(base, "path/to/extracted/archive")
```

Fastino testet diese Adapter mit transformers 5.19.0 und peft 0.21.2, nicht mit vLLM. Ein Nemotron-3.5-Lightning-Adapter, der Mamba-`out_proj` trainiert, braucht vor dem Laden in PEFT eine einzeilige Freigabe; die `README.md` im Archiv zeigt sie. Nur Sampler-Checkpoints werden konvertiert: Ein Trainingszustands-Checkpoint wird im internen Layout von Fastino heruntergeladen.

## Fehler

| Status | Bedeutung |
| --- | --- |
| `400` | `checkpoint_id` ist nicht `weights/<name>` oder `sampler_weights/<name>`. |
| `403` | Gewichte-Downloads wurden für das Team ausdrücklich deaktiviert. |
| `404` | Der Job oder Checkpoint ist nicht verfügbar, oder der Checkpoint hat keine herunterladbaren Dateien. |

Der Abruf von `download_url` liefert einen `application/x-tar`-Anhang. Die vorab signierte Objektspeicher-URL ist das Zugangsmittel und läuft nach den in der Antwort angegebenen `expires_in_seconds` ab.
