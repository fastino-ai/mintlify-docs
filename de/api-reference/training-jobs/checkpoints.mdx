`GET /v1/training/jobs/{job_id}/checkpoints`

Gibt die für einen Trainingsjob sichtbaren Checkpoints zurück.

## Request

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID eines Config-Jobs oder die von `POST /v1/training/jobs/create-model` zurückgegebene interaktive `job_id`.
</ParamField>

<RequestExample>

```bash cURL
curl https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID/checkpoints \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Response

<ResponseField name="success" type="boolean">
  Gibt an, ob die Anfrage erfolgreich war.
</ResponseField>

<ResponseField name="checkpoints" type="object[]">
  Gespeicherte Checkpoints. Die Form der Einträge hängt vom Jobtyp ab.
</ResponseField>

<ResponseField name="count" type="integer">
  Anzahl der zurückgegebenen Checkpoints.
</ResponseField>

### Config-Job

Config-Checkpoints enthalten `id`, `job_id`, Epoch, Step, Loss-, Metrik-,
Deployment- und Zeitstempelfelder. Ihre `id` wird vom Download-Endpunkt für
interaktive Checkpoints nicht akzeptiert.

<ResponseExample>

```json Response
{
  "success": true,
  "checkpoints": [
    {
      "id": "CHECKPOINT_ID",
      "job_id": "YOUR_TRAINING_JOB_ID",
      "epoch": 5,
      "step": 500,
      "training_loss": 0.12,
      "validation_loss": 0.18,
      "is_deployable": true,
      "is_best": true,
      "is_final": true,
      "created_at": "2026-09-22T20:30:00Z",
      "updated_at": "2026-09-22T20:30:00Z"
    }
  ],
  "count": 1
}
```

</ResponseExample>

### Interactive-Job

Interactive-Jobs geben zusätzlich `run_id` zurück. Die Checkpoints sind vom
neuesten zum ältesten sortiert. Verwenden Sie `checkpoint_id`, zum Beispiel
`sampler_weights/checkpoint-1`, mit dem
[Download-Endpunkt für interaktive Checkpoints](/de/api-reference/training-jobs/download-checkpoint).
Übergeben Sie nicht die Config-Checkpoint-`id` oder `tinker_path`.

<ResponseExample>

```json Response
{
  "success": true,
  "run_id": "session-1:train:0",
  "checkpoints": [
    {
      "checkpoint_id": "sampler_weights/checkpoint-1",
      "checkpoint_type": "sampler",
      "time": "2026-09-22T20:30:00Z",
      "tinker_path": "tinker://session-1:train:0/sampler_weights/checkpoint-1",
      "size_bytes": 12345,
      "public": false,
      "user_metadata": null,
      "expires_at": null
    }
  ],
  "count": 1
}
```

</ResponseExample>

Ein unbekannter oder nicht zugänglicher Job gibt `404` zurück.
