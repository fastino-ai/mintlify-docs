`POST /v1/training/jobs/{job_id}/terminate`

<Warning>
  Die umbenannte `/v1/training/jobs`-Oberfläche ist in der Entwicklung verifiziert, nicht in Produktion. Produktion kann `404` zurückgeben.
</Warning>

Stoppt einen aktiven `config`-Job und fordert den Abbruch beim Anbieter an.
Vorhandene Checkpoints und Artefakte bleiben standardmäßig erhalten.

<Warning>
  Wenn Sie `delete_checkpoints` auf `true` setzen, werden die Checkpoints und
  Artefakte des Jobs dauerhaft gelöscht, nachdem der Abbruch bestätigt wurde.
  Dies kann nicht rückgängig gemacht werden.
</Warning>

## Request

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID des Trainingsjobs.
</ParamField>

Der JSON-Body ist optional.

<ParamField body="delete_checkpoints" type="boolean" default="false">
  Löscht Checkpoints und Artefakte dauerhaft, nachdem der Abbruch bestätigt
  wurde.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID/terminate \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"delete_checkpoints": false}'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 — terminiert
{
  "success": true,
  "message": "Training job terminated. Checkpoints preserved (pass delete_checkpoints=true to remove them).",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "deleted_checkpoints": 0,
  "status": "terminated"
}
```

```json 202 — Abbruch ausstehend
{
  "success": true,
  "message": "Termination in progress. The job moves to 'terminated' once the provider confirms; checkpoints are preserved.",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "deleted_checkpoints": 0,
  "status": "stopping"
}
```

</ResponseExample>

Fragen Sie nach einer `202`-Antwort
`GET /v1/training/jobs/{job_id}` ab. Wiederholen Sie den
Terminierungsrequest nicht, solange der Abbruch aussteht.

| Status | Bedeutung |
| --- | --- |
| `200` | Der Job ist terminiert. |
| `202` | Die Terminierung läuft, während der Anbieter den Abbruch bestätigt. |
| `400` | `job_id` ist keine gültige UUID eines Config-Jobs. |
| `409 training_job_already_finished` | Der Job hat vor der Terminierung einen Endzustand erreicht. |
| `409 cancellation_unconfirmed` | Der Abbruch wurde nicht bestätigt und kann erneut versucht werden. |
| `422` | Der JSON-Request-Body ist ungültig. |

## Autorisierung

Erfordert die Teamrolle Owner, Admin oder Editor. Andere Rollen erhalten `403 Forbidden`.
