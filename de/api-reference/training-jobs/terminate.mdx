`POST /v1/training-jobs/{job_id}/terminate`

Stoppt den Anbieter-Job, falls er aktiv ist, und markiert den Job als terminiert. Vorhandene Checkpoints und Artefakte bleiben standardmäßig erhalten.

<Warning>
  Wenn `delete_checkpoints` auf `true` gesetzt wird, werden die Checkpoints und Artefakte des Jobs dauerhaft gelöscht. Dies kann nicht rückgängig gemacht werden.
</Warning>

## Request

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID des Trainingsjobs.
</ParamField>

<ParamField body="delete_checkpoints" type="boolean" default="false">
  Gibt an, ob alle Checkpoints und Artefakte dauerhaft gelöscht werden. Lassen Sie das Feld weg oder setzen Sie es auf `false`, um sie zu erhalten.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training-jobs/YOUR_TRAINING_JOB_ID/terminate \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"delete_checkpoints": false}'
```

</RequestExample>

## Response

<ResponseExample>

```json Response
{
  "success": true,
  "message": "Training job terminated. Checkpoints preserved (pass delete_checkpoints=true to remove them).",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "deleted_checkpoints": 0
}
```

</ResponseExample>

Ein unbekannter Job oder ein Job, der nicht terminiert werden kann, gibt einen anfragespezifischen `4xx`-Fehler zurück.
