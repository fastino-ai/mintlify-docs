`POST /v1/training-jobs/{job_id}/terminate`

Stoppt den Anbieter-Job, falls er aktiv ist, und markiert den Job als terminiert. Checkpoints bleiben standardmäßig erhalten. Sie werden nur gelöscht, wenn Sie `{"delete_checkpoints": true}` senden, und erst nachdem der Anbieter bestätigt hat, dass der Job gestoppt ist.

<Warning>
  Die Terminierung ist unumkehrbar. Auch das Löschen von Checkpoints mit `delete_checkpoints: true` ist unumkehrbar: Alle Checkpoints und gespeicherten Artefakte des Jobs werden dauerhaft entfernt.
</Warning>

## Request

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID des Trainingsjobs.
</ParamField>

Der JSON-Body ist optional. Lassen Sie ihn weg, um den Job zu terminieren und seine Checkpoints zu behalten.

<ParamField body="delete_checkpoints" type="boolean" default="false">
  Alle Checkpoints und Artefakte dieses Jobs dauerhaft löschen. Unumkehrbar. Standardwert ist `false`, sodass die Terminierung niemals Artefakte zerstört, für deren Erstellung Sie bereits bezahlt haben.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training-jobs/YOUR_TRAINING_JOB_ID/terminate \
  -H "X-API-Key: $FASTINO_API_KEY"
```

```bash cURL (delete checkpoints)
curl -X POST https://api.fastino.ai/v1/training-jobs/YOUR_TRAINING_JOB_ID/terminate \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"delete_checkpoints": true}'
```

</RequestExample>

## Response

<ResponseExample>

```json Response
{
  "success": true,
  "message": "Training job terminated. Checkpoints preserved (pass delete_checkpoints=true to remove them).",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "deleted_checkpoints": 0
}
```

</ResponseExample>

Mit `delete_checkpoints: true` meldet die Nachricht, wie viele Checkpoints gelöscht wurden, und `deleted_checkpoints` enthält diese Anzahl.

Hat der Anbieter den Abbruch noch nicht bestätigt, gibt der Endpunkt `202` mit `status: "stopping"` und `deleted_checkpoints: 0` zurück. Der Job wechselt zu `terminated`, sobald der Anbieter bestätigt; Checkpoints werden danach nur gelöscht, wenn Sie `delete_checkpoints: true` gesetzt haben. Fragen Sie `GET /v1/training-jobs/{job_id}` ab, statt terminate erneut aufzurufen.

Ein unbekannter Job oder ein Job, der nicht terminiert werden kann, gibt einen anfragespezifischen `4xx`-Fehler zurück.
