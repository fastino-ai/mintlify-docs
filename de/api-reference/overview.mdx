Diese Anleitung führt Sie auf dem schnellsten Weg zu einer funktionierenden Fastino-Integration. Am Ende
haben Sie einen erfolgreichen Inferenzaufruf ausgeführt und kennen den Aufbau der API. Sie benötigen
lediglich ein Fastino-Konto und ein Terminal.

<Steps>
  <Step title="Registrieren und API-Schlüssel erhalten">
    Erstellen Sie ein Konto bei [Fastino](https://fastino.ai).

    Sobald Sie angemeldet sind, gehen Sie zu **Settings → API Keys** und generieren Sie einen neuen Schlüssel. Kopieren Sie ihn
    an einen sicheren Ort, denn nach dem Schließen des Dialogs können Sie ihn nicht mehr einsehen.

    <Warning>
      Halten Sie Ihren API-Schlüssel aus der Versionsverwaltung heraus. Verwenden Sie eine Umgebungsvariable oder einen
      Secrets-Manager, anstatt ihn fest in Ihren Quelldateien zu hinterlegen.
    </Warning>

    Legen Sie Ihren Schlüssel als Umgebungsvariable fest, damit die folgenden Beispiele unverändert funktionieren:

    ```bash
    export FASTINO_API_KEY="your_api_key_here"
    ```
  </Step>

  <Step title="Verfügbare Basismodelle auflisten (optional)">
    Verwenden Sie `GET /v1/base-models`, um die bei Fastino verfügbaren Modelle zu durchsuchen.

    <CodeGroup>

    ```bash curl
    curl https://api.fastino.ai/v1/base-models \
      -H "X-API-Key: $FASTINO_API_KEY"
    ```

    ```python Python
    import os
    import requests

    response = requests.get(
        "https://api.fastino.ai/v1/base-models",
        headers={"X-API-Key": os.environ["FASTINO_API_KEY"]},
    )
    response.raise_for_status()
    print(response.json())
    ```

    ```javascript JavaScript
    const response = await fetch(
      "https://api.fastino.ai/v1/base-models",
      {
        headers: {
          "X-API-Key": process.env.FASTINO_API_KEY
        }
      }
    );

    if (!response.ok) {
      throw new Error(`Model request failed: ${response.status}`);
    }

    console.log(await response.json());
    ```

    </CodeGroup>

    Die Antwort listet Modell-IDs auf, die Sie an `/v1/chat/completions` übergeben können. Beispielsweise
    ist `fastino/gliner2-base-v1` ein GLiNER-Basismodell für Extraktionsaufgaben.
  </Step>

  <Step title="Ersten Inferenzaufruf ausführen">
    Rufen Sie `POST /v1/chat/completions` mit einem Modell, einer Nachricht und einem Schema auf, das festlegt,
    was Sie extrahieren möchten. Dieses Beispiel verwendet GLiNER, um benannte Entitäten aus einem Satz zu extrahieren.

    <CodeGroup>

    ```bash curl
    curl -X POST "https://api.fastino.ai/v1/chat/completions" \
      -H "Authorization: Bearer $FASTINO_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "fastino/gliner2.5-multi-v1",
        "messages": [
          {
            "role": "user",
            "content": "Apple announced the MacBook Pro at WWDC in Cupertino."
          }
        ],
        "schema": {
          "entities": [
            {
              "name": "organization",
              "description": "business or institution name"
            },
            {
              "name": "product",
              "description": "named commercial product"
            },
            {
              "name": "event",
              "description": "named conference or event"
            },
            {
              "name": "location",
              "description": "city, region, or place"
            }
          ]
        },
        "threshold": 0.5
      }'
    ```

    ```python Python
    import json
    import os

    import requests

    response = requests.post(
        "https://api.fastino.ai/v1/chat/completions",
        headers={
            "Authorization": f"Bearer {os.environ['FASTINO_API_KEY']}",
            "Content-Type": "application/json",
        },
        json={
            "model": "fastino/gliner2.5-multi-v1",
            "messages": [
                {
                    "role": "user",
                    "content": "Apple announced the MacBook Pro at WWDC in Cupertino.",
                }
            ],
            "schema": {
                "entities": [
                    {"name": "organization", "description": "business or institution name"},
                    {"name": "product", "description": "named commercial product"},
                    {"name": "event", "description": "named conference or event"},
                    {"name": "location", "description": "city, region, or place"},
                ]
            },
            "threshold": 0.5,
        },
    )
    response.raise_for_status()

    result = response.json()
    entities = json.loads(result["choices"][0]["message"]["content"])
    print(json.dumps(entities, indent=2))
    ```

    ```javascript JavaScript
    const response = await fetch(
      "https://api.fastino.ai/v1/chat/completions",
      {
        method: "POST",
        headers: {
          Authorization: `Bearer ${process.env.FASTINO_API_KEY}`,
          "Content-Type": "application/json",
        },
        body: JSON.stringify({
          model: "fastino/gliner2.5-multi-v1",
          messages: [
            {
              role: "user",
              content: "Apple announced the MacBook Pro at WWDC in Cupertino.",
            },
          ],
          schema: {
            entities: [
              { name: "organization", description: "business or institution name" },
              { name: "product", description: "named commercial product" },
              { name: "event", description: "named conference or event" },
              { name: "location", description: "city, region, or place" },
            ],
          },
          threshold: 0.5,
        }),
      }
    );

    if (!response.ok) {
      throw new Error(`Inference failed: ${response.status} ${await response.text()}`);
    }

    const result = await response.json();
    const entities = JSON.parse(result.choices[0].message.content);
    console.log(JSON.stringify(entities, null, 2));
    ```

    </CodeGroup>

    Bei Encoder-Modellen wie GLiNER definiert das `schema`-Objekt die Aufgabe und kann Folgendes enthalten:

    - `entities` — Entitätsdefinitionen für die Extraktion benannter Entitäten
    - `classifications` — `{task, labels}`-Definitionen für die Textklassifikation
    - `structures` — Definitionen strukturierter Datensätze für die JSON-Extraktion
    - `relations` — Relationsdefinitionen

    Lassen Sie bei Decoder-Modellen `schema` weg und senden Sie eine normale Chat-Nachricht.

    <Note>
      `model` muss eine inferenzfähige Basismodell-ID oder die UUID eines abgeschlossenen,
      bereitstellbaren Trainingsjobs sein. Stellen Sie nach dem Training das ausgewählte Artefakt bereit, bevor Sie die
      Job-UUID für die Inferenz verwenden.
    </Note>
  </Step>

  <Step title="Einen Trainingsjob starten (optional)">
    Wenn Sie bereit sind, ein Modell mit Ihren eigenen Daten feinabzustimmen, starten Sie einen Trainingsjob:

    <CodeGroup>

    ```bash curl
    curl -X POST https://api.fastino.ai/v1/training-jobs \
      -H "X-API-Key: $FASTINO_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model_name": "my-ner-model",
        "base_model": "fastino/gliner2-base-v1",
        "datasets": [{"name": "my-dataset"}],
        "training_type": "lora",
        "nr_epochs": 5,
        "learning_rate": 5e-5
      }'
    ```

    ```python Python
    import os
    import requests

    response = requests.post(
        "https://api.fastino.ai/v1/training-jobs",
        headers={
            "X-API-Key": os.environ["FASTINO_API_KEY"],
            "Content-Type": "application/json",
        },
        json={
            "model_name": "my-ner-model",
            "base_model": "fastino/gliner2-base-v1",
            "datasets": [{"name": "my-dataset"}],
            "training_type": "lora",
            "nr_epochs": 5,
            "learning_rate": 5e-5,
        },
    )
    response.raise_for_status()
    print(response.json())
    ```

    </CodeGroup>

    Die Antwort enthält eine Job-`id`. Fragen Sie `GET /v1/training-jobs/{id}` ab, um den Status zu prüfen.
    Sobald der Job `complete` erreicht, stellen Sie das ausgewählte Artefakt bereit, bevor Sie die Job-ID als
    `model` in `/v1/chat/completions` verwenden.

    Der Job-Status durchläuft `requested` → `running` → `complete` oder endet als `failed` oder
    `stopped`.
  </Step>
</Steps>

## Migration vom Pioneer-API-Ursprung

Wenn eine bestehende Trainings- oder Inferenzintegration `https://api.pioneer.ai` aufruft, aktualisieren Sie ihre
Basis-URL auf `https://api.fastino.ai`.

Trainingsrouten verwenden jetzt das Präfix `/v1`. Zum Beispiel wird `/felix/training-jobs` jetzt zu
`/v1/training-jobs`, und die jobspezifischen Operationen bleiben unter dieser neuen Routenfamilie.

Direkte API-Integrationen sollten `FASTINO_API_KEY` mit einem neu generierten `fast_sk_`-Schlüssel verwenden;
veraltete `pio_sk_`-Schlüssel wurden eingestellt. Sowohl `X-API-Key`- als auch Bearer-Authentifizierung bleiben gültig.
