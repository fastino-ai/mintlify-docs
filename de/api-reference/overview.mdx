Mit der Fastino REST API können Sie Inferenzen ausführen, Datensätze verwalten, Trainingsjobs starten und Modelle programmatisch evaluieren. Alle Ressourcen liegen unter einer einzigen Basis-URL. Die meisten Operationen erfordern Ihren API-Schlüssel; ausdrücklich öffentliche Katalog-Routen wie `GET /v1/models` nicht. Fastino stellt außerdem OpenAI- und Anthropic-kompatible Endpunkte bereit, sodass Sie sich in jedes Tool integrieren können, das diese Formate bereits unterstützt.

**Basis-URL:** `https://api.fastino.ai`

## Authentifizierung

Authentifizierte native Anfragen verwenden einen `X-API-Key`-Header. Erstellen Sie Ihren Schlüssel im Fastino-Dashboard unter [agent.fastino.ai/api-keys](https://agent.fastino.ai/api-keys) oder öffnen Sie nach der Anmeldung **Settings** -> **API Keys**. Weitere Details, einschließlich der Endpunkte zur Schlüsselverwaltung, finden Sie auf der Seite [Authentifizierung](/de/api-reference/authentication).

## Empfohlener Workflow

Folgen Sie dieser Reihenfolge, wenn Sie ein feinabgestimmtes Modell durchgängig aufbauen:

<Steps>
  <Step title="Einen Datensatz erstellen oder hochladen">
    Verwenden Sie `POST /v1/generate`, um synthetische, gelabelte Daten zu erzeugen. Die Antwort enthält eine `job_id`; fragen Sie `GET /v1/generate/jobs/{job_id}` ab, bis der Status `ready` zurückgibt.

    Um eigene gelabelte Daten hochzuladen, verwenden Sie den dreistufigen Upload-Ablauf:

    1. Rufen Sie `POST /v1/datasets/upload/url` auf, um eine vorsignierte S3-URL zu erhalten.
    2. Führen Sie einen `PUT` Ihrer Datei direkt an S3 aus.
    3. Rufen Sie `POST /v1/datasets/upload/process` auf, um die Verarbeitung anzustoßen.

    Fragen Sie `GET /v1/datasets/{name}/{version}` ab, bis der Status `ready` ist.<br />Weitere Details finden Sie auf der Seite [Datensätze](/api-reference/datasets).
  </Step>
  <Step title="Einen Trainingsjob starten">
    Rufen Sie `POST /v1/training-jobs` mit Ihrem model\_name, Ihren datasets und base\_model auf. Die Antwort enthält eine `job_id`. Bewahren Sie diese für die folgenden Schritte auf.
  </Step>
  <Step title="Trainingsstatus abfragen">
    Rufen Sie `GET /v1/training-jobs/:id` wiederholt auf, bis das Statusfeld `complete` ist. Abgeschlossene Jobs enthalten F1-, Precision- und Recall-Metriken.
  </Step>
  <Step title="Eine Evaluation ausführen">
    Erstellen Sie mit `POST /v1/projects/{project_id}/evaluation-suites` eine Evaluation-Suite und führen Sie sie anschließend gegen das ausgewählte Modell aus, bevor Sie Traffic bereitstellen.
  </Step>
  <Step title="Inferenz ausführen">
    Rufen Sie `POST /v1/chat/completions` auf, wobei `model` auf Ihre Trainingsjob-ID gesetzt ist, und übergeben Sie Ihre Eingabe in `messages`. Sie können auch eine unterstützte Basismodell-ID ohne Fine-Tuning verwenden.
  </Step>
</Steps>

<Note>
  Ersetzen Sie Platzhalterwerte wie `YOUR_DATASET_NAME` und `YOUR_TRAINING_JOB_ID` durch echte Werte, bevor Sie Beispielbefehle ausführen.
</Note>

## OpenAI- und Anthropic-Kompatibilität

Fastino bietet Drop-in-Ersatz für die OpenAI- und Anthropic-SDKs. Verwenden Sie Ihren Fastino-API-Schlüssel und die unten angegebene SDK-spezifische Basis-URL.

| SDK | Basis-URL | Hinweise |
| --- | --- | --- |
| OpenAI | `https://api.fastino.ai/v1` | `base_url` setzen; Fastino-spezifische Felder über `extra_body` übergeben |
| Anthropic | `https://api.fastino.ai` | `base_url` setzen; das SDK hängt `/v1/messages` an |

Übergeben Sie Fastino-spezifische Felder wie `schema` über `extra_body` (OpenAI SDK) oder den entsprechenden Mechanismus für zusätzliche Parameter Ihrer Client-Bibliothek.

## `/v1` und Ausnahmen für Root-Routen

Native Produkt-Routen verwenden das Präfix `/v1`. OpenAI- und Anthropic-kompatible Routen behalten ihre bestehenden `/v1`-Pfade. Protokoll- und Betriebsressourcen bleiben im Root, darunter `/health`, `/openapi.json` und `/.well-known/*`.

Stellen Sie `/v1` nicht pauschal voran. Verwenden Sie den exakten Pfad aus dieser Referenz oder dem kuratierten OpenAPI-Dokument.

## Migration vom Pioneer-API-Origin

Wenn eine bestehende Integration `https://api.pioneer.ai` aufruft, ändern Sie ihre Basis-URL in `https://api.fastino.ai`. Native Routen für Datensätze, Training, Projekte, Modellkatalog und Inferenz-Historie verwenden jetzt das Präfix `/v1`. Beispielsweise ist `/felix/training-jobs` jetzt `/v1/training-jobs`.

OpenAI- und Anthropic-kompatible Routen beginnen bereits mit `/v1` und behalten ihre bestehenden Pfade. Fügen Sie kein zweites Präfix hinzu: `/v1/chat/completions` bleibt `/v1/chat/completions`, nicht `/v1/v1/chat/completions`. Direkte API-Integrationen sollten `FASTINO_API_KEY` mit einem neu erzeugten `fast_sk_`-Schlüssel verwenden; ältere `pio_sk_`-Schlüssel sind außer Betrieb genommen. Die bestehenden Header-Formen `X-API-Key` und Bearer-Authentifizierung bleiben gültig. Die Fastino CLI liest weiterhin `PIONEER_API_KEY`, bis ihre separate Konfigurationsmigration veröffentlicht wird.
