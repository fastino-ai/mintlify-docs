Jedes Rezept ist eine funktionierende Anfrage für eine gängige Aufgabe. Es zeigt das Anfrage- und Antwortschema, eine echte Antwort der Live-API und Code, der das Ergebnis verarbeitet. Kopieren Sie ein Rezept, setzen Sie Ihre eigenen Daten ein und passen Sie die Kriterien oder Labels an.

Die GLiNER-Rezepte decken die drei häufigsten Einsatzzwecke von GLiNER 2.5 Multilingual ab: Entitätsextraktion, Klassifikation und Relationsextraktion.

Jede Rezeptanfrage wird gegen die Live-API geprüft, sodass die gezeigten Antworten dem entsprechen, was die API heute zurückgibt. Konfidenzwerte schwanken zwischen Aufrufen geringfügig.
