`GET /v1/training-runs/{run_id}/checkpoints`

Gibt die gespeicherten Checkpoints eines Trainingslaufs zurück, neueste zuerst. Checkpoints entstehen durch die Speicheraufrufe des SDK: Trainingszustands-Checkpoints (`weights/<name>`) setzen das Training fort, und Sampler-Checkpoints (`sampler_weights/<name>`) enthalten die Adaptergewichte für das Sampling.

## Anfrage

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField path="run_id" type="string" required>
  ID des Trainingslaufs.
</ParamField>

<RequestExample>

```bash cURL
curl https://api.fastino.ai/v1/training-runs/YOUR_RUN_ID/checkpoints \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Antwort

<ResponseField name="success" type="boolean">
  Ob die Anfrage erfolgreich war.
</ResponseField>

<ResponseField name="run_id" type="string">
  ID des Trainingslaufs.
</ResponseField>

<ResponseField name="checkpoints" type="object[]">
  Gespeicherte Checkpoints, neueste zuerst.

  <Expandable title="Checkpoint">
    <ResponseField name="checkpoint_id" type="string">
      Checkpoint-ID, entweder `weights/<name>` oder `sampler_weights/<name>`. Verwenden Sie sie mit [Checkpoint herunterladen](/de/api-reference/training-runs/download-checkpoint).
    </ResponseField>
    <ResponseField name="checkpoint_type" type="string">
      `training` für Trainingszustands-Checkpoints oder `sampler` für Sampler-Gewichte.
    </ResponseField>
    <ResponseField name="time" type="string">
      ISO-8601-Zeitstempel der Speicherung des Checkpoints.
    </ResponseField>
    <ResponseField name="tinker_path" type="string">
      Der `tinker://`-Pfad des Checkpoints, über den das SDK ihn lädt.
    </ResponseField>
    <ResponseField name="size_bytes" type="integer | null">
      Checkpoint-Größe in Bytes, sofern bekannt.
    </ResponseField>
    <ResponseField name="public" type="boolean">
      Ob der Checkpoint veröffentlicht ist.
    </ResponseField>
    <ResponseField name="user_metadata" type="object | null">
      An den Checkpoint angehängte String-Schlüssel-Wert-Metadaten.
    </ResponseField>
    <ResponseField name="expires_at" type="string | null">
      ISO-8601-Ablaufzeit oder `null`, wenn der Checkpoint bis zum Löschen erhalten bleibt.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="count" type="integer">
  Anzahl der zurückgegebenen Checkpoints.
</ResponseField>
