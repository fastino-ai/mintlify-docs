`GET /v1/training/jobs`

Gibt die für den authentifizierten Aufrufer sichtbaren Trainingsläufe zurück, neueste zuerst. Trainingsläufe sind schrittweise Läufe, die Sie mit dem Tinker-kompatiblen SDK erstellen und steuern. Setzen Sie die `base_url` des SDK auf `https://api.fastino.ai/v1/training/compat/tinker` und übergeben Sie Ihren Fastino-API-Schlüssel über den Credential-Befehl des SDK: `TINKER_CREDENTIAL_CMD='printf %s "$FASTINO_API_KEY"'`. Tinker-Schlüssel mit `tml-` werden mit `401` abgelehnt. Sie sehen Ihre eigenen Läufe und die Läufe Ihres Teams in Projekten, auf die Sie Zugriff haben.

## Anfrage

<ParamField header="X-API-Key" type="string" required>
  Ihr Fastino-API-Schlüssel.
</ParamField>

<ParamField query="type" type="string">
  Jobtyp. Verwenden Sie `interactive` (hier der Standard). `config` liefert `400`.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Seitengröße. Werte werden auf `1` bis `1000` begrenzt.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Anzahl der zu überspringenden Läufe.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs?type=interactive&limit=20&offset=0" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Antwort

<ResponseField name="success" type="boolean">
  Ob die Anfrage erfolgreich war.
</ResponseField>

<ResponseField name="training_jobs" type="object[]">
  Trainingsläufe dieser Seite. Jeder Lauf enthält die unter [Trainingslauf abrufen](/de/api-reference/training-runs/get) beschriebenen Felder.
</ResponseField>

<ResponseField name="count" type="integer">
  Anzahl der Läufe auf dieser Seite.
</ResponseField>

<ResponseField name="total" type="integer">
  Gesamtzahl der sichtbaren Läufe vor der Paginierung.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  Ob nach dieser Seite eine weitere Seite folgt.
</ResponseField>

Ungültige Paginierungswerte geben `422` zurück. Ein fehlender oder ungültiger API-Schlüssel gibt `401` zurück. Wenn Trainingsläufe für Ihr Team nicht aktiviert sind, gibt die Route `404` zurück.
