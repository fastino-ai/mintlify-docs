GLiNER-2.5-Decide ist Fastinos für englische Klassifikation optimiertes GLiNER-Modell. Übergeben Sie bei jeder Anfrage eigene Labels und klassifizieren Sie Absicht, Routing, Stimmung, Priorität, Richtlinien und andere operative Entscheidungen, ohne ein generatives Modell zu prompten.

## Wann Sie GLiNER-2.5-Decide verwenden sollten

Verwenden Sie GLiNER-2.5-Decide, wenn Klassifikation die Hauptaufgabe ist:

- **Absicht und Routing** - leiten Sie Support-Nachrichten, E-Mails oder Agentenanfragen an den richtigen Workflow weiter.
- **Mehrere Entscheidungen pro Eingabe** - klassifizieren Sie Absicht, Dringlichkeit, Route und menschliche Übergabe in einem Aufruf.
- **Single- und Multi-Label-Klassifikation** - wählen Sie eine Kategorie oder alle zutreffenden Labels.
- **Operative Gates** - bestimmen Sie, ob ein Agent fertig ist, ein Mensch übernehmen soll oder Inhalte gegen Richtlinien verstoßen.
- **Ordinale Labels** - bewerten Sie Schweregrad, Dringlichkeit oder Ratings mit einer geordneten Skala.
- **Benutzerdefinierte Taxonomien** - definieren Sie Labels und kurze Beschreibungen pro Anfrage, ohne neu zu trainieren.

Das gehostete Modell unterstützt weiterhin Entitäten, Relationen und strukturierte Extraktion, aber Klassifikation ist der Grund, es zu wählen. Verwenden Sie [GLiNER2.5](/de/concepts/gliner), wenn Extraktion im Vordergrund steht, Sie Span-Attribute oder gemeinsame Entitäten-Relations-Extraktion benötigen oder der Text mehrsprachig ist.

## So verwenden Sie GLiNER-2.5-Decide

Rufen Sie das Modell über denselben Fastino-Inferenz-Endpunkt wie jedes andere GLiNER-Modell auf und verwenden Sie dabei ein `classifications`-Schema. Bewerten Sie mehrere zusammenhängende Urteile in einem Aufruf, indem Sie weitere Aufgabeneinträge hinzufügen:

```bash
curl -X POST "https://api.fastino.ai/v1/chat/completions" \
  -H "Authorization: Bearer $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "fastino/GLiNER-2.5-Decide",
    "messages": [
      { "role": "user", "content": "My subscription renewed on April 15 after the service was already down. Can I get that refunded?" }
    ],
    "schema": {
      "classifications": [
        {
          "task": "intent",
          "labels": ["refund_request", "cancel_subscription", "login_problem", "speak_to_human"],
          "multi_label": false
        },
        {
          "task": "urgency",
          "labels": ["low", "normal", "high", "critical"],
          "multi_label": false
        }
      ]
    }
  }'
```

`intent` und `urgency` werden gemeinsam bewertet, sodass der Router beide Entscheidungen aus einer Anfrage erhält. In der [Chat-Completions-API](/de/inference/chat-completions) finden Sie den Response-Vertrag, Multi-Label-Klassifikation und Konfidenzschwellen.
