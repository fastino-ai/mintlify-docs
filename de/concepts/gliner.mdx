GLiNER2.5 Multi ist Fastinos mehrsprachiges Multi-Task-Modell für Informationsextraktion. Mit einem Schema extrahieren Sie Entitäten, klassifizieren Text, erstellen strukturierte Datensätze, erkennen Relationen und versehen Spans mit Attributen.

## Wann Sie GLiNER 2.5 verwenden sollten

Verwenden Sie GLiNER2.5 Multi, wenn Extraktion oder mehrsprachige Abdeckung im Mittelpunkt stehen:

- **Entitätsextraktion** - Extrahieren Sie Personen, Organisationen, Produkte, Orte oder domänenspezifische Entitäten (Medikamente, Dosierungen, Klauseln) aus Freitext, inklusive Zeichen-Offsets und Konfidenzwerten.
- **Strukturierte Datensätze** - Verwandeln Sie „Alice bought apples and Bob bought oranges" in `[{"buyer": "Alice", "item": "apples"}, {"buyer": "Bob", "item": "oranges"}]`, wobei die Felder jeder Instanz miteinander verknüpft bleiben.
- **Relations- und Wissensgraph-Extraktion** - Extrahieren Sie typisierte Entitäts-Relations-Graphen (`works_for`, `located_in`) für Agenten-Speicher oder eine Wissensdatenbank.
- **Span-Attribute** - Versehen Sie jede extrahierte Entität im selben Durchlauf wie die Extraktion mit einem Attribut, etwa dem Sentiment pro Person.
- **Lange Dokumente** - Verarbeiten Sie einen kodierten Kontext von bis zu 4.096 Tokens, mit Chunking und Offset-Neuzuordnung für längere Dokumente.
- **Mehrere Aufgaben gleichzeitig** - Kombinieren Sie Entitäten, Klassifikation, Strukturen und Relationen in einem einzigen schema-gebundenen Aufruf, statt mehrere Modellanfragen zu verketten.
- **Konsistente Ergebnisse** - Verwenden Sie eingeschränkte Klassifikation oder gemeinsame Entitäten-Relations-Dekodierung, wenn Labels und Relationsendpunkte übereinstimmen müssen.

GLiNER2.5 Multi unterstützt ebenfalls Klassifikation. Wählen Sie [GLiNER-2.5-Decide](/de/concepts/gliner-2-5-decide), wenn der Text englisch ist und Klassifikation - Absicht, Routing, Stimmung, Priorität, Moderation oder Scoring - die Hauptaufgabe ist.

## So verwenden Sie GLiNER 2.5

Rufen Sie den mehrsprachigen Checkpoint über den OpenAI-kompatiblen Inferenz-Endpunkt von Fastino auf. Geben Sie den Text in einer User-Nachricht an und beschreiben Sie die Aufgabe in `schema`:

```bash
curl -X POST "https://api.fastino.ai/v1/chat/completions" \
  -H "Authorization: Bearer $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "fastino/gliner2.5-multi-v1",
    "messages": [
      { "role": "user", "content": "Apple CEO Tim Cook unveiled the iPhone 15 Pro in Cupertino." }
    ],
    "schema": {
      "entities": [
        { "name": "person", "description": "named individual" },
        { "name": "organization", "description": "business or institution name" },
        { "name": "product", "description": "named commercial product" },
        { "name": "location", "description": "city, region, or place" }
      ]
    }
  }'
```

Fügen Sie demselben `schema` die Schlüssel `classifications`, `structures` oder `relations` hinzu, um mehrere Aufgaben in einem Aufruf über denselben Text auszuführen. In der Referenz zur [Inferenz-API](/de/inference/chat-completions) finden Sie den vollständigen Request- und Response-Vertrag, einschließlich strukturierter Datensätze und Relationsschemas.

## Eingeschränkte Klassifikation mit GLiNER2.5 Multi

Verwenden Sie eingeschränkte Klassifikation, wenn mehrere Antworten gemeinsam eine gültige Entscheidung ergeben müssen. Anders als klassische `classifications`, die jede Aufgabe unabhängig auswählen, sucht der eingeschränkte Decoder nach einer gemeinsamen Zuweisung, die die deklarierten Regeln erfüllt.

GLiNER2.5 Multi unterstützt drei Aufgabenformen:

| Aufgabenform | Auswahlregel | Typische Verwendung |
| --- | --- | --- |
| Einzelne Antwort | Genau eine zulässige Antwort auswählen | Absicht, Route oder Richtlinienurteil |
| Mehrere Antworten | Null oder mehr Antworten auswählen, optional mit Mindest- und Höchstanzahl | Themen, Auswirkungen oder erkannte Schäden |
| Ordinal | Genau eine Antwort aus einer von niedrig nach hoch geordneten Skala auswählen | Schweregrad, Dringlichkeit oder Bewertung |

Jede Aufgabe kann Antwortbeschreibungen, eine Anweisung und gelabelte Beispiele enthalten. Diese Felder geben dem Encoder Kontext für die Bewertung, während die Ausgabe auf die deklarierten Antworten beschränkt bleibt.

Constraints verknüpfen diese Aufgabenergebnisse:

| Constraint | Bedeutung |
| --- | --- |
| Implikation | Die Auswahl einer Antwort erfordert eine andere Antwort oder Bedingung |
| Ausschluss | Zwei Antworten können nicht beide ausgewählt werden |
| Kardinalität | Legt fest oder begrenzt, wie viele Antworten eine Aufgabe auswählt |
| Ordinale Schranke | Erfordert eine exakte, minimale, maximale oder begrenzte Stufe |

Das Ergebnis enthält für jede Aufgabe die ausgewählte Antwort, die Antwortwahrscheinlichkeiten, die Konfidenz und `_meta.feasible`. Constraints können eine weniger wahrscheinliche Antwort auswählen, wenn die unabhängig besten Antworten gegen eine Regel verstoßen würden. Sie erzwingen Konsistenz. Sie erhöhen oder rekalibrieren weder Wahrscheinlichkeiten noch Konfidenz.

Bei Aufgaben mit einzelner Antwort und ordinalen Aufgaben ist die Konfidenz die Wahrscheinlichkeit der ausgewählten Antwort. Bei Aufgaben mit mehreren Antworten ist sie das geometrische Mittel aus der Wahrscheinlichkeit jeder ausgewählten Antwort und dem Komplement jeder nicht ausgewählten Antwort (`1 - probability`). Ein leeres Ergebnis bei mehreren Antworten ohne Standardwert hat keinen Konfidenzwert.

Im [API-Beispiel zur eingeschränkten Klassifikation](/de/inference/chat-completions#schema-für-eingeschränkte-klassifikation) finden Sie die vollständige gehostete Anfrage, die unterstützten Schemafelder, Constraints und die Antwort.
