GLiNER ist eine Open-Source-Familie kleiner Sprachmodelle für effiziente Informationsextraktion. GLiNER 2.5 ist die aktuelle Generation und die Standardwahl für neue Extraktionsaufgaben.

## Wann Sie GLiNER 2.5 verwenden sollten

Greifen Sie zu GLiNER 2.5, wenn die Aufgabe eine Extraktionsaufgabe ist — wenn Sie die wörtlichen Spans, strukturierte Datensätze oder einen Relationsgraphen aus dem Text benötigen und nicht ein einzelnes Entscheidungs-Label.

- **Entitätsextraktion** — Extrahieren Sie Personen, Organisationen, Produkte, Orte oder domänenspezifische Entitäten (Medikamente, Dosierungen, Klauseln) aus Freitext, inklusive Zeichen-Offsets und Konfidenzwerten.
- **Strukturierte Datensätze** — Verwandeln Sie „Alice bought apples and Bob bought oranges" in `[{"buyer": "Alice", "item": "apples"}, {"buyer": "Bob", "item": "oranges"}]`, wobei die Felder jeder Instanz miteinander verknüpft bleiben.
- **Relations- und Wissensgraph-Extraktion** — Extrahieren Sie typisierte Entitäts-Relations-Graphen (`works_for`, `located_in`) für Agenten-Speicher oder eine Wissensdatenbank.
- **Span-Attribute** — Versehen Sie jede extrahierte Entität im selben Durchlauf wie die Extraktion mit einem Attribut, etwa dem Sentiment pro Person.
- **Lange Dokumente** — Verarbeiten Sie Verträge, Transkripte und Berichte mit bis zu 4.096 Wörtern, mit automatischem Chunking und Offset-Neuzuordnung für alles, was länger ist.
- **Mehrere Aufgaben gleichzeitig** — Kombinieren Sie Entitäten, Klassifikation, Strukturen und Relationen in einem einzigen schema-gebundenen Aufruf, statt mehrere Modellanfragen zu verketten.

Verwenden Sie stattdessen [GLiNER-2.5-Decide](/de/concepts/gliner-2-5-decide), wenn die Aufgabe eine Entscheidung ist — eine Route, ein Label, ein Score — und nicht der zugrunde liegende Text.

## So verwenden Sie GLiNER 2.5

Rufen Sie den mehrsprachigen Checkpoint über den OpenAI-kompatiblen Inferenz-Endpunkt von Fastino auf. Geben Sie den Text in einer User-Nachricht an und beschreiben Sie die Aufgabe in `schema`:

```bash
curl -X POST "https://api.fastino.ai/v1/chat/completions" \
  -H "Authorization: Bearer $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "fastino/gliner2.5-multi-v1",
    "messages": [
      { "role": "user", "content": "Apple CEO Tim Cook unveiled the iPhone 15 Pro in Cupertino." }
    ],
    "schema": {
      "entities": [
        { "name": "person", "description": "named individual" },
        { "name": "organization", "description": "business or institution name" },
        { "name": "product", "description": "named commercial product" },
        { "name": "location", "description": "city, region, or place" }
      ]
    }
  }'
```

Fügen Sie demselben `schema` die Schlüssel `classifications`, `structures` oder `relations` hinzu, um mehrere Aufgaben in einem Aufruf über denselben Text auszuführen. In der Referenz zur [Inferenz-API](/de/inference) finden Sie den vollständigen Request- und Response-Vertrag, einschließlich strukturierter Datensätze und Relationsschemas.

## GLiNER-Generationen vergleichen

| | GLiNER2.5 | GLiNER2 | GLiNER |
| --- | --- | --- | --- |
| Architektur | Grenzvorhersage | Span-Enumeration | Span-Enumeration |
| Hauptverwendung | Regelbewusste strukturierte Extraktion | Entitätsextraktion und strukturiertes Parsing | Open-Vocabulary-NER |
| Modellgrößen | 74M Small, 194M Base, 287M Multilingual | 205M Base, 300M Multilingual | 50M Small, 90M Medium |
| Eingabekontext | 4.096 Wörter | 2.048 Tokens | 512 Tokens |
| Maximale Span-Länge | Keine feste Obergrenze | 8 Wörter | 12 Wörter |
| Textklassifikation | Ja, mit aufgabenübergreifenden Regeln | Ja | Nein |
| Strukturierte Extraktion | Ja | Ja | Nein |
| Relationsextraktion | Ja | Ja | Nein |
| Span-Attribute | Ja | Nein | Nein |

GLiNER2.5 ist der empfohlene Ausgangspunkt für neue Extraktionsprojekte. Verwenden Sie GLiNER2 für bestehende schemabasierte Integrationen und das ursprüngliche GLiNER für Open-Vocabulary-NER-Checkpoints, die auf dem Paket der ersten Generation aufbauen.
