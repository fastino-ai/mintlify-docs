GLiNER 2.5 Decide gibt einen standardmäßigen Chat-Completions-Umschlag zurück. Das Klassifizierungsergebnis selbst ist als JSON in `choices[0].message.content` serialisiert.

## Das Ergebnis parsen

```python
import json

body = response.json()
result = json.loads(body["choices"][0]["message"]["content"])
```

Lesen Sie Klassifizierungsaufgaben nicht direkt aus `choices[0]`; parsen Sie zuerst `message.content`.

## Single-Label-Aufgabe

Bei `multi_label: false` gibt jede Aufgabe ein Objekt zurück:

```json
{
  "intent": {
    "label": "refund_request",
    "confidence": 0.999862551689148
  }
}
```

- `label` ist einer der Strings, die im `labels`-Array dieser Aufgabe bereitgestellt wurden.
- `confidence` ist die Konfidenz des Modells für das ausgewählte Label, von `0` bis `1`.

## Multi-Label-Aufgabe

Bei `multi_label: true` gibt jede Aufgabe ein Array ausgewählter Labels zurück:

```json
{
  "tags": [
    {"label": "technical_issue", "confidence": 0.4421546757221222},
    {"label": "login_problem", "confidence": 0.21206879615783691},
    {"label": "urgent", "confidence": 0.4834045469760895},
    {"label": "human_handoff", "confidence": 0.8267117738723755}
  ]
}
```

Nur Labels, die `cls_threshold` der Aufgabe erreichen, werden ausgewählt. Ein strengerer Schwellenwert kann zu einem kürzeren Array oder zu gar keinen ausgewählten Labels führen.

## Mehrere Aufgaben

Das geparste Objekt verwendet die `task`-Namen aus der Anfrage als Schlüssel:

```json
{
  "intent": {
    "label": "refund_request",
    "confidence": 0.99
  },
  "urgency": {
    "label": "normal",
    "confidence": 0.82
  }
}
```

Jede klassische Klassifizierungsaufgabe wird unabhängig bewertet.

## Antwortumschlag

| Feld | Bedeutung |
| --- | --- |
| `model` | Für die Inferenz verwendete Modell-ID |
| `choices[0].message.content` | JSON-codiertes Klassifizierungsergebnis |
| `choices[0].finish_reason` | Abschlussstatus, normalerweise `stop` |
| `usage.prompt_tokens` | Anzahl der Eingabe-Token |
| `usage.completion_tokens` | Anzahl der Ausgabe-Token |
| `usage.total_tokens` | Kombinierte Nutzung |
| `token_usage` | Von Fastino gemeldete kombinierte Token-Nutzung |
| `x_fastino.inference_id` | ID der persistierten Inferenz, wenn Speicherung aktiviert ist |
| `x_fastino.default_schema_applied` | Ob das Katalog-Standardschema des Modells verwendet wurde |

`x_fastino` kann `null` sein, wenn keine zusätzlichen Fastino-Metadaten zurückgegeben werden.
