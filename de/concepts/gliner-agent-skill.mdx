Der [GLiNER2 Agent-Skill](https://github.com/jaanavit/gliner2-skill) gibt Cursor, Claude Code und Codex Anleitungen für GLiNER2.5-, GLiNER2- und GLiNER-Workflows, einschließlich Modellauswahl, Schema-Design, Extraktion, Klassifikation, Relationen und Fine-Tuning.

## Installation

Führen Sie diesen Befehl in Ihrem Projekt aus:

```bash
npx skills add jaanavit/gliner2-skill
```

Der Installer lässt Sie wählen, welche unterstützten Agenten den Skill erhalten.

## Nicht-interaktive Installation

Verwenden Sie den Befehl für Ihren Agenten, um den Skill ohne Rückfragen im aktuellen Projekt zu installieren:

<CodeGroup>

```bash Cursor
npx skills add jaanavit/gliner2-skill -a cursor -y
```

```bash Claude Code
npx skills add jaanavit/gliner2-skill -a claude-code -y
```

```bash Codex
npx skills add jaanavit/gliner2-skill -a codex -y
```

</CodeGroup>

Die Option `-a` wählt den Ziel-Agenten und `-y` bestätigt die Installationsabfragen, wodurch diese Befehle für Skripte und CI geeignet sind.
