Das [Fastino GLiNER Agent Skill](https://api.fastino.ai/.well-known/agent-skills/fastino-gliner/SKILL.md) hilft Cursor, Claude Code und Codex dabei, Fastinos gehostete APIs für Extraktion, Klassifikation, Dataset-Vorbereitung, Fine-Tuning, Evaluation und Inferenz zu nutzen.

## Installation

Führe diesen Befehl in deinem Projekt aus:

```bash
npx skills add https://api.fastino.ai --skill fastino-gliner
```

Der Installer lässt dich auswählen, welche unterstützten Agenten das Skill erhalten.

Bevor du das Skill verwendest, stelle deinen Fastino-API-Schlüssel in der Umgebung des Agenten bereit:

```bash
export FASTINO_API_KEY="..."
```

Rufe es anschließend explizit mit `/fastino-gliner` auf oder bitte deinen Agenten um einen gehosteten GLiNER-Workflow für Extraktion, Klassifikation, Fine-Tuning, Evaluation oder Inferenz.

## Nicht-interaktive Installation

Verwende den Befehl für deinen Agenten, um das Skill ohne Rückfragen im aktuellen Projekt zu installieren:

<CodeGroup>

```bash Cursor
npx skills add https://api.fastino.ai --skill fastino-gliner -a cursor -y
```

```bash Claude Code
npx skills add https://api.fastino.ai --skill fastino-gliner -a claude-code -y
```

```bash Codex
npx skills add https://api.fastino.ai --skill fastino-gliner -a codex -y
```

```text Any agent
"Install the Fastino GLiNER agent skill. Follow the installation
instructions in Fastino's documentation at
https://docs.fastino.ai/concepts/gliner-agent-skill. Use one
installation method appropriate for your agent environment. Then use
the Fastino GLiNER skill when working on this project, especially for
schema-driven information extraction, entity extraction,
classification, and relation extraction"
```

</CodeGroup>

Für Cursor, Claude Code und Codex wählt die Option `-a` den Ziel-Agenten aus und `-y` bestätigt die Installationsaufforderungen, wodurch diese Befehle für Skripte und CI geeignet sind.
