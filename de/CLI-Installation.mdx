Installieren Sie die Pioneer CLI, wenn Sie über das Terminal auf Trainingsjobs, Modellartefakte, Datensätze und den interaktiven Pioneer-Agenten zugreifen möchten.

<Info>
  Die Pioneer CLI wird als `@fastino-ai/pioneer-cli` veröffentlicht und läuft mit Bun `1.1.0` oder neuer.
</Info>

## Voraussetzungen

- macOS oder Linux
- Bun `1.1.0` oder neuer
- Node.js und npm
- Ein Pioneer-API-Schlüssel von [Pioneer-API-Schlüssel](https://app.pioneer.ai/api-keys)

## CLI installieren

<Steps>
  <Step title="Bun installieren">
    ```bash
    curl -fsSL https://bun.sh/install | bash
    ```

    Öffnen Sie nach Abschluss der Installation ein neues Terminal und bestätigen Sie, dass Bun verfügbar ist:

    ```bash
    bun --version
    ```
  </Step>
  <Step title="Pioneer CLI installieren">
    ```bash
    npm install -g @fastino-ai/pioneer-cli
    ```
  </Step>
  <Step title="Befehl überprüfen">
    ```bash
    pioneer --version
    pioneer --help
    ```
  </Step>
</Steps>

## Authentifizierung

<Steps>
  <Step title="API-Schlüssel erstellen">
    Erstellen Sie einen API-Schlüssel im Pioneer-Dashboard und halten Sie ihn für die Anmeldeaufforderung bereit.
  </Step>
  <Step title="Interaktiv anmelden">
    ```bash
    pioneer auth login
    ```

    Die CLI validiert den Schlüssel, bevor sie ihn speichert.
  </Step>
  <Step title="Sitzung bestätigen">
    ```bash
    pioneer auth status
    ```
  </Step>
</Steps>

<Note>
  Bei der interaktiven Anmeldung wird Ihr API-Schlüssel in `~/.pioneer/config.json` gespeichert. Die CLI unterstützt außerdem `PIONEER_API_KEY` für CI oder kurzlebige Shell-Sitzungen.
</Note>

## Einrichtung überprüfen

Führen Sie einige Nur-Lese-Befehle aus, um zu bestätigen, dass die CLI Pioneer erreichen kann:

```bash
pioneer --version
pioneer auth status
pioneer model base-models
pioneer dataset list
```

## Aktualisieren

```bash
npm install -g @fastino-ai/pioneer-cli@latest
pioneer --version
```

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="pioneer: command not found" icon="circle-alert">
    Stellen Sie sicher, dass Ihr globales npm-bin-Verzeichnis im `PATH` enthalten ist.

    ```bash
    npm bin -g
    ```
  </Accordion>

  <Accordion title="env: bun: No such file or directory" icon="terminal">
    Installieren Sie Bun und öffnen Sie ein neues Terminal:

    ```bash
    curl -fsSL https://bun.sh/install | bash
    bun --version
    ```
  </Accordion>

  <Accordion title="Authentifizierung schlägt fehl" icon="key-round">
    Erstellen Sie einen neuen API-Schlüssel im Pioneer-Dashboard und führen Sie die interaktive Anmeldung erneut aus.

    ```bash
    pioneer auth login
    pioneer auth status
    ```
  </Accordion>
</AccordionGroup>
