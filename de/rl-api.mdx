Die RL API ist Fastinos programmierbare Schnittstelle für Reinforcement Learning
und benutzerdefiniertes Post-Training. Sie implementiert den Vertrag des Tinker
SDK, sodass Sie einen bestehenden Tinker-Trainingsloop übernehmen oder mit dem
Open-Source-Tinker-Cookbook beginnen können.

<Note>
  Die RL API ist nur eingeschränkt verfügbar. Vergewissern Sie sich, dass
  Fastino sie für Ihr Team aktiviert hat, bevor Sie eine Produktionsmigration
  planen.
</Note>

Sie steuern den Loop:

1. Antworten aus der aktuellen Policy sampeln.
2. Jede Antwort mit Ihrer Reward-Funktion bewerten.
3. Rewards in Advantages umwandeln.
4. Den Trainingsbatch an die RL API senden.
5. Einen Optimierungsschritt anwenden und das Ergebnis als Checkpoint speichern.

Fastino verwaltet die Trainings- und Sampling-Infrastruktur hinter diesem Loop.
Ihr Code behält die Kontrolle über Dataset, Reward-Funktion, Rollout-Strategie
und Abbruchkriterien.

<Tip>
  Sie verwenden bereits Tinker? Behalten Sie Ihre SDK-Aufrufe bei und setzen Sie
  den Fastino-Endpunkt und API-Schlüssel. Beginnen Sie mit
  [Von Tinker migrieren](/de/rl-api/migrate-from-tinker).
</Tip>

## Warum die RL API verwenden?

- **Bestehenden Code übernehmen.** Das offizielle Python-Paket `tinker` dient
  als Client.
- **Beliebige programmatische Rewards definieren.** Bewerten Sie Mathematik,
  Code, Tool-Nutzung, strukturierte Ausgaben oder Ihre eigene Umgebung.
- **Orchestrierung und Compute trennen.** Behalten Sie den Lernalgorithmus in
  Ihrer Anwendung, während Fastino die Modelloperationen ausführt.
- **Von dauerhaften Checkpoints fortsetzen.** Speichern Sie Gewichte oder
  Optimizer-Status und setzen Sie einen Lauf später fort.
- **Nutzung mit Fastino nachverfolgen.** Training, Sampling und
  Checkpoint-Speicher verwenden dieselbe Abrechnungsgrenze für Konto und Projekt
  wie Ihre anderen Fastino-Workloads.

## Voraussetzungen

Sie benötigen:

- Einen Fastino-API-Schlüssel, der mit `fast_sk_` beginnt
- Aktivierten RL-API-Zugriff für Ihr Fastino-Team
- Python 3.11 oder höher
- `tinker==0.32.0` für den getesteten Client-Vertrag

Die RL API wird bewusst getrennt von Fastinos OpenAPI-Referenz dokumentiert.
Verwenden Sie diese Seiten und die Typen des Tinker SDK für RL-Operationen.
Verwenden Sie die
[API-Referenz](/de/api-reference/inference/overview) für native
Fastino-HTTP-APIs.
