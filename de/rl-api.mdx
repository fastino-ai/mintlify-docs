Mit der RL API führen Sie Reinforcement Learning und benutzerdefiniertes
Post-Training auf Fastino aus. Ihr Code steuert Dataset, Reward-Funktion,
Rollout-Strategie und Abbruchkriterien. Fastino führt Sampling und Training aus.

<Note>
  Die RL API ist nur eingeschränkt verfügbar. Vergewissern Sie sich, dass
  Fastino sie für Ihr Team aktiviert hat, bevor Sie eine Produktionsmigration
  planen.
</Note>

Verwenden Sie das offizielle Python-SDK `tinker`. Bestehende
Tinker-Anwendungen können zu Fastino wechseln, ohne ihren Lernloop zu ersetzen.

## Was Sie steuern

Ihre Anwendung:

1. Sampelt Antworten aus der aktuellen Policy.
2. Bewertet jede Antwort mit Ihrer Reward-Funktion.
3. Wandelt Rewards in Advantages um.
4. Sendet den Trainingsbatch an die RL API.
5. Führt einen Optimierungsschritt aus und speichert sinnvolle Checkpoints.

Diese Trennung lässt Sie Reward oder Trainingsalgorithmus ändern, ohne
Modellinfrastruktur zu verwalten.
