Fastinos RL API ist ein gehosteter Dienst für Training und Sampling. Der
unterstützte Python-Client ist das für Fastino konfigurierte Paket `tinker`.
Ihr Code steuert Dataset, Reward-Funktion, Strategie zur Antwortgenerierung und
Abbruchkriterien. Fastino führt Sampling und Training aus.

<Note>
  Die RL API ist nur eingeschränkt verfügbar. Vergewissern Sie sich, dass
  Fastino sie für Ihr Team aktiviert hat, bevor Sie eine Produktionsmigration
  planen.
</Note>

Durch die Installation des Pakets `tinker` erhalten Sie keinen Zugriff auf
Fastinos RL API. Bestehende Tinker-Anwendungen, die von Fastino unterstützte
Modelle, LoRA-Training, Loss-Funktionen und Sampling-Operationen verwenden,
können ihren Lernloop in der Regel beibehalten.

Verwenden Sie diese API, wenn Ihre Anwendung wiederholt Antworten generieren,
bewerten und das Modell aktualisieren muss. Für verwaltetes Fine-Tuning mit
einem vorbereiteten Dataset verwenden Sie die [Training API](/de/training).

## Was Sie steuern

Ihre Anwendung:

1. Sampelt Antworten aus der aktuellen Policy.
2. Bewertet jede Antwort mit Ihrer Reward-Funktion.
3. Wandelt Rewards in Advantages um.
4. Sendet den Trainingsbatch an die RL API.
5. Führt einen Optimierungsschritt aus und speichert sinnvolle Checkpoints.

Diese Trennung lässt Sie Reward oder Trainingsalgorithmus ändern, ohne
Modellinfrastruktur zu verwalten.
