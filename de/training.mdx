Die Trainingsjobs-API verwaltet den gesamten Lebenszyklus eines Fine-Tuning-Jobs. Alle Endpunkte verwenden die Routenfamilie `/v1/training-jobs` und erfordern einen API-Schlüssel im Header `X-API-Key`.

```bash
-H "X-API-Key: $FASTINO_API_KEY"
```

Rufen Sie `GET /v1/base-models?supports_training=true` unmittelbar vor dem Erstellen eines Jobs auf. Dies ist die verbindliche Quelle für aktuell trainierbare Modell-IDs.

## Statuslebenszyklus

Antworten von Trainingsjobs enthalten:

- `status`: gespeicherter Job-Status.
- `normalized_status`: stabiler Status, der für das Polling im Client vorgesehen ist.
- `is_terminal_status`: gibt an, ob das Polling beendet werden kann.
- `error_message`: Fehlerinformationen, sofern verfügbar.
- `is_deployable`: gibt an, ob das fertige Artefakt die Bereitstellungsprüfung besteht.
- `deployability_reason`: Grund, warum das Artefakt nicht bereitstellbar ist.

Bevorzugen Sie in Polling-Clients `normalized_status` und `is_terminal_status`.

| Gespeicherter Status | Beschreibung |
| --- | --- |
| `requested` | Der Job wurde angenommen und wartet auf die Zuweisung oder Bereitstellung. |
| `running` | Das Training läuft. |
| `complete` | Das Training wurde erfolgreich abgeschlossen. Die Vorbereitung des Artefakts kann noch andauern. |
| `normalizing` | Fastino bereitet das trainierte Artefakt vor. |
| `artifact_ready` | Das trainierte Artefakt ist bereit. |
| `deployed` | Das Artefakt wurde bereitgestellt. |
| `paused` | Der Job oder seine Pipeline ist angehalten. |
| `errored` | Training, Zuweisung oder Artefaktvorbereitung ist fehlgeschlagen. |
| `stopped` | Der Job wurde gestoppt, während vorhandene Checkpoints erhalten blieben. |
| `terminated` | Der Job wurde beendet und seine Checkpoints wurden gelöscht. |

## Endpunkte

| Methode | Endpunkt | Zweck |
| --- | --- | --- |
| `POST` | [`/v1/training-jobs`](/de/api-reference/training-jobs/create) | Trainingsjob erstellen |
| `GET` | [`/v1/training-jobs`](/de/api-reference/training-jobs/list) | Trainingsjobs auflisten |
| `GET` | [`/v1/training-jobs/{job_id}`](/de/api-reference/training-jobs/get) | Status, Konfiguration und Metriken abrufen |
| `PATCH` | [`/v1/training-jobs/{job_id}`](/de/api-reference/training-jobs/update-project) | Projekt zuweisen oder Zuweisung aufheben |
| `PATCH` | [`/v1/training-jobs/{job_id}/model-name`](/de/api-reference/training-jobs/update-model-name) | Trainiertes Modell umbenennen |
| `GET` | [`/v1/training-jobs/{job_id}/logs`](/de/api-reference/training-jobs/logs) | Snapshot der Trainingslogs abrufen |
| `GET` | [`/v1/training-jobs/{job_id}/billing`](/de/api-reference/training-jobs/billing) | Abrechnungsergebnis abrufen |
| `POST` | [`/v1/training-jobs/{job_id}/stop`](/de/api-reference/training-jobs/stop) | Job stoppen und Checkpoints erhalten |
| `POST` | [`/v1/training-jobs/{job_id}/terminate`](/de/api-reference/training-jobs/terminate) | Job stoppen und Checkpoints löschen |
| `GET` | [`/v1/training-jobs/{job_id}/checkpoints`](/de/api-reference/training-jobs/checkpoints) | Checkpoints auflisten |
| `POST` | [`/v1/training-jobs/{job_id}/checkpoints/{checkpoint_id}/deploy`](/de/api-reference/training-jobs/deploy-checkpoint) | Checkpoint bereitstellen |
| `GET` | [`/v1/training-jobs/{job_id}/download`](/de/api-reference/training-jobs/download) | Temporäre Download-URL für Gewichte abrufen |
| `DELETE` | [`/v1/training-jobs/{job_id}`](/de/api-reference/training-jobs/delete) | Job und seine Checkpoints löschen |
