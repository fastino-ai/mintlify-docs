## Inferencia

| Modelo | Precio por 1M de tokens de entrada | Precio por 1M de tokens de salida |
| --- | --- | --- |
| GLiDE | \$0.15 | \$0 |
| GLiNER-2.5-Decide | \$0.03 | \$0 |
| GLiNER 2.5 | \$0.03 | \$0 |
| GLiNER2 | \$0.03 | \$0 |
| GLiGuard LLM Guardrails y PII | \$0.15 | \$0.15 |
| GLiGuard PII Multi | \$0.15 | \$0.15 |

Las respuestas de GLiDE informan `usage.output_tokens` para sus respuestas estructuradas, pero esos tokens
de salida tienen un precio de \$0; solo los tokens de entrada se facturan a la tarifa indicada.

Consulta el [Catálogo de modelos](/es/concepts/models) para ver los precios de cada ID de modelo.

## Entrenamiento

\$0.07 por minuto (\$4.20 por hora) para ajustar modelos GLiNER.

Puedes recargar créditos a medida que sigues usando Fastino, para que tus flujos de trabajo de inferencia y entrenamiento sigan funcionando.
