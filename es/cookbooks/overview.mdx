Cada receta es una ruta funcional para una tarea común. Copia una receta, sustituye los datos por los tuyos y ajusta sus criterios, etiquetas o recompensa.

Las recetas de GLiNER cubren las tres formas más habituales en que los equipos usan GLiNER 2.5 Multi: extracción de entidades, clasificación y extracción de relaciones.

Las solicitudes de las recetas de GLiDE y GLiNER se comprueban contra la API
activa. Los ejemplos de RL se comprueban contra el contrato documentado del SDK
de Tinker y la implementación de la API de RL de Fastino.
