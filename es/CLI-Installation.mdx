Instala la CLI de Pioneer cuando quieras acceder desde la terminal a los trabajos de entrenamiento, los artefactos de modelos, los conjuntos de datos y el agente interactivo de Pioneer.

<Info>
  La CLI de Pioneer se publica como `@fastino-ai/pioneer-cli` y se ejecuta con Bun `1.1.0` o una versión más reciente.
</Info>

## Requisitos

- macOS o Linux
- Bun `1.1.0` o una versión más reciente
- Node.js y npm
- Una clave de API de Pioneer desde [Claves de API de Pioneer](https://app.pioneer.ai/api-keys)

## Instalar la CLI

<Steps>
  <Step title="Instalar Bun">
    ```bash
    curl -fsSL https://bun.sh/install | bash
    ```

    Abre una nueva terminal cuando el instalador termine y confirma que Bun está disponible:

    ```bash
    bun --version
    ```
  </Step>
  <Step title="Instalar la CLI de Pioneer">
    ```bash
    npm install -g @fastino-ai/pioneer-cli
    ```
  </Step>
  <Step title="Verificar el comando">
    ```bash
    pioneer --version
    pioneer --help
    ```
  </Step>
</Steps>

## Autenticación

<Steps>
  <Step title="Crear una clave de API">
    Crea una clave de API en el panel de Pioneer y tenla lista para el aviso de inicio de sesión.
  </Step>
  <Step title="Iniciar sesión de forma interactiva">
    ```bash
    pioneer auth login
    ```

    La CLI valida la clave antes de guardarla.
  </Step>
  <Step title="Confirmar tu sesión">
    ```bash
    pioneer auth status
    ```
  </Step>
</Steps>

<Note>
  El inicio de sesión interactivo guarda tu clave de API en `~/.pioneer/config.json`. La CLI también admite `PIONEER_API_KEY` para CI o sesiones de shell de corta duración.
</Note>

## Comprobar la configuración

Ejecuta algunos comandos de solo lectura para confirmar que la CLI puede conectarse a Pioneer:

```bash
pioneer --version
pioneer auth status
pioneer model base-models
pioneer dataset list
```

## Actualizar

```bash
npm install -g @fastino-ai/pioneer-cli@latest
pioneer --version
```

## Solución de problemas

<AccordionGroup>
  <Accordion title="pioneer: command not found" icon="circle-alert">
    Asegúrate de que el directorio bin global de npm esté en `PATH`.

    ```bash
    npm bin -g
    ```
  </Accordion>

  <Accordion title="env: bun: No such file or directory" icon="terminal">
    Instala Bun y abre una nueva terminal:

    ```bash
    curl -fsSL https://bun.sh/install | bash
    bun --version
    ```
  </Accordion>

  <Accordion title="La autenticación falla" icon="key-round">
    Crea una nueva clave de API en el panel de Pioneer y vuelve a ejecutar el inicio de sesión interactivo.

    ```bash
    pioneer auth login
    pioneer auth status
    ```
  </Accordion>
</AccordionGroup>
