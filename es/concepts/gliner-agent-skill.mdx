El [skill de agente Fastino GLiNER](https://api.fastino.ai/.well-known/agent-skills/fastino-gliner/SKILL.md) ayuda a Cursor, Claude Code y Codex a usar las APIs alojadas de Fastino para extracción, clasificación, preparación de datasets, fine-tuning, evaluación e inferencia.

## Instalación

Ejecuta este comando desde tu proyecto:

```bash
npx skills add https://api.fastino.ai --skill fastino-gliner
```

El instalador te permite elegir a qué agentes compatibles se aplica el skill.

Antes de usar el skill, expón tu clave de API de Pioneer al entorno del agente:

```bash
export FASTINO_API_KEY="..."
```

Después invócalo explícitamente con `/fastino-gliner`, o pídele a tu agente un flujo de extracción, clasificación, fine-tuning, evaluación o inferencia con GLiNER alojado.

## Instalación no interactiva

Usa el comando correspondiente a tu agente para instalar el skill en el proyecto actual sin mostrar prompts:

<CodeGroup>

```bash Cursor
npx skills add https://api.fastino.ai --skill fastino-gliner -a cursor -y
```

```bash Claude Code
npx skills add https://api.fastino.ai --skill fastino-gliner -a claude-code -y
```

```bash Codex
npx skills add https://api.fastino.ai --skill fastino-gliner -a codex -y
```

</CodeGroup>

La opción `-a` selecciona el agente de destino y `-y` acepta los prompts de instalación, lo que hace que estos comandos sean adecuados para scripts y CI.
