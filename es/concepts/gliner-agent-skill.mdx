El [skill de agente de GLiNER2](https://github.com/jaanavit/gliner2-skill) proporciona a Cursor, Claude Code y Codex orientación sobre los flujos de trabajo de GLiNER2.5, GLiNER2 y GLiNER, incluyendo la selección de modelos, el diseño de esquemas, la extracción, la clasificación, las relaciones y el ajuste fino.

## Instalación

Ejecuta este comando desde tu proyecto:

```bash
npx skills add jaanavit/gliner2-skill
```

El instalador te permite elegir qué agentes compatibles reciben el skill.

## Instalación no interactiva

Usa el comando correspondiente a tu agente para instalar el skill en el proyecto actual sin indicaciones:

<CodeGroup>

```bash Cursor
npx skills add jaanavit/gliner2-skill -a cursor -y
```

```bash Claude Code
npx skills add jaanavit/gliner2-skill -a claude-code -y
```

```bash Codex
npx skills add jaanavit/gliner2-skill -a codex -y
```

</CodeGroup>

La opción `-a` selecciona el agente de destino y `-y` acepta las indicaciones de instalación, lo que hace que estos comandos sean adecuados para scripts y CI.
