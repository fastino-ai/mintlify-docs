GLiNER 2.5 Decide devuelve un envoltorio estándar de Chat Completions. El resultado de clasificación se serializa como JSON dentro de `choices[0].message.content`.

## Analiza el resultado

```python
import json

body = response.json()
result = json.loads(body["choices"][0]["message"]["content"])
```

No leas las tareas de clasificación directamente desde `choices[0]`; analiza primero `message.content`.

## Tarea de una sola etiqueta

Con `multi_label: false`, cada tarea devuelve un objeto:

```json
{
  "intent": {
    "label": "refund_request",
    "confidence": 0.999862551689148
  }
}
```

- `label` es una de las cadenas proporcionadas en el array `labels` de esa tarea.
- `confidence` es la confianza del modelo en la etiqueta seleccionada, de `0` a `1`.

## Tarea multietiqueta

Con `multi_label: true`, cada tarea devuelve un array de etiquetas seleccionadas:

```json
{
  "tags": [
    {"label": "technical_issue", "confidence": 0.4421546757221222},
    {"label": "login_problem", "confidence": 0.21206879615783691},
    {"label": "urgent", "confidence": 0.4834045469760895},
    {"label": "human_handoff", "confidence": 0.8267117738723755}
  ]
}
```

Solo se seleccionan las etiquetas que alcanzan el `cls_threshold` de la tarea. Un umbral más estricto puede producir un array más corto o ninguna etiqueta seleccionada.

## Varias tareas

El objeto analizado usa como claves los nombres `task` de la solicitud:

```json
{
  "intent": {
    "label": "refund_request",
    "confidence": 0.99
  },
  "urgency": {
    "label": "normal",
    "confidence": 0.82
  }
}
```

Cada tarea de clasificación clásica se evalúa de forma independiente.

## Envoltorio de respuesta

| Campo | Significado |
| --- | --- |
| `model` | Identificador del modelo usado para la inferencia |
| `choices[0].message.content` | Resultado de clasificación codificado como JSON |
| `choices[0].finish_reason` | Estado de finalización, normalmente `stop` |
| `usage.prompt_tokens` | Número de tokens de entrada |
| `usage.completion_tokens` | Número de tokens de salida |
| `usage.total_tokens` | Uso combinado |
| `token_usage` | Uso combinado de tokens indicado por Fastino |
| `x_fastino.inference_id` | Identificador de inferencia persistida cuando el almacenamiento está habilitado |
| `x_fastino.default_schema_applied` | Indica si se usó el esquema predeterminado del catálogo del modelo |

`x_fastino` puede ser `null` cuando no se devuelven metadatos adicionales de Fastino.
