GLiNER es una familia de código abierto de modelos de lenguaje pequeños para una extracción de información eficiente. GLiNER 2.5 es la generación actual y la opción predeterminada para nuevos trabajos de extracción.

## Cuándo usar GLiNER 2.5

Recurre a GLiNER 2.5 cuando la tarea sea de extracción: necesitas obtener del texto los spans literales, registros estructurados o un grafo de relaciones, no una única etiqueta de decisión.

- **Extracción de entidades**: extrae personas, organizaciones, productos, ubicaciones o entidades específicas del dominio (medicamentos, dosis, cláusulas) de texto libre, con offsets de caracteres y puntuaciones de confianza.
- **Registros estructurados**: convierte "Alice bought apples and Bob bought oranges" en `[{"buyer": "Alice", "item": "apples"}, {"buyer": "Bob", "item": "oranges"}]`, manteniendo vinculados los campos de cada instancia.
- **Extracción de relaciones y grafos de conocimiento**: extrae grafos tipados de entidades y relaciones (`works_for`, `located_in`) para la memoria de agentes o una base de conocimiento.
- **Atributos de span**: etiqueta cada entidad extraída con un atributo, como el sentimiento por persona, en la misma pasada que la extracción.
- **Documentos largos**: procesa contratos, transcripciones e informes de hasta 4,096 palabras, con división automática en fragmentos y reasignación de offsets para cualquier texto más largo.
- **Varias tareas a la vez**: combina entidades, clasificación, estructuras y relaciones en una única llamada con restricciones de esquema en lugar de encadenar varias solicitudes al modelo.

Usa [GLiNER-2.5-Decide](/es/concepts/gliner-2-5-decide) en su lugar cuando la tarea sea una decisión (una ruta, una etiqueta, una puntuación) en vez del texto subyacente.

## Cómo usar GLiNER 2.5

Llama al checkpoint multilingüe a través del endpoint de inferencia de Fastino compatible con OpenAI. Coloca el texto en un mensaje de usuario y describe la tarea en `schema`:

```bash
curl -X POST "https://api.fastino.ai/v1/chat/completions" \
  -H "Authorization: Bearer $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "fastino/gliner2.5-multi-v1",
    "messages": [
      { "role": "user", "content": "Apple CEO Tim Cook unveiled the iPhone 15 Pro in Cupertino." }
    ],
    "schema": {
      "entities": [
        { "name": "person", "description": "named individual" },
        { "name": "organization", "description": "business or institution name" },
        { "name": "product", "description": "named commercial product" },
        { "name": "location", "description": "city, region, or place" }
      ]
    }
  }'
```

Añade las claves `classifications`, `structures` o `relations` al mismo `schema` para ejecutar varias tareas sobre el mismo texto en una sola llamada. Consulta la referencia de la [API de inferencia](/es/inference) para ver el contrato completo de solicitud y respuesta, incluidos los registros estructurados y los esquemas de relaciones.

## Compara las generaciones de GLiNER

| | GLiNER2.5 | GLiNER2 | GLiNER |
| --- | --- | --- | --- |
| Arquitectura | Predicción de límites | Enumeración de spans | Enumeración de spans |
| Uso principal | Extracción estructurada con restricciones | Extracción de entidades y parsing estructurado | NER de vocabulario abierto |
| Tamaños de modelo | 74M small, 194M base, 287M multilingüe | 205M base, 300M multilingüe | 50M small, 90M medium |
| Contexto de entrada | 4,096 palabras | 2,048 tokens | 512 tokens |
| Longitud máxima de span | Sin límite configurado | 8 palabras | 12 palabras |
| Clasificación de texto | Sí, con restricciones entre tareas | Sí | No |
| Extracción estructurada | Sí | Sí | No |
| Extracción de relaciones | Sí | Sí | No |
| Atributos de span | Sí | No | No |

GLiNER2.5 es el punto de partida recomendado para nuevos proyectos de extracción. Usa GLiNER2 para integraciones existentes basadas en esquemas y el GLiNER original para checkpoints de NER de vocabulario abierto construidos sobre el paquete de primera generación.
