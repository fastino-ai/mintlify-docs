GLiDE devuelve decisiones calibradas sin generar texto. Envía un `state` compartido
y una o más preguntas tipadas a `POST /v1/systemone`.

## Elige un tipo de pregunta

| Tipo | Cuándo usarlo |
| --- | --- |
| Noul | Necesitas una probabilidad de sí/no |
| Choice | Necesitas una respuesta entre 2–255 opciones definidas por el cliente |
| Score | Necesitas un nivel ordenado y una puntuación esperada |

La respuesta conserva el orden de las preguntas y devuelve respuestas tipadas con
probabilidades y confianza. Tu aplicación decide aceptar, aplazar o usar un fallback.

## Antes de llamar

1. Exporta tu clave como `FASTINO_API_KEY`.
2. Coloca en `state` la evidencia que se evaluará.
3. Elige el tipo de pregunta que corresponda a la decisión.
4. Sigue la referencia de la API para los campos, límites, ejemplos y respuestas exactos.
