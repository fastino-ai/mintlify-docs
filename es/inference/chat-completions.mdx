GLiNER convierte texto en datos restringidos por un schema. Úsalo para extracción
de entidades, clasificación, registros estructurados, relaciones y decisiones
multitarea con restricciones. Usa [GLiDE](/es/inference/systemone) cuando necesites
una selección o clasificación estructurada.

## Elige un endpoint

| Carga de trabajo | Endpoint | Referencia |
| --- | --- | --- |
| Modelos alojados y ajustados | `POST /v1/chat/completions` | [Solicitud, respuesta, schemas y ejemplos](/es/api-reference/inference/chat-completions) |
| GLiNER-2 nativo síncrono | `POST /v1/gliner-2` | [Solicitud, respuesta y ejemplos](/es/api-reference/inference/gliner-2) |
| Entrada nativa de más de un millón de tokens | `POST /v1/gliner-2/async` | [Enviar un trabajo asíncrono](/es/api-reference/inference/gliner-2-async) |
| Consultar un trabajo asíncrono nativo | `GET /v1/gliner-2/jobs/{job_id}` | [Leer el estado y los resultados](/es/api-reference/inference/gliner-2-job-status) |

Para la mayoría de las integraciones, empieza con `POST /v1/chat/completions`.
Admite el envoltorio compatible con OpenAI de `model` y `messages`, IDs de modelos
ajustados, historial de inferencia persistente y la familia completa de schemas de GLiNER.

## Antes de llamar

1. Exporta tu clave como `FASTINO_API_KEY`.
2. Consulta `GET /v1/base-models?supports_inference=true&task_type=encoder`.
3. Confirma que `encoder_features` del modelo admite las funciones de schema necesarias.
4. Sigue la referencia completa de la API en lugar de inferir campos o formas de resultados.
