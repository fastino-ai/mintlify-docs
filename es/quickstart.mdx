## Configura tu API key

1. **Crea una cuenta de [Fastino](https://agent.fastino.ai/)**
2. **Obtén tu API key** en [Settings](https://agent.fastino.ai/api-keys)

Establece tu clave como una variable de entorno para que los ejemplos siguientes funcionen tal cual:

<CodeGroup>

```bash macOS/Linux
export FASTINO_API_KEY="your_api_key_here"
```

```powershell Windows
$env:FASTINO_API_KEY = "your_api_key_here"
```

</CodeGroup>

## Ejecuta tu primera llamada de inferencia

Llama a `POST /v1/systemone` con un `model`, un `state` que describa la situación y una o más `questions` tipadas. GLiDE devuelve directamente probabilidades calibradas y etiquetas. No hay texto generado que analizar. El ejemplo siguiente hace una sola pregunta de sí/no (`noul`).

GLiDE cuesta **0,15 \$ por cada millón de tokens de entrada**. Los tokens de salida son **gratuitos (0 \$)**.
Consulta [Precios](/es/pricing) para ver las tarifas de inferencia actuales.

<Tabs>
  <Tab title="cURL">
    **Para ejecutar una llamada de decisión con GLiDE**:

    ```bash
    curl --max-time 175 -X POST "https://api.fastino.ai/v1/systemone" \
      -H "X-API-Key: $FASTINO_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "fastino/GLiDE",
        "state": "Refund request: the receipt is attached, the purchase was 10 days ago, and refunds are allowed within 30 days.",
        "questions": {
          "refund_allowed": {
            "type": "noul",
            "instructions": "Does this request qualify for a refund?",
            "criteria": { "true": "Qualifies", "false": "Does not qualify" }
          }
        }
      }'
    ```
  </Tab>

  <Tab title="Python">
    **Para ejecutar una llamada de decisión con GLiDE**:

    ```python
    import os
    import requests

    response = requests.post(
        "https://api.fastino.ai/v1/systemone",
        headers={
            "X-API-Key": os.environ["FASTINO_API_KEY"],
            "Content-Type": "application/json",
        },
        json={
            "model": "fastino/GLiDE",
            "state": "Refund request: the receipt is attached, the purchase was 10 days ago, and refunds are allowed within 30 days.",
            "questions": {
                "refund_allowed": {
                    "type": "noul",
                    "instructions": "Does this request qualify for a refund?",
                    "criteria": {"true": "Qualifies", "false": "Does not qualify"},
                }
            },
        },
        timeout=175,
    )

    response.raise_for_status()
    print(response.json())
    ```
  </Tab>

  <Tab title="JavaScript">
    **Para ejecutar una llamada de decisión con GLiDE**:

    ```javascript
    const response = await fetch(
      "https://api.fastino.ai/v1/systemone",
      {
        method: "POST",
        headers: {
          "X-API-Key": process.env.FASTINO_API_KEY,
          "Content-Type": "application/json",
        },
        body: JSON.stringify({
          model: "fastino/GLiDE",
          state: "Refund request: the receipt is attached, the purchase was 10 days ago, and refunds are allowed within 30 days.",
          questions: {
            refund_allowed: {
              type: "noul",
              instructions: "Does this request qualify for a refund?",
              criteria: { true: "Qualifies", false: "Does not qualify" },
            },
          },
        }),
        signal: AbortSignal.timeout(175_000),
      }
    );

    if (!response.ok) {
      throw new Error(`Inference failed: ${response.status} ${await response.text()}`);
    }

    const result = await response.json();
    console.log(JSON.stringify(result, null, 2));
    ```
  </Tab>
</Tabs>

Cada ejemplo configura un tiempo de espera del cliente de 175 segundos, un poco por encima del presupuesto de
170 segundos del servidor de GLiDE. Consulta
[Tiempos de espera y reintentos](/es/inference/systemone#tiempos-de-espera-y-reintentos) para saber qué
errores reintentar.

Una respuesta correcta tiene este aspecto:

```json
{
  "model": "glide",
  "answers": {
    "refund_allowed": {
      "type": "noul",
      "noul": 0.99767683794902,
      "confidence": 0.9953536758980399
    }
  },
  "usage": { "input_tokens": 89, "output_tokens": 1 },
  "token_usage": 90
}
```

`answers.refund_allowed.noul` es la probabilidad de que la respuesta sea "sí". Redondeado a tres decimales, `0.998` es una señal clara de que la solicitud cumple los requisitos. Continúa con las referencias de [Noul](/es/concepts/glide-noul), [Choice](/es/concepts/glide-choice) y [Score](/es/concepts/glide-score), o usa la [guía de enrutamiento](/es/guides/glide-routing) para convertir la confianza en una acción.

<Accordion title="¿Quieres extraer entidades? Usa GLiNER 2.5">
  Si necesitas extracción a nivel de fragmento (NER, clasificación, registros estructurados) en lugar de una decisión, llama a `POST /v1/chat/completions` con un modelo, un mensaje y un esquema que defina qué quieres extraer:

  ```bash
  curl -X POST "https://api.fastino.ai/v1/chat/completions" \
    -H "Authorization: Bearer $FASTINO_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "fastino/gliner2.5-multi-v1",
      "messages": [
        {
          "role": "user",
          "content": "Apple announced the MacBook Pro at WWDC in Cupertino."
        }
      ],
      "schema": {
        "entities": [
          { "name": "organization", "description": "business or institution name" },
          { "name": "product", "description": "named commercial product" },
          { "name": "event", "description": "named conference or event" },
          { "name": "location", "description": "city, region, or place" }
        ]
      },
      "threshold": 0.5
    }'
  ```

  Para modelos encoder (GLiNER), el objeto `schema` define la tarea y puede incluir `entities`, `classifications`, `structures` y `relations`. Para modelos decoder (LLM), omite `schema` y envía un mensaje de chat normal. Consulta la [API de inferencia](/es/inference/chat-completions) para ver el contrato completo, ejemplos en Python/JavaScript y los códigos de error.
</Accordion>

## Crea un trabajo de entrenamiento de decodificador

Crea un trabajo LoRA interactivo cuando tu aplicación controle el entrenamiento
del decodificador paso a paso:

Consulta `GET /v1/base-models?supports_training=true` antes de crear el trabajo
y usa un ID exacto de modelo decodificador devuelto para tu equipo. Un límite
de contexto de entrenamiento interactivo describe esa operación de
entrenamiento; puede diferir del contexto de inferencia del modelo del catálogo
o del límite de solicitudes de un endpoint de inferencia.

```bash
curl -X POST "https://api.fastino.ai/v1/training/jobs/create-model" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "base_model": "nvidia/NVIDIA-Nemotron-3.5-Super-VL-120B-A12B-NVFP4",
    "lora_config": {"rank": 32}
  }'
```

La respuesta contiene el `job_id` y su `future_id` de creación. Continúa con la
[guía rápida del decodificador](/es/training/decoder-quickstart) para ejecutar
operaciones forward-backward y del optimizador y guardar un checkpoint.
