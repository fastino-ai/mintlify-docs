Fastino expone una única familia de rutas para el entrenamiento:

```text
/v1/training/jobs
```

Cada trabajo tiene un `type`:

<CardGroup cols={2}>
  <Card title="Trabajos de configuración" icon="sliders">
    Envía un dataset preparado y una configuración de entrenamiento. Fastino
    ejecuta el bucle de entrenamiento. Comienza con la [guía de ajuste fino de GLiNER](/es/guides/fine-tune-gliner).
  </Card>
  <Card title="Trabajos interactivos" icon="code">
    Ejecuta el bucle de entrenamiento paso a paso desde tu aplicación. Comienza
    con la [descripción general de la API de RL](/es/rl-api) y la [guía rápida de la API de RL](/es/rl-api/quickstart).
  </Card>
</CardGroup>

Usa un trabajo `config` para el ajuste fino gestionado. Usa un trabajo
`interactive` cuando tu aplicación deba controlar las pasadas hacia delante y
hacia atrás, los pasos del optimizador y el momento de crear checkpoints.

## Configura tu clave de API

1. **Crea una cuenta de [Fastino](https://agent.fastino.ai/)**
2. **Obtén tu clave de API** en [Configuración](https://agent.fastino.ai/api-keys)

Configura tu clave como variable de entorno para que los ejemplos siguientes
funcionen sin cambios:

<CodeGroup>

```bash macOS/Linux
export FASTINO_API_KEY="your_api_key_here"
```

```powershell Windows
$env:FASTINO_API_KEY = "your_api_key_here"
```

</CodeGroup>

La URL base de la API es `https://api.fastino.ai`. Envía
`X-API-Key: $FASTINO_API_KEY` en cada solicitud. Consulta la
[autenticación de la API](/es/authentication) para ver todas las formas de
autenticación compatibles.

## Guía rápida de los trabajos de configuración

### 1. Prepara un dataset

[Prepara, sube y procesa un dataset de entrenamiento](/es/concepts/datasets).
Espera hasta que la versión del dataset esté `ready`.

### 2. Elige un modelo base activo

Consulta el catálogo inmediatamente antes de enviar el trabajo. Es la fuente de
verdad para los IDs de modelos entrenables.

```bash
curl "https://api.fastino.ai/v1/base-models?supports_training=true" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

### 3. Crea el trabajo

Conserva el nombre de campo `base_model` y establece `type` en `config`:

```bash
curl -X POST "https://api.fastino.ai/v1/training/jobs" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "config",
    "model_name": "my-gliner-model",
    "base_model": "BASE_MODEL_ID_FROM_CATALOG",
    "datasets": [
      {"name": "my-ready-dataset", "version": "VERSION_NUMBER"}
    ],
    "training_type": "lora"
  }'
```

Guarda el `id` devuelto; es el `job_id` que utilizan todas las rutas específicas
del trabajo.

### 4. Consulta e inspecciona

```bash
curl "https://api.fastino.ai/v1/training/jobs/JOB_ID" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

Para los trabajos de configuración, las respuestas incluyen:

- `status`: estado persistido del trabajo.
- `normalized_status`: estado estable destinado a las consultas del cliente.
- `is_terminal_status`: indica si la consulta puede detenerse.
- `error_message`: información del fallo cuando esté disponible.
- `is_deployable`: indica si el artefacto completado supera la validación de despliegue.
- `deployability_reason`: motivo por el que el artefacto no es desplegable.

Al consultar un trabajo de configuración, prefiere `normalized_status` e
`is_terminal_status`. También puedes inspeccionar
[`GET /v1/training/jobs/{job_id}/logs`](/es/api-reference/training-jobs/logs),
[`GET /v1/training/jobs/{job_id}/billing`](/es/api-reference/training-jobs/billing)
y
[`GET /v1/training/jobs/{job_id}/checkpoints`](/es/api-reference/training-jobs/checkpoints).

## Ciclo de vida del estado de los trabajos de configuración

Los siguientes estados persistidos describen los trabajos de configuración
gestionados. Los trabajos interactivos tienen un comportamiento controlado por
el llamante; no deduzcas su ciclo de vida a partir de esta tabla.

| Estado persistido | Descripción |
| --- | --- |
| `requested` | El trabajo se aceptó y está a la espera de envío o aprovisionamiento. |
| `running` | El entrenamiento está en curso. |
| `complete` | El entrenamiento se completó correctamente. La preparación del artefacto puede continuar. |
| `normalizing` | Fastino está preparando el artefacto entrenado. |
| `artifact_ready` | El artefacto entrenado está listo. |
| `deployed` | El artefacto se ha desplegado. |
| `paused` | El trabajo gestionado está en pausa. |
| `errored` | El entrenamiento, el envío o la preparación del artefacto falló. |
| `stopped` | El trabajo se detuvo conservando los checkpoints existentes. |
| `terminated` | El trabajo se terminó y sus checkpoints se eliminaron. |

## Rutas disponibles para ambos tipos de trabajo

| Método | Ruta | Propósito |
| --- | --- | --- |
| `POST` | [`/v1/training/jobs`](/es/api-reference/training-jobs/create) | Crear directamente un trabajo de configuración; el SDK compatible crea trabajos interactivos mediante el adaptador de compatibilidad |
| `GET` | [`/v1/training/jobs`](/es/api-reference/training-jobs/list) | Listar trabajos |
| `GET` | [`/v1/training/jobs/{job_id}`](/es/api-reference/training-jobs/get) | Obtener un trabajo |
| `POST` | [`/v1/training/jobs/{job_id}/stop`](/es/api-reference/training-jobs/stop) | Detener un trabajo y liberar sus recursos de entrenamiento |
| `GET` | [`/v1/training/jobs/{job_id}/logs`](/es/api-reference/training-jobs/logs) | Leer logs |
| `GET` | [`/v1/training/jobs/{job_id}/billing`](/es/api-reference/training-jobs/billing) | Leer los detalles de facturación |
| `POST` | `/v1/training/jobs/{job_id}/deploy` | Desplegar el artefacto de un trabajo |
| `GET` | [`/v1/training/jobs/{job_id}/deployments`](/es/api-reference/training-jobs/deployments) | Listar despliegues |
| `GET` | [`/v1/training/jobs/{job_id}/checkpoints`](/es/api-reference/training-jobs/checkpoints) | Listar checkpoints |
| `GET` | `/v1/training/jobs/{job_id}/checkpoints/{checkpoint_id}` | Obtener un checkpoint |
| `GET` | `/v1/training/jobs/{job_id}/checkpoints/{checkpoint_id}/download` | Descargar un checkpoint |
| `POST` / `DELETE` | `/v1/training/jobs/{job_id}/checkpoints/{checkpoint_id}/publish` | Publicar o retirar la publicación de un checkpoint |
| `PUT` | `/v1/training/jobs/{job_id}/checkpoints/{checkpoint_id}/ttl` | Establecer la retención del checkpoint |
| `DELETE` | `/v1/training/jobs/{job_id}/checkpoints/{checkpoint_id}` | Eliminar un checkpoint |

## Rutas exclusivas de los trabajos de configuración

| Método | Ruta | Propósito |
| --- | --- | --- |
| `POST` | [`/v1/training/jobs/{job_id}/terminate`](/es/api-reference/training-jobs/terminate) | Terminar un trabajo y eliminar sus checkpoints |
| `POST` | [`/v1/training/jobs/{job_id}/sync`](/es/api-reference/training-jobs/sync) | Actualizar el estado del proveedor |
| `GET` | [`/v1/training/jobs/{job_id}/download`](/es/api-reference/training-jobs/download) | Descargar el modelo final |
| `PATCH` | [`/v1/training/jobs/{job_id}/model-name`](/es/api-reference/training-jobs/update-model-name) | Cambiar el nombre del modelo |
| `POST` | [`/v1/training/jobs/{job_id}/push-to-hub`](/es/api-reference/training-jobs/push-to-hub) | Enviar el modelo final a Hugging Face Hub |

## Rutas exclusivas de los trabajos interactivos

Los trabajos interactivos exponen las operaciones de entrenamiento individuales:

| Método | Ruta | Propósito |
| --- | --- | --- |
| `POST` | `/v1/training/jobs/{job_id}/forward` | Ejecutar una pasada hacia delante |
| `POST` | `/v1/training/jobs/{job_id}/forward-backward` | Ejecutar una pasada hacia delante y hacia atrás |
| `POST` | `/v1/training/jobs/{job_id}/optim-step` | Aplicar un paso del optimizador |
| `GET` | `/v1/training/jobs/{job_id}/operations/{operation_id}` | Obtener una operación asíncrona |
| `POST` | `/v1/training/jobs/{job_id}/operations/{operation_id}/cancel` | Cancelar una operación |
| `POST` | `/v1/training/jobs/{job_id}/checkpoints` | Guardar un checkpoint de estado o muestreador |
| `POST` | `/v1/training/jobs/{job_id}/checkpoints/{checkpoint_id}/load` | Cargar un checkpoint |
| `POST` | `/v1/training/jobs/{job_id}/checkpoints/{checkpoint_id}/sample` | Muestrear desde un checkpoint |

Llamar a una ruta de paso interactivo en un trabajo `config` devuelve `400`.
