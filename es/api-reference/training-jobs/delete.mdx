---
title: "Eliminar un trabajo de entrenamiento"
sidebarTitle: "Eliminar trabajo"
description: "Elimina un trabajo de entrenamiento de Fastino y sus checkpoints asociados."
api: "DELETE /felix/training-jobs/{job_id}"
noindex: true
---

Elimina el trabajo y sus artefactos almacenados. Si el trabajo está activo, el servicio también lo detiene.

<Warning>
  La eliminación es irreversible. Primero descarga lo que necesites a un almacenamiento que controles. La eliminación borra los checkpoints y los artefactos almacenados, y libera los despliegues alojados activos.
</Warning>

## Solicitud

<ParamField header="X-API-Key" type="string" required>
  Tu clave de API de Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID del trabajo de entrenamiento.
</ParamField>

<RequestExample>

```bash cURL
curl -X DELETE https://api.pioneer.ai/felix/training-jobs/YOUR_TRAINING_JOB_ID \
  -H "X-API-Key: $PIONEER_API_KEY"
```

</RequestExample>

## Respuesta

<ResponseExample>

```json Response
{
  "success": true,
  "message": "Training job deleted"
}
```

</ResponseExample>

Un trabajo desconocido o inaccesible devuelve `404`.
