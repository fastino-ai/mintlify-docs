`POST /v1/training/jobs/{job_id}/push-to-hub`

Esta operación solo está disponible para trabajos config; después de las comprobaciones normales de función y permisos, un ID de trabajo interactivo devuelve `400`, y los trabajos interactivos no tienen una operación Push to Hub.

Esta página documenta `POST /v1/training/jobs/{job_id}/push-to-hub`. La especificación OpenAPI es la fuente canónica para parámetros, respuestas y autenticación.
