Los clientes nativos crean un trabajo `interactive` con [`POST /v1/training/jobs/create-model`](/es/api-reference/training-jobs/interactive/create-model). Los clientes Tinker crean el mismo tipo mediante el SDK compatible.

`POST /v1/training/jobs`

Crea un trabajo de entrenamiento asíncrono `config` y devuelve su registro. En
un trabajo de configuración, proporcionas un dataset y una configuración, y
Fastino ejecuta el bucle.

Los trabajos de configuración entrenan codificadores GLiNER:
`fastino/gliner2-multi-v1` y `fastino/GLiNER-2.5-Decide`. Los modelos base
decodificadores devuelven `400`; entrena los decodificadores paso a paso con
un trabajo interactivo.

Para controlar el bucle paso a paso, crea un trabajo `interactive` con
[`POST /v1/training/jobs/create-model`](/es/api-reference/training-jobs/interactive/create-model)
y sigue la [ruta del bucle de entrenamiento personalizado](/es/training/quickstart#custom-training-loop).
Después de la creación, ambos tipos de trabajo usan sus IDs canónicos con las
operaciones documentadas del ciclo de vida en `/v1/training/jobs/{job_id}`.

Este endpoint está limitado a 20 solicitudes por minuto por usuario.

## Solicitud

<ParamField header="X-API-Key" type="string" required>
  Tu clave de API de Fastino.
</ParamField>

<ParamField body="model_name" type="string" required>
  Nombre para mostrar del modelo entrenado. Longitud: 1–100 caracteres.
</ParamField>

<ParamField body="base_model" type="string" required>
  Un ID de codificador GLiNER, `fastino/gliner2-multi-v1` o `fastino/GLiNER-2.5-Decide`, o un UUID de checkpoint compatible. Un modelo base decodificador devuelve `400`.
</ParamField>

<ParamField body="datasets" type="object[]" required>
  Una o más referencias a [datasets subidos](/es/concepts/datasets). Cada elemento requiere `name` y puede incluir `version`; las versiones omitidas se resuelven a la más reciente.
</ParamField>

<ParamField body="training_type" type="string" default="lora">
  `lora` o `full`. El modelo base seleccionado debe admitir el tipo solicitado.
</ParamField>

<ParamField body="validation_data_percentage" type="number" default="0.2">
  Fracción reservada para validación, de `0` a `0.9`.
</ParamField>

<ParamField body="nr_epochs" type="integer" default="100">
  Número máximo de épocas. Debe ser al menos `1`; la parada temprana puede terminar antes.
</ParamField>

<ParamField body="learning_rate" type="number">
  Tasa de aprendizaje pico positiva. Omítela para usar la receta de entrenamiento del modelo seleccionado.
</ParamField>

<ParamField body="batch_size" type="integer" default="4">
  Tamaño de lote por dispositivo. Es preferible omitirlo para que el servicio aplique o limite de forma segura el valor predeterminado específico del modelo.
</ParamField>

<ParamField body="seed" type="integer">
  Semilla opcional de reproducibilidad de `0` a `2147483647`. Establece `provider_name` en `modal` al usarla. Una semilla reduce una fuente de variación, pero no garantiza ejecuciones idénticas bit a bit en la GPU.
</ParamField>

<ParamField body="project_id" type="string">
  UUID del proyecto. Si se omite, Fastino asocia el trabajo al proyecto predeterminado del llamante.
</ParamField>

  </ParamField>
  <ParamField body="lora_dropout" type="number">
    Dropout de LoRA. Omítelo para usar la receta del modelo.
  </ParamField>
  <ParamField body="packing" type="boolean">

    Fracción de warmup de `0` a `1`. `warmup_steps` tiene prioridad.

  <ParamField body="provider_name" type="string">
    Fija un proveedor de entrenamiento compatible. Omítelo para la selección automática.

  <ParamField body="system_prompt" type="string">

  <ParamField body="encoder_learning_rate" type="number">
    Tasa de aprendizaje del codificador de GLiNER. Si se omite, usa `learning_rate`.

    Opción solo para decodificadores. No aplica: los trabajos de configuración no entrenan decodificadores.
  </ParamField>
</Expandable>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model_name": "my-model-name",
    "base_model": "fastino/gliner2-multi-v1",
    "datasets": [{"name": "my-ready-dataset"}],
    "training_type": "lora",
    "nr_epochs": 5,
    "learning_rate": 5e-5,
    "validation_data_percentage": 0.2
  }'
```

</RequestExample>

## Respuesta

Devuelve `200` con el registro completo del trabajo, incluidos un `id` UUID y el estado inicial.

<ResponseExample>

```json Response
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "type": "config",
  "model_name": "my-model-name",
  "base_model": "fastino/gliner2-multi-v1",
  "status": "requested",
  "training_type": "lora",
  "nr_epochs": 5,
  "learning_rate": 5e-5,
  "validation_data_percentage": 0.2
}
```

</ResponseExample>

Guarda el `id` de esta respuesta. Lo usarás para consultar el estado, obtener métricas y artefactos y ejecutar inferencia contra el modelo entrenado.

Un cuerpo con formato incorrecto devuelve `422`. Una combinación válida pero no disponible de modelo, dataset, tipo de entrenamiento o proveedor devuelve un error `4xx` específico de la solicitud.

Un modelo base decodificador devuelve `400`:

```json
{
  "detail": "Decoder training on this route is retired: 'Qwen/Qwen3.6-35B-A3B' cannot be trained here. Train decoders step by step with the training job routes under /v1/training/jobs (see https://docs.fastino.ai/training/quickstart)."
}
```

Para entrenar un decodificador, crea un trabajo interactivo con
[`POST /v1/training/jobs/create-model`](/es/api-reference/training-jobs/interactive/create-model)
y sigue el [bucle de entrenamiento personalizado](/es/training/quickstart#custom-training-loop).

## Autorización

Requiere el rol Owner, Admin o Editor del equipo. Los demás roles reciben `403 Forbidden`.
