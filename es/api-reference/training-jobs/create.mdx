`POST /v1/training/jobs`

Crea un trabajo de entrenamiento asíncrono `config` y devuelve su registro. En un
trabajo de configuración, tú proporcionas un dataset y una configuración, y
Fastino ejecuta el bucle de entrenamiento. Para controlar el bucle paso a paso,
sigue la [ruta del bucle de entrenamiento personalizado](/es/training/decoder-quickstart),
que crea un trabajo `interactive` mediante
[`POST /v1/training/jobs/create-model`](/es/api-reference/training-jobs/interactive/create-model)
o el SDK de Tinker compatible. Este endpoint no crea trabajos interactivos.
Después de la creación, ambos tipos de trabajo usan sus IDs canónicos con las
operaciones documentadas del ciclo de vida en `/v1/training/jobs/{job_id}`.

Los trabajos de configuración entrenan modelos codificadores que devuelve
`GET /v1/base-models?supports_training=true` y que tienen una ruta de despacho
compatible con trabajos de configuración. Los modelos base decodificadores
devuelven `400`; en su lugar, entrena los decodificadores paso a paso con un
trabajo interactivo.

Este endpoint está limitado a 20 solicitudes por minuto por usuario.

## Solicitud

<ParamField header="X-API-Key" type="string" required>
  Tu clave de API de Fastino.
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  Clave de reintento generada por el cliente, de 1–255 caracteres; se recomienda un UUID. Repetir la misma clave y cuerpo devuelve el trabajo original. Usar la misma clave con otro cuerpo devuelve `422`.
</ParamField>

<ParamField body="model_name" type="string" required>
  Nombre para mostrar del modelo entrenado. Longitud: 1–100 caracteres.
</ParamField>

<ParamField body="base_model" type="string" required>
  Un ID de codificador entrenable devuelto por `GET /v1/base-models?supports_training=true`. El `training_type` elegido debe tener una ruta de despacho compatible. Los UUID de checkpoint y los modelos base decodificadores devuelven `400`.
</ParamField>

<ParamField body="datasets" type="object[]" required>
  Una o más referencias a [datasets subidos](/es/concepts/datasets). Cada elemento requiere `name` y puede incluir `version`; las versiones omitidas se resuelven a la más reciente.
</ParamField>

<ParamField body="training_type" type="string" default="lora">
  `lora` o `full`. El modelo base seleccionado debe admitir el tipo solicitado.
</ParamField>

<ParamField body="validation_data_percentage" type="number" default="0.2">
  Fracción reservada para validación, de `0` a `0.9` en incrementos de `0.01`.
</ParamField>

<ParamField body="nr_epochs" type="integer" default="100">
  Número máximo de épocas, de `1` a `10000`; la parada temprana puede terminar antes.
</ParamField>

<ParamField body="learning_rate" type="number">
  Tasa de aprendizaje pico de `1e-8` a `1`. Omítela para usar la receta de entrenamiento del modelo seleccionado.
</ParamField>

<ParamField body="batch_size" type="integer" default="4">
  Tamaño de lote por dispositivo de `1` a `256`. Es preferible omitirlo para que el servicio aplique o limite de forma segura el valor predeterminado específico del modelo.
</ParamField>

<ParamField body="seed" type="integer">
  Semilla opcional de reproducibilidad de `0` a `2147483647`. Establece `provider_name` en `modal` al usarla. Una semilla reduce una fuente de variación, pero no garantiza ejecuciones idénticas bit a bit en la GPU.
</ParamField>

<ParamField body="project_id" type="string">
  UUID del proyecto. Si se omite, Fastino asocia el trabajo al proyecto predeterminado del llamante.
</ParamField>

<Expandable title="Parámetros de entrenamiento adicionales">
  <ParamField body="save_steps" type="integer" default="100">
    Guarda un checkpoint cada N pasos, con N de `1` a `2147483647`.
  </ParamField>

  <ParamField body="profile_training" type="boolean" default="false">
    Conserva un artefacto estructurado del perfil de entrenamiento.
  </ParamField>

  <ParamField body="wandb_api_key" type="string">
    Clave de API opcional de Weights & Biases. Trátala como un secreto y nunca la incluyas en el control de versiones, los logs ni los ejemplos.
  </ParamField>

  <ParamField body="lora_r" type="integer">
    Rango de LoRA de `1` a `256`. Omítelo para usar la receta del modelo.
  </ParamField>

  <ParamField body="lora_alpha" type="integer">
    Alpha de LoRA positivo, hasta `2147483647`. Omítelo para usar la receta del modelo.
  </ParamField>

  <ParamField body="lora_dropout" type="number">
    Dropout de LoRA de `0` (incluido) a `1` (excluido). Omítelo para usar la receta del modelo.
  </ParamField>

  <ParamField body="warmup_ratio" type="number">
    Fracción de warmup de `0` a `1`. Usa este campo para configurar el warmup de trabajos GLiNER.
  </ParamField>

  <ParamField body="warmup_steps" type="integer">
    Número absoluto de pasos de warmup, de `1` a `2147483647`. Los trabajos GLiNER rechazan este campo con `422 unsupported_encoder_scheduling`; usa `warmup_ratio`.
  </ParamField>

  <ParamField body="lr_scheduler_type" type="string">
    Programa de tasa de aprendizaje: `constant`, `linear` o `cosine`. Si se omite, GLiNER usa `linear`; solo se reenvía un valor explícito.
  </ParamField>

  <ParamField body="weight_decay" type="number">
    Se acepta por compatibilidad de la solicitud, pero no se reenvía al entrenamiento GLiNER. GLiNER usa el valor predeterminado del contenedor `0.01`.
  </ParamField>

  <ParamField body="early_stopping_patience" type="integer" default="3">
    Épocas de validación sin mejora antes de detenerse, de `0` a `10000`. Establece `0` para desactivarlo.
  </ParamField>

  <ParamField body="early_stopping_min_delta" type="number" default="0.0001">
    Mejora mínima no negativa de la pérdida de validación que cuenta como progreso.
  </ParamField>

  <ParamField body="provider_name" type="string">
    Fija un proveedor de entrenamiento compatible. Omítelo para la selección automática.
  </ParamField>

  <ParamField body="encoder_learning_rate" type="number">
    Tasa de aprendizaje del codificador de GLiNER de `1e-8` a `1`. Si se omite, usa `learning_rate`.
  </ParamField>

  <ParamField body="task_learning_rate" type="number">
    Tasa de aprendizaje de la cabeza de tarea de GLiNER de `1e-8` a `1`. Si se omite, usa `learning_rate`.
  </ParamField>

  <ParamField body="gradient_accumulation_steps" type="integer">
    Número positivo de minilotes que se acumulan, hasta `2147483647`.
  </ParamField>

  <ParamField body="auto_data_sizing" type="boolean">
    Habilita el dimensionado automático del dataset de GLiNER.
  </ParamField>

  <ParamField body="min_samples_per_dataset" type="integer">
    Límite inferior del dimensionado automático de GLiNER, de `1` a `2147483647`.
  </ParamField>

  <ParamField body="max_samples_per_dataset" type="integer">
    Límite superior del dimensionado automático de GLiNER, de `1` a `2147483647`.
  </ParamField>

  <ParamField body="samples_per_label" type="integer">
    Escala del dimensionado automático de GLiNER por etiqueta, de `1` a `2147483647`.
  </ParamField>

  <ParamField body="min_training_steps" type="integer">
    Pasos mínimos del optimizador de GLiNER, de `0` a `2147483647`.
  </ParamField>

  <ParamField body="eval_steps" type="integer">
    Intervalo de validación periódica de GLiNER2, de `1` a `2147483647` pasos del optimizador. Omítelo para validar solo al final de cada época.
  </ParamField>

  <ParamField body="max_eval_samples" type="integer">
    Límite por dataset para validación periódica de GLiNER2, de `1` a `2147483647`. Omítelo para no aplicar límite.
  </ParamField>

  <ParamField body="max_length" type="integer">
    Longitud máxima de entrada de GLiNER, de `1` a `2147483647` tokens. Omítela para usar el límite de contexto del modelo.
  </ParamField>

  <ParamField body="max_gold_per_query" type="integer">
    Máximo de spans gold conservados por consulta de GLiNER2, de `1` a `1024`. Omítelo para usar `32`.
  </ParamField>

  <ParamField body="on_capacity_exceeded" type="string">
    Comportamiento cuando los spans gold superan `max_gold_per_query`: `raise`, `truncate_with_warning` o `skip_sample`. Omítelo para usar `raise`.
  </ParamField>

  <ParamField body="training_algorithm" type="string" default="sft">
    Los trabajos de configuración solo admiten `sft`. Omítelo para usar el valor predeterminado.
  </ParamField>

</Expandable>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Idempotency-Key: YOUR_UNIQUE_RETRY_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model_name": "my-model-name",
    "base_model": "fastino/gliner2-base-v1",
    "datasets": [{"name": "my-ready-dataset"}],
    "training_type": "lora",
    "nr_epochs": 5,
    "learning_rate": 5e-5,
    "validation_data_percentage": 0.2
  }'
```

</RequestExample>

## Respuesta

Devuelve `200` con el registro completo del trabajo, incluidos un `id` UUID y el estado inicial. El ejemplo siguiente está abreviado; la respuesta real incluye todos los campos definidos por `TrainingJobResponse`.

<ResponseExample>

```json Response
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "type": "config",
  "model_name": "my-model-name",
  "base_model": "fastino/gliner2-base-v1",
  "status": "requested",
  "training_type": "lora",
  "nr_epochs": 5,
  "learning_rate": 5e-5,
  "validation_data_percentage": 0.2
}
```

</ResponseExample>

Guarda el `id` de esta respuesta. Lo usarás para consultar el estado, obtener métricas y artefactos y ejecutar inferencia contra el modelo entrenado.

Un cuerpo con formato incorrecto devuelve `422`. Una combinación válida pero no disponible de modelo, dataset, tipo de entrenamiento o proveedor devuelve un error `4xx` específico de la solicitud.

La creación puede devolver estos conflictos codificados:

| Estado | Significado |
| --- | --- |
| `409 duplicate_training_submission` | Ya hay un trabajo idéntico activo. |
| `409 idempotency_key_job_deleted` | Se eliminó el trabajo creado originalmente con esta clave de idempotencia. Usa una clave nueva para un trabajo nuevo. |
| `409` | Un dataset referenciado se retiró entre la validación y la inserción del trabajo. Resuelve el dataset y reintenta con una clave nueva. |

La misma `Idempotency-Key` y un cuerpo idéntico reproducen el trabajo original en vez de crear otro. Un cuerpo diferente con la misma clave devuelve `422`.

Un modelo base decodificador devuelve `400`:

```json
{
  "error": {
    "message": "Decoder training on this route is retired: 'Qwen/Qwen3.6-35B-A3B' cannot be trained here. Train decoders step by step with the training job routes under /v1/training/jobs (see https://docs.fastino.ai/training/quickstart).",
    "type": "invalid_request_error",
    "param": null,
    "code": null
  }
}
```

Para entrenar un decodificador, crea un trabajo interactivo con
[`POST /v1/training/jobs/create-model`](/es/api-reference/training-jobs/interactive/create-model)
y sigue el [bucle de entrenamiento personalizado](/es/training/decoder-quickstart).

## Autorización

Requiere el rol Owner, Admin o Editor del equipo. Los demás roles reciben `403 Forbidden`.
