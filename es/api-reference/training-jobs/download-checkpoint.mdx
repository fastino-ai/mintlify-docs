`GET /v1/training/jobs/{job_id}/checkpoints/{checkpoint_id}/download`

Devuelve una URL prefirmada de almacenamiento de objetos y corta duración para un checkpoint de un trabajo `interactive`. El archivo de un checkpoint sampler contiene los archivos del adaptador del decodificador. Los trabajos de configuración usan
[`GET /v1/training/jobs/{job_id}/download`](/es/api-reference/training-jobs/download)
para el artefacto de su modelo final.

## Solicitud

<ParamField header="X-API-Key" type="string" required>
  Tu clave de API de Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  `job_id` interactivo devuelto por `POST /v1/training/jobs/create-model`.
</ParamField>

<ParamField path="checkpoint_id" type="string" required>
  Identificador de checkpoint devuelto por la lista de checkpoints, como
  `weights/checkpoint-1` o `sampler_weights/checkpoint-1`. Conserva la `/` en
  la ruta; no codifiques como URL el identificador completo.
</ParamField>

<RequestExample>

```bash cURL
CHECKPOINT_ID="sampler_weights/checkpoint-1"
curl "https://api.fastino.ai/v1/training/jobs/JOB_ID/checkpoints/$CHECKPOINT_ID/download" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Respuesta

La respuesta contiene una URL prefirmada de almacenamiento de objetos que caduca a los 15 minutos.
Trata la URL como una credencial: no la registres, compartas ni conserves.

<ResponseField name="success" type="boolean">
  Indica si la solicitud se completó correctamente.
</ResponseField>

<ResponseField name="run_id" type="string">
  Trabajo interactive al que pertenece el checkpoint.
</ResponseField>

<ResponseField name="checkpoint_id" type="string">
  Identificador del checkpoint interactive descargable.
</ResponseField>

<ResponseField name="download_url" type="string">
  URL prefirmada de almacenamiento de objetos. No se requiere clave de API para obtenerla.
</ResponseField>

<ResponseField name="expires_in_seconds" type="integer">
  Tiempo de vida restante de la URL prefirmada. Los enlaces nuevos caducan a los 900 segundos.
</ResponseField>

<ResponseField name="file_name" type="string">
  Nombre de archivo `.tar` sugerido para el archivo.
</ResponseField>

<ResponseExample>

```json Response
{
  "success": true,
  "run_id": "session-1:train:0",
  "checkpoint_id": "sampler_weights/checkpoint-1",
  "download_url": "SIGNED_ARCHIVE_URL",
  "expires_in_seconds": 900,
  "file_name": "session-1_train_0-sampler_weights-checkpoint-1.tar"
}
```

</ResponseExample>

Las descargas de checkpoints están habilitadas de forma predeterminada. Un equipo cuyo acceso de descarga se haya deshabilitado explícitamente recibe `403`.

## Cargar un adaptador de decodificador

El checkpoint sampler de un decodificador se descarga como un adaptador PEFT estándar de Hugging Face para el modelo base público. El archivo contiene `adapter_config.json`, `adapter_model.safetensors` con todos los tensores entrenados y un `README.md` con código de carga:

```python
from peft import PeftModel
from transformers import AutoModelForCausalLM

base = AutoModelForCausalLM.from_pretrained("Qwen/Qwen3.6-35B-A3B", dtype="auto")
model = PeftModel.from_pretrained(base, "path/to/extracted/archive")
```

Fastino prueba estos adaptadores con transformers 5.19.0 y peft 0.21.2, no con vLLM. Un adaptador de Nemotron 3.5 Lightning que entrena `out_proj` de Mamba necesita una habilitación de una línea antes de que PEFT lo cargue; el `README.md` del archivo la muestra. Solo se convierten los checkpoints sampler: un checkpoint de estado de entrenamiento se descarga en el diseño interno de Fastino.

## Errores

| Estado | Significado |
| --- | --- |
| `400` | `checkpoint_id` no es `weights/<name>` ni `sampler_weights/<name>`. |
| `403` | Las descargas de pesos se deshabilitaron explícitamente para el equipo. |
| `404` | El trabajo o checkpoint no está disponible, o el checkpoint no tiene archivos descargables. |

Obtener `download_url` devuelve un adjunto `application/x-tar`. La URL prefirmada de almacenamiento de objetos es la credencial y caduca tras el valor `expires_in_seconds` de la respuesta.
