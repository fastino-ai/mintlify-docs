`GET /v1/training/jobs/{job_id}/deployments`

Esta operación solo está disponible para trabajos config; después de las comprobaciones normales de función y permisos, un ID de trabajo interactivo devuelve `400`. El despliegue de un checkpoint sampler informa del progreso inicial en su `status`; usa el `model_id` devuelto con este endpoint para listar los registros de despliegue de ese modelo servido.

Lista los despliegues creados desde un trabajo de entrenamiento o asociados a él.
