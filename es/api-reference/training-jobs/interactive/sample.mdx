`POST /v1/training/jobs/{job_id}/checkpoints/sampler_weights/{name}/sample`

Esta operación JSON nativa se aplica a trabajos de entrenamiento interactivos.

Encola muestreo desde un punto `sampler_weights`. El muestreo funciona después de detener el trabajo. Consulta [Obtener operación](/es/api-reference/training-jobs/interactive/get-operation) hasta un estado terminal.

Consulta [Crear un bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo completo.
