`POST /v1/training/jobs/{job_id}/sample`

Genera continuaciones de un prompt tokenizado con uno de los puntos de control
`sampler` del trabajo. El muestreo también funciona después de detener el trabajo.
Lee los tokens generados en `result.sequences` del future completado.

## Solicitud

<ParamField header="X-API-Key" type="string" required>
  Su clave API de Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  Identificación de trabajo interactiva.
</ParamField>

<ParamField body="checkpoint" type="string" required>
  El nombre de un checkpoint sampler guardado por este trabajo o su ruta `tinker://<job_id>/sampler_weights/<name>`.
</ParamField>

<ParamField body="prompt_tokens" type="integer[]" required>
  ID de token del prompt generados por el tokenizador del modelo base. Al menos un token.
</ParamField>

<ParamField body="num_samples" type="integer" default="1">
  Número de continuaciones, de `1` a `512`.
</ParamField>

<ParamField body="sampling_params" type="object">
  Configuración de decodificación.

  <Expandable title="properties">
    <ParamField body="max_tokens" type="integer" default="1024">
      Número máximo de tokens generados. El prompt más `max_tokens` debe caber en el límite de muestreo del modelo. Qwen puede muestrear hasta `65,536` tokens, aunque cada dato de entrenamiento de Qwen está limitado a `32,768` tokens.
    </ParamField>
    <ParamField body="temperature" type="number" default="1.0">
      Temperatura de muestreo.
    </ParamField>
    <ParamField body="top_p" type="number" default="1.0">
      Masa de probabilidad de muestreo del núcleo.
    </ParamField>
    <ParamField body="top_k" type="integer" default="-1">
      Límite superior-k. `-1` lo desactiva.
    </ParamField>
    <ParamField body="stop" type="string | string[] | integer[]">
      Cadenas de parada o ID de tokens de parada.
    </ParamField>
    <ParamField body="seed" type="integer">
      Semillas de muestreo.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="prompt_logprobs" type="boolean" default="false">
  También devuelve la probabilidad logarítmica de cada token de solicitud.
</ParamField>

<ParamField body="topk_prompt_logprobs" type="integer" default="0">
  Devuelve las alternativas top-k en cada posición del mensaje.
</ParamField>

<ParamField body="topk_sample_logprobs" type="integer" default="0">
  Devuelve las k alternativas top en cada posición generada.
</ParamField>

El array numérico de tokens del prompt siguiente es solo un marcador ilustrativo. Tokeniza el prompt real con el tokenizador del `base_model` del trabajo.

<Note>
  Un equipo puede tener como máximo `2,048` solicitudes de muestreo en curso. La API devuelve `429` al alcanzar ese límite; espera a que terminen los futures de muestreo existentes antes de reintentar.
</Note>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/sample" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "checkpoint": "step-000100",
    "prompt_tokens": [151644, 872, 198, 3838],
    "num_samples": 2,
    "sampling_params": {"max_tokens": 64, "temperature": 0.7}
  }'
```

</RequestExample>

## Respuesta

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "sample"
}
```

</ResponseExample>

Cada secuencia del resultado completado contiene `tokens`, `logprobs`, `stop_reason` (`stop` o `length`) y `topk_logprobs`. Decodifica `tokens` con el mismo tokenizador. Cancela un muestreo sin terminar con
[`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`](/es/api-reference/training-jobs/interactive/cancel-future).

| Estado | Significado |
| --- | --- |
| `400` | `checkpoint` no es válido, pertenece a otro trabajo, es un checkpoint de estado o el prompt es demasiado largo. |
| `402` | El equipo no tiene créditos o no tiene una configuración de pago válida. |
| `404` | El trabajo o checkpoint no existe, o el trabajo pertenece a otro equipo. |
| `429` | El equipo ya tiene `2,048` solicitudes de muestreo en curso. Espera a que terminen los futures de muestreo existentes antes de reintentar. |
| `422` | Falta `checkpoint` o `prompt_tokens` o el cuerpo tiene un campo desconocido. |
