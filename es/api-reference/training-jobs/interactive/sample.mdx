`POST /v1/training/jobs/{job_id}/sample`

Pone en cola el muestreo desde `checkpoint` y devuelve un `future_id`. Usa el nombre de un checkpoint de muestreo o la ruta `tinker://<job_id>/sampler_weights/<name>` del mismo trabajo. El muestreo sigue disponible después de detener el trabajo interactivo. Consulta [Obtener future](/es/api-reference/training-jobs/interactive/get-future) hasta alcanzar un estado terminal.

Consulta [el bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo de vida completo.
