`POST /v1/training/jobs/{job_id}/sample`

Encola un muestreo desde `checkpoint` y devuelve un `future_id`. Usa un nombre de punto de control de muestreo o la ruta `tinker://<job_id>/sampler_weights/<name>` propia de este trabajo. El muestreo sigue disponible después de detener el trabajo interactivo. Consulta [Obtener un future](/es/api-reference/training-jobs/interactive/get-future) hasta que alcance un estado terminal.

Consulta [el bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo de vida completo.
