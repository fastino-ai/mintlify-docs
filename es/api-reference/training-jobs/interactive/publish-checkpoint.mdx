`POST /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

Marca un checkpoint como público; su campo `public` pasa a `true`. `kind` es `weights` o `sampler_weights`. Devuelve `204 No Content`. Deshazlo con [`DELETE .../publish`](/es/api-reference/training-jobs/interactive/unpublish-checkpoint).

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/sampler_weights/step-000100/publish" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
