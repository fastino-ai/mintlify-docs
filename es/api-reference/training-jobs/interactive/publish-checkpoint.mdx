`POST /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

Publica un punto de control `weights` o `sampler_weights`. La publicación no concede a otro equipo permiso para cargarlo.

Consulta [el bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo de vida completo.
