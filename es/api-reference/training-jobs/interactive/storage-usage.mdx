`GET /v1/training/usage`

Esta operación JSON nativa se aplica a trabajos de entrenamiento interactivos.

Devuelve el almacenamiento de puntos interactivos del equipo y su precio mensual. No incluye cómputo ni facturación total.

Consulta [Crear un bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo completo.
