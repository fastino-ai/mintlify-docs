`GET /v1/training/usage`

Devuelve el almacenamiento activo de checkpoints de trabajos interactivos del
equipo, por proyecto y usuario, con su coste mensual estimado. Los checkpoints
eliminados y caducados no cuentan.

<ParamField query="project_id" type="string">
  Solo el almacenamiento de este proyecto.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/usage" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

<ResponseExample>

```json Response
{
  "effective_rate_usd_per_gigabyte_month": 0.05,
  "data": [
    {
      "project_id": "PROJECT_ID",
      "org_user_urn": "USER_URN",
      "user_email": "you@example.com",
      "user_name": "You",
      "checkpoint_count": 3,
      "size_bytes": 805306368,
      "size_gigabytes": 0.75,
      "estimated_monthly_cost_usd": 0.0375
    }
  ]
}
```

</ResponseExample>
