`GET /v1/training/usage`

Devuelve el almacenamiento activo de checkpoints de trabajos interactivos del equipo, con una fila por proyecto y su coste mensual estimado. Los campos de compatibilidad `org_user_urn` y `user_name` contienen el ID del equipo; `user_email` es `null`. Los checkpoints eliminados y caducados no cuentan.

<ParamField query="project_id" type="string">
  Solo el almacenamiento de este proyecto.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/usage" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
