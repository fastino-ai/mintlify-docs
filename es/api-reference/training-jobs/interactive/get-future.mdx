`GET /v1/training/jobs/{job_id}/futures/{future_id}`

Devuelve el estado y el resultado del future. Con `wait=true`, la solicitud espera como máximo 25 segundos y todavía puede devolver un estado no terminal. Consulta hasta obtener `completed`, `failed` o `cancelled`. El servicio conserva el resultado durante una hora. Un error HTTP indica que el servidor rechazó la solicitud. En cambio, un future en cola puede terminar con `status: "failed"` y un `error.message`; trata `error.category` como una cadena opaca.

Consulta [el bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo de vida completo.
