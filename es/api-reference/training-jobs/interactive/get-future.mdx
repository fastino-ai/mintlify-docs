`GET /v1/training/jobs/{job_id}/futures/{future_id}`

Cada llamada de trabajo interactivo que funciona devuelve un `future_id`. sondear el futuro
hasta que su `status` sea `completed`, `failed` o `cancelled`. Utilice `wait=true` para
espere hasta 25 segundos por solicitud; un tiempo de espera aún puede devolver un no terminal
futuro. Los resultados se conservan durante una hora.

## Solicitud

<ParamField header="X-API-Key" type="string" required>
  Su clave API de Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  Identificación de trabajo interactiva.
</ParamField>

<ParamField path="future_id" type="string" required>
  ID futuro devuelto cuando el trabajo estaba en cola.
</ParamField>

<ParamField query="wait" type="boolean" default="false">
  Espere hasta 25 segundos para ver un futuro inacabado antes de responder. repetir
  la solicitud hasta que finalice.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/futures/$FUTURE_ID?wait=true" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Respuesta

<ResponseField name="future_id" type="string">
  El futuro.
</ResponseField>

<ResponseField name="job_id" type="string">
  El trabajo.
</ResponseField>

<ResponseField name="type" type="string">
  `create`, `load`, `forward`, `forward_backward`, `optim_step`, `save` o `sample`.
</ResponseField>

<ResponseField name="status" type="string">
  `pending`, `running`, `completed`, `failed` o `cancelled`.
</ResponseField>

<ResponseField name="queue_state" type="string | null">
  Mientras no está terminado: `active` o `paused_capacity` mientras se calienta la capacidad de la GPU.
</ResponseField>

<ResponseField name="queue_state_reason" type="string | null">
  Una explicación de capacidad legible por humanos mientras `queue_state` es
  `paused_capacity`; de lo contrario `null`.
</ResponseField>

<ResponseField name="result" type="any">
  Una vez `completed`:

  - `forward` y `forward_backward`: `loss_fn_outputs` (una entrada de tensores por
    referencia, como `logprobs`) y `metrics`.
  - `sample`: `sequences`, cada uno con `tokens`, `logprobs` y `stop_reason`,
    más `prompt_logprobs` cuando se solicite.
  - `save`: la ruta del punto de control.
  - Otros tipos: un acuse de recibo.
</ResponseField>

<ResponseField name="error" type="object | null">
  Cuando `failed` o `cancelled`: `message` y `category` (`user` por un problema
  con la solicitud, `server` por un problema de Fastino).
</ResponseField>

| Estado | Significado |
| --- | --- |
| `404` | El trabajo o el futuro no existe, o pertenece a otro equipo. |
| `410` | La operación se perdió o su resultado retenido expiró. Vuelva a enviar la operación; un resultado caducado no se puede recuperar. |
