`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

Guarda un checkpoint `sampler_weights` para muestreo.

Envíe `name` y, opcionalmente, `ttl_seconds`; consulte la `future_id` devuelta antes de usar el checkpoint.
