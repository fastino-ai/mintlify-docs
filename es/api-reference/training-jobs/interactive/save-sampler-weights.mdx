`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

Guarda los pesos LoRA con `name` para el muestreo y la descarga de PEFT. La respuesta aceptada contiene un `future_id`, un ID de checkpoint `sampler_weights/<name>` y su ruta `tinker://`. Consulta [Obtener future](/es/api-reference/training-jobs/interactive/get-future) antes de muestrear o descargar.

Consulta [el bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo de vida completo.
