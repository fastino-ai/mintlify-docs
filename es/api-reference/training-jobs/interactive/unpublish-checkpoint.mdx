`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

Retira la publicación de un punto de control y se completa de forma síncrona sin cuerpo de respuesta.

Consulta [el bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo de vida completo.
