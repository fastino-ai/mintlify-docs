`POST /v1/training/jobs/create-model`

Crea un trabajo LoRA interactivo a partir de `base_model`, o desde `from_checkpoint` con la configuración opcional `load_optimizer`. La respuesta incluye el `job_id` y el `future_id` de creación. Si restauras un punto de control, también incluye `load_future_id`. Los clientes JSON nativos no envían valores `seq_id` ni heartbeats.

Consulta [el bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo de vida completo.
