`POST /v1/training/jobs/create-model`

Crea un trabajo de entrenamiento `interactive` LoRA en un modelo base de decodificador o un nuevo
Trabajo iniciado desde un estado de entrenamiento guardado. Luego, su aplicación envía cada
pase hacia adelante y hacia atrás, paso del optimizador, punto de control y muestra. JSON nativo
Los clientes no envían valores `seq_id` ni latidos. Para la formación gestionada desde
un conjunto de datos cargado, utilice [`POST /v1/training/jobs`](/es/api-reference/training-jobs/create).

El trabajo estará listo una vez que se complete su futuro `create`. Léelo con
[`GET /v1/training/jobs/{job_id}/futures/{future_id}`](/es/api-reference/training-jobs/interactive/get-future).

## Solicitud

<ParamField header="X-API-Key" type="string" required>
  Su clave API de Fastino.
</ParamField>

Envíe exactamente uno de `base_model` y `from_checkpoint`.

<ParamField body="base_model" type="string">
  `nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16`,
  `nvidia/NVIDIA-Nemotron-3-Super-120B-A12B-BF16` o `Qwen/Qwen3.6-35B-A3B`.
</ParamField>

<ParamField body="from_checkpoint" type="string">
  El `path` que [`save-weights`](/es/api-reference/training-jobs/interactive/save-weights)
  devuelto para uno de sus trabajos, como `tinker://<job_id>/weights/<name>`. el
  El nuevo trabajo toma el modelo base de ese punto de control y la configuración LoRA, así que omita
  `lora_config`. Se rechazan los puntos de control del muestreador.
</ParamField>

<ParamField body="load_optimizer" type="boolean" default="false">
  Configure `load_optimizer` con `from_checkpoint` para restaurar el estado del optimizador.
</ParamField>

<ParamField body="lora_config" type="object">
  Configuración de LoRA para un nuevo trabajo.

  <Expandable title="properties">
    <ParamField body="rank" type="integer" default="32">
      Rango LoRA, del 1 al 32.
    </ParamField>
    <ParamField body="seed" type="integer">
      Semilla de inicialización del adaptador.
    </ParamField>
    <ParamField body="train_attn" type="boolean" default="true">
      Entrenar capas de atención.
    </ParamField>
    <ParamField body="train_mlp" type="boolean" default="true">
      Entrene capas MLP.
    </ParamField>
    <ParamField body="train_unembed" type="boolean" default="true">
      Entrene la capa de desincrustación.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="optimizer_config" type="object">
  Familia de optimizadores. Solo se sirve `{"type": "adamw"}`, que es el valor predeterminado.
</ParamField>

<ParamField body="project_id" type="string">
  Proyecto al que pertenece el trabajo y su uso. El valor predeterminado es su proyecto predeterminado.
</ParamField>

<ParamField body="user_metadata" type="object">
  Tus propios metadatos JSON para el trabajo.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/create-model" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "base_model": "Qwen/Qwen3.6-35B-A3B",
    "lora_config": {"rank": 32}
  }'
```

</RequestExample>

## Respuesta

<ResponseField name="job_id" type="string">
  Identificación de trabajo interactiva. Úselo con todas las rutas `/v1/training/jobs/{job_id}`.
</ResponseField>

<ResponseField name="type" type="string">
  Siempre `interactive`.
</ResponseField>

<ResponseField name="base_model" type="string">
  Modelo base del trabajo.
</ResponseField>

<ResponseField name="future_id" type="string">
  El futuro del trabajo `create`.
</ResponseField>

<ResponseField name="load_future_id" type="string | null">
  Con `from_checkpoint`, el futuro que carga el puesto de control.
</ResponseField>

<ResponseExample>

```json Response
{
  "job_id": "SESSION_ID:train:0",
  "type": "interactive",
  "base_model": "Qwen/Qwen3.6-35B-A3B",
  "future_id": "FUTURE_ID",
  "load_future_id": null
}
```

</ResponseExample>

## Errores

| Estado | Significado |
| --- | --- |
| `400` | El modelo no se entrega, el rango está fuera de rango, `from_checkpoint` es un punto de control de muestra o `lora_config` se envió con `from_checkpoint`. |
| `402` | El equipo no tiene créditos o no tiene una configuración de pago válida. |
| `404` | La capacitación interactiva no está disponible para el equipo o el punto de control no existe. |
| `422` | Se enviaron ambos o ninguno de `base_model` y `from_checkpoint`, o el cuerpo tiene un campo desconocido. |
