`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

Esta operación JSON nativa se aplica a trabajos de entrenamiento interactivos.

Solicita la cancelación de mejor esfuerzo de una operación sample en cola o en ejecución. Las operaciones de entrenamiento no se pueden cancelar.

Consulta [Crear un bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo completo.
