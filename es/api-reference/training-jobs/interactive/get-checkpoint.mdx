`GET /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

Devuelve un punto de control. Para enumerar todos los puntos de control de un trabajo, utilice
[`GET /v1/training/jobs/{job_id}/checkpoints`](/es/api-reference/training-jobs/checkpoints).

## Solicitud

<ParamField path="job_id" type="string" required>
  Identificación de trabajo interactiva.
</ParamField>

<ParamField path="kind" type="string" required>
  `weights` para un punto de control de estado, o `sampler_weights` para un punto de control de muestreo.
</ParamField>

<ParamField path="name" type="string" required>
  Nombre del punto de control.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/sampler_weights/step-000100" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Respuesta

<ResponseExample>

```json Response
{
  "checkpoint_id": "sampler_weights/step-000100",
  "checkpoint_type": "sampler",
  "time": "2026-10-14T12:00:00Z",
  "tinker_path": "tinker://SESSION_ID:train:0/sampler_weights/step-000100",
  "size_bytes": 268435456,
  "public": false,
  "user_metadata": null,
  "expires_at": "2026-10-15T12:00:00Z"
}
```

</ResponseExample>

`checkpoint_type` es `training` para un punto de control estatal y `sampler` para un
punto de control del muestreador. `expires_at` es `null` cuando el punto de control no tiene TTL.
