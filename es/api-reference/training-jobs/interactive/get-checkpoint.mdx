`GET /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

Devuelve un punto de control interactivo. `kind` es `weights` o `sampler_weights`.

Consulta [el bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo de vida completo.
