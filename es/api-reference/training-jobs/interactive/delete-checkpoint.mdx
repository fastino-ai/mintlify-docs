`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

Elimina un punto de control `weights` o `sampler_weights`. La operación se completa de forma síncrona sin cuerpo de respuesta. Los archivos almacenados pueden purgarse más tarde.

Consulta [el bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo de vida completo.
