`POST /v1/training/jobs/{job_id}/load-weights`

Pone en cola una carga desde `path` y devuelve un `future_id`. Usa un nombre de estado o la ruta `tinker://<job_id>/weights/<name>` del mismo trabajo. Configura `optimizer` para restaurar el estado del optimizador. Consulta [Obtener future](/es/api-reference/training-jobs/interactive/get-future) hasta alcanzar un estado terminal.

Consulta [el bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo de vida completo.
