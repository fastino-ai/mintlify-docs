`POST /v1/training/jobs/{job_id}/load-weights`

Encola una carga desde `path` y devuelve un `future_id`. Usa un nombre de estado o la ruta `tinker://<job_id>/weights/<name>` propia de este trabajo. Configura `optimizer` para restaurar el estado del optimizador. Consulta [Obtener un future](/es/api-reference/training-jobs/interactive/get-future) hasta que alcance un estado terminal.

Consulta [el bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo de vida completo.
