`POST /v1/training/jobs/{job_id}/load-weights`

Esta operación JSON nativa se aplica a trabajos de entrenamiento interactivos.

Encola la carga del estado desde un punto `weights`. Puede restaurar el optimizador. Consulta [Obtener operación](/es/api-reference/training-jobs/interactive/get-operation) hasta un estado terminal.

Consulta [Crear un bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo completo.
