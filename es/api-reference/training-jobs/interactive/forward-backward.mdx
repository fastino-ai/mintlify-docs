`POST /v1/training/jobs/{job_id}/forward-backward`

Encola un pase hacia delante y atrás que acumula gradientes y devuelve un `future_id`. Consulta [Obtener future](/es/api-reference/training-jobs/interactive/get-future) hasta alcanzar un estado terminal.

Consulta [el bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo de vida completo.
