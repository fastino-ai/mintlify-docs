`POST /v1/training/jobs/{job_id}/forward-backward`

Encola un pase forward-backward que acumula gradientes y devuelve un `future_id`. Consulta [Obtener un future](/es/api-reference/training-jobs/interactive/get-future) hasta que alcance un estado terminal.

Consulta [el bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo de vida completo.
