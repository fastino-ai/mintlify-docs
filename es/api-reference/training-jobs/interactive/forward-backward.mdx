`POST /v1/training/jobs/{job_id}/forward-backward`

Esta operación JSON nativa se aplica a trabajos de entrenamiento interactivos.

Encola pases hacia delante y atrás que acumulan gradientes y devuelve `future_id`. Consulta [Obtener operación](/es/api-reference/training-jobs/interactive/get-operation) hasta un estado terminal.

Consulta [Crear un bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo completo.
