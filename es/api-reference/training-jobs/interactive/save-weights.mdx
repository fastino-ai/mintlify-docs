`POST /v1/training/jobs/{job_id}/save-weights`

Guarda los pesos LoRA y el estado del optimizador con `name`. La respuesta aceptada contiene un `future_id`, un ID de checkpoint `weights/<name>` y su ruta `tinker://`. Consulta [Obtener future](/es/api-reference/training-jobs/interactive/get-future) antes de cargar el estado o iniciar otro trabajo desde él.

Consulta [el bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo de vida completo.
