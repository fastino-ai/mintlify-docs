`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

Mantiene un punto de control para `ttl_seconds` a partir de ahora y luego lo elimina. Omitir
`ttl_seconds` o envíe `null` para conservar el punto de control hasta que lo elimine. Devuelve `204 No Content`.

`kind` es `weights` o `sampler_weights`.

<ParamField body="ttl_seconds" type="integer | null">
  Desde `3600` (1 hora) hasta `315360000` (10 años), o `null`.
</ParamField>

<RequestExample>

```bash cURL
curl -X PUT "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100/ttl" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"ttl_seconds": 604800}'
```

</RequestExample>

## Errores

| Estado | Significado |
| --- | --- |
| `400` | `ttl_seconds` está fuera de 3600–315360000. |
| `404` | El trabajo o punto de control no existe o pertenece a otro equipo. |
| `422` | El cuerpo contiene un campo desconocido. |
