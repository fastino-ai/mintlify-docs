`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

Configura el periodo de retención de un punto de control `weights` o `sampler_weights`. Un TTL nulo conserva el punto de control hasta su eliminación.

Consulta [el bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo de vida completo.
