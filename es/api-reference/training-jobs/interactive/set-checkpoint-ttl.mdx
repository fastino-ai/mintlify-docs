`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

Conserva un checkpoint durante `ttl_seconds` a partir de ahora y después lo
elimina. Omite `ttl_seconds` o envía `null` para conservar el checkpoint hasta
que lo elimines. Devuelve `204 No Content`.

`kind` es `weights` o `sampler_weights`.

<ParamField body="ttl_seconds" type="integer | null">
  De `3600` (1 hora) a `315360000` (10 años), o `null`.
</ParamField>

<RequestExample>

```bash cURL
curl -X PUT "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100/ttl" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"ttl_seconds": 604800}'
```

</RequestExample>

## Errores

| Estado | Significado |
| --- | --- |
| `400` | `ttl_seconds` está fuera del rango 3600–315360000. |
| `404` | El trabajo o el checkpoint no existe, o pertenece a otro equipo. |
| `422` | El cuerpo contiene un campo desconocido. |
