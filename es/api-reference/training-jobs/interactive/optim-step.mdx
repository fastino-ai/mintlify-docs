`POST /v1/training/jobs/{job_id}/optim-step`

Esta operación JSON nativa se aplica a trabajos de entrenamiento interactivos.

Encola un paso del optimizador sobre los gradientes acumulados y devuelve `future_id`. El cuerpo es opcional. Consulta [Obtener operación](/es/api-reference/training-jobs/interactive/get-operation) hasta un estado terminal.

Consulta [Crear un bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo completo.
