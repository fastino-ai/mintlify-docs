`POST /v1/training/jobs/{job_id}/optim-step`

Aplica las pendientes acumuladas por pases adelante-atrás desde el último
paso, usando AdamW. Las llamadas se ejecutan en el orden en que las recibe el trabajo, por lo que
Puede poner esto en cola justo después de un pase hacia adelante y hacia atrás sin esperarlo.

## Solicitud

<ParamField header="X-API-Key" type="string" required>
  Su clave API de Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  Identificación de trabajo interactiva.
</ParamField>

El cuerpo JSON es opcional.

<ParamField body="adam_params" type="object">
  Parámetros de AdamW. Los campos omitidos utilizan sus valores predeterminados.

  <Expandable title="properties">
    <ParamField body="learning_rate" type="number" default="0.0001">
      Tasa de aprendizaje, `>= 0`.
    </ParamField>
    <ParamField body="beta1" type="number" default="0.9">
      Desde `0` hasta, pero sin incluir, `1`.
    </ParamField>
    <ParamField body="beta2" type="number" default="0.95">
      Desde `0` hasta, pero sin incluir, `1`.
    </ParamField>
    <ParamField body="eps" type="number" default="1e-12">
      `> 0`.
    </ParamField>
    <ParamField body="weight_decay" type="number" default="0">
      `>= 0`.
    </ParamField>
    <ParamField body="grad_clip_norm" type="number" default="0">
      Clip de norma de degradado, `>= 0`. `0` desactiva el recorte.
    </ParamField>
  </Expandable>
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/optim-step" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"adam_params": {"learning_rate": 0.0001}}'
```

</RequestExample>

## Respuesta

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "optim_step"
}
```

</ResponseExample>

El `result` del futuro completado contiene las métricas del paso.

| Estado | Significado |
| --- | --- |
| `400` | Un parámetro de Adam está fuera de rango o el trabajo se detuvo. |
| `404` | El trabajo no existe o pertenece a otro equipo. |
| `422` | El cuerpo tiene un campo desconocido. |
