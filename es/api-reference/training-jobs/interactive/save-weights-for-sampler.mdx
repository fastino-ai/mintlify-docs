`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

Guarda los pesos LoRA del trabajo como `sampler_weights/<name>`. tu puedes
[muestra](/es/api-reference/training-jobs/interactive/sample) de él, también después de que se complete el trabajo.
detenido, o [descargarlo](/es/api-reference/training-jobs/download-checkpoint) como
Archivos PEFT LoRA. No tiene estado de optimizador, por lo que un trabajo no puede cargarlo ni comenzar desde
eso; utilizar [`POST /v1/training/jobs/{job_id}/save-weights`](/es/api-reference/training-jobs/interactive/save-weights)
por eso.

El guardado se ejecuta en orden con las otras llamadas del trabajo.

## Solicitud

<ParamField header="X-API-Key" type="string" required>
  Su clave API de Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  Identificación de trabajo interactiva.
</ParamField>

<ParamField body="name" type="string" required>
  De 1 a 128 caracteres de `A-Z`, `a-z`, `0-9`, `.`, `_` y `-`.
</ParamField>

<ParamField body="ttl_seconds" type="integer | null">
  Elimine el punto de control automáticamente después de tantos segundos, de `3600`
  (1 hora) a `315360000` (10 años). Omítelo o envía `null` para mantener el punto de control hasta que lo elimines. Los puntos de control activos cuentan para [uso de almacenamiento](/es/api-reference/training-jobs/interactive/storage-usage).
</ParamField>

<ParamField body="user_metadata" type="object">
  Metadatos de cadena de valor-clave almacenados con el punto de control.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/save-weights-for-sampler" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "step-000100", "ttl_seconds": 86400}'
```

</RequestExample>

## Respuesta

<ResponseField name="future_id" type="string">
  El futuro `save`.
</ResponseField>

<ResponseField name="checkpoint_id" type="string">
  `sampler_weights/<name>`.
</ResponseField>

<ResponseField name="path" type="string">
  Ruta completa del punto de control.
</ResponseField>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "save",
  "checkpoint_id": "sampler_weights/step-000100",
  "path": "tinker://SESSION_ID:train:0/sampler_weights/step-000100"
}
```

</ResponseExample>

| Estado | Significado |
| --- | --- |
| `400` | El nombre tiene caracteres o longitud no válidos, el TTL está fuera de rango o el trabajo se detuvo. |
| `404` | El trabajo no existe o pertenece a otro equipo. |
| `422` | Al cuerpo le falta `name` o tiene un campo desconocido. |
