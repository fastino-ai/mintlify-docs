`POST /v1/training/jobs/{job_id}/save-weights`

Guarda el estado de entrenamiento y del optimizador como un checkpoint `weights`.

Envíe `name` y, opcionalmente, `ttl_seconds`; consulte la `future_id` devuelta antes de usar el checkpoint.
