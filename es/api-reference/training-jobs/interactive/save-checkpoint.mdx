`POST /v1/training/jobs/{job_id}/checkpoints`

Esta operación JSON nativa se aplica a trabajos de entrenamiento interactivos.

Encola el guardado de un punto de control y devuelve `operation_id`. `state` se asigna a `weights` y `sampler` a `sampler_weights`. Consulta [Obtener operación](/es/api-reference/training-jobs/interactive/get-operation) antes de usarlo.

Consulta [Crear un bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo completo.
