`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

La cancelación de un future `sample` en cola o en ejecución se realiza en la
medida de lo posible. La ruta devuelve `204 No Content` cuando se acepta la
solicitud. Cancelar un future terminal o un future de entrenamiento también
devuelve `204`: es una operación sin efecto que se completa correctamente,
porque las operaciones de entrenamiento se ejecutan en orden y no se cancelan.

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/futures/$FUTURE_ID/cancel" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Errores

| Estado | Significado |
| --- | --- |
| `404` | El trabajo o el future no existe, o pertenece a otro equipo. |
