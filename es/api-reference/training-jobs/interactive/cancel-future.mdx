`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

La cancelación es el mejor esfuerzo para un futuro `sample` en cola o en ejecución. la ruta
devuelve `204 No Content` cuando se acepta la solicitud. Cancelar una terminal
futuro o un futuro de formación también devuelve `204`; es una operación no exitosa porque
Las operaciones de entrenamiento se ejecutan en orden y no se cancelan.

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/futures/$FUTURE_ID/cancel" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Errores

| Estado | Significado |
| --- | --- |
| `404` | El trabajo o el futuro no existe, o pertenece a otro equipo. |
