`GET /v1/training/jobs/{job_id}/futures/{future_id}`

Esta operación JSON nativa se aplica a trabajos de entrenamiento interactivos.

Devuelve el estado y el resultado. `wait=true` espera como máximo 25 segundos y aún puede devolver un estado no terminal. Consulta hasta `completed`, `failed` o `cancelled`. Un error HTTP indica rechazo; una operación aceptada puede terminar con `status: "failed"` y `error.message`. Trata `error.category` como una cadena opaca.

Consulta [Crear un bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo completo.
