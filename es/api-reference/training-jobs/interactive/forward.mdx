`POST /v1/training/jobs/{job_id}/forward`

Esta operación JSON nativa se aplica a trabajos de entrenamiento interactivos.

Encola un pase hacia delante sin gradientes y devuelve `operation_id`. Consulta [Obtener operación](/es/api-reference/training-jobs/interactive/get-operation) hasta `completed`, `failed` o `cancelled`.

Consulta [Crear un bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo completo.
