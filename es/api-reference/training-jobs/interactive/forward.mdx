`POST /v1/training/jobs/{job_id}/forward`

Encola un pase forward sin gradientes y devuelve un `future_id`. Consulta [Obtener un future](/es/api-reference/training-jobs/interactive/get-future) hasta que el estado sea `completed`, `failed` o `cancelled`.

Consulta [el bucle de entrenamiento personalizado](/es/training/training-loop) para ver el ciclo de vida completo.
