Los clientes nativos crean un trabajo `interactive` con [`POST /v1/training/jobs/create-model`](/es/api-reference/training-jobs/interactive/create-model). Los clientes Tinker crean el mismo tipo mediante el SDK compatible.

`GET /v1/training/jobs/{job_id}`

Returns one config or interactive training job visible to the caller's team.
For an interactive job, use the `job_id` returned by
[`POST /v1/training/jobs/create-model`](/es/api-reference/interactive-jobs/create).

## Request

<ParamField header="X-API-Key" type="string" required>
  Your Fastino API key.
</ParamField>

<ParamField path="job_id" type="string" required>
  Canonical Fastino training-job ID.
</ParamField>

<RequestExample>

```bash cURL
curl https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Response

### Config job

<ResponseField name="id" type="string">
  Canonical Fastino job ID for a config job.
</ResponseField>

<ResponseField name="type" type="string">
  `config` when Fastino runs the training loop or `interactive` when the caller
  controls the loop through the interactive-job routes.
</ResponseField>

<ResponseField name="status" type="string">
  Persisted lifecycle status.
</ResponseField>

<ResponseField name="normalized_status" type="string | null">
  Stable status for client compatibility.
</ResponseField>

<ResponseField name="is_terminal_status" type="boolean | null">
  Whether polling can stop.
</ResponseField>

<ResponseField name="progress_percent" type="integer | null">
  Current completion percentage from `0` through `100`.
</ResponseField>

<ResponseField name="current_epoch" type="integer | null">
  Current 1-indexed epoch.
</ResponseField>

<ResponseField name="error_message" type="string | null">
  Failure details when available.
</ResponseField>

<ResponseField name="metrics" type="object | null">
  Available training metrics. Common keys are `final_training_loss`, `final_validation_loss`, and `best_validation_loss`. Evaluation metrics are separate and are not guaranteed.
</ResponseField>

<ResponseField name="artifact_ready" type="boolean | null">
  Whether an artifact location is available.
</ResponseField>

<ResponseField name="is_deployable" type="boolean | null">
  Authoritative deployment-readiness decision.
</ResponseField>

<ResponseField name="deployability_reason" type="string | null">
  Why the job is not deployable.
</ResponseField>

Config-job records also return their submitted configuration, dataset
references, progress, metrics, and artifact metadata.

### Interactive job

<ResponseField name="training_run_id" type="string">
  Canonical Fastino job ID for an interactive job.
</ResponseField>

<ResponseField name="base_model" type="string">
  Base model used by the interactive training job.
</ResponseField>

<ResponseField name="model_owner" type="string">
  Team that owns the interactive job.
</ResponseField>

<ResponseField name="is_lora" type="boolean">
  Whether the job trains a LoRA adapter.
</ResponseField>

<ResponseField name="corrupted" type="boolean">
  Whether the training state is unusable for further steps.
</ResponseField>

<ResponseField name="lora_rank" type="integer | null">
  LoRA rank, when applicable.
</ResponseField>

<ResponseField name="last_request_time" type="string">
  ISO 8601 time of the most recent request to the job.
</ResponseField>

<ResponseField name="last_checkpoint" type="object | null">
  Latest training-state checkpoint.
</ResponseField>

<ResponseField name="last_sampler_checkpoint" type="object | null">
  Latest sampler-weights checkpoint. Checkpoint objects include
  `checkpoint_id`, `checkpoint_type`, `time`, `tinker_path`, `size_bytes`,
  `public`, `user_metadata`, and `expires_at`.
</ResponseField>

<ResponseField name="user_metadata" type="object | null">
  String key-value metadata attached when the interactive job was created.
</ResponseField>

Do not assume config-only fields are populated on an interactive job.
