`POST /v1/training/jobs/{job_id}/sync`

Esta operación solo está disponible para trabajos config; después de las comprobaciones normales de función y permisos, un ID de trabajo interactivo devuelve `400`, mientras que los trabajos interactivos exponen su estado actual mediante `GET /v1/training/jobs/{job_id}` y futures.

Esta página documenta `POST /v1/training/jobs/{job_id}/sync`. La especificación OpenAPI es la fuente canónica para parámetros, respuestas y autenticación.
