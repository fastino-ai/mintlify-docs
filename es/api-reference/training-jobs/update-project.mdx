`PATCH /felix/training-jobs/{job_id}`

Actualiza únicamente el `project_id` del trabajo.

## Solicitud

<ParamField header="X-API-Key" type="string" required>
  Tu clave de API de Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID del trabajo de entrenamiento.
</ParamField>

<ParamField body="project_id" type="string | null">
  UUID del proyecto a asignar. Envía `null` para desasignar el trabajo.
</ParamField>

```bash
curl -X PATCH https://api.pioneer.ai/felix/training-jobs/YOUR_TRAINING_JOB_ID \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"project_id": "YOUR_PROJECT_ID"}'
```

## Respuesta

Devuelve `200` con `success` y `message`.

```json
{
  "success": true,
  "message": "Training job project updated"
}
```

<Note>
  Esto solo cambia la etiqueta de proyecto del trabajo de entrenamiento. No mueve los despliegues, inferencias o ejecuciones de evaluación relacionadas.
</Note>

Campos de solicitud desconocidos, incluyendo otros campos del trabajo de entrenamiento, devuelven `422`. Un trabajo o proyecto no disponible devuelve un error `4xx` específico de la solicitud.
