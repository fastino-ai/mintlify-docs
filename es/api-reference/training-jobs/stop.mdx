`POST /v1/training/jobs/{job_id}/stop`

Detiene un trabajo en ejecución y preserva los checkpoints creados antes de la detención.

## Solicitud

<ParamField header="X-API-Key" type="string" required>
  Tu clave de API de Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID de un trabajo config o ID de un trabajo interactivo.
</ParamField>

### Trabajo de configuración

El cuerpo JSON es opcional para un trabajo de configuración.

<ParamField body="reason" type="string">
  Por qué se detuvo el trabajo.
</ParamField>

<ParamField body="scores" type="object">
  Métricas numéricas usadas para tomar la decisión de detención.
</ParamField>

<ParamField body="checkpoint" type="string">
  Ruta o paso del checkpoint asociado con la detención.
</ParamField>

### Trabajo interactivo

No envíes un cuerpo. La operación devuelve `success`, `job_id` y `status`
inmediatamente. El trabajo ya no acepta llamadas de entrenamiento, pero sus
checkpoints sampler siguen disponibles para muestreo y descarga.

### Ejemplo de solicitud para un trabajo de configuración

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID/stop \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"reason": "Validation loss stopped improving"}'
```

### Ejemplo de solicitud para un trabajo interactivo

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs/SESSION_ID:train:0/stop \
  -H "X-API-Key: $FASTINO_API_KEY"
```

## Respuesta de un trabajo de configuración

<ResponseExample>

```json Response
{
  "success": true,
  "message": "Training job stopped",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "status": "stopped"
}
```

```json 202 — cancelación pendiente
{
  "success": true,
  "message": "Training job cancellation is still being confirmed.",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "status": "stopping"
}
```

</ResponseExample>

El campo `message`, la respuesta `202`, la regla de consulta y los errores
específicos de configuración solo se aplican a trabajos de configuración. Tras
un `202` de configuración, consulta `GET /v1/training/jobs/{job_id}`. No repitas
la solicitud de detención mientras la cancelación esté pendiente.

## Respuesta de un trabajo interactivo

Una detención interactiva devuelve `200` inmediatamente sin consultas posteriores.

```json Interactive job
{
  "success": true,
  "job_id": "SESSION_ID:train:0",
  "status": "stopped"
}
```

## Estados de un trabajo de configuración

| Estado | Significado |
| --- | --- |
| `200` | El trabajo está detenido y los checkpoints existentes siguen disponibles. |
| `202` | La cancelación del proveedor todavía se está confirmando. |
| `400` | El ID o la solicitud del trabajo de configuración no son válidos. |
| `409 training_job_already_finished` | El trabajo alcanzó un estado terminal antes de la detención. |
| `422` | El cuerpo JSON del trabajo de configuración no es válido. |
