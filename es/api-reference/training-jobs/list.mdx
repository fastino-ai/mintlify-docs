`GET /v1/training/jobs`

Devuelve los trabajos de entrenamiento de configuración e interactivos visibles
para la cuenta autenticada.

## Solicitud

<ParamField header="X-API-Key" type="string" required>
  Tu clave de API de Fastino.
</ParamField>

<ParamField query="status" type="string">
  Filtra por el estado persistido del trabajo.
</ParamField>

<ParamField query="type" type="string">
  Filtra por `config` o `interactive`.
</ParamField>

<ParamField query="base_model" type="string">
  Filtra por ID de modelo base.
</ParamField>

<ParamField query="project_id" type="string">
  Filtra por ID de proyecto.
</ParamField>

<ParamField query="limit" type="integer" default="200">
  Tamaño de página, de `1` a `200`.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Número de trabajos coincidentes que se omiten.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs?type=config&status=complete&limit=50&offset=0" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Respuesta

<ResponseField name="success" type="boolean">
  Indica si la solicitud se completó correctamente.
</ResponseField>

<ResponseField name="training_jobs" type="object[]">
  Registros de trabajos de entrenamiento de esta página.
</ResponseField>

<ResponseField name="count" type="integer">
  Número de trabajos de esta página.
</ResponseField>

<ResponseField name="total" type="integer">
  Número total de trabajos coincidentes antes de la paginación.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  Indica si existe otra página después de esta.
</ResponseField>

<ResponseExample>

```json Response
{
  "success": true,
  "training_jobs": [],
  "count": 0,
  "total": 0,
  "has_more": false
}
```

</ResponseExample>

Los valores de paginación no válidos devuelven `422`.
