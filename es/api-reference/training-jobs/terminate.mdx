`POST /v1/training/jobs/{job_id}/terminate`

Detiene un trabajo `config` activo y solicita la cancelación al proveedor. Los
checkpoints y artefactos existentes se conservan de forma predeterminada.

<Warning>
  Establecer `delete_checkpoints` en `true` elimina de forma permanente los
  checkpoints y artefactos del trabajo una vez confirmada la cancelación. Esta
  acción no se puede deshacer.
</Warning>

## Solicitud

<ParamField header="X-API-Key" type="string" required>
  Tu clave de API de Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID del trabajo de entrenamiento.
</ParamField>

El cuerpo JSON es opcional.

<ParamField body="delete_checkpoints" type="boolean" default="false">
  Elimina de forma permanente los checkpoints y artefactos una vez confirmada
  la cancelación.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID/terminate \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"delete_checkpoints": false}'
```

</RequestExample>

## Respuesta

<ResponseExample>

```json 200 — terminado
{
  "success": true,
  "message": "Training job terminated. Checkpoints preserved.",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "deleted_checkpoints": 0,
  "status": "terminated"
}
```

```json 202 — cancelación pendiente
{
  "success": true,
  "message": "Training job cancellation is still being confirmed.",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "deleted_checkpoints": 0,
  "status": "stopping"
}
```

</ResponseExample>

Después de un `202`, consulta `GET /v1/training/jobs/{job_id}`; no repitas la
solicitud de terminación mientras la cancelación esté pendiente.

| Estado | Significado |
| --- | --- |
| `200` | El trabajo está terminado. |
| `202` | La cancelación del proveedor todavía se está confirmando. |
| `400` | `job_id` no es un UUID válido de un trabajo config. |
| `409 training_job_already_finished` | El trabajo alcanzó un estado terminal antes de la terminación. |
| `409 cancellation_unconfirmed` | La cancelación no se confirmó y se puede volver a intentar. |
| `422` | El cuerpo JSON de la solicitud no es válido. |
