`POST /v1/training-jobs/{job_id}/terminate`

Detiene el trabajo del proveedor si está activo y marca el trabajo como terminado. De forma predeterminada, se conservan los checkpoints y artefactos existentes.

<Warning>
  Establecer `delete_checkpoints` en `true` elimina permanentemente los checkpoints y artefactos del trabajo. Esta acción no se puede deshacer.
</Warning>

## Solicitud

<ParamField header="X-API-Key" type="string" required>
  Tu clave de API de Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  UUID del trabajo de entrenamiento.
</ParamField>

<ParamField body="delete_checkpoints" type="boolean" default="false">
  Indica si se deben eliminar permanentemente todos los checkpoints y artefactos. Omite este campo o establécelo en `false` para conservarlos.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training-jobs/YOUR_TRAINING_JOB_ID/terminate \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"delete_checkpoints": false}'
```

</RequestExample>

## Respuesta

<ResponseExample>

```json Response
{
  "success": true,
  "message": "Training job terminated. Checkpoints preserved (pass delete_checkpoints=true to remove them).",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "deleted_checkpoints": 0
}
```

</ResponseExample>

Un trabajo desconocido o un trabajo que no puede terminarse devuelve un error `4xx` específico de la solicitud.
