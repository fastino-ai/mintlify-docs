`GET /v1/training-runs`

Devuelve las ejecuciones de entrenamiento visibles para quien llama, de la más reciente a la más antigua. Las ejecuciones de entrenamiento son ejecuciones por pasos que creas y controlas con el SDK compatible con Tinker. Configura el `base_url` del SDK como `https://api.fastino.ai/v1/training-runs/sdk` y autentícate con tu clave de API de Fastino. Ves tus propias ejecuciones y las de tu equipo en los proyectos a los que tienes acceso.

## Solicitud

<ParamField header="X-API-Key" type="string" required>
  Tu clave de API de Fastino.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Tamaño de página. Los valores se ajustan al rango de `1` a `1000`.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Número de ejecuciones que se omiten.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training-runs?limit=20&offset=0" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Respuesta

<ResponseField name="success" type="boolean">
  Indica si la solicitud se completó correctamente.
</ResponseField>

<ResponseField name="training_runs" type="object[]">
  Ejecuciones de entrenamiento de esta página. Cada ejecución tiene los campos descritos en [Obtener una ejecución de entrenamiento](/es/api-reference/training-runs/get).
</ResponseField>

<ResponseField name="count" type="integer">
  Número de ejecuciones en esta página.
</ResponseField>

<ResponseField name="total" type="integer">
  Número total de ejecuciones visibles antes de la paginación.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  Indica si existe otra página después de esta.
</ResponseField>
