Esta guía te muestra el camino más rápido hacia una integración funcional con Fastino. Al terminar,
habrás realizado una llamada de inferencia correcta y entenderás la estructura de la API. Solo necesitas
una cuenta de Fastino y una terminal.

<Steps>
  <Step title="Regístrate y obtén tu clave de API">
    Crea una cuenta en [Fastino](https://fastino.ai).

    Después de iniciar sesión, ve a **Settings → API Keys** y genera una clave nueva. Cópiala
    en un lugar seguro, porque no podrás volver a verla después de cerrar el cuadro de diálogo.

    <Warning>
      Mantén tu clave de API fuera del control de versiones. Usa una variable de entorno o un gestor
      de secretos en lugar de escribirla directamente en tus archivos de código fuente.
    </Warning>

    Define tu clave como variable de entorno para que los ejemplos siguientes funcionen tal cual:

    ```bash
    export FASTINO_API_KEY="your_api_key_here"
    ```
  </Step>

  <Step title="Lista los modelos base disponibles (opcional)">
    Usa `GET /v1/base-models` para explorar los modelos que Fastino tiene disponibles.

    <CodeGroup>

    ```bash curl
    curl https://api.fastino.ai/v1/base-models \
      -H "X-API-Key: $FASTINO_API_KEY"
    ```

    ```python Python
    import os
    import requests

    response = requests.get(
        "https://api.fastino.ai/v1/base-models",
        headers={"X-API-Key": os.environ["FASTINO_API_KEY"]},
    )
    response.raise_for_status()
    print(response.json())
    ```

    ```javascript JavaScript
    const response = await fetch(
      "https://api.fastino.ai/v1/base-models",
      {
        headers: {
          "X-API-Key": process.env.FASTINO_API_KEY
        }
      }
    );

    if (!response.ok) {
      throw new Error(`Model request failed: ${response.status}`);
    }

    console.log(await response.json());
    ```

    </CodeGroup>

    La respuesta enumera los IDs de modelo que puedes pasar a `/v1/chat/completions`. Por ejemplo,
    `fastino/gliner2-base-v1` es un modelo base de GLiNER para tareas de extracción.
  </Step>

  <Step title="Ejecuta tu primera llamada de inferencia">
    Llama a `POST /v1/chat/completions` con un modelo, un mensaje y un esquema que defina lo que
    quieres extraer. Este ejemplo usa GLiNER para extraer entidades nombradas de una oración.

    <CodeGroup>

    ```bash curl
    curl -X POST "https://api.fastino.ai/v1/chat/completions" \
      -H "Authorization: Bearer $FASTINO_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "fastino/gliner2.5-multi-v1",
        "messages": [
          {
            "role": "user",
            "content": "Apple announced the MacBook Pro at WWDC in Cupertino."
          }
        ],
        "schema": {
          "entities": [
            {
              "name": "organization",
              "description": "business or institution name"
            },
            {
              "name": "product",
              "description": "named commercial product"
            },
            {
              "name": "event",
              "description": "named conference or event"
            },
            {
              "name": "location",
              "description": "city, region, or place"
            }
          ]
        },
        "threshold": 0.5
      }'
    ```

    ```python Python
    import json
    import os

    import requests

    response = requests.post(
        "https://api.fastino.ai/v1/chat/completions",
        headers={
            "Authorization": f"Bearer {os.environ['FASTINO_API_KEY']}",
            "Content-Type": "application/json",
        },
        json={
            "model": "fastino/gliner2.5-multi-v1",
            "messages": [
                {
                    "role": "user",
                    "content": "Apple announced the MacBook Pro at WWDC in Cupertino.",
                }
            ],
            "schema": {
                "entities": [
                    {"name": "organization", "description": "business or institution name"},
                    {"name": "product", "description": "named commercial product"},
                    {"name": "event", "description": "named conference or event"},
                    {"name": "location", "description": "city, region, or place"},
                ]
            },
            "threshold": 0.5,
        },
    )
    response.raise_for_status()

    result = response.json()
    entities = json.loads(result["choices"][0]["message"]["content"])
    print(json.dumps(entities, indent=2))
    ```

    ```javascript JavaScript
    const response = await fetch(
      "https://api.fastino.ai/v1/chat/completions",
      {
        method: "POST",
        headers: {
          Authorization: `Bearer ${process.env.FASTINO_API_KEY}`,
          "Content-Type": "application/json",
        },
        body: JSON.stringify({
          model: "fastino/gliner2.5-multi-v1",
          messages: [
            {
              role: "user",
              content: "Apple announced the MacBook Pro at WWDC in Cupertino.",
            },
          ],
          schema: {
            entities: [
              { name: "organization", description: "business or institution name" },
              { name: "product", description: "named commercial product" },
              { name: "event", description: "named conference or event" },
              { name: "location", description: "city, region, or place" },
            ],
          },
          threshold: 0.5,
        }),
      }
    );

    if (!response.ok) {
      throw new Error(`Inference failed: ${response.status} ${await response.text()}`);
    }

    const result = await response.json();
    const entities = JSON.parse(result.choices[0].message.content);
    console.log(JSON.stringify(entities, null, 2));
    ```

    </CodeGroup>

    En los modelos codificadores como GLiNER, el objeto `schema` define la tarea y puede incluir:

    - `entities` — definiciones de entidades para la extracción de entidades nombradas
    - `classifications` — definiciones `{task, labels}` para la clasificación de texto
    - `structures` — definiciones de registros estructurados para la extracción de JSON
    - `relations` — definiciones de relaciones

    En los modelos decodificadores, omite `schema` y envía un mensaje de chat normal.

    <Note>
      `model` debe ser el ID de un modelo base compatible con inferencia o el UUID de un trabajo de
      entrenamiento completado y desplegable. Después del entrenamiento, despliega el artefacto
      seleccionado antes de usar el UUID del trabajo para la inferencia.
    </Note>
  </Step>

  <Step title="Inicia un trabajo de entrenamiento (opcional)">
    Cuando quieras hacer ajuste fino con tus propios datos, inicia un trabajo de entrenamiento:

    <CodeGroup>

    ```bash curl
    curl -X POST https://api.fastino.ai/v1/training-jobs \
      -H "X-API-Key: $FASTINO_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model_name": "my-ner-model",
        "base_model": "fastino/gliner2-base-v1",
        "datasets": [{"name": "my-dataset"}],
        "training_type": "lora",
        "nr_epochs": 5,
        "learning_rate": 5e-5
      }'
    ```

    ```python Python
    import os
    import requests

    response = requests.post(
        "https://api.fastino.ai/v1/training-jobs",
        headers={
            "X-API-Key": os.environ["FASTINO_API_KEY"],
            "Content-Type": "application/json",
        },
        json={
            "model_name": "my-ner-model",
            "base_model": "fastino/gliner2-base-v1",
            "datasets": [{"name": "my-dataset"}],
            "training_type": "lora",
            "nr_epochs": 5,
            "learning_rate": 5e-5,
        },
    )
    response.raise_for_status()
    print(response.json())
    ```

    </CodeGroup>

    La respuesta incluye el `id` del trabajo. Consulta `GET /v1/training-jobs/{id}` periódicamente para comprobar su estado.
    Cuando el trabajo llegue a `complete`, despliega el artefacto seleccionado antes de usar el ID del trabajo como
    `model` en `/v1/chat/completions`.

    Los estados del trabajo avanzan de `requested` → `running` → `complete`, o terminan como `failed` o
    `stopped`.
  </Step>
</Steps>
