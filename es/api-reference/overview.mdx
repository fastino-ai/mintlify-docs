Usa esta página para elegir una familia de endpoints. OpenAPI define métodos, rutas, autenticación, campos y respuestas; las guías explican cuándo y por qué usarlos.

## Autenticación y convenciones

Los endpoints nativos usan `X-API-Key: $FASTINO_API_KEY`. Los endpoints compatibles usan la autenticación indicada en su referencia exacta. Consulta [Autenticación](/es/api-reference/authentication) y [Errores](/es/api-reference/errors).

## Elige un endpoint

| Tarea | Ruta canónica | Referencia |
| --- | --- | --- |
| Decisiones GLiDE | `POST /v1/systemone` | [Abrir referencia](/es/api-reference/decision/systemone) |
| Inferencia GLiNER y de decodificadores | `POST /v1/chat/completions` | [Abrir referencia](/es/api-reference/inference/chat-completions) |
| Compatibilidad con OpenAI Responses | `POST /v1/responses` | [Abrir referencia](/es/api-reference/inference/responses) |
| Compatibilidad con Anthropic Messages | `POST /v1/messages` | [Abrir referencia](/es/api-reference/inference/messages) |
| Entradas GLiNER-2 grandes | `POST /v1/gliner-2/async` + consulta del trabajo | [Abrir referencia](/es/api-reference/inference/gliner-2-async) |
| Capacidad y entrenamiento actuales | `GET /v1/base-models` | [Abrir referencia](/es/api-reference/models/base-models) |
| Lista de modelos para SDK compatibles | `GET /v1/models` | [Abrir referencia](/es/api-reference/models/compatibility-models) |
| Carga y versiones de datasets | `/v1/datasets` | [Abrir referencia](/es/api-reference/datasets/list) |
| Ciclo de entrenamiento | `/v1/training-jobs` | [Abrir referencia](/es/api-reference/training-jobs/create) |
| Historial y feedback de inferencia | `/v1/inferences` | [Abrir referencia](/es/api-reference/inference/history/list) |

## Guías por tarea

Para tu primera decisión GLiDE, usa [Inicio rápido](/es/quickstart). Para flujos completos, consulta [Modelos de decisión](/es/concepts/glide), [API de inferencia](/es/inference), [Preparación de datasets](/es/concepts/datasets) o [API de entrenamiento](/es/training).

Para consultar todas las operaciones en formato legible por máquinas, usa el [inventario de API](/es/api-reference/inventory) o [`openapi.json`](https://docs.fastino.ai/openapi.json).
