La API REST de Fastino te permite ejecutar inferencia, gestionar datasets, iniciar trabajos de entrenamiento y evaluar modelos de forma programática. Todos los recursos residen bajo una única URL base. La mayoría de las operaciones requieren tu clave de API; las rutas de catálogo explícitamente públicas, como `GET /v1/models`, no la requieren. Fastino también expone endpoints compatibles con OpenAI y Anthropic, por lo que puedes integrarlo con cualquier herramienta que ya admita esos formatos.

**URL base:** `https://api.fastino.ai`

## Autenticación

Las solicitudes nativas autenticadas usan un encabezado `X-API-Key`. Crea tu clave en el panel de Fastino en [agent.fastino.ai/api-keys](https://agent.fastino.ai/api-keys), o abre **Settings** -> **API Keys** después de iniciar sesión. Consulta la página de [Autenticación](/es/api-reference/authentication) para más detalles, incluyendo los endpoints de gestión de claves.

## Flujo de trabajo recomendado

Sigue esta secuencia cuando estés construyendo un modelo ajustado de principio a fin:

<Steps>
  <Step title="Crear o subir un dataset">
    Usa `POST /v1/generate` para generar datos etiquetados sintéticos. La respuesta incluye un `job_id`; consulta `GET /v1/generate/jobs/{job_id}` hasta que el estado devuelva `ready`.

    Para subir tus propios datos etiquetados, utiliza el flujo de subida en tres pasos:

    1. Llama a `POST /v1/datasets/upload/url` para obtener una URL prefirmada de S3,
    2. Envía tu archivo con `PUT` directamente a S3
    3. Llama a `POST /v1/datasets/upload/process` para iniciar el procesamiento.

    Consulta `GET /v1/datasets/{name}/{version}` hasta que el estado sea `ready`.<br />Consulta la página de [Datasets](/api-reference/datasets) para más detalles.
  </Step>
  <Step title="Iniciar un trabajo de entrenamiento">
    Llama a `POST /v1/training-jobs` con tu model\_name, datasets y base\_model. La respuesta incluye un `job_id`. Guárdalo para los siguientes pasos.
  </Step>
  <Step title="Consultar el estado del entrenamiento">
    Llama a `GET /v1/training-jobs/:id` repetidamente hasta que el campo de estado sea `complete`. Los trabajos completados incluyen métricas de F1, precisión y recall.
  </Step>
  <Step title="Ejecutar una evaluación">
    Crea una suite de evaluación con `POST /v1/projects/{project_id}/evaluation-suites` y, a continuación, ejecútala contra el modelo seleccionado antes de servir tráfico.
  </Step>
  <Step title="Ejecutar inferencia">
    Llama a `POST /v1/chat/completions` con `model` configurado como el ID de tu trabajo de entrenamiento y pasa tu entrada en `messages`. También puedes usar un ID de modelo base compatible sin ajuste fino.
  </Step>
</Steps>

<Note>
  Reemplaza los valores de marcador como `YOUR_DATASET_NAME` y `YOUR_TRAINING_JOB_ID` con valores reales antes de ejecutar cualquier comando de ejemplo.
</Note>

## Compatibilidad con OpenAI y Anthropic

Fastino ofrece reemplazos directos para los SDK de OpenAI y Anthropic. Utiliza tu clave de API de Fastino y la URL base específica de cada SDK que se indica a continuación.

| SDK | URL base | Notas |
| --- | --- | --- |
| OpenAI | `https://api.fastino.ai/v1` | Configura `base_url`; pasa los campos específicos de Fastino mediante `extra_body` |
| Anthropic | `https://api.fastino.ai` | Configura `base_url`; el SDK añade `/v1/messages` |

Pasa los campos específicos de Fastino como `schema` usando `extra_body` (SDK de OpenAI) o el mecanismo equivalente de parámetros adicionales para tu biblioteca cliente.

## Excepciones de `/v1` y rutas raíz

Las rutas nativas del producto usan el prefijo `/v1`. Las rutas compatibles con OpenAI y Anthropic mantienen sus rutas `/v1` existentes. Los recursos de protocolo y operativos permanecen en la raíz, incluidos `/health`, `/openapi.json` y `/.well-known/*`.

No antepongas `/v1` a ciegas. Usa la ruta exacta de esta referencia o del documento OpenAPI seleccionado.

## Migrar desde el origen de la API de Pioneer

Si una integración existente llama a `https://api.pioneer.ai`, actualiza su URL base a `https://api.fastino.ai`. Las rutas nativas de datasets, entrenamiento, proyectos, catálogo de modelos e historial de inferencias ahora usan el prefijo `/v1`. Por ejemplo, `/felix/training-jobs` ahora es `/v1/training-jobs`.

Las rutas compatibles con OpenAI y Anthropic ya empiezan por `/v1` y mantienen sus rutas existentes. No añadas un segundo prefijo: `/v1/chat/completions` sigue siendo `/v1/chat/completions`, no `/v1/v1/chat/completions`. Las integraciones directas con la API deben usar `FASTINO_API_KEY` con una clave `fast_sk_` recién generada; las claves heredadas `pio_sk_` están retiradas. Las formas de encabezado de autenticación `X-API-Key` y Bearer existentes siguen siendo válidas. La CLI de Fastino sigue leyendo `PIONEER_API_KEY` hasta que se publique su migración de configuración independiente.
