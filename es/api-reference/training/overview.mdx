sidebarTitle: "Descripción general"
description: "Contratos REST públicos para el entrenamiento gestionado y el ciclo de vida canónico compartido por los trabajos config e interactive."
---

Usa estos contratos para detalles de campos. Empieza con las guías de ciclo de vida para un flujo completo.

La API REST pública incluye:

- Descubrimiento de modelos base y gestión de datasets
- Creación de trabajos `config` gestionados con `POST /v1/training/jobs`
- Operaciones del ciclo de vida canónico bajo `/v1/training/jobs` para trabajos
  `config` e `interactive`

Para las operaciones de modelo de los bucles personalizados, accede a la API de
entrenamiento mediante el SDK de Tinker compatible. La interfaz HTTP del SDK en
`/v1/training/compat/tinker` no aparece en OpenAPI ni es un contrato REST para
solicitudes directas. Auto Train sigue siendo de acceso privado y no tiene un
contrato de API público.
