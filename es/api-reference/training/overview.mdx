Usa estos contratos para detalles de campos. Empieza con las guías de ciclo de vida para un flujo completo.

La API REST pública incluye:

- Descubrimiento de modelos base y gestión de datasets
- Creación de trabajos `config` gestionados con `POST /v1/training/jobs` para codificadores GLiNER
- [Trabajos interactivos](/es/api-reference/training-jobs/interactive/create-model) para entrenar decodificadores:
  `POST /v1/training/jobs/create-model` y, después, pasadas forward-backward,
  pasos del optimizador, checkpoints y muestreo bajo `/v1/training/jobs/{job_id}`
- Operaciones del ciclo de vida canónico bajo `/v1/training/jobs` para trabajos
  `config` e `interactive`

Auto Train sigue siendo de acceso
privado y no tiene un contrato de API público.
