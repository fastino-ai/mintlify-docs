Usa estos contratos para detalles de campos. Empieza con las guías de ciclo de vida para un flujo completo.

La API REST pública incluye:

- Descubrimiento de modelos base y gestión de datasets
- Creación de trabajos `config` gestionados con `POST /v1/training/jobs` para codificadores y decodificadores compatibles
- [Trabajos interactivos](/es/api-reference/interactive-jobs/create) para entrenamiento manual de decodificadores:
  `POST /v1/training/jobs/create-model` y, después, pasadas forward-backward,
  pasos del optimizador, checkpoints y muestreo bajo `/v1/training/jobs/{job_id}`
- Operaciones del ciclo de vida canónico bajo `/v1/training/jobs` para trabajos
  `config` e `interactive`

Los clientes JSON nativos usan las operaciones públicas de OpenAPI bajo `/v1/training/jobs` y `/v1/training/usage`. Los clientes Tinker existentes mantienen `tinker==0.32.0` y configuran solo `TINKER_BASE_URL=https://api.fastino.ai/v1/training/compat/tinker` y `TINKER_CREDENTIAL_CMD`. No construyas rutas hijas privadas de compatibilidad.
