`POST /v1/gliner-2`

El panel OpenAPI es la fuente de verdad para todos los campos de solicitud y
respuesta. Usa el schema unificado de GLiNER y omite el campo obsoleto `task`.

## Solicitud de extracción de entidades

```json
{
  "text": "Apple CEO Tim Cook introduced the iPhone in Cupertino.",
  "schema": {
    "entities": [
      {"name": "person", "description": "named individual"},
      {"name": "organization", "description": "business or institution"},
      {"name": "product", "description": "named commercial product"},
      {"name": "location", "description": "city, region, or place"}
    ]
  },
  "threshold": 0.5,
  "include_confidence": true,
  "include_spans": true
}
```

`schema` también admite `classifications`, `structures` y `relations`. Consulta
el schema completo y más ejemplos en
[`POST /v1/chat/completions`](/es/api-reference/inference/chat-completions).

## Respuesta correcta

```json
{
  "result": {
    "entities": [
      {
        "text": "Apple",
        "label": "organization",
        "score": 0.99,
        "start": 0,
        "end": 5
      }
    ]
  },
  "token_usage": 10
}
```
