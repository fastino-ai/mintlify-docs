`POST /inference` se ha eliminado.

Usa `POST /v1/chat/completions` para la inferencia alojada de GLiNER. La solicitud actual usa
`Authorization: Bearer $FASTINO_API_KEY` con los campos de nivel superior `model`, `messages` y `schema`.

Consulta [`/v1/chat/completions`](/es/inference/chat-completions) para ver la solicitud, la respuesta
y la guía de migración canónicas.
