Fastino ofrece endpoints compatibles con OpenAI para usar métodos compatibles del SDK de OpenAI con modelos de Fastino. Define `base_url` como `https://api.fastino.ai/v1`, autentícate con tu clave de API de Fastino y pasa como `model` un ID devuelto por `GET /v1/models` o el ID de tu trabajo de entrenamiento. Los campos específicos de Fastino, como `schema`, se pueden pasar mediante `extra_body` en el SDK de Python o incluir directamente en el cuerpo JSON.

<Tip>
  Para los métodos compatibles que se indican a continuación, una integración existente con OpenAI normalmente solo necesita un nuevo `base_url`, una clave de API y un ID de modelo.
</Tip>

## Superficie compatible del SDK

| Método del SDK de OpenAI | Endpoint de Fastino | Streaming |
|---|---|---|
| `client.chat.completions.create(...)` | `POST /v1/chat/completions` | Sí |
| `client.responses.create(...)` | `POST /v1/responses` | Sí |
| `client.models.list()` | `GET /v1/models` | No aplica |

<Warning>
  Fastino no implementa todas las API ni todos los recursos del SDK de OpenAI. Usa únicamente los métodos indicados arriba. El endpoint heredado `POST /v1/completions` se eliminó; migra las solicitudes basadas en prompts a Chat Completions.
</Warning>

## Configurar el SDK de OpenAI

Apunta el SDK a la URL base de Fastino y proporciona tu clave de API de Fastino:

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai/v1"
)
```

```bash cURL (base URL)
# Set this as the base for all requests
https://api.fastino.ai/v1
```

</CodeGroup>

## Chat completions

`POST /v1/chat/completions` acepta los campos principales de OpenAI Chat Completions. Pasa un ID de modelo compatible como `model` e incluye campos específicos de Fastino, como `schema`, en el cuerpo de la solicitud o mediante `extra_body`.

<CodeGroup>

```python Python (OpenAI SDK)
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai/v1"
)

response = client.chat.completions.create(
    model="YOUR_TRAINING_JOB_ID",
    messages=[
        {
            "role": "user",
            "content": "Extract entities from: Apple launched the iPhone."
        }
    ],
    extra_body={
        "schema": {
            "entities": ["organization", "product"]
        }
    }
)

print(response.choices[0].message.content)
```

```bash cURL
curl -X POST https://api.fastino.ai/v1/chat/completions \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_TRAINING_JOB_ID",
    "messages": [
      {
        "role": "user",
        "content": "Extract entities from: Apple launched the iPhone."
      }
    ],
    "schema": {
      "entities": ["organization", "product"]
    }
  }'
```

</CodeGroup>

## Listar los modelos disponibles

Usa `GET /v1/models` para obtener la lista de modelos que puedes usar con estos endpoints.

<CodeGroup>

```python Python (OpenAI SDK)
models = client.models.list()
for model in models.data:
    print(model.id)
```

```bash cURL
curl https://api.fastino.ai/v1/models \
  -H "X-API-Key: YOUR_API_KEY"
```

</CodeGroup>

## Streaming

Chat Completions y Responses admiten streaming. Define `stream=True` en el SDK o `"stream": true` en el cuerpo de la solicitud.

<CodeGroup>

```python Python (OpenAI SDK)
stream = client.chat.completions.create(
    model="YOUR_TRAINING_JOB_ID",
    messages=[{"role": "user", "content": "Summarize the following article: ..."}],
    stream=True
)

for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="")
```

```bash cURL
curl -X POST https://api.fastino.ai/v1/chat/completions \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_TRAINING_JOB_ID",
    "messages": [{"role": "user", "content": "Summarize the following article: ..."}],
    "stream": true
  }'
```

</CodeGroup>

## Pasar campos específicos de Fastino

El campo `schema` es una extensión de Fastino. En el SDK de Python de OpenAI, pásalo mediante `extra_body` para que se incluya en la solicitud sin afectar a la validación del SDK. En una solicitud HTTP sin procesar, inclúyelo en el nivel superior del cuerpo JSON junto con campos estándar como `model` y `messages`.
