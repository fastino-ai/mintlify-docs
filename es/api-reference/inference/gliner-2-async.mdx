`POST /v1/gliner-2/async`

Envía entradas muy grandes de GLiNER-2 para su procesamiento asíncrono. Usa este endpoint cuando la
entrada supere un millón de tokens o pueda exceder el tiempo de espera de la solicitud síncrona.

El panel OpenAPI de esta página es la fuente de verdad para cada campo de la solicitud y de la
respuesta `202`. La solicitud usa el mismo esquema nativo de GLiNER que
[`POST /v1/gliner-2`](/es/api-reference/inference/gliner-2).

## Ejemplo de solicitud

```bash
curl -X POST "https://api.fastino.ai/v1/gliner-2/async" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "A very large document to process asynchronously...",
    "schema": {
      "entities": [
        {"name": "person", "description": "named individual"},
        {"name": "organization", "description": "business or institution"}
      ]
    },
    "threshold": 0.5,
    "include_confidence": true,
    "include_spans": true
  }'
```

`text` también puede ser un array de cadenas. Omite el campo obsoleto `task`; el esquema
unificado identifica la extracción, la clasificación, las estructuras o las relaciones.

## Respuesta aceptada

El endpoint devuelve HTTP `202` de inmediato. Este payload ilustrativo acorta
`message`; el servicio proporciona una ruta de consulta concreta que contiene el ID de trabajo devuelto.

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "accepted",
  "estimated_tokens": 1284307,
  "message": "Job queued. ..."
}
```

Guarda `job_id` y luego consulta
[`GET /v1/gliner-2/jobs/{job_id}`](/es/api-reference/inference/gliner-2-job-status)
con la misma API key. Los trabajos están limitados al usuario autenticado.
