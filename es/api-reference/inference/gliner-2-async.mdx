`POST /v1/gliner-2/async`

El panel OpenAPI es la fuente de verdad para todos los campos de solicitud y de
la respuesta `202`. Usa este endpoint para más de un millón de tokens o cuando
la solicitud pueda superar el tiempo de espera síncrono.

## Ejemplo de solicitud

```json
{
  "text": "A very large document to process asynchronously...",
  "schema": {
    "entities": [
      {"name": "person", "description": "named individual"},
      {"name": "organization", "description": "business or institution"}
    ]
  },
  "threshold": 0.5,
  "include_confidence": true,
  "include_spans": true
}
```

## Respuesta aceptada

El ejemplo siguiente abrevia `message`; el servicio devuelve una ruta de
consulta concreta con el ID del trabajo.

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "accepted",
  "estimated_tokens": 1284307,
  "message": "Job queued. ..."
}
```

Guarda `job_id` y consulta con la misma clave de API
[`GET /v1/gliner-2/jobs/{job_id}`](/es/api-reference/inference/gliner-2-job-status).
