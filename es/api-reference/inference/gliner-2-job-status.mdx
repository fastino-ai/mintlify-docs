`GET /v1/gliner-2/jobs/{job_id}`

El panel OpenAPI es la fuente de verdad para el parámetro de ruta y todos los
campos de respuesta. Usa la misma clave de API que envió el trabajo.

## Solicitud

```bash
curl "https://api.fastino.ai/v1/gliner-2/jobs/3f08a17f-777a-4aa6-8ec5-879df37775a8" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

## Respuesta pendiente

Sigue consultando mientras `status` sea `pending` o `processing`:

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "pending",
  "result": null,
  "error": null,
  "token_usage": 1284307,
  "created_at": "2026-10-07T22:10:00+00:00",
  "completed_at": null
}
```

## Respuesta completa

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "complete",
  "result": {
    "entities": [
      {"text": "Apple", "label": "organization", "score": 0.99, "start": 0, "end": 5}
    ]
  },
  "error": null,
  "token_usage": 1284307,
  "created_at": "2026-10-07T22:10:00+00:00",
  "completed_at": "2026-10-07T22:13:42+00:00"
}
```

Los trabajos fallidos devuelven `status: "error"` y un mensaje en `error`.
Los trabajos desconocidos o de otro usuario devuelven `404`.
