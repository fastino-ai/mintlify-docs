`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

Elimina un checkpoint. Deja de contar para el almacenamiento de inmediato; sus archivos se purgan después. `kind` es `weights` o `sampler_weights`. Devuelve `204 No Content`.

<RequestExample>

```bash cURL
curl -X DELETE "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
