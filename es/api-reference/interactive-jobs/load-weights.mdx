`POST /v1/training/jobs/{job_id}/load-weights`

Restaura uno de los checkpoints `weights/<name>` de este trabajo en el mismo trabajo, por ejemplo para revertir una mala actualización. Para continuar en un trabajo nuevo, pasa su ruta como `from_checkpoint` a [`POST /v1/training/jobs/create-model`](/es/api-reference/interactive-jobs/create).

<ParamField header="X-API-Key" type="string" required>
  Tu clave de API de Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID del trabajo interactivo.
</ParamField>

<ParamField body="path" type="string" required>
  El nombre de un checkpoint de estado guardado por este trabajo, o su ruta `tinker://<job_id>/weights/<name>`.
</ParamField>

<ParamField body="optimizer" type="boolean" default="false">
  Restaura también el estado del optimizador.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/load-weights" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"path": "step-000100", "optimizer": true}'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "load"
}
```

</ResponseExample>
