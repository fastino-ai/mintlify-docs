`POST /v1/training/jobs/{job_id}/sample`

Genera continuaciones de un prompt tokenizado con uno de los checkpoints `sampler` del trabajo.
También funciona después de detener el trabajo. Lee los tokens generados en `result.sequences`
del future completado y decodifícalos con el mismo tokenizador.

<ParamField header="X-API-Key" type="string" required>
  Tu clave de API de Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID del trabajo interactivo.
</ParamField>

<ParamField body="checkpoint" type="string" required>
  El nombre de un checkpoint sampler guardado por este trabajo, o su ruta
  `tinker://<job_id>/sampler_weights/<name>`.
</ParamField>

<ParamField body="prompt_tokens" type="integer[]" required>
  IDs de token del prompt según el tokenizador del modelo base. Al menos uno.
</ParamField>

<ParamField body="num_samples" type="integer" default="1">
  Número de continuaciones.
</ParamField>

<ParamField body="sampling_params" type="object">
  Ajustes de decodificación: `max_tokens`, `temperature` (por defecto `1.0`), `top_p` (`1.0`),
  `top_k` (`-1` lo desactiva), `stop` y `seed`.
</ParamField>

<ParamField body="prompt_logprobs" type="boolean" default="false">
  Devuelve también la log-probabilidad de cada token del prompt.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/sample" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "checkpoint": "step-000100",
    "prompt_tokens": [151644, 872, 198, 3838],
    "num_samples": 2,
    "sampling_params": {"max_tokens": 64, "temperature": 0.7}
  }'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "sample"
}
```

</ResponseExample>
