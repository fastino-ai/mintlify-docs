`POST /v1/training/jobs/{job_id}/save-weights`

Guarda los pesos LoRA y el estado del optimizador del trabajo como `weights/<name>`. Puedes [cargarlo](/es/api-reference/interactive-jobs/load-weights) de nuevo en el mismo trabajo o [iniciar un trabajo nuevo](/es/api-reference/interactive-jobs/create) desde él. Para muestrear o descargar pesos, guárdalos con [`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`](/es/api-reference/interactive-jobs/save-weights-for-sampler).

<ParamField header="X-API-Key" type="string" required>
  Tu clave de API de Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID del trabajo interactivo.
</ParamField>

<ParamField body="name" type="string" required>
  De 1 a 128 caracteres de `A-Z`, `a-z`, `0-9`, `.`, `_` y `-`.
</ParamField>

<ParamField body="ttl_seconds" type="integer | null">
  Elimina el checkpoint automáticamente tras estos segundos, de `3600` (1 hora) a `315360000`
  (10 años). Omítelo para conservarlo hasta que lo elimines.
</ParamField>

<ParamField body="overwrite" type="boolean" default="false">
  Reemplaza un checkpoint de estado con el mismo nombre.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/save-weights" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "step-000100"}'
```

</RequestExample>

La respuesta contiene el `future_id` del future `save`, `checkpoint_id` y `path`. Pasa `path` como `from_checkpoint` al crear un trabajo.

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "save",
  "checkpoint_id": "weights/step-000100",
  "path": "tinker://SESSION_ID:train:0/weights/step-000100"
}
```

</ResponseExample>
