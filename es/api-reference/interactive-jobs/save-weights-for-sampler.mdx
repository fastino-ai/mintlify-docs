`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

Guarda los pesos LoRA del trabajo como `sampler_weights/<name>`. Puedes [muestrear](/es/api-reference/interactive-jobs/sample) desde él, también después de detener el trabajo, o [descargarlo](/es/api-reference/training-jobs/download-checkpoint) como archivos PEFT LoRA. No incluye el estado del optimizador, así que un trabajo no puede cargarlo ni iniciarse desde él; para eso usa [`POST /v1/training/jobs/{job_id}/save-weights`](/es/api-reference/interactive-jobs/save-weights).

<ParamField header="X-API-Key" type="string" required>
  Tu clave de API de Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID del trabajo interactivo.
</ParamField>

<ParamField body="name" type="string" required>
  De 1 a 128 caracteres de `A-Z`, `a-z`, `0-9`, `.`, `_` y `-`.
</ParamField>

<ParamField body="ttl_seconds" type="integer | null">
  Elimina el checkpoint automáticamente tras estos segundos, de `3600` (1 hora) a `315360000`
  (10 años). Omítelo para conservarlo hasta que lo elimines.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/save-weights-for-sampler" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "step-000100", "ttl_seconds": 86400}'
```

</RequestExample>

La respuesta contiene el `future_id` del future `save`, `checkpoint_id` y `path`.

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "save",
  "checkpoint_id": "sampler_weights/step-000100",
  "path": "tinker://SESSION_ID:train:0/sampler_weights/step-000100"
}
```

</ResponseExample>
