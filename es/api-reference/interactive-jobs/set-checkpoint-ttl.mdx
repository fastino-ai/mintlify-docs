`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

Conserva un checkpoint `ttl_seconds` a partir de ahora y luego lo elimina, de `3600` (1 hora) a `315360000` (10 años). Envía `null` para conservarlo hasta que lo elimines. `kind` es `weights` o `sampler_weights`. Devuelve `204 No Content`.

<RequestExample>

```bash cURL
curl -X PUT "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100/ttl" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"ttl_seconds": 604800}'
```

</RequestExample>
