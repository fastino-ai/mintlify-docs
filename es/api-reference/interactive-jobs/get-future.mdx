`GET /v1/training/jobs/{job_id}/futures/{future_id}`

Lee el future hasta que su `status` sea `completed`, `failed` o `cancelled`. Los resultados se
conservan una hora. Con `wait=true`, la solicitud espera hasta 25 segundos.

- `type`: `create`, `load`, `forward`, `forward_backward`, `optim_step`, `save` o `sample`.
- `result` (cuando es `completed`): `loss_fn_outputs` y `metrics` para forward; `sequences`
  (cada una con `tokens`, `logprobs` y `stop_reason`) para `sample`; la ruta del checkpoint para `save`.
- `error` (cuando es `failed` o `cancelled`): `message` y `category` (`user` o `server`).

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/futures/$FUTURE_ID?wait=true" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
