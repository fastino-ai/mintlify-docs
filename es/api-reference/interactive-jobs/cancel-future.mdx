`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

Cancela, en la medida de lo posible, una future `sample` en cola o en ejecución. Las operaciones de entrenamiento se ejecutan en orden y no se cancelan. Devuelve `204 No Content`.

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/futures/$FUTURE_ID/cancel" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
