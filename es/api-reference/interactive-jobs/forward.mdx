`POST /v1/training/jobs/{job_id}/forward`

Calcula la pérdida y las log-probabilidades por token de un lote sin acumular gradientes. Úsalo
para evaluar. El cuerpo, la respuesta y el resultado coinciden con
[`POST /v1/training/jobs/{job_id}/forward-backward`](/es/api-reference/interactive-jobs/forward-backward);
el `type` de la operación es `forward`.

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/forward" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "datums": [
      {
        "model_input": {"chunks": [{"type": "encoded_text", "tokens": [151644, 872, 198, 3838]}]},
        "loss_fn_inputs": {
          "target_tokens": {"data": [872, 198, 3838, 30], "dtype": "int64"}
        }
      }
    ]
  }'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "forward"
}
```

</ResponseExample>
