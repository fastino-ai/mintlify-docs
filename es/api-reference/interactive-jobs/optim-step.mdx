`POST /v1/training/jobs/{job_id}/optim-step`

Aplica con AdamW los gradientes acumulados por las pasadas forward-backward desde el último
paso. El trabajo ejecuta las operaciones en el orden en que las recibe, así que puedes encolarlo
justo después de una pasada forward-backward sin esperar.

<ParamField header="X-API-Key" type="string" required>
  Tu clave de API de Fastino.
</ParamField>

<ParamField path="job_id" type="string" required>
  ID del trabajo interactivo.
</ParamField>

<ParamField body="adam_params" type="object">
  Parámetros AdamW opcionales: `learning_rate` (por defecto `0.0001`), `beta1` (`0.9`), `beta2`
  (`0.95`), `eps` (`1e-12`), `weight_decay` (`0`) y `grad_clip_norm` (`0` desactiva el recorte).
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/optim-step" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"adam_params": {"learning_rate": 0.0001}}'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "future_id": "FUTURE_ID",
  "job_id": "SESSION_ID:train:0",
  "type": "optim_step"
}
```

</ResponseExample>
