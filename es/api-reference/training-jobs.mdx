La API de trabajos de entrenamiento gestiona el ciclo de vida completo de un trabajo de ajuste fino. Todos los endpoints usan la familia de rutas `/felix/training-jobs` y requieren una clave de API en el encabezado `X-API-Key`.

```bash
-H "X-API-Key: YOUR_API_KEY"
```

Usa `GET /base-models?supports_training=true` inmediatamente antes de crear un trabajo. Es la fuente de verdad en tiempo real para los IDs de modelos entrenables.

El [documento OpenAPI de producción](https://api.pioneer.ai/openapi.json) es la fuente de verdad legible por máquina para los esquemas actuales de solicitud y respuesta.

## Flujo de trabajo típico

<Steps>
  <Step title="Crear un trabajo">
    Envía un dataset listo (`ready`) y un `base_model` actualmente soportado.
  </Step>
  <Step title="Consultar el trabajo">
    Lee `normalized_status` y detén la consulta cuando `is_terminal_status` sea `true`.
  </Step>
  <Step title="Inspeccionar el resultado">
    Lee los logs de la instantánea, las métricas de entrenamiento, la facturación y los checkpoints.
  </Step>
  <Step title="Entregar el artefacto">
    Despliega un checkpoint desplegable o descarga los pesos.
  </Step>
</Steps>

## Ciclo de vida del estado

El `status` persistido puede incluir `requested`, `running`, `complete`, `normalizing`, `artifact_ready`, `deployed`, `paused`, `errored`, `stopped` y `terminated`.

Para la automatización, prefiere:

- `normalized_status`: estado estable de compatibilidad, como `requested`, `running`, `complete`, `deployed`, `failed` o `cancelled`.
- `is_terminal_status`: si un bucle de consulta puede detenerse.
- `error_message`: detalles del fallo cuando estén disponibles.
- `is_deployable` y `deployability_reason`: la decisión del servidor sobre si el modelo está listo para desplegarse.

<Note>
  El objeto `metrics` puede contener `final_training_loss`, `final_validation_loss` y `best_validation_loss`. Las métricas de calidad de evaluación son independientes y no se garantiza que estén presentes.
</Note>

## Endpoints

| Método | Endpoint | Propósito |
| --- | --- | --- |
| `POST` | [`/felix/training-jobs`](/es/api-reference/training-jobs/create) | Crear un trabajo de entrenamiento |
| `GET` | [`/felix/training-jobs`](/es/api-reference/training-jobs/list) | Listar trabajos de entrenamiento |
| `GET` | [`/felix/training-jobs/{job_id}`](/es/api-reference/training-jobs/get) | Obtener el estado, la configuración y las métricas |
| `PATCH` | [`/felix/training-jobs/{job_id}`](/es/api-reference/training-jobs/update-project) | Asignar o desasignar un proyecto |
| `PATCH` | [`/felix/training-jobs/{job_id}/model-name`](/es/api-reference/training-jobs/update-model-name) | Renombrar el modelo entrenado |
| `GET` | [`/felix/training-jobs/{job_id}/logs`](/es/api-reference/training-jobs/logs) | Obtener una instantánea de los logs de entrenamiento |
| `GET` | [`/felix/training-jobs/{job_id}/billing`](/es/api-reference/training-jobs/billing) | Obtener el resultado de facturación |
| `POST` | [`/felix/training-jobs/{job_id}/stop`](/es/api-reference/training-jobs/stop) | Detener un trabajo y preservar los checkpoints |
| `POST` | [`/felix/training-jobs/{job_id}/terminate`](/es/api-reference/training-jobs/terminate) | Detener un trabajo y eliminar los checkpoints |
| `GET` | [`/felix/training-jobs/{job_id}/checkpoints`](/es/api-reference/training-jobs/checkpoints) | Listar checkpoints |
| `POST` | [`/felix/training-jobs/{job_id}/checkpoints/{checkpoint_id}/deploy`](/es/api-reference/training-jobs/deploy-checkpoint) | Desplegar un checkpoint |
| `GET` | [`/felix/training-jobs/{job_id}/download`](/es/api-reference/training-jobs/download) | Obtener una URL temporal de descarga de pesos |
| `DELETE` | [`/felix/training-jobs/{job_id}`](/es/api-reference/training-jobs/delete) | Eliminar un trabajo y sus checkpoints |

La ruta obsoleta `GET /felix/training-jobs/{job_id}/deployments` no forma parte de esta referencia. Usa `/projects/{project_id}/deployments` en su lugar.
