`GET /v1/datasets`

Esta página documenta `GET /v1/datasets`. La especificación OpenAPI es la fuente canónica para parámetros, respuestas y autenticación.

## Comportamiento de los resultados

De forma predeterminada, la respuesta contiene la versión más reciente de cada
nombre de dataset y excluye las cargas fallidas. Usa
`include_all_versions=true` para devolver todas las versiones o
`include_failed=true` para incluir tus cargas fallidas.

Los resultados más recientes aparecen primero. `limit` es 200 de forma
predeterminada y como máximo; usa `offset` para solicitar páginas posteriores.
