`POST /v1/datasets/upload/url`

Esta página documenta `POST /v1/datasets/upload/url`. La especificación OpenAPI es la fuente canónica para parámetros, respuestas y autenticación.

## Sube el archivo

Sube los bytes exactos del archivo a `presigned_url` antes de que caduque. La
solicitud firmada requiere `Content-Type: application/octet-stream`; omitir
este encabezado o usar otro valor devuelve `403`.

```bash
curl --fail-with-body -X PUT \
  -H "Content-Type: application/octet-stream" \
  --upload-file training.jsonl "$PRESIGNED_URL"
```

Después de una carga correcta, pasa el `dataset_id` devuelto a
[`POST /v1/datasets/upload/process`](/es/api-reference/datasets/process-upload).

## Autorización

Requiere el rol Owner, Admin o Editor del equipo. Los demás roles reciben `403 Forbidden`.
