`POST /v1/datasets/upload/process`

Esta página documenta `POST /v1/datasets/upload/process`. La especificación OpenAPI es la fuente canónica para parámetros, respuestas y autenticación.

## Procesamiento asíncrono

Una solicitud correcta devuelve `202` y pone el procesamiento en cola; el
dataset todavía no está listo. Consulta
[`GET /v1/datasets/{name}`](/es/api-reference/datasets/versions), selecciona el
`version_number` exacto devuelto al crear la URL de carga y espera a que
`status` sea `ready` o `failed`. Si falla, lee `processing_error` antes de
corregir el archivo y subir una versión nueva.

Un `503` indica que la verificación del almacenamiento o la puesta en cola
falló antes de empezar; se puede reintentar la misma carga.

## Autorización

Requiere el rol Owner, Admin o Editor del equipo. Los demás roles reciben `403 Forbidden`.
