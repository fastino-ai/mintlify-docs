`DELETE /v1/datasets/{name}`

Elimina de forma lógica un dataset y todas sus versiones almacenadas por
nombre. Esta ruta no elimina una sola versión seleccionada.

## Autorización

Requiere el rol Owner, Admin o Editor del equipo. Los demás roles reciben `403 Forbidden`.
