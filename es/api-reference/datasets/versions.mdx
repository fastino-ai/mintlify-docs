`GET /v1/datasets/{name}`

Esta página documenta `GET /v1/datasets/{name}`. La especificación OpenAPI es la fuente canónica para parámetros, respuestas y autenticación.

## Estado del procesamiento

La respuesta contiene `success`, `versions` y `count`. Al consultar una carga
reciente, selecciona exactamente su `version_number`. Una versión solo se puede
usar para entrenar cuando su `status` es `ready`; las versiones `failed`
incluyen `processing_error`.
