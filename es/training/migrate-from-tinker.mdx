---
title: "Migrar desde Tinker"
description: "Ejecuta una carga de trabajo existente del SDK de Tinker en Fastino."
---

No necesitas reescribir el bucle de entrenamiento. Fastino admite el SDK de
Python `tinker==0.32.0`. Cambia la URL base y la credencial del SDK y ejecuta
tu programa existente.

## 1. Instala el SDK compatible

<CodeGroup>

```bash uv
uv add "tinker==0.32.0"
```

```bash pip
pip install "tinker==0.32.0"
```

</CodeGroup>

## 2. Apunta el SDK a Fastino

<CodeGroup>

```bash macOS/Linux
export FASTINO_API_KEY="fast_sk_..."
export TINKER_BASE_URL="https://api.fastino.ai/v1/training/compat/tinker"
export TINKER_CREDENTIAL_CMD='printf "%s\n" "$FASTINO_API_KEY"'
```

```powershell Windows
$env:FASTINO_API_KEY = "fast_sk_..."
$env:TINKER_BASE_URL = "https://api.fastino.ai/v1/training/compat/tinker"
$env:TINKER_CREDENTIAL_CMD = 'powershell -NoProfile -Command "[Console]::Out.WriteLine($env:FASTINO_API_KEY)"'
```

</CodeGroup>

`TINKER_CREDENTIAL_CMD` se ejecuta con cada solicitud de token y debe imprimir
una credencial no vacía. Usa una clave normal `fast_sk_` de Fastino; las
credenciales `tml-` se rechazan. No establezcas `TINKER_API_KEY`.

## 3. Verifica la conexión

```python
import tinker

service_client = tinker.ServiceClient()
print(service_client.get_server_capabilities())
```

Elige un modelo devuelto por `get_server_capabilities()` y ejecuta una versión
pequeña de tu carga. La prueba debe completar una actualización, guardar y
recargar el estado y guardar pesos del muestreador con un TTL explícito antes
de muestrear. Aumenta la carga cuando termine.

## Compatibilidad con el SDK de Tinker

Cada cliente de entrenamiento de Tinker es un trabajo interactivo de Fastino.
El ID de modelo del SDK también es su ID en `/v1/training/jobs`.

| Área | Comportamiento compatible |
| --- | --- |
| Entrenamiento | Crea o restaura un cliente; inspecciona y ejecuta operaciones forward, forward/backward, pérdida personalizada y optimizador |
| Checkpoints | Guarda y carga estado; guarda pesos del muestreador; inspecciona, lista, descarga, elimina, publica y configura retención |
| Muestreo | Crea o recupera un cliente de muestreo y llama a `sample` |
| Futures | Recupera resultados asíncronos individuales; cancela futures de muestreo sin terminar |
| Uso | Lista ejecuciones interactivas y consulta almacenamiento o uso facturado por hora |

<AccordionGroup>
  <Accordion title="Llamadas de administración compatibles">
    Fastino admite `list_training_runs`, `get_training_run`,
    `list_checkpoints`, `list_user_checkpoints`,
    `get_weights_info_by_tinker_path`, `get_checkpoint_archive_url`,
    `delete_checkpoint_from_tinker_path`,
    `publish_checkpoint_from_tinker_path`,
    `unpublish_checkpoint_from_tinker_path`,
    `set_checkpoint_ttl_from_tinker_path`,
    `get_current_checkpoint_storage_usage` y `get_billing_usage`.
  </Accordion>
  <Accordion title="Límites">
    - El rango LoRA debe estar entre 1 y 32.
    - El optimizador es AdamW.
    - Las pérdidas compatibles son `cross_entropy`, `importance_sampling`, `ppo`, `cispo` y `dro`.
    - Los fragmentos de prompt deben usar `encoded_text`.
    - Las operaciones de entrenamiento se ejecutan en orden y sus futures no se pueden cancelar.
    - Las descargas requieren acceso de descarga de pesos. Sin él devuelven `403`; contacta con sales@fastino.ai.
    - La publicación solo cambia la visibilidad dentro del equipo propietario.
  </Accordion>
  <Accordion title="Llamadas no compatibles">
    - Recuperación por lotes con `retrieve_futures`
    - `save_weights_external` y `external_weights_urls`
    - Exportación de trazas de sesión y entradas del registro de auditoría
    - Muestreo sin `SamplingClient`
    - `target_prompt_logprobs` y valores positivos de `prompt_alt_tokens_k`
  </Accordion>
</AccordionGroup>

Si falla la autenticación, confirma que `TINKER_CREDENTIAL_CMD` imprima
exactamente una clave `fast_sk_` actual y que `TINKER_BASE_URL` coincida con el
valor anterior.
