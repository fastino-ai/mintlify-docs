Esta guía rápida cubre las dos vías de la API de entrenamiento. Usa el
entrenamiento gestionado cuando quieras que Fastino ejecute el bucle. Usa un
bucle de entrenamiento personalizado cuando tu aplicación deba controlar el
muestreo, las recompensas y las actualizaciones del modelo.

## 1. Autentícate

1. Crea una [cuenta de Fastino](https://agent.fastino.ai/).
2. Abre [Claves de API](https://agent.fastino.ai/api-keys).
3. Crea una clave y cópiala cuando se muestre.

Guarda la clave en una variable de entorno:

<CodeGroup>

```bash macOS/Linux
export FASTINO_API_KEY="fast_sk_..."
```

```powershell Windows
$env:FASTINO_API_KEY = "fast_sk_..."
```

</CodeGroup>

Envía esta clave como `X-API-Key: $FASTINO_API_KEY`. Consulta
[Autenticación](/es/authentication) para ver el contrato de autenticación
completo.

## 2. Elige una vía

| Objetivo | Vía |
| --- | --- |
| Proporcionar datos y configuración y dejar que Fastino ejecute el entrenamiento | [Entrenamiento gestionado](#managed-training) |
| Controlar el muestreo, las recompensas y las actualizaciones en tu aplicación | [Bucle de entrenamiento personalizado](#custom-training-loop) |

## Entrenamiento gestionado

### 3. Prepara un dataset

[Sube y procesa un dataset de entrenamiento](/es/concepts/datasets) y espera
hasta que su versión esté `ready`.

### 4. Elige un modelo

Consulta el catálogo activo antes del envío:

```bash
curl "https://api.fastino.ai/v1/base-models?supports_training=true" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

Guarda el ID del modelo seleccionado.

### 5. Crea el trabajo

```bash
curl -X POST "https://api.fastino.ai/v1/training/jobs" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  -d '{
    "model_name": "my-trained-model",
    "base_model": "MODEL_ID_FROM_CATALOG",
    "datasets": [
      {"name": "my-ready-dataset", "version": "VERSION_NUMBER"}
    ],
    "training_type": "lora"
  }'
```

Guarda el `id` devuelto. Es el `job_id` que usan todas las rutas específicas
del trabajo. Reutiliza la misma `Idempotency-Key` únicamente al reintentar esta
misma solicitud de creación.

### 6. Consulta el trabajo

```bash
curl "https://api.fastino.ai/v1/training/jobs/JOB_ID" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

Para los trabajos de configuración:

- `status` es el valor persistido del ciclo de vida, como `errored`.
- `normalized_status` es el valor estable para las consultas, como `failed`.
- `is_terminal_status` indica al cliente cuándo dejar de consultar.
- `error_message` describe un fallo cuando está disponible.

Continúa hasta que `is_terminal_status` sea `true` y, después, inspecciona el
estado final, los checkpoints, los logs y la posibilidad de despliegue.

## Bucle de entrenamiento personalizado

Los bucles de entrenamiento personalizados requieren Python 3.11 o posterior.
Accede a la API de entrenamiento mediante los siguientes métodos del SDK de
Tinker compatible. No construyas solicitudes HTTP equivalentes.

### 3. Instala el cliente probado

<CodeGroup>

```bash uv
uv init fastino-training
cd fastino-training
uv add "tinker==0.33.1"
```

```bash pip
mkdir fastino-training && cd fastino-training
python -m venv .venv
source .venv/bin/activate
pip install "tinker==0.33.1"
```

```powershell pip · Windows
mkdir fastino-training
cd fastino-training
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install "tinker==0.33.1"
```

</CodeGroup>

### 4. Configura el cliente

`TINKER_CREDENTIAL_CMD` se ejecuta con cada solicitud de token y debe imprimir
una única credencial no vacía.

<CodeGroup>

```bash macOS/Linux
export TINKER_BASE_URL="https://api.fastino.ai/v1/training/compat/tinker"
export TINKER_CREDENTIAL_CMD='printf "%s\n" "$FASTINO_API_KEY"'
```

```powershell Windows
$env:TINKER_BASE_URL = "https://api.fastino.ai/v1/training/compat/tinker"
$env:TINKER_CREDENTIAL_CMD = 'powershell -NoProfile -Command "[Console]::Out.WriteLine($env:FASTINO_API_KEY)"'
```

</CodeGroup>

Usa una clave normal de Fastino que comience por `fast_sk_`. Las credenciales
que comienzan por `tml-` se rechazan. No establezcas `TINKER_API_KEY`.

### 5. Elige un modelo habilitado

Llama a `ServiceClient.get_server_capabilities()` y selecciona un modelo
habilitado. Capabilities informa los nombres y longitudes de contexto, pero no
rangos LoRA, optimizadores, pérdidas, métodos opcionales ni límites de operación.
Fastino acepta actualmente rangos LoRA de 1 a 32 y usa 32 de forma predeterminada.

<CodeGroup>

```bash macOS/Linux
export FASTINO_TRAINING_MODEL="<model from capabilities>"
export FASTINO_TRAINING_LORA_RANK="32"
```

```powershell Windows
$env:FASTINO_TRAINING_MODEL = "<model from capabilities>"
$env:FASTINO_TRAINING_LORA_RANK = "32"
```

</CodeGroup>

### 6. Crea el trabajo y muestrea

Crea `quickstart.py`:

```python
import os

import tinker


service_client = tinker.ServiceClient()
outcome = "errored"
try:
    capabilities = service_client.get_server_capabilities()
    print(capabilities)

    training_client = service_client.create_lora_training_client(
        base_model=os.environ["FASTINO_TRAINING_MODEL"],
        rank=int(os.environ["FASTINO_TRAINING_LORA_RANK"]),
    )

    job_id = training_client.get_info().model_id
    print(f"TRAINING_JOB_ID={job_id}")

    checkpoint = training_client.save_weights_for_sampler(
        "quickstart-sampler",
        ttl_seconds=24 * 60 * 60,
    ).result()
    sampling_client = service_client.create_sampling_client(
        model_path=checkpoint.path
    )

    tokenizer = sampling_client.get_tokenizer()
    prompt_tokens = tokenizer.apply_chat_template(
        conversation=[
            {
                "role": "user",
                "content": "Explain the purpose of a reward function in one sentence.",
            }
        ],
        add_generation_prompt=True,
        return_dict=False,
    )
    result = sampling_client.sample(
        prompt=tinker.types.ModelInput.from_ints(prompt_tokens),
        num_samples=1,
        sampling_params=tinker.types.SamplingParams(max_tokens=64),
    ).result()

    print(tokenizer.decode(result.sequences[0].tokens))
except KeyboardInterrupt:
    outcome = "interrupted"
    raise
else:
    outcome = "success"
finally:
    service_client.close(outcome).result()
```

Ejecuta el script:

```bash
python quickstart.py
```

Copia el valor que se imprime después de `TRAINING_JOB_ID=`.

### 7. Verifica el trabajo canónico

<CodeGroup>

```bash macOS/Linux
export TRAINING_JOB_ID="<ID printed by quickstart.py>"
curl --fail-with-body \
  -H "X-API-Key: $FASTINO_API_KEY" \
  "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID"
```

```powershell Windows
$env:TRAINING_JOB_ID = "<ID printed by quickstart.py>"
Invoke-RestMethod `
  -Headers @{ "X-API-Key" = "$env:FASTINO_API_KEY" } `
  -Uri "https://api.fastino.ai/v1/training/jobs/$env:TRAINING_JOB_ID"
```

</CodeGroup>

La respuesta describe el mismo trabajo creado por
`create_lora_training_client(...)`. Sigue usando el cliente del SDK para las
operaciones del modelo y la API canónica de trabajos para las lecturas de
trabajos documentadas.
