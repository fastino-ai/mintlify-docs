---
title: "Flujo de historial y feedback de inferencia"
description: "Conserva IDs de inferencia, inspecciona resultados históricos y envía correcciones sin duplicar el contrato OpenAPI."
---

Fastino puede guardar llamadas compatibles y devolver un `inference_id`. Consérvalo para auditoría o feedback humano.

## Flujo

1. Ejecuta la inferencia y conserva el `inference_id`.
2. [Lista el historial](/es/api-reference/inference/history/list) o [recupera un registro](/es/api-reference/inference/history/get).
3. [Envía feedback](/es/api-reference/inference/history/submit-feedback) con el contrato OpenAPI exacto.
4. [Lee el feedback guardado](/es/api-reference/inference/history/get-feedback) para confirmar la anotación.

<Note>OpenAPI define filtros, validación, campos y respuestas. Esta guía solo define el flujo.</Note>
