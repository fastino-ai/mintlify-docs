La API de RL ejecuta cargas de trabajo de aprendizaje por refuerzo y
postentrenamiento personalizado en Fastino. Tu código controla el conjunto de
datos, la función de recompensa, la estrategia de rollout y los criterios de
parada. Fastino ejecuta el muestreo y el entrenamiento del modelo.

<Note>
  La API de RL tiene acceso limitado. Confirma que Fastino la haya habilitado
  para tu equipo antes de planificar una migración a producción.
</Note>

Usa el SDK oficial de Python `tinker`. Las aplicaciones de Tinker existentes
pueden migrar a Fastino sin reemplazar su bucle de aprendizaje.

## Qué controlas

Tu aplicación:

1. Muestrea respuestas de la política actual.
2. Puntúa cada respuesta con tu función de recompensa.
3. Convierte las recompensas en ventajas.
4. Envía el lote de entrenamiento a la API de RL.
5. Aplica un paso del optimizador y guarda los puntos de control útiles.

Esta separación permite cambiar la recompensa o el algoritmo de entrenamiento
sin gestionar la infraestructura del modelo.
