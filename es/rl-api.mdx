La API de RL de Fastino es un servicio alojado de entrenamiento y muestreo.
El cliente de Python compatible es el paquete `tinker` configurado para usar
Fastino. Tu código controla el conjunto de datos, la función de recompensa, la
estrategia de generación de respuestas y los criterios de parada. Fastino
ejecuta el muestreo y el entrenamiento del modelo.

<Note>
  La API de RL tiene acceso limitado. Confirma que Fastino la haya habilitado
  para tu equipo antes de planificar una migración a producción.
</Note>

Instalar el paquete `tinker` no concede acceso a la API de RL de Fastino.
Una aplicación existente que use el SDK puede conservar las formas de sus
llamadas solo cuando cumpla todos los puntos de la [lista de comprobación de
compatibilidad](/es/rl-api/compatibility).

Usa esta API cuando tu aplicación deba generar respuestas, puntuarlas y
actualizar el modelo de forma reiterada. Para el ajuste fino gestionado a partir
de un conjunto de datos preparado, usa la [API de entrenamiento](/es/training).

## Cómo funciona

Tu aplicación:

1. Muestrea respuestas de la política actual.
2. Puntúa cada respuesta con tu función de recompensa.
3. Convierte las recompensas en ventajas.
4. Envía el lote de entrenamiento a la API de RL.
5. Aplica un paso del optimizador y guarda los puntos de control útiles.

Esta separación te permite controlar la lógica de aprendizaje sin gestionar la
infraestructura del modelo. Usa únicamente las operaciones y los nombres de
funciones de pérdida integradas que se documentan en la referencia de
compatibilidad.
