La API de RL es la interfaz programable de Fastino para el aprendizaje por
refuerzo y el postentrenamiento personalizado. Implementa el contrato del SDK
de Tinker, por lo que puedes reutilizar un bucle de entrenamiento de Tinker
existente o comenzar con el recetario de código abierto de Tinker.

<Note>
  La API de RL tiene acceso limitado. Confirma que Fastino la haya habilitado
  para tu equipo antes de planificar una migración a producción.
</Note>

Tú controlas el bucle:

1. Muestrea respuestas de la política actual.
2. Puntúa cada respuesta con tu función de recompensa.
3. Convierte las recompensas en ventajas.
4. Envía el lote de entrenamiento a la API de RL.
5. Aplica un paso del optimizador y guarda un punto de control del resultado.

Fastino gestiona la infraestructura de entrenamiento y muestreo que ejecuta ese
bucle. Tu código conserva el control del conjunto de datos, la función de
recompensa, la estrategia de rollout y los criterios de parada.

<Tip>
  ¿Ya usas Tinker? Conserva tus llamadas al SDK y configura el endpoint y la
  clave de API de Fastino. Comienza con
  [Migrar desde Tinker](/es/rl-api/migrate-from-tinker).
</Tip>

## Por qué usar la API de RL

- **Reutiliza el código existente.** El paquete oficial de Python `tinker` es
  el cliente.
- **Define cualquier recompensa programática.** Evalúa matemáticas, código, uso
  de herramientas, resultados estructurados o tu propio entorno.
- **Separa la orquestación del cómputo.** Mantén el algoritmo de aprendizaje en
  tu aplicación mientras Fastino ejecuta las operaciones del modelo.
- **Reanuda desde puntos de control duraderos.** Guarda los pesos o el estado
  del optimizador y restaura una ejecución más adelante.
- **Controla el uso con Fastino.** El entrenamiento, el muestreo y el
  almacenamiento de puntos de control usan el mismo límite de facturación de
  cuenta y proyecto que tus otras cargas de trabajo de Fastino.

## Antes de comenzar

Necesitas:

- Una clave de API de Fastino que comience por `fast_sk_`
- Acceso a la API de RL habilitado para tu equipo de Fastino
- Python 3.11 o posterior
- `tinker==0.32.0` para el contrato de cliente probado

La API de RL se documenta por separado de la referencia OpenAPI de Fastino de
forma intencionada. Usa estas páginas y los tipos del SDK de Tinker para las
operaciones de RL. Usa la [referencia de la
API](/es/api-reference/inference/overview) para las API HTTP nativas de Fastino.
