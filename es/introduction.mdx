Fastino ofrece API para inferencia especializada y entrenamiento de modelos.
Usa **GLiDE** para clasificación, enrutamiento y puntuación con probabilidades
calibradas, o **GLiNER** para extracción a nivel de fragmento. Con la
[API de entrenamiento](/es/training), puedes ejecutar ajuste gestionado,
controlar un bucle personalizado o delegar el ciclo de entrenamiento a Auto Train.

## Modelos compatibles

### Inferencia

- **GLiDE** para decisiones: clasificación, enrutamiento y puntuación con probabilidades calibradas en lugar de texto generado.
- **GLiNER-2.5-Decide** para clasificación en inglés: intención, enrutamiento, sentimiento, prioridad, moderación y puntuación ordinal.
- **GLiNER 2.5 Multilingual** para extracción estructurada multilingüe.
- **GLiNER2 y GLiGuard** para extracción de entidades, clasificación, datos estructurados, seguridad y flujos de PII.

### Entrenamiento

| Flujo de trabajo | Modelos |
| --- | --- |
| Entrenamiento gestionado de codificadores | GLiNER2 Multilingual, GLiNER-2.5-Decide |
| Entrenamiento interactivo de decodificadores | Nemotron 3.5 Lightning, Nemotron 3.5 Super VL, Qwen3.6-35B-A3B |

Llama a `GET /v1/base-models?supports_training=true` para consultar la
disponibilidad y las capacidades actuales de entrenamiento. Consulta
[Modelos](/es/concepts/models) para ver el catálogo completo.
