Apunta tu cliente de OpenAI o Anthropic a Fastino. Identificamos dónde se queda corto tu modelo actual y luego entrenamos modelos especialistas que son más precisos, más baratos y más rápidos.

## Qué puedes hacer con Fastino

<CardGroup cols={2}>
  <Card title="Intégralo y haz inferencia como siempre" icon="plug" href="/es/concepts/inference">
    Apunta tu cliente existente de OpenAI o Anthropic a Fastino: la misma API, el mismo código. No se requiere migración.
  </Card>

  <Card title="Detección automática de brechas" icon="chart-bar" href="/guides/adaptive-inference">
    Fastino agrupa tu tráfico por caso de uso y expone exactamente dónde tu modelo actual está dejando precisión, coste o latencia sobre la mesa.
  </Card>

  <Card title="Entrenamiento de modelos especialistas" icon="brain" href="/guides/fine-tune-llm">
    Fastino entrena y evalúa modelos especialistas Nemotron 3.5 Lightning y GLiNER en tu nombre. Cero MLOps de tu parte.
  </Card>

  <Card title="Tú controlas el enrutamiento" icon="bolt" href="/guides/adaptive-inference">
    Fastino muestra datos de mejora, coste y latencia para cada modelo especialista. Tú decides cuándo y cómo enrutar tráfico hacia ellos.
  </Card>
</CardGroup>

## Tu modelo se reentrena solo mientras duermes.

<CardGroup cols={2}>
  <Card title="Inferencia adaptativa" icon="rotate" href="/guides/adaptive-inference">
    El bucle de mejora continua de Fastino. Extrae de tus fallos en producción los ejemplos con mayor señal, reentrena automáticamente un modelo especialista y promueve los checkpoints mejorados detrás del mismo endpoint. Sin necesidad de redepliegue.
  </Card>

  <Card title="Descarga tus activos" icon="download" href="/guides/adaptive-inference">
    Tus pesos y conjuntos de datos de entrenamiento son tuyos. Descárgalos cuando quieras: llévalos a cualquier otra plataforma o sigue ajustándolos en tu propia infraestructura.
  </Card>

  <Card title="Usa tus propias evaluaciones" icon="chart-bar" href="/concepts/evaluations">
    Usa el conjunto de evaluación integrado de Fastino o conecta el tuyo. Cada ejecución de reentrenamiento se compara antes de promover cualquier tráfico.
  </Card>

  <Card title="Rastro de auditoría completo" icon="file-text" href="/guides/adaptive-inference">
    Cada ejecución de Inferencia adaptativa genera un informe PDF completo: datos de entrenamiento, diferencias de evaluación, etapas de despliegue e historial de checkpoints incluidos.
  </Card>
</CardGroup>

## Familias de modelos soportadas

- **GLiNER 2.5 Multilingual** para extracción estructurada multilingüe.
- **GLiNER2 y GLiGuard** para extracción de entidades, clasificación, datos estructurados, seguridad y flujos de PII.
- **Nemotron 3.5 Lightning** en variantes de propósito general, Healthcare y Finance.

Consulta [Modelos](/es/concepts/models) para IDs de modelo y disponibilidad actual.
