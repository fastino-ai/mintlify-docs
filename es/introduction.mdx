Empieza con **GLiDE** para obtener decisiones estructuradas (clasificación, enrutamiento y puntuación) como probabilidades calibradas en una sola llamada, sin texto generado que analizar. Descubre en qué se diferencian los [modelos de decisión](/es/concepts/decision-models) de los LLM generativos y cuándo usar cada uno. Recurre a **GLiNER** cuando necesites extracción a nivel de fragmento, usa la API de entrenamiento para el ajuste fino gestionado o usa la **API de RL** cuando tu aplicación controle la recompensa y el bucle de aprendizaje.

## Familias de modelos soportadas

- **GLiDE** para decisiones: clasificación, enrutamiento y puntuación con probabilidades calibradas en lugar de texto generado.
- **GLiNER-2.5-Decide** para clasificación en inglés: intención, enrutamiento, sentimiento, prioridad, moderación y puntuación ordinal.
- **GLiNER 2.5 Multilingual** para extracción estructurada multilingüe.
- **GLiNER2 y GLiGuard** para extracción de entidades, clasificación, datos estructurados, seguridad y flujos de PII.

Consulta [Modelos](/es/concepts/models) para IDs de modelo y disponibilidad actual.
