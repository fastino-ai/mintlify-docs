Empieza con **GLiDE** para obtener decisiones estructuradas (clasificación, enrutamiento y puntuación) como probabilidades calibradas en una sola llamada, sin texto generado que analizar. Recurre a **GLiNER** cuando necesites extracción a nivel de fragmento, y ajusta cualquiera de las dos familias con tus propios datos a través de la API de entrenamiento de Fastino.

## Familias de modelos soportadas

- **GLiDE** para decisiones: clasificación, enrutamiento y puntuación con probabilidades calibradas en lugar de texto generado.
- **GLiNER-2.5-Decide** para decisiones tipadas, restricciones, extracción de fragmentos, relaciones y registros estructurados.
- **GLiNER 2.5 Multilingual** para extracción estructurada multilingüe.
- **GLiNER2 y GLiGuard** para extracción de entidades, clasificación, datos estructurados, seguridad y flujos de PII.

Consulta [Modelos](/es/concepts/models) para IDs de modelo y disponibilidad actual.
