Usa Fastino Agent para ajustar de forma autónoma modelos GLiNER a tus casos de uso específicos. Ejecuta inferencia tanto con modelos base como con modelos especializados ajustados a través de nuestra API.

## Qué puedes hacer con Fastino

<CardGroup cols={2}>
  <Card title="Intégralo y haz inferencia como siempre" icon="plug" href="/es/inference">
    Apunta tu cliente existente de OpenAI o Anthropic a Fastino para ejecutar inferencia con modelos base de GLiNER.
  </Card>

  <Card title="Entrenamiento de modelos especialistas" icon="brain" href="/guides/adaptive-inference">
    Fastino entrena y evalúa modelos especialistas GLiNER en tu nombre. Cero MLOps de tu parte.
  </Card>

  <Card title="Usa tus propias evaluaciones" icon="bolt" href="/guides/fine-tune-llm">
    Usa el conjunto de evaluación integrado de Fastino o conecta el tuyo. Cada ejecución de entrenamiento también genera un informe PDF completo con detalles de evaluación, etapas de despliegue e historial de checkpoints.
  </Card>

  <Card title="Descarga tus activos" icon="download" href="/guides/adaptive-inference">
    Tus pesos y conjuntos de datos de entrenamiento son tuyos. Descárgalos cuando quieras y llévalos a cualquier otra plataforma o sigue ajustándolos en tu propia infraestructura.
  </Card>
</CardGroup>

## Familias de modelos soportadas

- **GLiNER 2.5 Multilingual** para extracción estructurada multilingüe.
- **GLiNER2 y GLiGuard** para extracción de entidades, clasificación, datos estructurados, seguridad y flujos de PII.

Consulta [Modelos](/es/concepts/models) para IDs de modelo y disponibilidad actual.
