Before deploying a model, compare it against held-out labeled cases. Fastino evaluation suites pin those cases and their scorer configuration to a project so every selected model is measured consistently.

## Evaluation suites and runs

An **evaluation suite** defines:

- The project and source of the labeled cases
- The task and field mapping
- The scorer used for each case
- An optional case limit

An **evaluation run** applies that pinned suite to one selected model. Starting a suite run for several model IDs creates one run per model, which lets you compare a base model and fine-tuned candidates on identical inputs.

## Recommended workflow

1. Create a suite with `POST /v1/projects/{project_id}/evaluation-suites`.
2. Inspect or preview the pinned cases before spending inference credits.
3. Start runs with `POST /v1/projects/{project_id}/evaluation-suites/{suite_id}/runs`.
4. Poll each run at `GET /v1/projects/{project_id}/evaluation-runs/{run_id}`.
5. Inspect case-level results at `GET /v1/projects/{project_id}/evaluation-runs/{run_id}/results`.

Use the same suite for every model in a comparison. Review aggregate metrics and individual failures; a single summary score can hide regressions on rare labels or difficult examples.

## Endpoint summary

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/v1/projects/{project_id}/evaluation-suites` | List project suites |
| `POST` | `/v1/projects/{project_id}/evaluation-suites` | Create and pin a suite |
| `GET` | `/v1/projects/{project_id}/evaluation-suites/{suite_id}/preview` | Preview pinned cases |
| `GET` | `/v1/projects/{project_id}/evaluation-suites/{suite_id}/runs` | List suite runs |
| `POST` | `/v1/projects/{project_id}/evaluation-suites/{suite_id}/runs` | Start model runs |
| `GET` | `/v1/projects/{project_id}/evaluation-runs/{run_id}` | Read run status and metrics |
| `GET` | `/v1/projects/{project_id}/evaluation-runs/{run_id}/results` | Read case-level results |

See the [Evaluation API reference](/api-reference/evaluations) for request examples.
