GLiNER 2.5 Decide is a compact, 340M-parameter English model optimized for schema-defined classification.

## Classification capabilities

- Define labels at request time without retraining for every taxonomy change.
- Run single-label classification when exactly one label should win.
- Run multi-label classification when several labels may apply.
- Evaluate several independently named classification tasks in one forward pass.
- Return a selected label or labels with confidence.
- Use `cls_threshold` to control selection in multi-label tasks.
- Use a catalog-default classification task when both `schema` and `response_format` are omitted.

Common workloads include intent, routing, sentiment, priority, moderation, tags, operational gates, and custom text taxonomies.

## Performance characteristics

The released checkpoint reached **38.3 ms p50** on an NVIDIA V100 and **167.3 ms** on a 48-vCPU Intel Xeon for the published short-input benchmark. See the [model article](https://fastino.ai/blog/gliner-2-5-decide-open-weight-decision-model) for the benchmark setup and methodology.

## Schema limits

- Every task requires at least two labels.
- `labels` must be an array of strings.
- Label-description objects are not supported.
- A classification task accepts only `task`, `labels`, `multi_label`, `cls_threshold`, and `top_k`.
- `top_k` is accepted but currently has no effect.
- `cls_threshold` affects multi-label selection only.
- Single-label tasks always return the highest-scoring label.

## Decision limits

- Classic classification labels are unordered. Label order does not create an ordinal scale.
- Tasks in the same request are independent.
- Classic classification does not enforce implications, exclusions, cardinality relationships, or ordinal bounds between tasks.
- Decide does not generate explanations, conversations, or open-ended text.

Use [GLiNER 2.5 Multi](/concepts/gliner) when extraction, multilingual coverage, label descriptions, or constrained relationships between tasks are primary requirements. Use [GLiDE Score](/concepts/glide-score) when your application needs an explicitly ordered rubric.
