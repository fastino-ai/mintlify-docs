Fastino offers GLiNER models for structured extraction and Nemotron models for text generation.

## GLiNER 2.5

GLiNER2.5 uses boundary prediction rather than span enumeration, enabling wide spans and a
4,096-word context while retaining a single schema-driven interface for entities,
classifications, structures, records, relations, span attributes, and joint extraction.

| Model ID | Parameters | Language | Recommended use |
| --- | ---: | --- | --- |
| `fastino/gliner2.5-small-v1` | 74M | English | Fast local, CPU, or edge inference |
| `fastino/gliner2.5-base-v1` | 194M | English | Default English extraction |
| `fastino/gliner2.5-multi-v1` | 287M | Multilingual | Multilingual and hosted extraction |

All three checkpoints are available from the
[GLiNER2.5 Hugging Face collection](https://huggingface.co/collections/fastino/gliner25-models).
Hosted availability may differ; use `GET /v1/base-models` as the live API catalog.
