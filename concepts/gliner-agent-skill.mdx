The [Fastino GLiNER agent skill](https://api.pioneer.ai/.well-known/agent-skills/fastino-gliner/SKILL.md) helps Cursor, Claude Code, and Codex use Fastino's hosted APIs for extraction, classification, dataset preparation, fine-tuning, evaluation, and inference.

## Install

Run this command from your project:

```bash
npx skills add https://api.pioneer.ai --skill fastino-gliner
```

The installer lets you choose which supported agents receive the skill.

Before using the skill, expose your Pioneer API key to the agent's environment:

```bash
export PIONEER_API_KEY="..."
```

Then invoke it explicitly with `/fastino-gliner`, or ask your agent for a hosted GLiNER extraction, classification, fine-tuning, evaluation, or inference workflow.

## Non-interactive installation

Use the command for your agent to install the skill into the current project without prompts:

<CodeGroup>

```bash Cursor
npx skills add https://api.pioneer.ai --skill fastino-gliner -a cursor -y
```

```bash Claude Code
npx skills add https://api.pioneer.ai --skill fastino-gliner -a claude-code -y
```

```bash Codex
npx skills add https://api.pioneer.ai --skill fastino-gliner -a codex -y
```

</CodeGroup>

The `-a` option selects the target agent and `-y` accepts the installation prompts, making these commands suitable for scripts and CI.
