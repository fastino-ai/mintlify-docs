The [Fastino GLiNER agent skill](https://api.fastino.ai/.well-known/agent-skills/fastino-gliner/SKILL.md) helps Cursor, Claude Code, and Codex use Fastino's hosted APIs for extraction, classification, dataset preparation, fine-tuning, evaluation, and inference.

## Install

Run this command from your project:

```bash
npx skills add https://api.fastino.ai --skill fastino-gliner
```

The installer lets you choose which supported agents receive the skill.

Before using the skill, expose your Fastino API key to the agent's environment:

```bash
export FASTINO_API_KEY="..."
```

Then invoke it explicitly with `/fastino-gliner`, or ask your agent for a hosted GLiNER extraction, classification, fine-tuning, evaluation, or inference workflow.

## Non-interactive installation

Use the command for your agent to install the skill into the current project without prompts:

<CodeGroup>

```bash Cursor
npx skills add https://api.fastino.ai --skill fastino-gliner -a cursor -y
```

```bash Claude Code
npx skills add https://api.fastino.ai --skill fastino-gliner -a claude-code -y
```

```bash Codex
npx skills add https://api.fastino.ai --skill fastino-gliner -a codex -y
```

```text Any agent
Paste this prompt into your coding agent:

"Install the Fastino GLiNER agent skill. Follow the installation
instructions in Fastino's documentation at
https://docs.fastino.ai/concepts/gliner-agent-skill. Use one
installation method appropriate for your agent environment. Then use
the Fastino GLiNER skill when working on this project, especially for
schema-driven information extraction, entity extraction,
classification, and relation extraction"
```

</CodeGroup>

For Cursor, Claude Code, and Codex, the `-a` option selects the target agent and `-y` accepts the installation prompts, making those commands suitable for scripts and CI.
