GLiNER2.5 Multi is Fastino's multilingual, multi-task information-extraction model. Use one schema to extract entities, classify text, build structured records, identify relations, and attach attributes to spans.

## When to use GLiNER 2.5

Use GLiNER2.5 Multi when extraction or multilingual coverage is central to the task:

- **Entity extraction** — pull people, organizations, products, locations, or domain-specific entities (medications, dosages, clauses) out of free text, with character offsets and confidence scores.
- **Structured records** — turn "Alice bought apples and Bob bought oranges" into `[{"buyer": "Alice", "item": "apples"}, {"buyer": "Bob", "item": "oranges"}]`, keeping each instance's fields linked.
- **Relation and knowledge-graph extraction** — extract typed entity-relation graphs (`works_for`, `located_in`) for agent memory or a knowledge base.
- **Span attributes** — tag each extracted entity with an attribute, such as per-person sentiment, in the same pass as extraction.
- **Long documents** — process an encoded context of up to 4,096 tokens, with chunking and offset remapping for longer documents.
- **Multiple tasks at once** — combine entities, classification, structures, and relations in a single schema-constrained call instead of chaining several model requests.
- **Consistent outputs** — use constrained classification or joint entity-relation decoding when labels and relation endpoints must agree.

GLiNER2.5 Multi also supports classification. Choose [GLiNER-2.5-Decide](/concepts/gliner-2-5-decide) when the input is English and classification itself—intent, routing, sentiment, priority, moderation, or scoring—is the primary workload.

## How to use GLiNER 2.5

Call the multilingual checkpoint through Fastino's OpenAI-compatible inference endpoint. Put the text in a user message and describe the task in `schema`:

```bash
curl -X POST "https://api.fastino.ai/v1/chat/completions" \
  -H "Authorization: Bearer $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "fastino/gliner2.5-multi-v1",
    "messages": [
      { "role": "user", "content": "Apple CEO Tim Cook unveiled the iPhone 15 Pro in Cupertino." }
    ],
    "schema": {
      "entities": [
        { "name": "person", "description": "named individual" },
        { "name": "organization", "description": "business or institution name" },
        { "name": "product", "description": "named commercial product" },
        { "name": "location", "description": "city, region, or place" }
      ]
    }
  }'
```

Add `classifications`, `structures`, or `relations` keys to the same `schema` to run several tasks over the same text in one call. See the [Inference API](/inference/chat-completions) reference for the full request and response contract, including structured records and relation schemas.
