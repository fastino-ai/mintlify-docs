GLiDE (Generalized Lightweight Decision Engine) is a thinking decision model. Instead of generating free-form text, it evaluates the application state you provide against one or more typed questions and returns structured labels, probabilities, and confidence scores across outcomes you define.

GLiDE first makes a fast assessment, then spends additional reasoning on uncertain decisions. The final probabilities incorporate that reasoning, so the same interface works for routine classification and decisions that require arithmetic, code tracing, temporal logic, policy interpretation, or several related facts. Your application never has to parse a chain of thought or generated answer before acting.

## Why use a decision model

- **Structured by construction** - every answer matches a Noul, Choice, or Score shape.
- **Adaptive reasoning** - straightforward cases stay fast while difficult cases receive more computation automatically.
- **Explicit uncertainty** - use the full probability distribution and confidence margin to automate, ask for approval, or escalate.
- **Large decision spaces** - evaluate up to 255 options or levels against as much as 40,000 tokens of state and instructions per question.

## When to use GLiDE

GLiDE is a good fit whenever software must choose from defined outcomes:

| Use case | Example decision |
| --- | --- |
| Agent and tool routing | Select the next action from a large tool set while considering permissions and previous results |
| High-risk action control | Execute, sandbox, request approval, or block a proposed operation |
| Incident response | Monitor, restart, roll back, isolate, or escalate from alerts, logs, and runbooks |
| Contracts and policies | Apply cross-references, dates, thresholds, and exceptions to a case |
| Model-output verification | Accept, reject, or request revision for reasoning-intensive output |
| Everyday classification | Route tickets, moderate content, score urgency, or replace an LLM-as-judge step |

Use a general-purpose language model instead for free-form generation, multi-turn conversation, open-ended Q&A, summarization, or code generation.

## Evaluated on broad decision tasks

On Decision Index 0.2.1, GLiDE scored **64.81** compared with Jev's published **57.91**. It led across all five evaluation areas and on 31 of 38 benchmarks, with its largest gains in knowledge, reasoning, and tool-use tasks. These results are from Fastino's run with the official scorer; submissions to the public 0.2.1 leaderboard were paused at launch.

Read [Introducing GLiDE](https://fastino.ai/blog/introducing-glide-the-first-thinking-decision-model) for the benchmark breakdown and methodology.

## From model concept to inference

1. Read [GLiDE Reference](/concepts/decision-models) for the shared `state`, `questions`,
   limits, and confidence contract.
2. Choose [Noul](/concepts/glide-noul), [Choice](/concepts/glide-choice), or
   [Score](/concepts/glide-score) based on the answer shape your application needs.
3. Call [`POST /v1/systemone`](/inference/systemone). GLiDE does not use
   `/v1/chat/completions`.
