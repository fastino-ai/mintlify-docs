GLiNER 2.5 Decide returns a standard Chat Completions envelope. The classification result itself is serialized as JSON inside `choices[0].message.content`.

## Parse the result

```python
import json

body = response.json()
result = json.loads(body["choices"][0]["message"]["content"])
```

Do not read classification tasks directly from `choices[0]`; parse `message.content` first.

## Single-label task

For `multi_label: false`, each task returns one object:

```json
{
  "intent": {
    "label": "refund_request",
    "confidence": 0.999862551689148
  }
}
```

- `label` is one of the strings supplied in that task's `labels` array.
- `confidence` is the model's confidence for the selected label, from `0` to `1`.

## Multi-label task

For `multi_label: true`, each task returns an array of selected labels:

```json
{
  "tags": [
    {"label": "technical_issue", "confidence": 0.4421546757221222},
    {"label": "login_problem", "confidence": 0.21206879615783691},
    {"label": "urgent", "confidence": 0.4834045469760895},
    {"label": "human_handoff", "confidence": 0.8267117738723755}
  ]
}
```

Only labels meeting the task's `cls_threshold` are selected. A stricter threshold can produce a shorter array or no selected labels.

## Multiple tasks

The parsed object is keyed by the `task` names from the request:

```json
{
  "intent": {
    "label": "refund_request",
    "confidence": 0.99
  },
  "urgency": {
    "label": "normal",
    "confidence": 0.82
  }
}
```

Each classic classification task is evaluated independently.

## Response envelope

| Field | Meaning |
| --- | --- |
| `model` | Model identifier used for inference |
| `choices[0].message.content` | JSON-encoded classification result |
| `choices[0].finish_reason` | Completion status, normally `stop` |
| `usage.prompt_tokens` | Input token count |
| `usage.completion_tokens` | Output token count |
| `usage.total_tokens` | Combined usage |
| `token_usage` | Combined token usage reported by Fastino |
| `x_fastino.inference_id` | Persisted inference identifier when storage is enabled |
| `x_fastino.default_schema_applied` | Whether the model's catalog-default schema was used |

`x_fastino` can be `null` when no additional Fastino metadata is returned.
