GLiNER-2.5-Decide is a decision model for applications that need to make several related judgments from the same text. It combines typed decisions with explicit constraints, span extraction, relations, and structured records.

<CardGroup cols={3}>
  <Card title="Typed decisions" icon="list-checks">
    Return bounded categorical or ordinal answers instead of unconstrained text.
  </Card>

  <Card title="Explicit constraints" icon="shield-check">
    Keep related decisions consistent by preventing contradictory combinations.
  </Card>

  <Card title="Structured evidence" icon="scan-text">
    Combine decisions with spans, relations, records, probabilities, and confidence scores.
  </Card>
</CardGroup>

## What you can build

Decision models are useful when software must make several related judgments from the same text. GLiNER-2.5-Decide supports schema-driven, low-latency decision-making across these use cases:

<CardGroup cols={2}>
  <Card title="Model routing" icon="route">
    Route requests by destination, complexity, or escalation level and return the selected route with probabilities and confidence scores.
  </Card>

  <Card title="Tool calling" icon="wrench">
    Select from a permitted set of tools and capture arguments from the request as structured records.
  </Card>

  <Card title="Browser and computer use" icon="mouse-pointer-click">
    Evaluate the current state, select the next action, and represent its target and parameters as a structured record.
  </Card>

  <Card title="Guardrails" icon="shield">
    Evaluate safety, harm type, and escalation together, extract harmful spans verbatim, and prevent contradictory answers.
  </Card>

  <Card title="Context pruning" icon="filter">
    Decide which context is relevant and return the exact character spans associated with that decision.
  </Card>

  <Card title="LLM-as-a-judge" icon="scale">
    Express rubric criteria as categorical or ordinal questions and return selected values with probability distributions and confidence scores.
  </Card>
</CardGroup>

<Card title="Games and simulations" icon="gamepad-2">
  Evaluate game state to determine intent, action, or outcome. Represent actors and state information through entities, relations, and structured records.
</Card>

## One model, connected outputs

<Steps>
  <Step title="Define the decisions">
    Express each judgment as a typed choice with an allowed set of answers.
  </Step>

  <Step title="Capture supporting context">
    Extract spans, relations, and structured records alongside the decisions.
  </Step>

  <Step title="Apply constraints">
    Encode relationships between answers so the final result stays internally consistent.
  </Step>

  <Step title="Use confidence signals">
    Consume probabilities and confidence scores when routing, escalating, or taking action.
  </Step>
</Steps>
