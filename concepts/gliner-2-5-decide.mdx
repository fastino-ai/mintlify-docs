GLiNER-2.5-Decide is Fastino's 340M-parameter, English decision model for schema-defined classification. Supply your labels at request time and receive structured answers, probabilities, and confidence scores without prompting a generative model.

## Why use a schema-defined decision model

A schema-defined model fits applications that need to turn text into a permitted action:

- **Predictable outputs** - the model chooses from labels you define, so downstream code does not have to parse or validate generated prose.
- **Actionable uncertainty** - probabilities and confidence support thresholds, human review, and fallback handling.
- **Related judgments in one pass** - classify intent, urgency, route, and handoff from the same input instead of making separate generation calls.

## Why GLiNER-2.5-Decide

- **Compact and fast** - the released 340M-parameter checkpoint reached 38.3 ms p50 on an NVIDIA V100 and 167.3 ms on a 48-vCPU Intel Xeon for the published short-input benchmark.
- **Open and deployable** - Apache 2.0 open weights support local CPU inference, air-gapped deployment, and full or LoRA fine-tuning.
- **More than classification** - the same GLiNER architecture can combine classification with entities, relations, and structured records.
- **Flexible schemas** - change labels and descriptions at request time instead of retraining for every taxonomy change.

## When to use GLiNER-2.5-Decide

Use GLiNER-2.5-Decide when classification is the primary task:

- **Intent and routing** - send support messages, emails, or agent requests to the right workflow.
- **Several decisions per input** - classify intent, urgency, route, and handoff in one model call.
- **Single- and multi-label classification** - select one category or every applicable tag.
- **Operational gates** - decide whether an agent finished, a human should take over, or content violates a policy.
- **Ordinal labels** - score severity, urgency, or ratings using an ordered label set.
- **Custom taxonomies** - define labels and short descriptions at request time instead of retraining for every category change.

The hosted model retains entity, relation, and structured-extraction support, but classification is the reason to choose it. Use [GLiNER2.5](/concepts/gliner) when extraction is primary, you need span attributes or joint entity-relation decoding, or the input is multilingual. Use a general-purpose language model when the result must be open-ended prose, a conversation, or newly generated content rather than a schema-defined decision.

## How to use GLiNER-2.5-Decide

Call it through Fastino's OpenAI-compatible inference endpoint with a `classifications` schema. Every classification task requires at least two candidate labels. Add multiple tasks to classify several aspects of the same text in one call:

```bash
curl -X POST "https://api.fastino.ai/v1/chat/completions" \
  -H "Authorization: Bearer $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "fastino/GLiNER-2.5-Decide",
    "messages": [
      { "role": "user", "content": "My subscription renewed on April 15 after the service was already down. Can I get that refunded?" }
    ],
    "schema": {
      "classifications": [
        {
          "task": "intent",
          "labels": ["refund_request", "cancel_subscription", "login_problem", "speak_to_human"],
          "multi_label": false
        },
        {
          "task": "urgency",
          "labels": ["low", "normal", "high", "critical"],
          "multi_label": false
        }
      ]
    }
  }'
```

`intent` and `urgency` are scored together, so a router gets both judgments from one request. Send an explicit schema when you need your own taxonomy. If you omit both `schema` and `response_format`, Decide uses its catalog-default `intent` task (`book`, `cancel`, `change`, and `status`) and returns `x_fastino.default_schema_applied: true`.

See the [Chat Completions API](/inference/chat-completions) for the response contract, multi-label classification, and confidence thresholds.

## Evaluation

On Fastino's 17-dataset Fast Decisions benchmark, GLiNER-2.5-Decide achieved the highest average score at **60.1%** and led 9 datasets. It outperformed the 4B-class JevK5 reproduction (**57.5%**) and SemIf (**56.4%**), as well as the encoder models GLiFormer and Laya. This is an internal benchmark, not JevBench, and JevK5 is not TypeSafe's Jev.

Read [GLiNER2.5-Decide: An Open-Weight Model for Structured Decision Making](https://fastino.ai/blog/gliner-2-5-decide-open-weight-decision-model) for the benchmark design, complete results, and latency methodology.
