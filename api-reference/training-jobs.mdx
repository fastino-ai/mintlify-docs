The Training Jobs API manages the full lifecycle of a fine-tuning job. All endpoints use the `/felix/training-jobs` route family and require an API key in the `X-API-Key` header.

```bash
-H "X-API-Key: YOUR_API_KEY"
```

Use `GET /base-models?supports_training=true` immediately before creating a job. It is the live source of truth for trainable model IDs.

The [production OpenAPI document](https://api.pioneer.ai/openapi.json) is the machine-readable source of truth for the current request and response schemas.

## Typical workflow

<Steps>
  <Step title="Create a job">
    Submit a ready dataset and a currently supported `base_model`.
  </Step>
  <Step title="Poll the job">
    Read `normalized_status` and stop polling when `is_terminal_status` is `true`.
  </Step>
  <Step title="Inspect the result">
    Read snapshot logs, training metrics, billing, and checkpoints.
  </Step>
  <Step title="Deliver the artifact">
    Deploy a deployable checkpoint or download the weights.
  </Step>
</Steps>

## Status lifecycle

The persisted `status` can include `requested`, `running`, `complete`, `normalizing`, `artifact_ready`, `deployed`, `paused`, `errored`, `stopped`, and `terminated`.

For automation, prefer:

- `normalized_status`: stable compatibility status such as `requested`, `running`, `complete`, `deployed`, `failed`, or `cancelled`.
- `is_terminal_status`: whether a polling loop can stop.
- `error_message`: failure details when available.
- `is_deployable` and `deployability_reason`: the server's deployment-readiness decision.

<Note>
  The `metrics` object may contain `final_training_loss`, `final_validation_loss`, and `best_validation_loss`. Evaluation quality metrics are separate and are not guaranteed to be present.
</Note>

## Endpoints

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `POST` | [`/felix/training-jobs`](/api-reference/training-jobs/create) | Create a training job |
| `GET` | [`/felix/training-jobs`](/api-reference/training-jobs/list) | List training jobs |
| `GET` | [`/felix/training-jobs/{job_id}`](/api-reference/training-jobs/get) | Get status, configuration, and metrics |
| `PATCH` | [`/felix/training-jobs/{job_id}`](/api-reference/training-jobs/update-project) | Assign or unassign a project |
| `PATCH` | [`/felix/training-jobs/{job_id}/model-name`](/api-reference/training-jobs/update-model-name) | Rename the trained model |
| `GET` | [`/felix/training-jobs/{job_id}/logs`](/api-reference/training-jobs/logs) | Get a snapshot of training logs |
| `GET` | [`/felix/training-jobs/{job_id}/billing`](/api-reference/training-jobs/billing) | Get the billing outcome |
| `POST` | [`/felix/training-jobs/{job_id}/stop`](/api-reference/training-jobs/stop) | Stop a job and preserve checkpoints |
| `POST` | [`/felix/training-jobs/{job_id}/terminate`](/api-reference/training-jobs/terminate) | Stop a job and delete checkpoints |
| `GET` | [`/felix/training-jobs/{job_id}/checkpoints`](/api-reference/training-jobs/checkpoints) | List checkpoints |
| `POST` | [`/felix/training-jobs/{job_id}/checkpoints/{checkpoint_id}/deploy`](/api-reference/training-jobs/deploy-checkpoint) | Deploy a checkpoint |
| `GET` | [`/felix/training-jobs/{job_id}/download`](/api-reference/training-jobs/download) | Get a temporary weights download URL |
| `DELETE` | [`/felix/training-jobs/{job_id}`](/api-reference/training-jobs/delete) | Delete a job and its checkpoints |

The deprecated `GET /felix/training-jobs/{job_id}/deployments` route is not part of this reference. Use `/projects/{project_id}/deployments` instead.
