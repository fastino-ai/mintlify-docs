`POST /inference` has been removed.

Use `POST /v1/chat/completions` for hosted GLiNER inference. The current request uses
`Authorization: Bearer $FASTINO_API_KEY` with top-level `model`, `messages`, and `schema`
fields.

See the [Inference API](/inference) for the canonical request, response, and migration
guidance.
