`GET /v1/gliner-2/jobs/{job_id}`

Poll a GLiNER-2 asynchronous job until it completes or fails. Use the same API key that
submitted the job; jobs are scoped to the authenticated user.

The OpenAPI panel on this page is the source of truth for the `job_id` path parameter and
every response field.

## Request example

```bash
curl "https://api.fastino.ai/v1/gliner-2/jobs/3f08a17f-777a-4aa6-8ec5-879df37775a8" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

## Processing response

Continue polling while `status` is `pending` or `processing`:

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "pending",
  "result": null,
  "error": null,
  "token_usage": 1284307,
  "created_at": "2026-10-07T22:10:00+00:00",
  "completed_at": null
}
```

## Complete response

Stop polling when `status` is `complete`. The `result` follows the schema from the
submission request:

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "complete",
  "result": {
    "entities": [
      {
        "text": "Apple",
        "label": "organization",
        "score": 0.99,
        "start": 0,
        "end": 5
      }
    ]
  },
  "error": null,
  "token_usage": 1284307,
  "created_at": "2026-10-07T22:10:00+00:00",
  "completed_at": "2026-10-07T22:13:42+00:00"
}
```

## Error response

A finished job can report `status: "error"` with a message in `error`:

```json
{
  "job_id": "3f08a17f-777a-4aa6-8ec5-879df37775a8",
  "status": "error",
  "result": null,
  "error": "The input could not be processed",
  "token_usage": 1284307,
  "created_at": "2026-10-07T22:10:00+00:00",
  "completed_at": "2026-10-07T22:10:08+00:00"
}
```

An unknown job, or one belonging to another user, returns `404`.
