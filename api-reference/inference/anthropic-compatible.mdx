Fastino implements an Anthropic-compatible Messages endpoint so you can run GLiNER models through the Anthropic SDK. Set `base_url` to `https://api.fastino.ai`, authenticate with your Fastino API key, and use a GLiNER model ID from `GET /v1/models` or your GLiNER training job ID as the model name. The Anthropic SDK appends `/v1/messages` itself.

## Supported SDK surface

| Anthropic SDK method | Fastino endpoint | GLiNER result |
|---|---|---|
| `client.messages.create(...)` | [`POST /v1/messages`](/api-reference/inference/messages) | Structured JSON in `message.content[0].text` |

<Warning>
  GLiNER inference returns one structured result and does not support `stream=True` or `client.messages.stream(...)`. Fastino does not implement every Anthropic API or SDK resource.
</Warning>

## Configure the Anthropic SDK

Pass your Fastino API key and base URL when constructing the client:

<CodeGroup>

```python Python
import anthropic

client = anthropic.Anthropic(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai"
)
```

</CodeGroup>

## Create a message

`POST /v1/messages` accepts the core Anthropic Messages fields. Set `model` to a supported GLiNER model ID, include your `messages` array, and pass the extraction or classification `schema` through `extra_body`.

### Request parameters

<ParamField body="model" type="string" required>
  Training job ID (e.g. `job_abc123`) or a base model ID. This is the model that processes your request.
</ParamField>

<ParamField body="max_tokens" type="number" required>
  Required by the Anthropic SDK for request compatibility. GLiNER returns structured output rather than generated tokens.
</ParamField>

<ParamField body="messages" type="object[]" required>
  Conversation messages. Each object has a `role` (`"user"` or `"assistant"`) and a `content` string.
</ParamField>

<ParamField body="schema" type="object">
  Fastino-specific extraction schema. Define `entities`, `classifications`, `structures`, or `relations` to control what the model extracts. See [Fastino inference](/api-reference/inference/pioneer) for full schema documentation.
</ParamField>

### Examples

<CodeGroup>

```python Python (Anthropic SDK)
import anthropic

client = anthropic.Anthropic(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai"
)

message = client.messages.create(
    model="YOUR_TRAINING_JOB_ID",
    max_tokens=1024,
    messages=[
        {
            "role": "user",
            "content": "Extract entities from: Apple launched the iPhone."
        }
    ],
    extra_body={
        "schema": {
            "entities": ["organization", "product"]
        }
    }
)

print(message.content[0].text)
```

```bash cURL
curl -X POST https://api.fastino.ai/v1/messages \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_TRAINING_JOB_ID",
    "max_tokens": 1024,
    "messages": [
      {
        "role": "user",
        "content": "Extract entities from: Apple launched the iPhone."
      }
    ],
    "schema": {
      "entities": ["organization", "product"]
    }
  }'
```

</CodeGroup>

## Streaming

GLiNER inference is non-streaming. Use `client.messages.create(...)` without `stream=True`; the API returns the complete structured result after processing the input.
