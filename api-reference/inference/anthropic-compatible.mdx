Fastino implements an Anthropic-compatible Messages endpoint so you can use supported Anthropic SDK methods with Fastino models. Set `base_url` to `https://api.fastino.ai`, authenticate with your Fastino API key, and use a model ID from `GET /v1/models` or your training job ID as the model name. The Anthropic SDK appends `/v1/messages` itself.

## Supported SDK surface

| Anthropic SDK method | Fastino endpoint | Streaming |
|---|---|---|
| `client.messages.create(...)` | `POST /v1/messages` | No (default) |
| `client.messages.create(..., stream=True)` | `POST /v1/messages` | Yes |
| `client.messages.stream(...)` | `POST /v1/messages` | Yes |

<Warning>
  Fastino does not implement every Anthropic API or SDK resource. Use the Messages methods listed above.
</Warning>

## Configure the Anthropic SDK

Pass your Fastino API key and base URL when constructing the client:

<CodeGroup>

```python Python
import anthropic

client = anthropic.Anthropic(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai"
)
```

</CodeGroup>

## Create a message

`POST /v1/messages` accepts the core Anthropic Messages fields. Set `model` to a supported model ID and include your `messages` array. You can pass Fastino-specific fields like `schema` alongside the standard Anthropic fields.

### Request parameters

<ParamField body="model" type="string" required>
  Training job ID (e.g. `job_abc123`) or a base model ID. This is the model that processes your request.
</ParamField>

<ParamField body="max_tokens" type="number" required>
  Maximum number of tokens to generate in the response.
</ParamField>

<ParamField body="messages" type="object[]" required>
  Conversation messages. Each object has a `role` (`"user"` or `"assistant"`) and a `content` string.
</ParamField>

<ParamField body="schema" type="object">
  Fastino-specific extraction schema. Define `entities`, `classifications`, `structures`, or `relations` to control what the model extracts. See [Fastino inference](/api-reference/inference/pioneer) for full schema documentation.
</ParamField>

### Examples

<CodeGroup>

```python Python (Anthropic SDK)
import anthropic

client = anthropic.Anthropic(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai"
)

message = client.messages.create(
    model="YOUR_TRAINING_JOB_ID",
    max_tokens=1024,
    messages=[
        {
            "role": "user",
            "content": "Extract entities from: Apple launched the iPhone."
        }
    ],
    extra_body={
        "schema": {
            "entities": ["organization", "product"]
        }
    }
)

print(message.content[0].text)
```

```bash cURL
curl -X POST https://api.fastino.ai/v1/messages \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_TRAINING_JOB_ID",
    "max_tokens": 1024,
    "messages": [
      {
        "role": "user",
        "content": "Extract entities from: Apple launched the iPhone."
      }
    ],
    "schema": {
      "entities": ["organization", "product"]
    }
  }'
```

</CodeGroup>

## Streaming

The `/v1/messages` endpoint supports streaming. Set `stream=True` in the SDK or `"stream": true` in the raw request body.

<CodeGroup>

```python Python (Anthropic SDK)
import anthropic

client = anthropic.Anthropic(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai"
)

with client.messages.stream(
    model="YOUR_TRAINING_JOB_ID",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Summarize the following: ..."}]
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)
```

```bash cURL
curl -X POST https://api.fastino.ai/v1/messages \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_TRAINING_JOB_ID",
    "max_tokens": 1024,
    "messages": [{"role": "user", "content": "Summarize the following: ..."}],
    "stream": true
  }'
```

</CodeGroup>
