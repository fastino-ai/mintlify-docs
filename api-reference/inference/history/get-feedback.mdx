`GET /v1/inferences/{inference_id}/feedback`

Retrieve the feedback stored for one inference.

## Identify the reviewer

Read `human_feedback_by` to identify the member who submitted the feedback. It
is a user ID, not a display name. The value is `null` for feedback recorded
before authorship tracking was available.

```bash
curl --fail-with-body -sS \
  "https://api.fastino.ai/v1/inferences/$INFERENCE_ID/feedback" \
  -H "X-API-Key: $FASTINO_API_KEY" |
  jq '{human_verdict, human_feedback_by}'
```

The inference record returned by `GET /v1/inferences/{inference_id}` also
includes `human_feedback_by` for its current feedback.
