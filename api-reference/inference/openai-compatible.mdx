Fastino exposes OpenAI-compatible endpoints so you can run GLiNER models through supported OpenAI SDK methods. Set `base_url` to `https://api.fastino.ai/v1`, authenticate with your Fastino API key, and pass a GLiNER model ID from `GET /v1/models` or your GLiNER training job ID as `model`. Pass the extraction or classification `schema` through `extra_body` in the Python SDK or directly in the JSON body.

<Tip>
  Reuse your OpenAI client for GLiNER by changing `base_url`, the API key, and the model ID, then adding the Fastino `schema`.
</Tip>

## Supported SDK surface

| OpenAI SDK method | Fastino endpoint | GLiNER result |
|---|---|---|
| `client.chat.completions.create(...)` | `POST /v1/chat/completions` | Structured JSON in `choices[0].message.content` |
| `client.responses.create(...)` | `POST /v1/responses` | Structured JSON in `response.output_text` |
| `client.models.list()` | `GET /v1/models` | Available model IDs |

<Warning>
  GLiNER inference returns one structured result and does not support `stream=True`. Fastino does not implement every OpenAI API or SDK resource; use only the methods listed above.
</Warning>

## Configure the OpenAI SDK

Point the SDK at Fastino's base URL and supply your Fastino API key:

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai/v1"
)
```

```bash cURL (base URL)
# Set this as the base for all requests
https://api.fastino.ai/v1
```

</CodeGroup>

## Chat completions

`POST /v1/chat/completions` accepts the core OpenAI Chat Completions fields. Pass a supported GLiNER model ID as `model` and include the extraction or classification `schema` through `extra_body`.

<CodeGroup>

```python Python (OpenAI SDK)
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai/v1"
)

response = client.chat.completions.create(
    model="YOUR_TRAINING_JOB_ID",
    messages=[
        {
            "role": "user",
            "content": "Extract entities from: Apple launched the iPhone."
        }
    ],
    extra_body={
        "schema": {
            "entities": ["organization", "product"]
        }
    }
)

print(response.choices[0].message.content)
```

```bash cURL
curl -X POST https://api.fastino.ai/v1/chat/completions \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_TRAINING_JOB_ID",
    "messages": [
      {
        "role": "user",
        "content": "Extract entities from: Apple launched the iPhone."
      }
    ],
    "schema": {
      "entities": ["organization", "product"]
    }
  }'
```

</CodeGroup>

## Responses

For GLiNER, the Responses API expects the schema at `text.format.schema`.

<CodeGroup>

```python Python (OpenAI SDK)
response = client.responses.create(
    model="YOUR_TRAINING_JOB_ID",
    input="Extract entities from: Apple launched the iPhone.",
    max_output_tokens=128,
    extra_body={
        "text": {
            "format": {
                "schema": {
                    "entities": ["organization", "product"]
                }
            }
        }
    }
)

print(response.output_text)
```

</CodeGroup>

## First call after idle

<Note>
  When a model has scaled to zero after a period without traffic, your first request can return HTTP `425` with error code `model_warming`. This is expected and does not mean your request is wrong. The model is usually ready within 30 to 60 seconds. The response includes a `Retry-After` header with the number of seconds to wait, and `x-should-retry: true`.
</Note>

The official OpenAI SDKs retry this response automatically because it carries `x-should-retry: true`. By default they retry 2 times and wait the `Retry-After` value between attempts (the Python SDK honors values up to 120 seconds). The default can run out before a slow warm-up finishes, so raise `max_retries` for a first call:

```python Python (OpenAI SDK)
response = client.with_options(max_retries=5).chat.completions.create(
    model="YOUR_TRAINING_JOB_ID",
    messages=[{"role": "user", "content": "Extract entities from: Apple launched the iPhone."}],
    extra_body={"schema": {"entities": ["organization", "product"]}},
)
```

To apply the limit to every request, pass `max_retries=5` to `OpenAI(...)` instead.

Without an SDK, send the same request again after the `Retry-After` delay. Each example retries at most 5 times, waits `Retry-After` seconds (30 if the header is missing), sets a 300-second client timeout, and stops on any other non-2xx response.

<CodeGroup>

```bash cURL
for attempt in 0 1 2 3 4 5; do
  http_code=$(curl -sS --max-time 300 -o response.json -D headers.txt -w "%{http_code}" \
    https://api.fastino.ai/v1/chat/completions \
    -H "X-API-Key: $FASTINO_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "YOUR_TRAINING_JOB_ID",
      "messages": [{ "role": "user", "content": "Extract entities from: Apple launched the iPhone." }],
      "schema": { "entities": ["organization", "product"] }
    }')
  [ "$http_code" = "425" ] && [ "$attempt" -lt 5 ] || break
  delay=$(awk 'tolower($1) == "retry-after:" && $2 + 0 > 0 { print $2 + 0 }' headers.txt)
  sleep "${delay:-30}"
done

if [ "$http_code" -ge 200 ] && [ "$http_code" -lt 300 ]; then
  cat response.json
else
  echo "Request failed with HTTP $http_code: $(cat response.json)" >&2
fi
```

```python Python
import os
import time
import requests

MAX_RETRIES = 5

for attempt in range(MAX_RETRIES + 1):
    response = requests.post(
        "https://api.fastino.ai/v1/chat/completions",
        headers={"X-API-Key": os.environ["FASTINO_API_KEY"]},
        json={
            "model": "YOUR_TRAINING_JOB_ID",
            "messages": [
                {"role": "user", "content": "Extract entities from: Apple launched the iPhone."}
            ],
            "schema": {"entities": ["organization", "product"]},
        },
        timeout=300,
    )
    if response.status_code != 425 or attempt == MAX_RETRIES:
        break
    retry_after = response.headers.get("Retry-After", "")
    time.sleep(int(retry_after) if retry_after.isdigit() else 30)

if not 200 <= response.status_code < 300:
    raise RuntimeError(f"Request failed: {response.status_code} {response.text}")
print(response.json()["choices"][0]["message"]["content"])
```

```javascript JavaScript
const MAX_RETRIES = 5;
let response;

for (let attempt = 0; attempt <= MAX_RETRIES; attempt++) {
  response = await fetch("https://api.fastino.ai/v1/chat/completions", {
    method: "POST",
    headers: {
      "X-API-Key": process.env.FASTINO_API_KEY,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "YOUR_TRAINING_JOB_ID",
      messages: [{ role: "user", content: "Extract entities from: Apple launched the iPhone." }],
      schema: { entities: ["organization", "product"] },
    }),
    signal: AbortSignal.timeout(300_000),
  });
  if (response.status !== 425 || attempt === MAX_RETRIES) break;
  const retryAfter = Number(response.headers.get("Retry-After"));
  await new Promise((resolve) => setTimeout(resolve, (retryAfter || 30) * 1000));
}

if (!response.ok) {
  throw new Error(`Request failed: ${response.status} ${await response.text()}`);
}
const completion = await response.json();
console.log(completion.choices[0].message.content);
```

</CodeGroup>

## Streaming

GLiNER inference is non-streaming. Do not set `stream=True`; the API returns the complete structured result after processing the input.

## Passing Fastino-specific fields

For Chat Completions, pass `schema` through `extra_body={"schema": ...}`. For Responses, pass it through `extra_body={"text": {"format": {"schema": ...}}}`. Raw HTTP requests use the same endpoint-specific shapes.
