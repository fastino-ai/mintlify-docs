Fastino exposes OpenAI-compatible endpoints so you can use supported OpenAI SDK methods with Fastino models. Set `base_url` to `https://api.fastino.ai/v1`, authenticate with your Fastino API key, and pass a model ID from `GET /v1/models` or your training job ID as `model`. Fastino-specific fields such as `schema` can be passed through `extra_body` in the Python SDK or included directly in the JSON body.

<Tip>
  For the supported methods below, an existing OpenAI integration usually needs only a new `base_url`, API key, and model ID.
</Tip>

## Supported SDK surface

| OpenAI SDK method | Fastino endpoint | Streaming |
|---|---|---|
| `client.chat.completions.create(...)` | `POST /v1/chat/completions` | Yes |
| `client.responses.create(...)` | `POST /v1/responses` | Yes |
| `client.models.list()` | `GET /v1/models` | Not applicable |

<Warning>
  Fastino does not implement every OpenAI API or SDK resource. Use only the methods listed above. Legacy `POST /v1/completions` has been removed; migrate prompt-based requests to Chat Completions.
</Warning>

## Configure the OpenAI SDK

Point the SDK at Fastino's base URL and supply your Fastino API key:

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai/v1"
)
```

```bash cURL (base URL)
# Set this as the base for all requests
https://api.fastino.ai/v1
```

</CodeGroup>

## Chat completions

`POST /v1/chat/completions` accepts the core OpenAI Chat Completions fields. Pass a supported model ID as `model` and include Fastino-specific fields like `schema` in the request body or through `extra_body`.

<CodeGroup>

```python Python (OpenAI SDK)
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.fastino.ai/v1"
)

response = client.chat.completions.create(
    model="YOUR_TRAINING_JOB_ID",
    messages=[
        {
            "role": "user",
            "content": "Extract entities from: Apple launched the iPhone."
        }
    ],
    extra_body={
        "schema": {
            "entities": ["organization", "product"]
        }
    }
)

print(response.choices[0].message.content)
```

```bash cURL
curl -X POST https://api.fastino.ai/v1/chat/completions \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_TRAINING_JOB_ID",
    "messages": [
      {
        "role": "user",
        "content": "Extract entities from: Apple launched the iPhone."
      }
    ],
    "schema": {
      "entities": ["organization", "product"]
    }
  }'
```

</CodeGroup>

## List available models

Use `GET /v1/models` to retrieve the list of models you can use with these endpoints.

<CodeGroup>

```python Python (OpenAI SDK)
models = client.models.list()
for model in models.data:
    print(model.id)
```

```bash cURL
curl https://api.fastino.ai/v1/models \
  -H "X-API-Key: YOUR_API_KEY"
```

</CodeGroup>

## Streaming

Chat Completions and Responses support streaming. Set `stream=True` in the SDK or `"stream": true` in the request body.

<CodeGroup>

```python Python (OpenAI SDK)
stream = client.chat.completions.create(
    model="YOUR_TRAINING_JOB_ID",
    messages=[{"role": "user", "content": "Summarize the following article: ..."}],
    stream=True
)

for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="")
```

```bash cURL
curl -X POST https://api.fastino.ai/v1/chat/completions \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_TRAINING_JOB_ID",
    "messages": [{"role": "user", "content": "Summarize the following article: ..."}],
    "stream": true
  }'
```

</CodeGroup>

## Passing Fastino-specific fields

The `schema` field is a Fastino extension. In the OpenAI Python SDK, pass it via `extra_body` so it is included in the request without affecting SDK validation. In a raw HTTP request, include it at the top level of the JSON body alongside standard fields like `model` and `messages`.
