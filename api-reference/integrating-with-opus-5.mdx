## Integrating Pioneer with Opus 5

Point your agent at Pioneer's inference endpoint and switch between models using each agent's native `/model` command.

1. Download and [set up](https://code.claude.com/docs/en/quickstart) Claude Code.
2. Follow the [Claude Code integration](/claude-code) guide to point Claude Code at Pioneer and launch with `claude-opus-5`.
3. Use `/model` to switch between supported Pioneer models. Query `GET /base-models?supports_inference=true` for the live catalog.
