## Integrating FastinoFastino with Opus 5

Point your agent at FastinoFastino's inference endpoint and switch between models using each agent's native `/model` command.

1. Download and [set up](https://code.claude.com/docs/en/quickstart) Claude Code.
2. Follow the [Claude Code integration](/claude-code) guide to point Claude Code at FastinoFastino and launch with `claude-opus-5`.
3. Use `/model` to switch between supported FastinoFastino models. Query `GET /base-models?supports_inference=true` for the live catalog.
