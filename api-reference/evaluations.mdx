Evaluation suites pin labeled cases and scorer configuration to a project. Run the same suite against one or more base or fine-tuned models to compare them consistently before deployment.

## Workflow

<Steps>
  <Step title="Create an evaluation suite">
    Call `POST /v1/projects/{project_id}/evaluation-suites` with one supported source and its field mapping.
  </Step>
  <Step title="Start runs">
    Call `POST /v1/projects/{project_id}/evaluation-suites/{suite_id}/runs` with the model IDs to compare.
  </Step>
  <Step title="Poll the run">
    Call `GET /v1/projects/{project_id}/evaluation-runs/{run_id}` until the run reaches a terminal state.
  </Step>
  <Step title="Read case results">
    Call `GET /v1/projects/{project_id}/evaluation-runs/{run_id}/results` for the scored examples.
  </Step>
</Steps>

## Create a suite

```text
POST /v1/projects/{project_id}/evaluation-suites
```

<ParamField body="name" type="string" required>
  A project-scoped suite name.
</ParamField>

<ParamField body="source_kind" type="string" required>
  One of `agent_generated`, `huggingface`, `platform_catalog`, or `upload`.
</ParamField>

<ParamField body="task_type" type="string" required>
  The task evaluated by the pinned cases.
</ParamField>

<ParamField body="dataset_id" type="string">
  Dataset source ID when the selected source kind uses an uploaded dataset.
</ParamField>

<ParamField body="field_mapping" type="object">
  Maps source fields to the evaluator's expected inputs and labels.
</ParamField>

<ParamField body="scorer_kind" type="string" default="native">
  One of `native`, `llmaj`, or `harness`.
</ParamField>

```bash
curl -X POST "https://api.fastino.ai/v1/projects/PROJECT_ID/evaluation-suites" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "held-out-ner",
    "source_kind": "upload",
    "task_type": "ner",
    "dataset_id": "DATASET_ID",
    "field_mapping": {
      "text": "text",
      "labels": "entities"
    }
  }'
```

## Start suite runs

```text
POST /v1/projects/{project_id}/evaluation-suites/{suite_id}/runs
```

<ParamField body="model_ids" type="string[]" required>
  Between 1 and 20 base-model or fine-tuned model IDs to compare.
</ParamField>

<ParamField body="max_examples" type="number">
  Optional cap on pinned cases executed for each model.
</ParamField>

```bash
curl -X POST "https://api.fastino.ai/v1/projects/PROJECT_ID/evaluation-suites/SUITE_ID/runs" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model_ids": ["BASE_MODEL_ID", "TRAINING_JOB_ID"]
  }'
```

The response contains one run record per selected model. Save each run ID.

## Retrieve a run

```bash
curl "https://api.fastino.ai/v1/projects/PROJECT_ID/evaluation-runs/RUN_ID" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

For case-level results:

```bash
curl "https://api.fastino.ai/v1/projects/PROJECT_ID/evaluation-runs/RUN_ID/results" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

Use the response status and metrics as returned by the API. Do not promote a model solely from aggregate scores; inspect per-case failures and compare every model on the same pinned suite.
