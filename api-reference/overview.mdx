Use this page to choose an endpoint family. The OpenAPI specification owns methods, paths, authentication, request fields, and response schemas; guides explain when and why to use them.

## Authentication and conventions

Native Fastino endpoints use `X-API-Key: $FASTINO_API_KEY`. Compatibility endpoints use the authentication shown on their exact reference page. See [Authentication](/api-reference/authentication) and [Errors](/api-reference/errors).

## Choose an endpoint

| Task | Canonical route | Reference |
| --- | --- | --- |
| GLiDE decisions | `POST /v1/systemone` | [Open reference](/api-reference/decision/systemone) |
| GLiNER and decoder inference | `POST /v1/chat/completions` | [Open reference](/api-reference/inference/chat-completions) |
| OpenAI Responses compatibility | `POST /v1/responses` | [Open reference](/api-reference/inference/responses) |
| Anthropic Messages compatibility | `POST /v1/messages` | [Open reference](/api-reference/inference/messages) |
| Large GLiNER-2 inputs | `POST /v1/gliner-2/async` + job polling | [Open reference](/api-reference/inference/gliner-2-async) |
| Live capability and trainability | `GET /v1/base-models` | [Open reference](/api-reference/models/base-models) |
| Compatibility SDK model list | `GET /v1/models` | [Open reference](/api-reference/models/compatibility-models) |
| Dataset upload and versions | `/v1/datasets` | [Open reference](/api-reference/datasets/list) |
| Training lifecycle | `/v1/training-jobs` | [Open reference](/api-reference/training-jobs/create) |
| Inference history and feedback | `/v1/inferences` | [Open reference](/api-reference/inference/history/list) |
