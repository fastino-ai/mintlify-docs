`POST /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

Marks a checkpoint public. Its `public` field becomes `true`. Returns
`204 No Content`. Undo it with
[`DELETE .../publish`](/api-reference/interactive-jobs/unpublish-checkpoint).

`kind` is `weights` or `sampler_weights`.

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/sampler_weights/step-000100/publish" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
