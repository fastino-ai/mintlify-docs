`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

Deletes a checkpoint. It stops counting toward storage right away; its files
are purged later. Returns `204 No Content`.

`kind` is `weights` or `sampler_weights`.

<RequestExample>

```bash cURL
curl -X DELETE "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
