Use these contracts for field-level details. Start with the lifecycle guides when building an end-to-end training workflow.

The public REST surface covers:

- Base-model discovery and dataset management
- Managed `config` job creation with `POST /v1/training/jobs`
- Canonical lifecycle operations under `/v1/training/jobs` for both `config`
  and `interactive` jobs
- Native interactive creation, model operations, checkpoints, sampling, and
  checkpoint storage usage

Native JSON clients use the operations in this reference. Existing Tinker
clients keep `tinker==0.32.0` and set
`TINKER_BASE_URL=https://api.fastino.ai/v1/training/compat/tinker` plus
`TINKER_CREDENTIAL_CMD`. Compatibility child routes are private and absent from
OpenAPI. Auto Train remains private access and has no public API contract.
