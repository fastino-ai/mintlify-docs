Use these contracts for field-level details. Start with the lifecycle guides when building an end-to-end training workflow.

The public REST surface covers:

- Base-model discovery and dataset management
- Managed `config` job creation with `POST /v1/training/jobs` for supported
  encoders and decoders
- [Interactive jobs](/api-reference/interactive-jobs/create) for manual decoder training:
  `POST /v1/training/jobs/create-model`, then forward-backward passes,
  optimizer steps, checkpoints, and sampling under `/v1/training/jobs/{job_id}`
- Canonical lifecycle operations under `/v1/training/jobs` for both `config`
  and `interactive` jobs

Auto Train remains private access and has no public API contract.
