`GET /v1/datasets`

List datasets available to the authenticated Fastino account.

## Result behavior

By default, the response contains the latest version of each dataset name and
excludes failed uploads. Set `include_all_versions=true` to return every
version or `include_failed=true` to include your failed uploads.

Results are newest first. `limit` defaults to 200 and cannot exceed 200; use
`offset` to request subsequent pages.
