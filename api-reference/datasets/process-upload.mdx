`POST /v1/datasets/upload/process`

Queue processing after a dataset file upload completes.

## Asynchronous processing

A successful request returns `202` and queues processing; it does not mean the
dataset is ready. Poll
[`GET /v1/datasets/{name}`](/api-reference/datasets/versions), select the exact
`version_number` returned when the upload URL was created, and continue until
its `status` is `ready` or `failed`. For a failure, read `processing_error`
before correcting the file and uploading a new version.

A `503` means storage verification or queueing failed before processing began
and the same upload can be retried.

## Authorization

Requires the Owner, Admin, or Editor team role. Other roles receive `403 Forbidden`.
