`GET /v1/datasets/{name}`

List all visible versions and metadata for one dataset.

## Processing status

The response contains `success`, `versions`, and `count`. Match
`version_number` exactly when polling a recent upload. A version is usable for
training only when its `status` is `ready`; `failed` versions include
`processing_error`.
