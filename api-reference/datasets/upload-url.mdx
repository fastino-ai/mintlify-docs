`POST /v1/datasets/upload/url`

Create a presigned upload URL for a new dataset file.

## Upload the file

Upload the exact file bytes to `presigned_url` before it expires. The signed
request requires `Content-Type: application/octet-stream`; omitting that header
or using another value returns `403`.

```bash
curl --fail-with-body -X PUT \
  -H "Content-Type: application/octet-stream" \
  --upload-file training.jsonl "$PRESIGNED_URL"
```

After the upload succeeds, pass the returned `dataset_id` to
[`POST /v1/datasets/upload/process`](/api-reference/datasets/process-upload).

## Authorization

Requires the Owner, Admin, or Editor team role. Other roles receive `403 Forbidden`.
