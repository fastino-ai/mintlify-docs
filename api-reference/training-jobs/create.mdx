`POST /v1/training/jobs`

<Warning>
  This renamed Training API is available in the development contract. Its production rollout is not yet verified: production may return `404` for `/v1/training/jobs`. Confirm availability for your team before launching paid work.
</Warning>

Creates an asynchronous `config` training job and returns its job record. In a
config job, you provide a dataset and configuration and Fastino runs the
training loop. To control the loop step by step, follow the
[custom training loop path](/training/quickstart#custom-training-loop), which
creates an `interactive` job through
[`POST /v1/training/jobs/create-model`](/api-reference/training-jobs/interactive/create-model)
or the supported Tinker SDK. This endpoint does not create interactive jobs.
After creation, both job types use their canonical IDs with the documented
`/v1/training/jobs/{job_id}` lifecycle operations.

Config jobs train encoder models that are returned by
`GET /v1/base-models?supports_training=true` and have a compatible config-job
dispatch route. Decoder base models return `400`; train decoders step by step
with an interactive job instead.

This endpoint is limited to 20 requests per minute per user.

## Request

<ParamField header="X-API-Key" type="string" required>
  Your Fastino API key.
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  Client-generated retry key, 1–255 characters; a UUID is recommended. Repeating the same key and body returns the original job. Reusing the key with a different body returns `422`.
</ParamField>

<ParamField body="model_name" type="string" required>
  Display name for the trained model. Length: 1–100 characters.
</ParamField>

<ParamField body="base_model" type="string" required>
  A trainable encoder ID returned by `GET /v1/base-models?supports_training=true`, or a supported checkpoint UUID. The selected `training_type` must have a compatible dispatch route. A decoder base model returns `400`.
</ParamField>

<ParamField body="datasets" type="object[]" required>
  One or more [uploaded dataset](/concepts/datasets) references. Each item requires `name` and may include `version`; omitted versions resolve to the latest version.
</ParamField>

<ParamField body="training_type" type="string" default="lora">
  `lora` or `full`. The selected base model must support the requested type.
</ParamField>

<ParamField body="validation_data_percentage" type="number" default="0.2">
  Fraction held out for validation, from `0` to `0.9` in increments of `0.01`.
</ParamField>

<ParamField body="nr_epochs" type="integer" default="100">
  Maximum epoch count, from `1` to `10000`; early stopping can finish sooner.
</ParamField>

<ParamField body="learning_rate" type="number">
  Peak learning rate from `1e-8` to `1`. Omit it to use the selected model's training recipe.
</ParamField>

<ParamField body="batch_size" type="integer" default="4">
  Per-device batch size from `1` to `256`. Prefer omitting it so the training service can apply or safely clamp to the model-specific default.
</ParamField>

<ParamField body="seed" type="integer">
  Optional reproducibility seed from `0` through `2147483647`. Set `provider_name` to `modal` when using it. A seed reduces one source of variation but does not guarantee bit-identical GPU runs.
</ParamField>

<ParamField body="project_id" type="string">
  Project UUID. When omitted, Fastino associates the job with the caller's default project.
</ParamField>

  <ParamField body="gradient_accumulation_steps" type="integer">

  <ParamField body="min_samples_per_dataset" type="integer">

  <ParamField body="max_samples_per_dataset" type="integer">
    GLiNER auto-sizing upper bound, from `1` to `2147483647`.

  <ParamField body="samples_per_label" type="integer">
    GLiNER auto-sizing scale per label, from `1` to `2147483647`.

    GLiNER2 per-dataset cap for periodic validation, from `1` to `2147483647`. Omit it for no cap.

    GLiNER maximum input length, from `1` to `2147483647` tokens. Omit it to use the model context limit.

    GLiNER2 maximum retained gold spans per query, from `1` to `1024`. Omit it to use `32`.
  </ParamField>

    GLiNER2 behavior when gold spans exceed `max_gold_per_query`: `raise`, `truncate_with_warning`, or `skip_sample`. Omit it to use `raise`.

    Only `sft` is supported for config jobs. Omit it to use the default.
  </ParamField>

</Expandable>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Idempotency-Key: YOUR_UNIQUE_RETRY_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model_name": "my-model-name",
    "base_model": "fastino/gliner2-multi-v1",
    "datasets": [{"name": "my-ready-dataset"}],
    "training_type": "lora",
    "nr_epochs": 5,
    "learning_rate": 5e-5,
    "validation_data_percentage": 0.2
  }'
```

</RequestExample>

## Response

Returns `200` with the full training-job record, including a UUID `id` and initial status. The example below is abbreviated; the actual response includes all fields defined by `TrainingJobResponse`.

<ResponseExample>

```json Response
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "type": "config",
  "model_name": "my-model-name",
  "base_model": "fastino/gliner2-multi-v1",
  "status": "requested",
  "training_type": "lora",
  "nr_epochs": 5,
  "learning_rate": 5e-5,
  "validation_data_percentage": 0.2
}
```

</ResponseExample>

Save the `id` from this response. You will use it to poll status, retrieve metrics and artifacts, and run inference against the trained model.

A malformed body returns `422`. A valid but unavailable model, dataset, training type, or provider combination returns a request-specific `4xx` error.

Creation can return these coded conflicts:

| Status | Meaning |
| --- | --- |
| `409 duplicate_training_submission` | An identical job is already active. |
| `409 idempotency_key_job_deleted` | The job originally created with this idempotency key was deleted. Use a new key for a new job. |
| `409` | A referenced dataset retired between validation and job insertion. Resolve the dataset and retry with a new key. |

The same `Idempotency-Key` and identical body replay the original job instead of creating another. A changed body with the same key returns `422`.

A decoder base model returns `400`:

```json
{
  "detail": "Decoder training on this route is retired: 'Qwen/Qwen3.6-35B-A3B' cannot be trained here. Train decoders step by step with the training job routes under /v1/training/jobs (see https://docs.fastino.ai/training/quickstart)."
}
```

To train a decoder, create an interactive job with
[`POST /v1/training/jobs/create-model`](/api-reference/training-jobs/interactive/create-model)
and follow the [custom training loop](/training/quickstart#custom-training-loop).

## Authorization

Requires the Owner, Admin, or Editor team role. Other roles receive `403 Forbidden`.
