`GET /v1/training/jobs/{job_id}/logs`

This operation is config-only; after normal feature and permission checks, an interactive job ID returns `400`, so inspect each interactive operation through its future instead.

Returns structured `stdout`, `stderr`, and `system` entries. This endpoint does
not stream; poll it to follow a running job.

## Request

<ParamField header="X-API-Key" type="string" required>
  Your Fastino API key.
</ParamField>

<ParamField path="job_id" type="string" required>
  Training-job UUID.
</ParamField>

<RequestExample>

```bash cURL
curl https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID/logs \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Response

<ResponseField name="job_id" type="string">
  Training-job UUID.
</ResponseField>

<ResponseField name="logs" type="object[]">
  Log entries. Each entry contains `id`, `job_id`, `timestamp`, `level`,
  `message`, and `source`. Fastino emits `stdout`, `stderr`, or `system` as the
  source. The API schema represents this field as a string rather than a
  closed enum.
</ResponseField>

<ResponseField name="total_logs" type="integer">
  Number of entries returned.
</ResponseField>

<ResponseExample>

```json Response
{
  "job_id": "YOUR_TRAINING_JOB_ID",
  "logs": [
    {
      "id": "LOG_ID",
      "job_id": "YOUR_TRAINING_JOB_ID",
      "timestamp": "2026-09-22T20:00:00Z",
      "level": "INFO",
      "message": "Epoch 2 completed",
      "source": "stdout"
    }
  ],
  "total_logs": 1
}
```

</ResponseExample>

An unknown or inaccessible job returns `404`.
