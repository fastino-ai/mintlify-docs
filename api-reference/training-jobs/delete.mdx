`DELETE /v1/training/jobs/{job_id}`

Deletes a config or interactive job and its stored artifacts.

<Warning>
  Deletion is irreversible. First download anything you need into storage you
  control.
</Warning>

For a config job, the service first requests cancellation when the job is
active. Deletion completes in the same call only when cancellation is confirmed.
It removes checkpoints and stored artifacts and releases active hosted
deployments.

For an interactive job, the service cancels queued non-sampling training calls,
requests a stop, and marks the job and its checkpoints deleted in the same
request. The job immediately becomes unavailable through list, get, checkpoint,
and future routes. Queued sampling calls and calls already running still finish
and are billed before background cleanup completes.

Models already deployed from the job's sampler checkpoints remain separate
model resources and continue serving until deleted separately.

## Request

<ParamField header="X-API-Key" type="string" required>
  Your Fastino API key.
</ParamField>

<ParamField path="job_id" type="string" required>
  Config-job UUID or interactive job ID.
</ParamField>

<RequestExample>

```bash cURL
curl -X DELETE https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Response

<ResponseExample>

```json Response
{
  "success": true,
  "message": "Training job deleted successfully"
}
```

</ResponseExample>

An unknown or inaccessible job returns `404`.

| Status | Meaning |
| --- | --- |
| `409 training_job_already_finished` | For a config job, the job completed or failed before cancellation landed. Read the job state before deciding whether to retry. |
| `409 cancellation_unconfirmed` | For a config job, the job is still stopping. Poll `GET /v1/training/jobs/{job_id}`, then retry this `DELETE` after the job is stopped. Deletion does not complete in the background. |

## Authorization

Requires the Owner, Admin, or Editor team role. Other roles receive `403 Forbidden`.
