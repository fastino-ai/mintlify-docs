`GET /v1/training/usage`

Returns the team's live interactive-job checkpoint storage, one row per
project, with its estimated monthly cost. The compatibility fields
`org_user_urn` and `user_name` contain the team ID; `user_email` is `null`.
Deleted and expired checkpoints don't count.

<ParamField query="project_id" type="string">
  Only this project's storage.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/usage" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>
