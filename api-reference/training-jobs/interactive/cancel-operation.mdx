`POST /v1/training/jobs/{job_id}/operations/{operation_id}/cancel`

Requests best-effort cancellation of a queued or running sample operation. Training operations cannot be cancelled.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
