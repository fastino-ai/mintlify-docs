`POST /v1/training/jobs/{job_id}/checkpoints`

Queues a checkpoint save and returns an `operation_id`. Save kind `state` creates `weights`; save kind `sampler` creates `sampler_weights`. Poll [Get an operation](/api-reference/training-jobs/interactive/get-operation) before using the checkpoint.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
