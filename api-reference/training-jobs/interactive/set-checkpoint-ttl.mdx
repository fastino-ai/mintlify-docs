`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

Keeps a checkpoint for `ttl_seconds` from now, then deletes it. Omit
`ttl_seconds` or send `null` to keep the checkpoint until you delete it. Returns `204 No Content`.

`kind` is `weights` or `sampler_weights`.

<ParamField body="ttl_seconds" type="integer | null">
  From `3600` (1 hour) to `315360000` (10 years), or `null`.
</ParamField>

<RequestExample>

```bash cURL
curl -X PUT "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/weights/step-000100/ttl" \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"ttl_seconds": 604800}'
```

</RequestExample>

## Errors

| Status | Meaning |
| --- | --- |
| `400` | `ttl_seconds` is outside 3600–315360000. |
| `404` | The job or checkpoint doesn't exist, or belongs to another team. |
| `422` | The body contains an unknown field. |
