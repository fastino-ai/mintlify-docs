`PUT /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/ttl`

Sets the retention period for a `weights` or `sampler_weights` checkpoint. A null TTL keeps the checkpoint until deletion.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
