`GET /v1/training/jobs/{job_id}/operations/{operation_id}`

Returns the operation status and result. With `wait=true`, the request waits for at most 25 seconds and can still return a nonterminal status. Poll until `completed`, `failed`, or `cancelled`. An HTTP error means that the server rejected the request. A queued operation can instead finish with `status: "failed"` and an `error.message`; treat `error.category` as an opaque string.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
