`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

Cancellation is best effort for a queued or running `sample` future. The route
returns `204 No Content` when the request is accepted. Cancelling a terminal
future or a training future also returns `204`; it is a successful no-op because
training operations run in order and are not cancelled.

<RequestExample>

```bash cURL
curl -X POST "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/futures/$FUTURE_ID/cancel" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Errors

| Status | Meaning |
| --- | --- |
| `404` | The job or future doesn't exist, or belongs to another team. |
