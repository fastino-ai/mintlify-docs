`POST /v1/training/jobs/{job_id}/futures/{future_id}/cancel`

Requests best-effort cancellation of a queued or running sample future. Only sample futures can be cancelled. Training futures run in order and cannot be cancelled.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
