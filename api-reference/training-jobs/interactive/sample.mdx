`POST /v1/training/jobs/{job_id}/sample`

Queues sampling from `checkpoint` and returns a `future_id`. Use a sampler checkpoint name or this job's own `tinker://<job_id>/sampler_weights/<name>` path. Sampling remains available after the interactive job is stopped. Poll [Get a future](/api-reference/training-jobs/interactive/get-future) until it reaches a terminal status.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
