`POST /v1/training/jobs/{job_id}/checkpoints/sampler_weights/{name}/sample`

Queues sampling from a `sampler_weights` checkpoint and returns an `operation_id`. Sampling remains available after the interactive job is stopped. Poll [Get an operation](/api-reference/training-jobs/interactive/get-operation) until it reaches a terminal status.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
