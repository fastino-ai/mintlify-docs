`POST /v1/training/jobs/create-model`

Creates an interactive LoRA job from `base_model`, or from `from_checkpoint` with the optional `load_optimizer` setting. The response includes the `job_id` and the create `future_id`. If you restore a checkpoint, it also includes `load_future_id`. Native JSON clients do not send `seq_id` values or heartbeats.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
