`POST /v1/training/jobs/{job_id}/optim-step`

Queues an optimizer step over accumulated gradients and returns an `operation_id`. The request body is optional. Poll [Get an operation](/api-reference/training-jobs/interactive/get-operation) until it reaches a terminal status.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
