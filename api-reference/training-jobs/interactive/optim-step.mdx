`POST /v1/training/jobs/{job_id}/optim-step`

Queues an optimizer step over accumulated gradients and returns a `future_id`. The request body is optional. Poll [Get a future](/api-reference/training-jobs/interactive/get-future) until it reaches a terminal status.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
