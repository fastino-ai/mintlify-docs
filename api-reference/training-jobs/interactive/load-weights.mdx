`POST /v1/training/jobs/{job_id}/load-weights`

Queues a load from `path` and returns a `future_id`. Use a state name or this job's own `tinker://<job_id>/weights/<name>` path. Set `optimizer` to restore the optimizer state. Poll [Get a future](/api-reference/training-jobs/interactive/get-future) until it reaches a terminal status.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
