`POST /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}/publish`

Publishes a `weights` or `sampler_weights` checkpoint. Publication does not grant another team permission to load it.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
