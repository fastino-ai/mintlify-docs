`POST /v1/training/jobs/interactive`

Creates an interactive job from `base_model`, or from `from_checkpoint` with the optional `load_optimizer` setting. Native JSON clients do not send `seq_id` values or heartbeats.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
