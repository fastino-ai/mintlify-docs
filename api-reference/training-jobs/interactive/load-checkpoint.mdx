`POST /v1/training/jobs/{job_id}/load-weights`

Queues a training-state load from a `weights` checkpoint and returns an `future_id`. The request can restore optimizer state. Poll [Get an operation](/api-reference/training-jobs/interactive/get-operation) until it reaches a terminal status.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
