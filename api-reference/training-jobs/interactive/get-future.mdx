`GET /v1/training/jobs/{job_id}/futures/{future_id}`

Returns the future status and result. With `wait=true`, the request waits for at most 25 seconds and can still return a nonterminal status. Poll until `completed`, `failed`, or `cancelled`. The service retains a result for one hour. An HTTP error means that the server rejected the request. A queued future can instead finish with `status: "failed"` and an `error.message`; treat `error.category` as an opaque string.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
