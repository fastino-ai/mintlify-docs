`POST /v1/training/jobs/{job_id}/save-weights-for-sampler`

Saves the LoRA weights under `name` for sampling and PEFT download. The accepted response contains a `future_id`, a `sampler_weights/<name>` checkpoint ID, and its `tinker://` path. Poll [Get a future](/api-reference/training-jobs/interactive/get-future) before sampling or downloading.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
