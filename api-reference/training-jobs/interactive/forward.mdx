`POST /v1/training/jobs/{job_id}/forward`

Queues a forward pass without gradients and returns a `future_id`. Poll [Get a future](/api-reference/training-jobs/interactive/get-future) until the status is `completed`, `failed`, or `cancelled`.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
