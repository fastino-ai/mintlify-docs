`DELETE /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

Deletes a `weights` or `sampler_weights` checkpoint. The operation completes synchronously with no response body. Stored files can be purged later.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
