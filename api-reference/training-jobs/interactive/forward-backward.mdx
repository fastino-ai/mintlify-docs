`POST /v1/training/jobs/{job_id}/forward-backward`

Queues a forward-backward pass that accumulates gradients and returns a `future_id`. Poll [Get a future](/api-reference/training-jobs/interactive/get-future) until it reaches a terminal status.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
