`POST /v1/training/jobs/{job_id}/forward-backward`

Queues a forward and backward pass that accumulates gradients, then returns an `operation_id`. Poll [Get an operation](/api-reference/training-jobs/interactive/get-operation) until it reaches a terminal status.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
