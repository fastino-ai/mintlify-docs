`POST /v1/training/jobs/{job_id}/save-weights`

Saves the LoRA weights and optimizer state under `name`. The accepted response contains a `future_id`, a `weights/<name>` checkpoint ID, and its `tinker://` path. Poll [Get a future](/api-reference/training-jobs/interactive/get-future) before loading the state or starting another job from it.

See [the custom training loop](/training/training-loop) for the end-to-end lifecycle.
