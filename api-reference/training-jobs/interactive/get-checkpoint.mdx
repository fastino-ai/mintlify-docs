`GET /v1/training/jobs/{job_id}/checkpoints/{kind}/{name}`

Returns one checkpoint. To list all of a job's checkpoints, use
[`GET /v1/training/jobs/{job_id}/checkpoints`](/api-reference/training-jobs/checkpoints).

## Request

<ParamField path="job_id" type="string" required>
  Interactive job ID.
</ParamField>

<ParamField path="kind" type="string" required>
  `weights` for a state checkpoint, or `sampler_weights` for a sampler checkpoint.
</ParamField>

<ParamField path="name" type="string" required>
  Checkpoint name.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs/$TRAINING_JOB_ID/checkpoints/sampler_weights/step-000100" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Response

<ResponseExample>

```json Response
{
  "checkpoint_id": "sampler_weights/step-000100",
  "checkpoint_type": "sampler",
  "time": "2026-10-14T12:00:00Z",
  "tinker_path": "tinker://SESSION_ID:train:0/sampler_weights/step-000100",
  "size_bytes": 268435456,
  "public": false,
  "user_metadata": null,
  "expires_at": "2026-10-15T12:00:00Z"
}
```

</ResponseExample>

`checkpoint_type` is `training` for a state checkpoint and `sampler` for a
sampler checkpoint. `expires_at` is `null` when the checkpoint has no TTL.
