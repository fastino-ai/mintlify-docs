`POST /felix/training-jobs/{job_id}/sync`

Requests an immediate provider-status refresh and returns the updated training-job record.

## Request

<ParamField header="X-API-Key" type="string" required>
  Your Fastino API key.
</ParamField>

<ParamField path="job_id" type="string" required>
  Training-job UUID.
</ParamField>

```bash
curl -X POST https://api.pioneer.ai/felix/training-jobs/YOUR_TRAINING_JOB_ID/sync \
  -H "X-API-Key: YOUR_API_KEY"
```

## Response

Returns `200` with the same job shape as [`GET /felix/training-jobs/{job_id}`](/api-reference/training-jobs/get). Use `normalized_status` and `is_terminal_status` for polling decisions.

An unknown job returns `404`. Provider synchronization failures return a request-specific `4xx` or `5xx` error.
