`POST /v1/training/jobs/{job_id}/sync`

This operation is config-only; after normal feature and permission checks, an interactive job ID returns `400`, while interactive jobs expose current state through `GET /v1/training/jobs/{job_id}` and futures.

Refresh the training-job status from its training provider.
