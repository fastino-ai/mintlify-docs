`GET /v1/training/jobs/{job_id}/deployments`

This operation is config-only; after normal feature and permission checks, an interactive job ID returns `400`. A sampler-checkpoint deployment reports initial progress in its `status`; use the returned `model_id` with this endpoint to list that served model's deployment records.

List deployments created from or associated with a training job.
