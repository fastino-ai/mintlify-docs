`POST /v1/training/jobs/{job_id}/terminate`

Stops an active `config` job and requests provider cancellation. Existing
checkpoints and artifacts are preserved by default.

<Warning>
  Setting `delete_checkpoints` to `true` permanently deletes the job's
  checkpoints and artifacts after cancellation is confirmed. This cannot be
  undone.
</Warning>

## Request

<ParamField header="X-API-Key" type="string" required>
  Your Fastino API key.
</ParamField>

<ParamField path="job_id" type="string" required>
  Training-job UUID.
</ParamField>

The JSON body is optional.

<ParamField body="delete_checkpoints" type="boolean" default="false">
  Permanently delete checkpoints and artifacts after cancellation is
  confirmed.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training/jobs/YOUR_TRAINING_JOB_ID/terminate \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"delete_checkpoints": false}'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 — terminated
{
  "success": true,
  "message": "Training job terminated. Checkpoints preserved.",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "deleted_checkpoints": 0,
  "status": "terminated"
}
```

```json 202 — cancellation pending
{
  "success": true,
  "message": "Training job cancellation is still being confirmed.",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "deleted_checkpoints": 0,
  "status": "stopping"
}
```

</ResponseExample>

Poll `GET /v1/training/jobs/{job_id}` after a `202`; do not repeat the
termination request while cancellation is pending.

| Status | Meaning |
| --- | --- |
| `200` | The job is terminated. |
| `202` | Provider cancellation is still being confirmed. |
| `400` | `job_id` is not a valid config-job UUID. |
| `409 training_job_already_finished` | The job reached a terminal state before termination. |
| `409 cancellation_unconfirmed` | Cancellation was not confirmed and may be retried. |
| `422` | The JSON request body is invalid. |
