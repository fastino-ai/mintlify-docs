`POST /v1/training-jobs/{job_id}/terminate`

Stops the provider job if it is active and marks the job as terminated. By default, existing checkpoints and artifacts are preserved.

<Warning>
  Setting `delete_checkpoints` to `true` permanently deletes the job's checkpoints and artifacts. This cannot be undone.
</Warning>

## Request

<ParamField header="X-API-Key" type="string" required>
  Your Fastino API key.
</ParamField>

<ParamField path="job_id" type="string" required>
  Training-job UUID.
</ParamField>

<ParamField body="delete_checkpoints" type="boolean" default="false">
  Whether to permanently delete every checkpoint and artifact. Omit this field or set it to `false` to preserve them.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.fastino.ai/v1/training-jobs/YOUR_TRAINING_JOB_ID/terminate \
  -H "X-API-Key: $FASTINO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"delete_checkpoints": false}'
```

</RequestExample>

## Response

<ResponseExample>

```json Response
{
  "success": true,
  "message": "Training job terminated. Checkpoints preserved (pass delete_checkpoints=true to remove them).",
  "job_id": "YOUR_TRAINING_JOB_ID",
  "deleted_checkpoints": 0
}
```

</ResponseExample>

An unknown job or a job that cannot be terminated returns a request-specific `4xx` error.
