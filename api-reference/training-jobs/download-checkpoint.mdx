`GET /v1/training/jobs/{job_id}/checkpoints/{checkpoint_id}/download`

Returns a short-lived presigned object-storage URL for one checkpoint from an
`interactive` job. A sampler checkpoint's archive contains the decoder adapter
files.
Config jobs use
[`GET /v1/training/jobs/{job_id}/download`](/api-reference/training-jobs/download)
for their final model artifact.

## Request

<ParamField header="X-API-Key" type="string" required>
  Your Fastino API key.
</ParamField>

<ParamField path="job_id" type="string" required>
  Interactive `job_id` returned by `POST /v1/training/jobs/create-model`.
</ParamField>

<ParamField path="checkpoint_id" type="string" required>
  Checkpoint identifier returned by the checkpoint list, such as
  `weights/checkpoint-1` or `sampler_weights/checkpoint-1`. Keep the `/` in the
  path; do not URL-encode the entire identifier.
</ParamField>

<RequestExample>

```bash cURL
CHECKPOINT_ID="sampler_weights/checkpoint-1"
curl "https://api.fastino.ai/v1/training/jobs/JOB_ID/checkpoints/$CHECKPOINT_ID/download" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Response

The response contains a signed archive URL that expires after 15 minutes. Treat
the URL as a credential: do not log, share, or persist it.

<ResponseField name="success" type="boolean">
  Whether the request succeeded.
</ResponseField>

<ResponseField name="run_id" type="string">
  Interactive job that owns the checkpoint.
</ResponseField>

<ResponseField name="checkpoint_id" type="string">
  Downloadable interactive checkpoint identifier.
</ResponseField>

<ResponseField name="download_url" type="string">
  Presigned object-storage URL. No API key is required when fetching it.
</ResponseField>

<ResponseField name="expires_in_seconds" type="integer">
  Remaining lifetime of the signed URL. New links expire after 900 seconds.
</ResponseField>

<ResponseField name="file_name" type="string">
  Suggested `.tar` file name for the archive.
</ResponseField>

<ResponseExample>

```json Response
{
  "success": true,
  "run_id": "session-1:train:0",
  "checkpoint_id": "sampler_weights/checkpoint-1",
  "download_url": "SIGNED_ARCHIVE_URL",
  "expires_in_seconds": 900,
  "file_name": "session-1_train_0-sampler_weights-checkpoint-1.tar"
}
```

</ResponseExample>

Checkpoint downloads are enabled by default. A team whose download access was
explicitly disabled receives `403`.

## Load a decoder adapter

A decoder's sampler checkpoint downloads as a standard Hugging Face PEFT
adapter for the public base model. The archive holds `adapter_config.json`,
`adapter_model.safetensors` with every trained tensor, and a `README.md` with
loading code:

```python
from peft import PeftModel
from transformers import AutoModelForCausalLM

base = AutoModelForCausalLM.from_pretrained("Qwen/Qwen3.6-35B-A3B", dtype="auto")
model = PeftModel.from_pretrained(base, "path/to/extracted/archive")
```

Fastino tests these adapters with transformers 5.19.0 and peft 0.21.2, not
with vLLM. A Nemotron 3.5 Lightning adapter that trains Mamba `out_proj` needs
a one-line opt-in before PEFT loads it; the archive's `README.md` shows it.
Only sampler checkpoints are converted: a training-state checkpoint downloads
in Fastino's internal layout.

## Errors

| Status | Meaning |
| --- | --- |
| `400` | `checkpoint_id` is not `weights/<name>` or `sampler_weights/<name>`. |
| `403` | Weight downloads were explicitly disabled for the team. |
| `404` | The job or checkpoint is unavailable, or the checkpoint has no downloadable files. |

Fetching `download_url` returns an `application/x-tar` attachment. The presigned
URL is the credential and expires after the response's `expires_in_seconds`.
