`POST /v1/training/jobs/{job_id}/push-to-hub`

This operation is config-only; after normal feature and permission checks, an interactive job ID returns `400`, and interactive jobs have no Push to Hub operation.

Publish a completed training artifact to Hugging Face Hub.
