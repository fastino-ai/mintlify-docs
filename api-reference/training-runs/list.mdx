`GET /v1/training/jobs`

Returns the interactive training jobs visible to the authenticated caller, newest first. An interactive job is a training run that you create and drive step by step with the Tinker-compatible SDK; its job ID is the SDK's run ID. Set the SDK's `base_url` to `https://api.fastino.ai/v1/training/compat/tinker` and pass your Fastino API key through the SDK's credential command: `TINKER_CREDENTIAL_CMD='printf %s "$FASTINO_API_KEY"'`. Tinker `tml-` keys are rejected with `401`. You see your own runs and your team's runs in projects you can access.

## Request

<ParamField header="X-API-Key" type="string" required>
  Your Fastino API key.
</ParamField>

<ParamField query="type" type="string">
  Job type. Use `interactive` (the default here). Config jobs are listed by [List training jobs](/api-reference/training-jobs/list) for now, so `config` returns `400`.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Page size. Values are clamped to `1` through `1000`.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of runs to skip.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training/jobs?type=interactive&limit=20&offset=0" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Response

<ResponseField name="success" type="boolean">
  Whether the request succeeded.
</ResponseField>

<ResponseField name="training_jobs" type="object[]">
  Training runs for this page. Each run has the fields described in [Get a training run](/api-reference/training-runs/get).
</ResponseField>

<ResponseField name="count" type="integer">
  Number of runs in this page.
</ResponseField>

<ResponseField name="total" type="integer">
  Total number of visible runs before pagination.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  Whether another page exists after this one.
</ResponseField>
