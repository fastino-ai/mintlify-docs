`GET /v1/training-runs`

Returns the training runs visible to the authenticated caller, newest first. Training runs are step-level runs that you create and drive with the Tinker-compatible SDK. Set the SDK's `base_url` to `https://api.fastino.ai/v1/training-runs/sdk` and authenticate with your Fastino API key. You see your own runs and your team's runs in projects you can access.

## Request

<ParamField header="X-API-Key" type="string" required>
  Your Fastino API key.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Page size. Values are clamped to `1` through `1000`.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of runs to skip.
</ParamField>

<RequestExample>

```bash cURL
curl "https://api.fastino.ai/v1/training-runs?limit=20&offset=0" \
  -H "X-API-Key: $FASTINO_API_KEY"
```

</RequestExample>

## Response

<ResponseField name="success" type="boolean">
  Whether the request succeeded.
</ResponseField>

<ResponseField name="training_runs" type="object[]">
  Training runs for this page. Each run has the fields described in [Get a training run](/api-reference/training-runs/get).
</ResponseField>

<ResponseField name="count" type="integer">
  Number of runs in this page.
</ResponseField>

<ResponseField name="total" type="integer">
  Total number of visible runs before pagination.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  Whether another page exists after this one.
</ResponseField>
