GLiDE returns calibrated decisions without generating prose. Send one shared `state`
and one or more typed questions to `POST /v1/systemone`.

## Choose a question type

| Type | Use it when |
| --- | --- |
| Noul | You need a yes/no probability |
| Choice | You need one answer from 2–255 caller-defined options |
| Score | You need an ordered level and expected score |

The response preserves question order and returns typed answers with probabilities and
confidence. Your application decides whether to accept, defer, or fall back.

## Before you call

1. Export your key as `FASTINO_API_KEY`.
2. Put the evidence to evaluate in `state`.
3. Choose the question type that matches the decision.
4. Follow the API Reference for exact fields, limits, request examples, and response shapes.
