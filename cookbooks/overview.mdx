Each cookbook is one working request for a common task. It shows the request and response schemas, a real response from the live API, and code that acts on the result. Copy a cookbook, swap in your own data, and adjust the criteria or labels.

The GLiNER cookbooks cover the three most common ways teams use GLiNER 2.5 Multi: entity extraction, classification, and relation extraction.
